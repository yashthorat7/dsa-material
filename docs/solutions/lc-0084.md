## What are we solving?

Given an array of integers `heights` representing the histogram's bar height where the width of each bar is `1`, return the area of the largest rectangle in the histogram.

The core question is: **how do we find the left and right boundaries for every bar where it acts as the minimum height in $O(n)$ time?**

**Example 1:**
```
Input:  heights = [2,1,5,6,2,3]
Output: 10
Explanation: The above is a histogram where width of each bar is 1. The largest rectangle is shown in the red area, which has an area = 10 units (between index 2 and 3, height 5, width 2).
```

**Example 2:**
```
Input:  heights = [2,4]
Output: 4
```

**Constraints:**
- $1 \le \text{heights.length} \le 10^5$
- $0 \le \text{heights}[i] \le 10^4$

## Approach 1 — Monotonic Increasing Stack with Sentinel Boundaries ✅

**Key insight:**
For each bar `h = heights[i]`, what is the widest rectangle with height `h`?
- Left boundary: first bar to the left strictly shorter than `h`.
- Right boundary: first bar to the right strictly shorter than `h`.
Maintain a monotonic **increasing** stack of indices.
When we see a bar `heights[i]` smaller than `heights[st.top()]`:
- Pop `hIdx = st.top()`.
- Height of rectangle is `heights[hIdx]`.
- Right boundary is `i`.
- Left boundary is `st.empty() ? -1 : st.top()`.
- Width is `i - leftBoundary - 1`.
- `area = height * width`.

```
heights = [2, 1, 5, 6, 2, 3]

Add sentinel 0 at end: [2, 1, 5, 6, 2, 3, 0]
i=0 (2): st = [0]
i=1 (1): 1 < 2 -> pop 0: h=2, w=1-0=1, area=2 -> push 1: st=[1]
i=2 (5): st = [1, 2]
i=3 (6): st = [1, 2, 3]
i=4 (2): 2 < 6 -> pop 3: h=6, left=2, w=4-2-1=1, area=6
         2 < 5 -> pop 2: h=5, left=1, w=4-1-1=2, area=10 (MAX!) -> push 4: st=[1, 4]
i=5 (3): st = [1, 4, 5]
i=6 (0): pops remaining bars...

Max Area: 10 ✓
```

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        heights.push_back(0); // Sentinel to flush stack at end
        int n = heights.size();
        stack<int> st;
        int maxArea = 0;
        
        for (int i = 0; i < n; i++) {
            while (!st.empty() && heights[i] < heights[st.top()]) {
                int h = heights[st.top()];
                st.pop();
                int w = st.empty() ? i : i - st.top() - 1;
                maxArea = max(maxArea, h * w);
            }
            st.push(i);
        }
        
        return maxArea;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Hard classic problem solved in optimal linear time with sentinel flush.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All bars equal height `[2, 2, 2, 2]` | Width calculation | Sentinel flushes all bars, calculating full width `4 * 2 = 8` |
| Strictly ascending `[1, 2, 3, 4, 5]` | Stack not emptied without sentinel | Appended `0` forces complete stack unwinding |

---

## Pattern Takeaway

Adding a **sentinel zero** to the end of the array guarantees all monotonic stack frames are evaluated and popped without redundant cleanup loops.

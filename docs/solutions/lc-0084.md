## What are we solving?

Given an array of integers `heights` representing the histogram's bar heights where the width of each bar is `1`, return the **area of the largest rectangle** that can be formed within the histogram.

```
 Heights: [ 2,  1,  5,  6,  2,  3 ]
 
       6 |             [ ]
       5 |          [X][X]
       4 |          [X][X]
       3 |          [X][X]      [ ]
       2 |  [ ]     [X][X]  [ ] [ ]
       1 |  [ ] [ ] [X][X]  [ ] [ ]
       0 +---+---+---+---+---+---+
             0   1   2   3   4   5
                     ^   ^
             Height = 5, Width = 2
             Max Rectangle Area = 5 * 2 = 10
```

### Input & Output Contract
- **Input:**
  - `heights`: `vector<int>` where $1 \le n \le 10^5$, $0 \le \text{heights}[i] \le 10^4$.
- **Output:**
  - `int` representing the maximum rectangular area.

### The Core Challenge
For any bar $i$ of height $h = \text{heights}[i]$:
- What is the leftmost index $L$ it can expand to such that every bar between $L$ and $i$ has height $\ge h$?
- What is the rightmost index $R$ it can expand to such that every bar between $i$ and $R$ has height $\ge h$?

The rectangle formed with $h$ as its bottleneck has width $W = R - L + 1$ and area $A = h \times W$.
Finding this for all $n$ bars naively takes $O(n^2)$, which TLEs on $n = 10^5$. We need an **$O(n)$ Monotonic Stack** that resolves both boundaries simultaneously!

---

**Example 1:**
```
Input:  heights = [2,1,5,6,2,3]
Output: 10
Explanation: The largest rectangle is formed by heights 5 and 6 with height 5 and width 2 (area = 10).
```

**Example 2:**
```
Input:  heights = [2,4]
Output: 4
```

**Constraints:**
- $1 \le \text{heights.length} \le 10^5$
- $0 \le \text{heights}[i] \le 10^4$

## Approach 1 — Brute Force (Evaluate All Pairs)

### Intuition
For every bar $i \in [0, n - 1]$, consider it as the minimum-height bounding bar of a rectangle. Expand left and right to find the boundary of bars with height $\ge \text{heights}[i]$.

### C++ Implementation
```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n = heights.size();
        int maxArea = 0;
        
        for (int i = 0; i < n; i++) {
            int h = heights[i];
            int left = i, right = i;
            
            while (left >= 0 && heights[left] >= h) left--;
            while (right < n && heights[right] >= h) right++;
            
            // Width between (left, right) exclusive is right - left - 1
            int width = right - left - 1;
            maxArea = max(maxArea, h * width);
        }
        
        return maxArea;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Expanding outward for each bar takes $O(n)$ in the worst case (flat array). |
| **Space** | $O(1)$ | No extra memory allocated. |

> **Verdict:** Suboptimal. Monotonic stack computes previous and next smaller bounds in $O(n)$ time.

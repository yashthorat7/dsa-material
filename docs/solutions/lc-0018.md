# 18. 4Sum

https://leetcode.com/problems/4sum

> **Medium** $\rightarrow$ **Two-Pointer**


> **Companies:** Adobe, Amazon, Apple, Goldman Sachs

---

## What are we solving?

Given an array `nums` of $n$ integers and an integer `target`, return an array of all **unique quadruplets** `[nums[a], nums[b], nums[c], nums[d]]` such that:
1. $0 \le a, b, c, d < n$
2. $a, b, c, \text{ and } d$ are distinct indices.
3. $\text{nums}[a] + \text{nums}[b] + \text{nums}[c] + \text{nums}[d] == \text{target}$.

You may return the quadruplets in any order. The output must not contain duplicate quadruplets.

```
 nums = [ 1, 0, -1, 0, -2, 2 ],  target = 0
 
 Sorted: [ -2, -1, 0, 0, 1, 2 ]
 
 Quadruplets summing to 0:
 1. [-2, -1, 1, 2]  -> sum = 0
 2. [-2,  0, 0, 2]  -> sum = 0
 3. [-1,  0, 0, 1]  -> sum = 0
 
 Output: [ [-2,-1,1,2], [-2,0,0,2], [-1,0,0,1] ]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 200$, $-10^9 \le \text{nums}[i] \le 10^9$.
  - `target`: `int` ($-10^9 \le \text{target} \le 10^9$).
- **Output:**
  - `vector<vector<int>>` containing all unique quadruplet lists.

### The Core Challenge
1. **Deduplication:** Skipping duplicate numbers horizontally at both the outer nested loops and inner two pointers without using expensive hash sets.
2. **64-bit Overflow:** Four elements with values up to $10^9$ can sum to $4 \times 10^9$, overflowing standard 32-bit signed integers. We must cast sum calculations to `long long`.

## Approach 1 — Brute Force (4 Loops + Set)

### Intuition
Enumerate every 4-tuple $(i, j, k, l)$ with $0 \le i < j < k < l < n$. If their sum equals `target`, sort the 4 elements and insert into a `set<vector<int>>` to eliminate duplicate quadruplets.

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int n = nums.size();
        set<vector<int>> uniqueQuads;
        
        for (int i = 0; i < n - 3; i++) {
            for (int j = i + 1; j < n - 2; j++) {
                for (int k = j + 1; k < n - 1; k++) {
                    for (int l = k + 1; l < n; l++) {
                        long long sum = (long long)nums[i] + nums[j] + nums[k] + nums[l];
                        if (sum == target) {
                            vector<int> quad = {nums[i], nums[j], nums[k], nums[l]};
                            sort(quad.begin(), quad.end());
                            uniqueQuads.insert(quad);
                        }
                    }
                }
            }
        }
        
        return vector<vector<int>>(uniqueQuads.begin(), uniqueQuads.end());
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^4 \log(\text{count}))$ | $\approx O(n^4)$ quadruplet evaluations with set insertion overhead. |
| **Space** | $O(n)$ | Storage for set of unique quadruplets. |

> **Verdict:** Suboptimal. Sorting first reduces complexity to $O(n^3)$ without hash sets.

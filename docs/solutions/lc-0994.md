## What are we solving?

You are given an `m x n` grid where each cell can have one of three values:
- `0` representing an empty cell,
- `1` representing a fresh orange, or
- `2` representing a rotten orange.

Every minute, any fresh orange that is **4-directionally adjacent** to a rotten orange becomes rotten.

Return the **minimum number of minutes** that must elapse until no cell has a fresh orange. If this is impossible, return `-1`.

**Example 1:**
```
Input:  grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
```

**Example 2:**
```
Input:  grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
Explanation: The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.
```

**Example 3:**
```
Input:  grid = [[0,2]]
Output: 0
Explanation: Since there are already no fresh oranges at minute 0, the answer is just 0.
```

**Constraints:**
- $m == \text{grid.length}$
- $n == \text{grid}[i].\text{length}$
- $1 \le m, n \le 10$
- `grid[i][j]` is `0`, `1`, or `2`.

## Approach 1 — Multi-Source BFS by Minute Level ✅

**Key insight:**
All rotten oranges spread infection simultaneously $\implies$ **Multi-Source BFS**!
1. Enqueue all initial rotten oranges `(r, c)` into a BFS queue `q`, and count `freshCount`.
2. If `freshCount == 0`, return `0`.
3. While `!q.empty() && freshCount > 0`:
   - Increment `minutes++`.
   - Process current queue level (`levelSize = q.size()`).
   - For each neighbor `(nr, nc)`: if `grid[nr][nc] == 1`, turn rotten (`grid[nr][nc] = 2`), `freshCount--`, push `(nr, nc)` to `q`.
4. Return `freshCount == 0 ? minutes : -1`.

```
Grid:
2 1 1
1 1 0
0 1 1
Initial: q=[(0,0)], fresh=6

Minute 1: infect (0,1), (1,0) -> fresh=4
Minute 2: infect (0,2), (1,1) -> fresh=2
Minute 3: infect (2,1) -> fresh=1
Minute 4: infect (2,2) -> fresh=0

Result: 4 minutes ✓
```

```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        queue<pair<int, int>> q;
        int freshCount = 0;
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 2) {
                    q.push({r, c});
                } else if (grid[r][c] == 1) {
                    freshCount++;
                }
            }
        }
        
        if (freshCount == 0) return 0;
        
        int minutes = 0;
        vector<int> dr = {0, 0, 1, -1};
        vector<int> dc = {1, -1, 0, 0};
        
        while (!q.empty() && freshCount > 0) {
            int sz = q.size();
            minutes++;
            for (int i = 0; i < sz; i++) {
                auto [r, c] = q.front();
                q.pop();
                
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2;
                        freshCount--;
                        q.push({nr, nc});
                    }
                }
            }
        }
        
        return freshCount == 0 ? minutes : -1;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(m \cdot n)$ |

> **This is the one.** Multi-source BFS simulates concurrent time diffusion accurately.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| No fresh oranges initially `[[0, 2]]` | Returning 1 minute | `freshCount == 0` check returns 0 immediately |
| Isolated fresh orange surrounded by 0s | Infinite loop | `freshCount > 0` at end returns `-1` |

---

## Pattern Takeaway

**Multi-Source BFS** initializes the queue with all simultaneous starting points to model parallel propagation.

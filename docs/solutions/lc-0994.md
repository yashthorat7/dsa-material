# 994. Rotting Oranges

https://leetcode.com/problems/rotting-oranges

> **Medium** $\rightarrow$ **Graph Traversal**


> **Companies:** Amazon, Microsoft, VMware, LinkedIn, Ola, Swiggy, Wipro

## What are we solving?

You are given an `m x n` grid where each cell can have one of three values:
- `0` representing an **empty cell**,
- `1` representing a **fresh orange**, or
- `2` representing a **rotten orange**.

Every minute, any fresh orange that is **4-directionally adjacent** (up, down, left, right) to a rotten orange becomes rotten.

Return the **minimum number of minutes** that must elapse until no cell has a fresh orange. If this is impossible (e.g. isolated fresh oranges), return `-1`.

```
 Minute 0:           Minute 1:           Minute 2:           Minute 4:
 [ 2  1  1 ]         [ 2  2  1 ]         [ 2  2  2 ]         [ 2  2  2 ]
 [ 1  1  0 ]  --->   [ 2  1  0 ]  --->   [ 2  2  0 ]  --->   [ 2  2  0 ]
 [ 0  1  1 ]         [ 0  1  1 ]         [ 0  2  1 ]         [ 0  2  2 ]
 
 Total Elapsed Time = 4 minutes
```

### Input & Output Contract
- **Input:**
  - `grid`: `vector<vector<int>>` where $1 \le m, n \le 10$, $\text{grid}[i][j] \in \{0, 1, 2\}$.
- **Output:**
  - `int`: Minimum minutes to rot all fresh oranges, or `-1` if any fresh oranges remain unreachable.

### The Core Challenge
Rotting spreads simultaneously from **all initially rotten oranges in parallel** at a rate of 1 unit distance per minute. This is the definition of **Multi-Source Breadth-First Search (BFS)** where each BFS level corresponds to 1 minute of elapsed time.

---

**Example 1:**
```
Input:  grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
```

**Example 2:**
```
Input:  grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
Explanation: The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.
```

**Example 3:**
```
Input:  grid = [[0,2]]
Output: 0
Explanation: Since there are already no fresh oranges at minute 0, the answer is 0.
```

**Constraints:**
- $m == \text{grid.length}$
- $n == \text{grid}[i].\text{length}$
- $1 \le m, n \le 10$
- `grid[i][j]` is `0`, `1`, or `2`.

## Approach 1 — Iterative Step Simulation (Brute Force)

### Intuition
In each minute, clone the grid. For every fresh orange adjacent to a rotten orange in the previous grid, mark it as rotten in the new grid. Repeat until no state changes.

### C++ Implementation
```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int minutes = 0;
        const int dr[] = {0, 0, 1, -1};
        const int dc[] = {1, -1, 0, 0};
        
        while (true) {
            vector<vector<int>> nextGrid = grid;
            bool newlyRotted = false;
            
            for (int r = 0; r < m; r++) {
                for (int c = 0; c < n; c++) {
                    if (grid[r][c] == 2) {
                        for (int d = 0; d < 4; d++) {
                            int nr = r + dr[d], nc = c + dc[d];
                            if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                                nextGrid[nr][nc] = 2;
                                newlyRotted = true;
                            }
                        }
                    }
                }
            }
            
            if (!newlyRotted) break;
            grid = nextGrid;
            minutes++;
        }
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) return -1;
            }
        }
        
        return minutes;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O((m \cdot n)^2)$ | Rescans full matrix every minute. |
| **Space** | $O(m \cdot n)$ | Grid clone per round. |

> **Verdict:** Suboptimal. Multi-source BFS queue runs in strictly linear $O(m \cdot n)$ grid time.

## Approach 2 — Multi-Source BFS (Queue Level Simulation) ✅

### Key Insight
1. **Initialization:**
   - Enqueue **all initial rotten oranges `(r, c)`** simultaneously into a FIFO queue `q`.
   - Count the total number of fresh oranges `freshCount`.
2. **Special Case:** If `freshCount == 0`, return `0` (no fresh oranges exist).
3. **Level-by-Level Expansion:**
   - While `!q.empty() && freshCount > 0`:
     - Increment `minutes++`.
     - Snapshot `int sz = q.size()`.
     - For each of the `sz` rotten oranges:
       - Check all 4 adjacent neighbors `(nr, nc)`.
       - If `grid[nr][nc] == 1` (fresh):
         - Rot it: `grid[nr][nc] = 2`.
         - Decrement `freshCount--`.
         - Enqueue `q.push({nr, nc})`.
4. **Final Check:**
   - If `freshCount == 0`: return `minutes`.
   - Otherwise: some fresh oranges were disconnected $\rightarrow$ return `-1`.

```
Grid (3x3):
2 1 1
1 1 0
0 1 1

Initial: q = [(0, 0)], freshCount = 6

Minute 1: rot (0,1), (1,0) -> freshCount = 4 -> q = [(0,1), (1,0)]
Minute 2: rot (0,2), (1,1) -> freshCount = 2 -> q = [(0,2), (1,1)]
Minute 3: rot (2,1)        -> freshCount = 1 -> q = [(2,1)]
Minute 4: rot (2,2)        -> freshCount = 0 -> q = [(2,2)]

freshCount == 0 -> Return 4 minutes ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        queue<pair<int, int>> q;
        int freshCount = 0;
        
        // Pass 1: Identify all initial rotten sources and count fresh oranges
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 2) {
                    q.push({r, c});
                } else if (grid[r][c] == 1) {
                    freshCount++;
                }
            }
        }
        
        // If there are no fresh oranges, 0 minutes required
        if (freshCount == 0) return 0;
        
        int minutes = 0;
        const int dr[] = {0, 0, 1, -1};
        const int dc[] = {1, -1, 0, 0};
        
        // Multi-Source BFS
        while (!q.empty() && freshCount > 0) {
            int sz = q.size();
            minutes++;
            
            for (int i = 0; i < sz; i++) {
                auto [r, c] = q.front();
                q.pop();
                
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];
                    
                    // If neighbor is within bounds and is a fresh orange
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2; // Infect immediately to avoid duplicate queue entries
                        freshCount--;
                        q.push({nr, nc});
                    }
                }
            }
        }
        
        return freshCount == 0 ? minutes : -1;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Each cell is visited and enqueued at most once. |
| **Space** | $O(m \cdot n)$ | In the worst case, queue holds all $m \cdot n$ cells. |

> **This is the one.** Multi-source BFS models simultaneous viral spread in optimal linear grid time.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Zero Fresh Oranges Initially** | `[[0, 2]]` | Incrementing minutes erroneously | Early check `if (freshCount == 0) return 0;` returns 0 immediately. |
| **Unreachable Fresh Orange** | `[[2, 1, 0], [0, 0, 0], [0, 1, 0]]` | Returning partial minute count | `freshCount > 0` after queue exhaustion returns `-1`. |
| **Empty Grid or All Empty Cells** | `[[0, 0], [0, 0]]` | `freshCount == 0` | Returns 0. |

---

## Pattern Takeaways

1. **Multi-Source BFS Pattern:**  
   When multiple infection sources act simultaneously, enqueue all sources before beginning the BFS loop rather than running separate BFS searches.
2. **In-Place Infection Marking:**  
   Mutating `grid[nr][nc] = 2` upon discovery prevents adjacent nodes in the same minute from enqueueing duplicate copies of the same cell.

> **Hard** $\rightarrow$ **Heap / Priority Queue**


> **Companies:** Meta, Amazon, Microsoft, Apple, Google, ByteDance, Walmart Global Tech, Sprinklr, Infosys

## What are we solving?

You are given an array of `k` linked-lists `lists`, each linked-list is sorted in ascending order. Merge all the linked-lists into one sorted linked-list and return it.

The challenge is: **how does a Min-Heap of list node pointers achieve $O(N \log k)$ optimal multi-way merge?**

**Example 1:**
```
Input:  lists = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Explanation: The linked-lists are:
[
  1->4->5,
  1->3->4,
  2->6
]
merging them into one sorted list:
1->1->2->3->4->4->5->6
```

**Example 2:**
```
Input:  lists = []
Output: []
```

**Example 3:**
```
Input:  lists = [[]]
Output: []
```

**Constraints:**
- $k == \text{lists.length}$
- $0 \le k \le 10^4$
- $0 \le \text{lists}[i].\text{length} \le 500$
- $-10^4 \le \text{lists}[i][j] \le 10^4$
- `lists[i]` is sorted in ascending order.
- The sum of `lists[i].length` will not exceed $10^4$.

## Approach 1 — Min-Heap of K Head Pointers ✅

**Key insight:**
1. Initialize a min-heap storing the active head pointer of each non-empty list.
2. The heap size is at most $k$.
3. At each step:
   - Extract smallest node: `minNode = pq.top()`, `pq.pop()`.
   - Append `minNode` to merged list (`tail->next = minNode`).
   - If `minNode->next != nullptr`, push `minNode->next` into heap.
   - Advance `tail`.

```
lists = [1->4->5, 1->3->4, 2->6]
Heap initial: [1(L1), 1(L2), 2(L3)]

1. Pop 1(L1) -> append 1 -> push 4(L1) -> heap: [1(L2), 2(L3), 4(L1)]
2. Pop 1(L2) -> append 1 -> push 3(L2) -> heap: [2(L3), 3(L2), 4(L1)]
3. Pop 2(L3) -> append 2 -> push 6(L3) -> heap: [3(L2), 4(L1), 6(L3)]
...
Result: 1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6 ✓
```

```cpp
class Solution {
    struct CompareNode {
        bool operator()(ListNode* a, ListNode* b) const {
            return a->val > b->val;
        }
    };
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        priority_queue<ListNode*, vector<ListNode*>, CompareNode> pq;
        for (ListNode* head : lists) {
            if (head) pq.push(head);
        }
        
        ListNode dummy(0);
        ListNode* tail = &dummy;
        
        while (!pq.empty()) {
            ListNode* minNode = pq.top();
            pq.pop();
            tail->next = minNode;
            tail = tail->next;
            if (minNode->next) {
                pq.push(minNode->next);
            }
        }
        
        return dummy.next;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(N \log k)$ where $N$ is total nodes and $k$ is number of lists | $O(k)$ for the priority queue |

> **This is the one.** Optimal $k$-way merge with $O(k)$ memory.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty `lists = []` or `lists = [nullptr, nullptr]` | Null dereference in comparator | `if (head)` check prevents nulls from entering heap |
| Single list `lists = [1->2->3]` | Heap overhead | Pushes 1 list head and merges in $O(N)$ |

---

## Pattern Takeaway

**K-Way Merge with a Min-Heap** maintains $k$ pointers and advances the global minimum in $O(\log k)$ per extracted element.

## What are we solving?

A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers. Given a string `s`, return `true` if it is a palindrome, or `false` otherwise.

The question is: **how do we compare characters inward from both ends while skipping punctuation on the fly?**

**Example 1:**
```
Input:  s = "A man, a plan, a canal: Panama"
Output: true
Explanation: "amanaplanacanalpanama" is a palindrome.
```

**Example 2:**
```
Input:  s = "race a car"
Output: false
Explanation: "raceacar" is not a palindrome.
```

**Example 3:**
```
Input:  s = " "
Output: true
Explanation: s is an empty string "" after removing non-alphanumeric characters. Since an empty string reads the same forward and backward, it is a palindrome.
```

**Constraints:**
- $1 \le s.\text{length} \le 2 \times 10^5$
- `s` consists only of printable ASCII characters.

## Approach 1 — In-Place Two Pointers ✅

**Key insight:** Set `left = 0` and `right = s.length() - 1`. While `left < right`, advance `left` past non-alphanumerics, decrement `right` past non-alphanumerics, and compare `tolower(s[left]) == tolower(s[right])`. Zero memory allocated.

```
s = "A man, a plan, a canal: Panama"
left=0 ('A'), right=29 ('a') -> 'a' == 'a' -> left++, right--
left=1 (' '), skip -> left=2 ('m'), right=28 ('m') -> 'm' == 'm'
...
All matched -> return true ✓
```

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0, right = s.size() - 1;
        while (left < right) {
            while (left < right && !isalnum(s[left])) left++;
            while (left < right && !isalnum(s[right])) right--;
            if (tolower(s[left]) != tolower(s[right])) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** In-place, $O(1)$ auxiliary space.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty string or only punctuation `" ,.:; "` | Pointers crossing or out-of-bounds | `left < right` check inside inner while loops prevents out-of-bounds, returns `true` |
| Numbers included `"0P"` | Comparing numbers with letters | `tolower('0') != tolower('P')` returns `false` |
| Single character `"a"` | Loop does not run | Returns `true` directly |

---

## Pattern Takeaway

**Converging Two Pointers** is the standard approach for palindrome verification. Skipping invalid tokens inline preserves $O(1)$ space without creating sanitized copies.

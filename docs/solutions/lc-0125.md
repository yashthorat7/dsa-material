## What are we solving?

A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include English letters (`a-z`, `A-Z`) and digits (`0-9`).

Given a string `s`, return `true` if it is a palindrome, or `false` otherwise.

```
 Input:  "A man, a plan, a canal: Panama"
 Filter: "amanaplanacanalpanama"
 
 Check:  a m a n a p l a n a c a n a l p a n a m a
         ↑                                       ↑
        left                                   right
        (left and right characters match at all converging positions)
        
 Output: true
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of length $1 \le n \le 2 \times 10^5$, containing printable ASCII characters.
- **Output:**
  - `bool`: `true` if alphanumeric characters form a palindrome; otherwise `false`.

### The Core Challenge
We want to verify the palindrome property in a **single pass without allocating sanitized string copies** ($O(1)$ auxiliary space) while correctly bypassing punctuation, spaces, and casing differences.

---

**Example 1:**
```
Input:  s = "A man, a plan, a canal: Panama"
Output: true
Explanation: "amanaplanacanalpanama" is a palindrome.
```

**Example 2:**
```
Input:  s = "race a car"
Output: false
Explanation: "raceacar" is not a palindrome.
```

**Example 3:**
```
Input:  s = " "
Output: true
Explanation: s is an empty string "" after removing non-alphanumeric characters, which is a palindrome.
```

**Constraints:**
- $1 \le s.\text{length} \le 2 \times 10^5$
- `s` consists only of printable ASCII characters.

## Approach 1 — Filter Clean String and Reverse

### Intuition
1. Iterate through `s` and copy only alphanumeric characters in lowercase to a new string `filtered`.
2. Compare `filtered` against its reverse: `string reversed = filtered; reverse(...)`.
3. If `filtered == reversed`, return `true`.

### C++ Implementation
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        string filtered = "";
        for (char c : s) {
            if (isalnum(static_cast<unsigned char>(c))) {
                filtered += tolower(static_cast<unsigned char>(c));
            }
        }
        
        string reversed = filtered;
        reverse(reversed.begin(), reversed.end());
        return filtered == reversed;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | One pass to filter, one pass to reverse, one pass to compare. |
| **Space** | $O(n)$ | Creates two auxiliary string copies of size up to $n$. |

> **Verdict:** Straightforward, but uses unnecessary $O(n)$ heap allocations.

## Approach 2 — In-Place Converging Two Pointers ✅

### Key Insight
Maintain two pointers starting at the opposite ends: `left = 0` and `right = s.length() - 1`.
In each step of the `while (left < right)` loop:
1. Advance `left` forward until `s[left]` is alphanumeric (skipping spaces and punctuation).
2. Decrement `right` backward until `s[right]` is alphanumeric.
3. Compare `tolower(s[left]) == tolower(s[right])`. If they differ, return `false` immediately!
4. Advance `left++` and `right--`.

```
s = "A man, a plan, a canal: Panama"

Step 1: left=0 ('A'), right=29 ('a') -> 'a' == 'a' -> left=1, right=28
Step 2: left=1 (' '), skip -> left=2 ('m'); right=28 ('m') -> 'm' == 'm' -> left=3, right=27
Step 3: left=3 ('a'), right=27 ('a') -> 'a' == 'a' -> left=4, right=26
...
Pointers meet in middle -> return true ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0;
        int right = s.length() - 1;
        
        while (left < right) {
            // Skip non-alphanumeric characters from left
            while (left < right && !isalnum(static_cast<unsigned char>(s[left]))) {
                left++;
            }
            
            // Skip non-alphanumeric characters from right
            while (left < right && !isalnum(static_cast<unsigned char>(s[right]))) {
                right--;
            }
            
            // Compare characters case-insensitively
            if (tolower(static_cast<unsigned char>(s[left])) != 
                tolower(static_cast<unsigned char>(s[right]))) {
                return false;
            }
            
            left++;
            right--;
        }
        
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each character is inspected at most twice as pointers converge inwards. |
| **Space** | $O(1)$ | Zero extra string buffers; purely stack index variables. |

> **This is the one.** Constant space, early exit on mismatch, single pass.

## Approach 3 — Recursive Two-Pointer Check

### Intuition
Convert the converging two-pointer logic into a recursive function `isPalHelper(s, left, right)`.

### C++ Implementation
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        return helper(s, 0, s.length() - 1);
    }

private:
    bool helper(const string& s, int left, int right) {
        while (left < right && !isalnum(static_cast<unsigned char>(s[left]))) left++;
        while (left < right && !isalnum(static_cast<unsigned char>(s[right]))) right--;
        
        if (left >= right) return true;
        
        if (tolower(static_cast<unsigned char>(s[left])) != 
            tolower(static_cast<unsigned char>(s[right]))) {
            return false;
        }
        
        return helper(s, left + 1, right - 1);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear scan. |
| **Space** | $O(n)$ | Call stack depth reaches up to $n/2$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Only Punctuation / Spaces** | `" ,.:; "` | Out of bounds pointer decrement | `left < right` checked inside inner `while` loops prevents negative indices; returns `true`. |
| **Digits vs Letters** | `"0P"` | Treating digits as letters | `tolower('0') = '0' != 'p'`, returns `false`. |
| **Single Character** | `"a"` | Loop does not execute | `left = 0, right = 0 (left < right is false)`, returns `true`. |
| **Empty String** | `""` | Immediate termination | `right = -1 < left = 0`, returns `true`. |

---

## Pattern Takeaways

1. **The In-Place Token Skipping Invariant:**  
   When validating formatted text (palindromes, reverse words, string compression), skip invalid tokens inline with bounded inner `while (left < right && !isValid(s[left]))` loops to maintain $O(1)$ memory.
2. **C++ `isalnum` Safety:**  
   Always cast characters to `unsigned char` before passing to `<cctype>` functions (`tolower`, `isalnum`) to prevent undefined behavior on negative `char` values.

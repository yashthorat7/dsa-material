# 1039. Minimum Score Triangulation of Polygon

https://leetcode.com/problems/minimum-score-triangulation-of-polygon

> **Medium** $\rightarrow$ **Dynamic Programming**


> **Companies:** Uber, Amazon

---

## What are we solving?

You have a convex `n`-sided polygon where each vertex has an integer value. You are given an integer array `values` where `values[i]` is the value of the $i$-th vertex (i.e., clockwise order).

Triangulate the polygon into `n - 2` triangles. For each triangle, the value of that triangle is the product of the values of its vertices, and the total score of the triangulation is the sum of these values over all `n - 2` triangles.

Return the **minimum possible score** that you can achieve with some triangulation of the polygon.

**Example 1:**
```
Input:  values = [1,2,3]
Output: 6
Explanation: The polygon is already a triangle, and no additional triangles can be added.
```

**Example 2:**
```
Input:  values = [3,7,4,5]
Output: 144
Explanation: There are two triangulations, with possible scores: 3*7*5 + 4*5*7 = 245, or 3*4*5 + 3*4*7 = 144. The minimum score is 144.
```

**Example 3:**
```
Input:  values = [1,3,1,4,1,5]
Output: 13
```

**Constraints:**
- $n == \text{values.length}$
- $3 \le n \le 50$
- $1 \le \text{values}[i] \le 100$

## Approach 1 — Matrix Chain Multiplication (MCM / Interval DP) ✅

**Key insight:**
Consider the base edge connecting vertex `i` and vertex `j`.
To form a triangle on base edge `(i, j)`, pick any third vertex `k` between `i` and `j` (`i < k < j`).
The triangle `(i, k, j)` partitions the remaining polygon into two independent sub-polygons:
1. Left sub-polygon on vertices `[i..k]`.
2. Right sub-polygon on vertices `[k..j]`.

Recurrence:
`dp[i][j] = min_{i < k < j} (dp[i][k] + dp[k][j] + values[i] * values[k] * values[j])`.
Base case: `dp[i][i + 1] = 0` (adjacent vertices cannot form a triangle).

```
values = [3, 7, 4, 5] (n = 4)
Interval length len = 3 (triangles of 3 vertices):
dp[0][2] = val[0]*val[1]*val[2] = 3*7*4 = 84
dp[1][3] = val[1]*val[2]*val[3] = 7*4*5 = 140

Interval length len = 4 (full polygon [0..3]):
k=1: dp[0][1] + dp[1][3] + 3*7*5 = 0 + 140 + 105 = 245
k=2: dp[0][2] + dp[2][3] + 3*4*5 = 84 + 0 + 60 = 144 -> MINIMUM!

Result: 144 ✓
```

```cpp
class Solution {
public:
    int minScoreTriangulation(vector<int>& values) {
        int n = values.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = INT_MAX;
                for (int k = i + 1; k < j; k++) {
                    int cost = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j];
                    dp[i][j] = min(dp[i][j], cost);
                }
            }
        }
        
        return dp[0][n - 1];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n^3)$ | $O(n^2)$ |

> **This is the one.** Classic Matrix Chain Multiplication interval DP.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `n = 3` (single triangle) | Loop termination | Computes `values[0] * values[1] * values[2]` |
| Convex polygon of size 50 | Time limit | $50^3 = 125,000$ operations runs in $< 2$ ms |

---

## Pattern Takeaway

**Matrix Chain Multiplication (Interval DP)** splits an interval `[i..j]` on pivot `k` via `dp[i][k] + dp[k][j] + cost(i, k, j)`.

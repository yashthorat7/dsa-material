# 1039. Minimum Score Triangulation of Polygon

https://leetcode.com/problems/minimum-score-triangulation-of-polygon

> **Medium** $\rightarrow$ **Dynamic Programming**


> **Companies:** Uber, Amazon

## What are we solving?

You have a convex $n$-sided polygon where each vertex has an integer value. You are given an integer array `values` where `values[i]` is the value of the $i$-th vertex in clockwise order.

Triangulate the polygon into $n - 2$ non-overlapping triangles. For each triangle, the value of that triangle is the **product of the values of its three vertices**, and the total score of the triangulation is the sum of these values over all $n - 2$ triangles.

Return the **minimum possible score** that you can achieve with some triangulation of the polygon.

```
 Polygon: [ 3, 7, 4, 5 ]
 
 Triangulation Option 1:
 Triangles (0,1,3) + (1,2,3) -> 3*7*5 + 7*4*5 = 105 + 140 = 245
 
 Triangulation Option 2:
 Triangles (0,1,2) + (0,2,3) -> 3*7*4 + 3*4*5 = 84 + 60 = 144 (OPTIMAL!)
 
 Minimum Score: 144
 Output: 144
```

### Input & Output Contract
- **Input:**
  - `values`: `vector<int>` ($3 \le n \le 50$, $1 \le \text{values}[i] \le 100$).
- **Output:**
  - `int`: Minimum total triangulation score.

### The Matrix Chain Multiplication (MCM) Reduction
Fix the base edge connecting vertex $i$ and vertex $j$:
- Any valid triangulation containing edge $(i, j)$ must choose a **third vertex $k$ strictly between $i$ and $j$** ($i < k < j$) to form a triangle $\triangle (i, k, j)$.
- The triangle $\triangle(i, k, j)$ costs $\text{values}[i] \times \text{values}[k] \times \text{values}[j]$ and splits the remaining polygon into two independent sub-polygons:
  1. Sub-polygon on vertices $[i \dots k]$.
  2. Sub-polygon on vertices $[k \dots j]$.
$$\mathbf{\text{dp}[i][j] = \min_{i < k < j} \Big( \text{dp}[i][k] + \text{dp}[k][j] + \text{values}[i] \times \text{values}[k] \times \text{values}[j] \Big)}$$

---

**Example 1:**
```
Input:  values = [1,2,3]
Output: 6
Explanation: The polygon is already a triangle (1*2*3 = 6).
```

**Example 2:**
```
Input:  values = [3,7,4,5]
Output: 144
```

**Constraints:**
- $n == \text{values.length}$
- $3 \le n \le 50$
- $1 \le \text{values}[i] \le 100$

## Approach 1 — Top-Down Memoization ($O(n^3)$)

### Intuition
Define `solve(i, j)` returning the min cost to triangulate polygon segment $[i \dots j]$. Base case: if $j - i < 2$, return $0$ (a line segment has area 0). Loop over all $k \in (i, j)$ and memoize in 2D array.

### C++ Implementation
```cpp
class Solution {
public:
    int minScoreTriangulation(vector<int>& values) {
        int n = values.size();
        vector<vector<int>> memo(n, vector<int>(n, -1));
        return solve(0, n - 1, values, memo);
    }

private:
    int solve(int i, int j, const vector<int>& v, vector<vector<int>>& memo) {
        if (j - i < 2) return 0; // Less than 3 vertices cannot form a triangle
        if (memo[i][j] != -1) return memo[i][j];
        
        int minScore = INT_MAX;
        for (int k = i + 1; k < j; k++) {
            int score = solve(i, k, v, memo) + solve(k, j, v, memo) + v[i] * v[k] * v[j];
            minScore = min(minScore, score);
        }
        
        return memo[i][j] = minScore;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | $O(n^2)$ states, each testing $O(n)$ choices of $k$. |
| **Space** | $O(n^2)$ | 2D memo table of size $50 \times 50$. |

## Approach 2 — Bottom-Up Interval DP Table ✅

### Key Insight
1. Allocate 2D array `dp[n][n]` initialized to 0.
2. Iterate interval length `len` from 3 up to $n$:
   - For each starting vertex $i \in [0 \dots n - \text{len}]$:
     - End vertex $j = i + \text{len} - 1$.
     - `dp[i][j] = INT_MAX`.
     - For each intermediate vertex $k \in [i + 1 \dots j - 1]$:
       $$\text{cost} = \text{dp}[i][k] + \text{dp}[k][j] + \text{values}[i] \times \text{values}[k] \times \text{values}[j]$$
       $$\text{dp}[i][j] = \min(\text{dp}[i][j], \text{cost})$$
3. Return `dp[0][n - 1]`.

```
values = [3, 7, 4, 5] (n = 4)

len = 3:
- dp[0][2] = v[0]*v[1]*v[2] = 3*7*4 = 84
- dp[1][3] = v[1]*v[2]*v[3] = 7*4*5 = 140

len = 4 (interval [0..3]):
- k = 1: dp[0][1] + dp[1][3] + 3*7*5 = 0 + 140 + 105 = 245
- k = 2: dp[0][2] + dp[2][3] + 3*4*5 = 84 + 0 + 60 = 144 (MINIMUM!)

Result: 144 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int minScoreTriangulation(vector<int>& values) {
        int n = values.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        
        // len is the number of vertices in the sub-polygon (minimum 3 for a triangle)
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                dp[i][j] = INT_MAX;
                
                // Pick vertex k to form triangle (i, k, j)
                for (int k = i + 1; k < j; k++) {
                    int cost = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j];
                    dp[i][j] = min(dp[i][j], cost);
                }
            }
        }
        
        return dp[0][n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | $\frac{50^3}{6} \approx 20,000$ operations (<1ms). |
| **Space** | $O(n^2)$ | 2D table of size $50 \times 50$. |

> **This is the one.** Classic, elegant Matrix Chain Multiplication formulation.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`n = 3` (Single Triangle)** | `values = [1, 2, 3]` | Loop execution | Runs only `len = 3`, evaluates `1 * 2 * 3 = 6`. |
| **Identical Vertices** | `[2, 2, 2, 2]` | Redundant minimums | All symmetric partitions cost $2^3 + 2^3 = 16$. |

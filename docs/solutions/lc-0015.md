## What are we solving?

Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that `i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`. Notice that the solution set must not contain **duplicate triplets**.

The core challenge is: **how do we reduce the 3-variable problem to 2Sum while gracefully bypassing all duplicates in $O(n^2)$ time?**

**Example 1:**
```
Input:  nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
The distinct triplets are [-1,0,1] and [-1,-1,2].
```

**Example 2:**
```
Input:  nums = [0,1,1]
Output: []
Explanation: The only possible triplet does not sum up to 0.
```

**Example 3:**
```
Input:  nums = [0,0,0]
Output: [[0,0,0]]
```

**Constraints:**
- $3 \le \text{nums.length} \le 3000$
- $-10^5 \le \text{nums}[i] \le 10^5$

## Approach 1 — Sort + Fixed Element + Two Pointers ✅

**Key insight:**
1. Sort `nums` first.
2. Iterate `i` from `0` to `n-3`. Fix `nums[i]`. If `nums[i] > 0`, break early (sum of 3 positives cannot be 0).
3. If `i > 0 && nums[i] == nums[i-1]`, skip to avoid duplicate triplets for the first position.
4. Run Two Pointers `left = i + 1` and `right = n - 1` with target `-nums[i]`.
5. On finding a match, advance `left` past duplicates (`nums[left] == nums[left+1]`) and `right` past duplicates (`nums[right] == nums[right-1]`).

```
nums = [-1, 0, 1, 2, -1, -4]
Sorted: [-4, -1, -1, 0, 1, 2]

i=0 (num = -4): left=1 (-1), right=5 (2) -> max sum = -4 + 1 + 2 = -1 < 0 -> no triplet
i=1 (num = -1): left=2 (-1), right=5 (2) -> sum = -1 + (-1) + 2 = 0 -> MATCH: [-1, -1, 2]
                left=3 (0), right=4 (1)  -> sum = -1 + 0 + 1 = 0    -> MATCH: [-1, 0, 1]
i=2 (num = -1): nums[2] == nums[1] -> SKIP duplicate
i=3 (num = 0):  left=4 (1), right=5 (2) -> sum = 0 + 1 + 2 = 3 > 0

Result: [[-1, -1, 2], [-1, 0, 1]] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> result;
        int n = nums.size();
        
        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break; // impossible to sum to 0
            if (i > 0 && nums[i] == nums[i - 1]) continue; // skip dup
            
            int left = i + 1, right = n - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    result.push_back({nums[i], nums[left], nums[right]});
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n^2)$ | $O(1)$ or $O(n)$ depending on sorting algorithm |

> **This is the one.** Standard optimal $O(n^2)$ solution with clean duplicate skipping.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Multiple zeroes `[0, 0, 0, 0]` | Returning multiple `[0, 0, 0]` triplets | Duplicate checks on both `i` and `left/right` guarantee single `[0, 0, 0]` output |
| No valid triplet `[1, 2, 3]` | Needless loop execution | `nums[i] > 0` breaks immediately, returns `[]` |
| Heavy duplicate negatives `[-2, 0, 0, 2, 2]` | Duplicate sets | Skips redundant iterations |

---

## Pattern Takeaway

The **Sort + K-Sum Reduction** technique reduces any K-Sum problem to (K-1)-Sum down to 2Sum with Two Pointers. Skipping identical values at every pointer level guarantees duplicate-free combinations.

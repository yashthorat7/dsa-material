## What are we solving?

You have a bomb to defuse, and your informer has given you a **circular array** `code` of length $n$ and a key $k$.

To decrypt the code, you must replace every number according to the following rules:
- If $k > 0$: replace the $i$-th number with the sum of the **next $k$ numbers**.
- If $k < 0$: replace the $i$-th number with the sum of the **previous $|k|$ numbers**.
- If $k == 0$: replace the $i$-th number with `0`.

As `code` is circular, the next element of `code[n-1]` is `code[0]`, and the previous element of `code[0]` is `code[n-1]`.

```
 code = [ 5, 7, 1, 4 ],  k = 3 (n = 4)
 
 Decryptions:
 - i=0 (val 5): next 3 -> 7 + 1 + 4 = 12
 - i=1 (val 7): next 3 -> 1 + 4 + 5 = 10
 - i=2 (val 1): next 3 -> 4 + 5 + 7 = 16
 - i=3 (val 4): next 3 -> 5 + 7 + 1 = 13
 
 Output: [ 12, 10, 16, 13 ]
```

### Input & Output Contract
- **Input:**
  - `code`: `vector<int>` ($1 \le n \le 100$, $1 \le \text{code}[i] \le 100$).
  - `k`: `int` ($-(n - 1) \le k \le n - 1$).
- **Output:**
  - `vector<int>` of length $n$ with decrypted values.

---

**Example 1:**
```
Input:  code = [5,7,1,4], k = 3
Output: [12,10,16,13]
```

**Example 2:**
```
Input:  code = [1,2,3,4], k = 0

```

**Example 3:**
```
Input:  code = [2,4,9,3], k = -2
```

- $n == \text{code.length}$
- $1 \le n \le 100$
- $1 \le \text{code}[i] \le 100$
- $-(n - 1) \le k \le n - 1$

## Approach 1 — Brute Force Circular Sum ($O(n \cdot |k|)$)

### Intuition
For each index $i \in [0, n - 1]$, sum the corresponding $|k|$ elements using a nested loop and circular modulo arithmetic $(i + j + n) \% n$.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> decrypt(vector<int>& code, int k) {
        int n = code.size();
        vector<int> result(n, 0);
        if (k == 0) return result;
        
        for (int i = 0; i < n; i++) {
            int sum = 0;
            if (k > 0) {
                for (int j = 1; j <= k; j++) {
                    sum += code[(i + j) % n];
                }
            } else {
                for (int j = 1; j <= -k; j++) {
                    sum += code[(i - j + n) % n];
                }
            }
            result[i] = sum;
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot |k|)$ | Nested loop calculating sum for each index. |
| **Space** | $O(1)$ auxiliary | Output vector memory only. |

> **Verdict:** Suboptimal. Fixed circular sliding window achieves $O(n)$ linear time.

## Approach 2 — Fixed Circular Sliding Window ✅

### Key Insight
Instead of recalculating the sum of $|k|$ elements from scratch for every index:
1. If $k == 0$: return array of zeroes.
2. Determine initial window bounds:
   - If $k > 0$: initial window is `[start = 1, end = k]`.
   - If $k < 0$: initial window is `[start = n - |k|, end = n - 1]`.
3. Precalculate initial `windowSum` for indices `[start ... end]`.
4. For each $i \in [0 \dots n - 1]$:
   - `result[i] = windowSum`.
   - **Slide Window:**
     - Subtract outgoing element: `windowSum -= code[start % n]`.
     - Advance `start++`, `end++`.
     - Add incoming element: `windowSum += code[end % n]`.
5. Every transition takes pure **$O(1)$ arithmetic**!

```
code = [5, 7, 1, 4], k = 3, n = 4
start = 1, end = 3
windowSum = code[1] + code[2] + code[3] = 7 + 1 + 4 = 12

i=0: result[0] = 12. Slide: sum -= code[1](7), sum += code[4%4=0](5) -> sum = 10, start=2, end=4
i=1: result[1] = 10. Slide: sum -= code[2](1), sum += code[5%4=1](7) -> sum = 16, start=3, end=5
i=2: result[2] = 16. Slide: sum -= code[3](4), sum += code[6%4=2](1) -> sum = 13, start=4, end=6
i=3: result[3] = 13.

Result: [ 12, 10, 16, 13 ] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> decrypt(vector<int>& code, int k) {
        int n = code.size();
        vector<int> result(n, 0);
        if (k == 0) return result;
        
        // Define initial window boundaries
        int start = 1;
        int end = k;
        if (k < 0) {
            start = n - abs(k);
            end = n - 1;
        }
        
        // Precompute initial window sum
        int windowSum = 0;
        for (int i = start; i <= end; i++) {
            windowSum += code[i % n];
        }
        
        // Slide the window across all n output positions
        for (int i = 0; i < n; i++) {
            result[i] = windowSum;
            windowSum -= code[start % n];
            start++;
            end++;
            windowSum += code[end % n];
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Initial sum takes $O(|k|)$; sliding loop takes exactly $n$ steps ($O(n)$ total). |
| **Space** | $O(1)$ auxiliary | Output vector memory only. |

> **This is the one.** Clean, robust, single-pass circular sliding window.

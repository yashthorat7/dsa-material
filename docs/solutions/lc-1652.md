## What are we solving?

You have a bomb to defuse, and your informer has given you a **circular** array `code` of length `n` and a key `k`.
- If `k > 0`, replace the $i$-th number with the sum of the next `k` numbers.
- If `k < 0`, replace the $i$-th number with the sum of the previous `|k|` numbers.
- If `k == 0`, replace the $i$-th number with `0`.

As `code` is circular, the next element of `code[n-1]` is `code[0]`, and the previous element of `code[0]` is `code[n-1]`.

The challenge is: **how to maintain a sliding window across circular boundaries in $O(n)$ time?**

**Example 1:**
```
Input:  code = [5,7,1,4], k = 3
Output: [12,10,16,13]
Explanation: Each number is replaced by the sum of the next 3 numbers. The decrypted code is [7+1+4, 1+4+5, 4+5+7, 5+7+1] = [12,10,16,13].
```

**Example 2:**
```
Input:  code = [1,2,3,4], k = 0
Output: [0,0,0,0]
Explanation: When k is zero, the numbers are replaced by 0.
```

**Example 3:**
```
Input:  code = [2,4,9,3], k = -2
Output: [12,5,6,13]
Explanation: The decrypted code is [3+9, 2+3, 4+2, 9+4] = [12,5,6,13].
```

**Constraints:**
- $n == \text{code.length}$
- $1 \le n \le 100$
- $1 \le \text{code}[i] \le 100$
- $-(n - 1) \le k \le n - 1$

## Approach 1 — Circular Sliding Window ✅

**Key insight:**
- If `k == 0`: return array of zeroes.
- For `k > 0`: initial window is `[1 .. k]`.
- For `k < 0`: initial window is `[n - |k| .. n - 1]`.
Compute the initial window sum. Then for each index `i` from `0` to `n-1`:
- Store `result[i] = windowSum`.
- Slide the window: subtract `code[start % n]`, add `code[(end + 1) % n]`, advance `start++`, `end++`.

```
code = [5, 7, 1, 4], k = 3, n = 4
start = 1, end = 3
windowSum = code[1]+code[2]+code[3] = 7 + 1 + 4 = 12

i=0: result[0] = 12. Slide: sum -= code[1](7), sum += code[4%4=0](5) -> sum = 10, start=2, end=4
i=1: result[1] = 10. Slide: sum -= code[2](1), sum += code[5%4=1](7) -> sum = 16, start=3, end=5
i=2: result[2] = 16. Slide: sum -= code[3](4), sum += code[6%4=2](1) -> sum = 13, start=4, end=6
i=3: result[3] = 13.

Result: [12, 10, 16, 13] ✓
```

```cpp
class Solution {
public:
    vector<int> decrypt(vector<int>& code, int k) {
        int n = code.size();
        vector<int> result(n, 0);
        if (k == 0) return result;
        
        int start = 1, end = k;
        if (k < 0) {
            start = n - abs(k);
            end = n - 1;
        }
        
        int windowSum = 0;
        for (int i = start; i <= end; i++) {
            windowSum += code[i % n];
        }
        
        for (int i = 0; i < n; i++) {
            result[i] = windowSum;
            windowSum -= code[start % n];
            start++;
            end++;
            windowSum += code[end % n];
        }
        
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Linear circular window updates with modulo indexing.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `k == 0` | Division/modulo by 0 or unnecessary sum calculation | Early exit returning vector of 0s |
| `k < 0` negative index wrap | Negative modulo arithmetic in C++ | `start = n - abs(k)` guarantees positive indices before `% n` |
| `|k| = n - 1` | Window encompasses almost entire array | Sliding window handles up to full size seamlessly |

---

## Pattern Takeaway

Circular array sliding windows are cleanly modeled using **modulo indexing `% n`** on continuously advancing start and end indices.

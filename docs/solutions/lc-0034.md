## What are we solving?

Given an array of integers `nums` sorted in **non-decreasing order**, find the **starting and ending position** of a given `target` value.

If `target` is not found in the array, return `[-1, -1]`.

You must write an algorithm with **$O(\log n)$ runtime complexity**.

```
 nums = [ 5,  7,  7,  8,  8, 10 ],  target = 8
          0   1   2   3   4   5
                      ^   ^
                    First Last
                    
 Output: [3, 4]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` sorted in non-decreasing order ($0 \le n \le 10^5$, $-10^9 \le \text{nums}[i] \le 10^9$).
  - `target`: `int` search key ($-10^9 \le \text{target} \le 10^9$).
- **Output:**
  - `vector<int>` of size 2 containing `[first_index, last_index]`, or `[-1, -1]` if not present.
- **Constraint:** Must achieve $O(\log n)$ time complexity.

### The Core Challenge
When `nums[mid] == target`, standard binary search halts and returns `mid`. However, multiple copies of `target` may exist to the left and right of `mid`. We need a technique to continue binary searching until the exact leftmost and rightmost boundaries are locked in $O(\log n)$ time.

---

**Example 1:**
```
Input:  nums = [5,7,7,8,8,10], target = 8
Output: [3,4]
```

**Example 2:**
```
Input:  nums = [5,7,7,8,8,10], target = 6
Output: [-1,-1]
```

**Example 3:**
```
Input:  nums = [], target = 0
Output: [-1,-1]
```

**Constraints:**
- $0 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$
- `nums` is a non-decreasing array.
- $-10^9 \le \text{target} \le 10^9$

## Approach 1 — Linear Scan (Brute Force)

### Intuition
Traverse the array once from left to right:
- Record the first index where `nums[i] == target`.
- Continue updating the last index as long as `nums[i] == target`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int first = -1, last = -1;
        
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] == target) {
                if (first == -1) first = i;
                last = i;
            }
        }
        
        return {first, last};
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear scan through the array. |
| **Space** | $O(1)$ | No auxiliary memory used. |

> **Verdict:** Fails the mandatory $O(\log n)$ requirement.

## Approach 2 — Standard Binary Search + Linear Expansion

### Intuition
Find any occurrence of `target` using standard binary search. Once located at index `mid`, expand two pointers `left` and `right` outward linearly until characters differ.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int low = 0, high = nums.size() - 1;
        int foundIdx = -1;
        
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (nums[mid] == target) {
                foundIdx = mid;
                break;
            } else if (nums[mid] < target) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        
        if (foundIdx == -1) return {-1, -1};
        
        int first = foundIdx, last = foundIdx;
        while (first > 0 && nums[first - 1] == target) first--;
        while (last + 1 < nums.size() && nums[last + 1] == target) last++;
        
        return {first, last};
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ Worst Case | Degenerates to $O(n)$ when all elements equal `target` (`[8,8,8,8,8]`). |
| **Space** | $O(1)$ | Scalar pointer registers. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Array** | `nums = [], target = 0` | Vector indexing crash | `low <= high` (0 <= -1) is false, returns `[-1, -1]`. |
| **Element Missing** | `[5, 7, 7, 10], target = 8` | Boundary assignment | `nums[mid] == target` never triggers; returns `[-1, -1]`. |
| **All Elements Identical** | `[8, 8, 8, 8], target = 8` | Degradation to $O(n)$ | Pure binary search halves range, returns `[0, 3]` in $O(\log n)$. |
| **Single Element Match** | `[5], target = 5` | Loop bounds | Returns `[0, 0]`. |

---

## Pattern Takeaways

1. **Boundary Binary Search Template:**  
   To find the **first** occurrence of a condition, set `ans = mid; high = mid - 1;`.  
   To find the **last** occurrence of a condition, set `ans = mid; low = mid + 1;`.
2. **Lower/Upper Bound Equivalence:**  
   `searchRange` is the fundamental blueprint for interval search queries in databases and range query engines.

## What are we solving?

Given a string `s`, partition `s` such that every **substring** in the partition is a **palindrome**.

Return all possible **palindrome partitionings** of `s`.

```
 s = " a a b "
 
 Cuts:
 1. "a" | "a" | "b"  -> ["a", "a", "b"]  (All single characters are palindromes)
 2. "aa" | "b"       -> ["aa", "b"]       ("aa" and "b" are both palindromes)
 
 Output: [ ["a", "a", "b"], ["aa", "b"] ]
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of lowercase English letters ($1 \le n \le 16$).
- **Output:**
  - `vector<vector<string>>` containing all valid palindrome partition arrays.

### The Core Challenge
For a string of length $n$, there are $n - 1$ possible cut points, generating $2^{n - 1}$ total partition combinations. We must evaluate candidate prefix cuts `s[start...end]` and **only recurse when the chosen prefix is a verified palindrome**.

---

**Example 1:**
```
Input:  s = "aab"
Output: [["a","a","b"],["aa","b"]]
```

**Example 2:**
```
Input:  s = "a"
Output: [["a"]]
```

**Constraints:**
- $1 \le s.\text{length} \le 16$
- `s` contains only lowercase English letters.

## Approach 1 — Backtracking with Two-Pointer Palindrome Check

### Intuition
From current index `start`:
1. Loop `end` from `start` to $n - 1$.
2. Check if substring `s[start...end]` is a palindrome using two pointers.
3. If it is: append substring to `current`, recurse on `end + 1`, and pop from `current` to backtrack.
4. Base case: `if (start == s.length())` add `current` to `result`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> result;
        vector<string> current;
        backtrack(0, s, current, result);
        return result;
    }

private:
    void backtrack(int start, const string& s, vector<string>& current,
                   vector<vector<string>>& result) {
        if (start == s.length()) {
            result.push_back(current);
            return;
        }
        
        for (int end = start; end < s.length(); end++) {
            if (isPalindrome(s, start, end)) {
                current.push_back(s.substr(start, end - start + 1));
                backtrack(end + 1, s, current, result);
                current.pop_back(); // Backtrack
            }
        }
    }
    
    bool isPalindrome(const string& s, int l, int r) {
        while (l < r) {
            if (s[l++] != s[r--]) return false;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | $2^n$ potential states $\times O(n)$ palindrome verification per substring. |
| **Space** | $O(n)$ | Call stack depth bounded by $n \le 16$. |

## Approach 2 — Backtracking with 2D DP Palindrome Lookup Table ✅

### Key Insight
Precomputing a 2D boolean table `isPal[i][j]` takes $O(n^2)$ time:
$$\text{isPal}[i][j] = (s[i] == s[j]) \land (j - i \le 2 \lor \text{isPal}[i + 1][j - 1])$$
This reduces all subsequent palindrome checks inside backtracking from $O(n)$ to **$O(1)$ instantaneous table lookup**!

```
s = "aab"
Precomputed isPal table:
      0(a)  1(a)  2(b)
0(a)   T     T     F
1(a)   .     T     F
2(b)   .     .     T

backtrack(start=0):
- end=0 ("a"): isPal[0][0] is T -> pick "a" -> start=1:
  - end=1 ("a"): isPal[1][1] is T -> pick "a" -> start=2:
    - end=2 ("b"): isPal[2][2] is T -> pick "b" -> start=3 (match: ["a", "a", "b"])
- end=1 ("aa"): isPal[0][1] is T -> pick "aa" -> start=2:
  - end=2 ("b"): isPal[2][2] is T -> pick "b" -> start=3 (match: ["aa", "b"])

Result: [ ["a", "a", "b"], ["aa", "b"] ] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<string>> partition(string s) {
        int n = s.length();
        vector<vector<bool>> isPal(n, vector<bool>(n, false));
        
        // Step 1: Precompute palindrome lookup table in O(n^2)
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s[i] == s[j]) {
                    isPal[i][j] = (len <= 2) || isPal[i + 1][j - 1];
                }
            }
        }
        
        vector<vector<string>> result;
        vector<string> current;
        backtrack(0, s, isPal, current, result);
        return result;
    }

private:
    void backtrack(int start, const string& s, const vector<vector<bool>>& isPal,
                   vector<string>& current, vector<vector<string>>& result) {
        if (start == s.length()) {
            result.push_back(current);
            return;
        }
        
        for (int end = start; end < s.length(); end++) {
            if (isPal[start][end]) {
                current.push_back(s.substr(start, end - start + 1));
                backtrack(end + 1, s, isPal, current, result);
                current.pop_back(); // Backtrack
            }
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2 + n \cdot 2^n)$ | $O(n^2)$ precomputation + $O(1)$ lookup per backtrack branch. |
| **Space** | $O(n^2)$ | 2D table of size $16 \times 16$ (negligible). |

> **This is the one.** Instantaneous $O(1)$ palindrome checks accelerate backtracking.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Character** | `"a"` | Base cases | Returns `[["a"]]`. |
| **All Identical Characters** | `"aaa"` | Multiple valid partitionings | Generates all 4 partitions: `["a","a","a"]`, `["a","aa"]`, `["aa","a"]`, `["aaa"]`. |
| **No Multi-Character Palindromes** | `"abc"` | False branching | Only single character partition `["a","b","c"]` is produced. |

---

## Pattern Takeaways

1. **The Substring Cut Invariant:**  
   String partitioning represents making binary decisions at $n - 1$ boundaries between characters.
2. **DP Precomputation Synergy:**  
   Combining a 2D DP lookup table with recursive backtracking eliminates repeated inner string scans.

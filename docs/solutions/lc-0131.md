## What are we solving?

Given a string `s`, partition `s` such that every **substring** of the partition is a **palindrome**. Return all possible palindrome partitioning of `s`.

The question is: **how do we backtrack over all prefix cuts and only branch deeper if the current prefix is a valid palindrome?**

**Example 1:**
```
Input:  s = "aab"
Output: [["a","a","b"],["aa","b"]]
```

**Example 2:**
```
Input:  s = "a"
Output: [["a"]]
```

**Constraints:**
- $1 \le s.\text{length} \le 16$
- `s` contains only lowercase English letters.

## Approach 1 — Backtracking with Prefix Palindrome Validation ✅

**Key insight:**
At index `start`:
1. Iterate `end` from `start` to `s.size() - 1`.
2. Check if substring `s[start..end]` is a palindrome.
3. If it IS a palindrome:
   - Choose it: `current.push_back(s.substr(start, end - start + 1))`.
   - Recurse on remaining suffix: `backtrack(end + 1, ...)`.
   - Backtrack: `current.pop_back()`.
4. Base case: `if (start == s.size())` $\rightarrow$ add `current` to `result`.

```
s = "aab"
start=0:
  end=0 ("a" is pal): choose "a" -> start=1:
    end=1 ("a" is pal): choose "a" -> start=2:
      end=2 ("b" is pal): choose "b" -> start=3 (end reached!) -> ["a", "a", "b"] ✓
    end=2 ("ab" not pal)
  end=1 ("aa" is pal): choose "aa" -> start=2:
    end=2 ("b" is pal): choose "b" -> start=3 -> ["aa", "b"] ✓
  end=2 ("aab" not pal)

Result: [["a","a","b"], ["aa","b"]] ✓
```

```cpp
class Solution {
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> result;
        vector<string> current;
        backtrack(0, s, current, result);
        return result;
    }
private:
    void backtrack(int start, const string& s, vector<string>& current, vector<vector<string>>& result) {
        if (start == s.size()) {
            result.push_back(current);
            return;
        }
        
        for (int end = start; end < s.size(); end++) {
            if (isPal(s, start, end)) {
                current.push_back(s.substr(start, end - start + 1));
                backtrack(end + 1, s, current, result);
                current.pop_back();
            }
        }
    }
    
    bool isPal(const string& s, int l, int r) {
        while (l < r) {
            if (s[l++] != s[r--]) return false;
        }
        return true;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot 2^n)$ | $O(n)$ recursion stack |

> **This is the one.** Clean prefix partitioning recursion.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single character `"a"` | Single branch | Returns `[["a"]]` |
| All identical characters `"aaa"` | All partitions valid | Generates `["a","a","a"]`, `["a","aa"]`, `["aa","a"]`, `["aaa"]` |

## Pattern Takeaway

String partitioning problems explore all $2^{n-1}$ binary cut positions; pruning invalid prefix cuts early keeps search space minimal.

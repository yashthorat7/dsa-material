> **Companies:** Amazon, Google, Bloomberg

## What are we solving?

You are given an integer array `nums` and an integer `k`.

Find the **maximum subarray sum** of all subarrays of `nums` that meet the following two conditions:
1. The length of the subarray is **exactly $k$**, and
2. All the elements of the subarray are **distinct** (no duplicates).

Return the maximum subarray sum. If no subarray meets the conditions, return `0`.

```
 nums = [ 1, 5, 4, 2, 9, 9, 9 ],  k = 3
 
 Window [1, 5, 4]: Sum = 10, all distinct -> valid!
 Window [5, 4, 2]: Sum = 11, all distinct -> valid!
 Window [4, 2, 9]: Sum = 15, all distinct -> valid! (MAXIMUM)
 Window [2, 9, 9]: Duplicate 9           -> INVALID
 Window [9, 9, 9]: Duplicate 9           -> INVALID
 
 Maximum Valid Sum: 15
 Output: 15
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($1 \le k \le n \le 10^5$, $1 \le \text{nums}[i] \le 10^5$).
  - `k`: `int` window width.
- **Output:**
  - `long long`: Maximum sum over all distinct $k$-element subarrays, or `0`.

### The Window Invariant
A window $[ \text{left} \dots \text{right} ]$ is valid if and only if:
1. $\text{right} - \text{left} + 1 == k$, AND
2. $\text{count of unique elements in window} == k$.
Using a frequency map `freq` or hash set `seen`, we can check uniqueness and update the running sum in **$O(1)$ amortized time per element**.

---

**Example 1:**
```
Input:  nums = [1,5,4,2,9,9,9], k = 3
Output: 15
Explanation: The subarrays of nums with length 3 are:
- [1,5,4] which meets the requirements and has a sum of 10.
- [5,4,2] which meets the requirements and has a sum of 11.
- [4,2,9] which meets the requirements and has a sum of 15.
- [2,9,9] does not meet requirements because element 9 is repeated.
- [9,9,9] does not meet requirements.
Return 15 because it is the maximum subarray sum of all valid subarrays.
```

**Example 2:**
```
Input:  nums = [4,4,4], k = 3
Output: 0
```

**Constraints:**
- $1 \le k \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$

## Approach 1 — Sliding Window with Hash Set ($O(n)$)

### Intuition
Maintain a hash set `seen` and running sum. While `nums[right]` is already in `seen` or the window length exceeds $k$, remove `nums[left]` from `seen`, subtract from sum, and advance `left`. Once valid and length is $k$, record `maxSum`.

### C++ Implementation
```cpp
class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        long long maxSum = 0, currentSum = 0;
        unordered_set<int> seen;
        int left = 0;
        
        for (int right = 0; right < nums.size(); right++) {
            // Shrink window if duplicate found or window too large
            while (seen.count(nums[right]) || right - left + 1 > k) {
                seen.erase(nums[left]);
                currentSum -= nums[left];
                left++;
            }
            
            seen.insert(nums[right]);
            currentSum += nums[right];
            
            if (right - left + 1 == k) {
                maxSum = max(maxSum, currentSum);
            }
        }
        
        return maxSum;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each element is inserted and erased at most once. |
| **Space** | $O(k)$ | Hash set holds at most $k$ elements. |

## Approach 2 — Fixed Sliding Window with Frequency Map ✅

### Key Insight
1. Maintain `runningSum` (as `long long`) and `unordered_map<int, int> freq`.
2. Expand `right` from $0$ to $n - 1$:
   - `runningSum += nums[right]`, `freq[nums[right]]++`.
   - If window size $> k$:
     - `runningSum -= nums[left]`.
     - `freq[nums[left]]--`.
     - If `freq[nums[left]] == 0`, `freq.erase(nums[left])`.
     - `left++`.
   - If window size $== k$ AND `freq.size() == k`:
     - `maxSum = max(maxSum, runningSum)`.
3. Return `maxSum`.

```
nums = [1, 5, 4, 2, 9, 9, 9], k = 3

right=0 (1): sum=1, freq={1:1}
right=1 (5): sum=6, freq={1:1, 5:1}
right=2 (4): sum=10, freq={1:1, 5:1, 4:1}. size=3, unique=3 -> maxSum = 10
right=3 (2): pop 1 -> sum=10-1+2=11, freq={5:1, 4:1, 2:1}. unique=3 -> maxSum = 11
right=4 (9): pop 5 -> sum=11-5+9=15, freq={4:1, 2:1, 9:1}. unique=3 -> maxSum = 15
right=5 (9): pop 4 -> sum=15-4+9=20, freq={2:1, 9:2}. unique=2 (< 3) -> skip
right=6 (9): pop 2 -> sum=20-2+9=27, freq={9:3}. unique=1 (< 3) -> skip

Result: 15 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        long long maxSum = 0;
        long long runningSum = 0;
        unordered_map<int, int> freq;
        int left = 0;
        
        for (int right = 0; right < nums.size(); right++) {
            runningSum += nums[right];
            freq[nums[right]]++;
            
            // Maintain fixed window size k
            if (right - left + 1 > k) {
                runningSum -= nums[left];
                freq[nums[left]]--;
                if (freq[nums[left]] == 0) {
                    freq.erase(nums[left]);
                }
                left++;
            }
            
            // Check if window is of size k and contains k unique elements
            if (right - left + 1 == k && freq.size() == k) {
                maxSum = max(maxSum, runningSum);
            }
        }
        
        return maxSum;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass over $n$ elements with $O(1)$ amortized map operations. |
| **Space** | $O(k)$ | Map contains at most $k + 1$ keys. |

> **This is the one.** Clean, robust fixed sliding window with unique element count tracking.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **All Duplicates** | `nums = [4, 4, 4], k = 3` | Returning non-zero sum | `freq.size() == 1 != 3`, returns 0. |
| **`k = 1`** | `[5, 2, 8], k = 1` | Zero sum | Every single element is distinct, returns `max(nums) = 8`. |
| **64-Bit Integer Overflow** | $10^5 \times 10^5 = 10^{10}$ | 32-bit `int` overflow | `long long` used for `runningSum` and `maxSum`. |

## What are we solving?

Given an array of `points` where `points[i] = [xi, yi]` represents a point on the **X-Y** plane and an integer `k`, return the `k` closest points to the origin `(0, 0)`.

The distance between two points on the X-Y plane is the Euclidean distance (i.e., $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$). You may return the answer in **any order**.

The question is: **how does a Max-Heap of size K keep only the K smallest distance vectors?**

**Example 1:**
```
Input:  points = [[1,3],[-2,2]], k = 1
Output: [[-2,2]]
Explanation: The distance between (1, 3) and the origin is sqrt(10).
The distance between (-2, 2) and the origin is sqrt(8).
Since sqrt(8) < sqrt(10), (-2, 2) is closer to the origin.
```

**Example 2:**
```
Input:  points = [[3,3],[5,-1],[-2,4]], k = 2
Output: [[3,3],[-2,4]]
```

**Constraints:**
- $1 \le k \le \text{points.length} \le 10^4$
- $-10^4 \le x_i, y_i \le 10^4$

## Approach 1 — Max-Heap of Size K (Squared Distances) ✅

**Key insight:**
1. Avoid expensive `sqrt` calculations; compare squared distance $x^2 + y^2$.
2. Maintain a **Max-Heap** of size $k$ storing `{distSquared, {x, y}}`.
3. For each point:
   - Calculate $d = x^2 + y^2$.
   - Push into heap.
   - If heap size exceeds $k$, pop the point with the largest distance.
4. The $k$ remaining points in the heap are the $k$ closest to the origin!

```
points = [[1,3], [-2,2]], k = 1
point [1,3]:  d = 1+9 = 10 -> heap: [{10, [1,3]}]
point [-2,2]: d = 4+4 = 8  -> heap: [{10, [1,3]}, {8, [-2,2]}]
Size > 1 -> pop max (10, [1,3]) -> heap: [{8, [-2,2]}]

Result: [[-2,2]] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        // Max-heap storing {distSquared, pointIndex}
        priority_queue<pair<int, int>> maxHeap;
        
        for (int i = 0; i < points.size(); i++) {
            int dist = points[i][0] * points[i][0] + points[i][1] * points[i][1];
            maxHeap.push({dist, i});
            if (maxHeap.size() > k) {
                maxHeap.pop();
            }
        }
        
        vector<vector<int>> result;
        while (!maxHeap.empty()) {
            result.push_back(points[maxHeap.top().second]);
            maxHeap.pop();
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log k)$ | $O(k)$ |

> **This is the one.** Streaming $O(n \log k)$ nearest-neighbor filtering.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `k == points.length` | Full return | Pushes all points and returns entire set |
| Equidistant points `[1, 1], [-1, -1], [1, -1]` | Strict distance ties | Any subset of $k$ equidistant points is valid according to problem spec |

---

## Pattern Takeaway

To find the **$K$ smallest items**, maintain a **Max-Heap of size $K$** and continuously pop the maximum candidate when capacity is exceeded.

## What are we solving?

Write a function to find the **longest common prefix** string amongst an array of strings `strs`.

If there is no common prefix, return an empty string `""`.

```
 strs = [ "flower", "flow", "flight" ]
 
 Column 0: 'f', 'f', 'f' -> MATCH ('f')
 Column 1: 'l', 'l', 'l' -> MATCH ('l')
 Column 2: 'o', 'o', 'i' -> MISMATCH ('o' vs 'i')
 
 Longest Common Prefix = "fl"
```

### Input & Output Contract
- **Input:**
  - `strs`: `vector<string>` ($1 \le n \le 200$, $0 \le \text{length} \le 200$, lowercase English letters).
- **Output:**
  - `string` representing the shared prefix.

---

**Example 1:**
```
Input:  strs = ["flower","flow","flight"]
Output: "fl"
```

**Example 2:**
```
Input:  strs = ["dog","racecar","car"]
Output: ""
Explanation: There is no common prefix among the input strings.
```

**Constraints:**
- $1 \le \text{strs.length} \le 200$
- $0 \le \text{strs}[i].\text{length} \le 200$
- `strs[i]` consists of only lowercase English letters.

## Approach 1 — Horizontal Scanning

### Intuition
Set `prefix = strs[0]`. Iterate through each subsequent string $s$: shrink `prefix` until $s$ begins with `prefix` (`s.find(prefix) == 0`).

### C++ Implementation
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        string prefix = strs[0];
        
        for (int i = 1; i < strs.size(); i++) {
            while (strs[i].find(prefix) != 0) {
                prefix = prefix.substr(0, prefix.length() - 1);
                if (prefix.empty()) return "";
            }
        }
        
        return prefix;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(S)$ | Where $S$ is the sum of characters across all strings. |
| **Space** | $O(1)$ | No memory allocated. |

## Approach 2 — Vertical Column Scanning ✅

### Key Insight
Scan column by column:
- For character index $i$ of `strs[0]`:
  - Check `strs[j][i]` for all strings $j \in [1, n - 1]$.
  - If $i == \text{strs}[j].\text{length}()$ OR $\text{strs}[j][i] \ne \text{strs}[0][i]$:
    - Return `strs[0].substr(0, i)` immediately!
- If all columns match, return `strs[0]`.

```
strs = ["flower", "flow", "flight"]

i=0: strs[0][0]='f', strs[1][0]='f', strs[2][0]='f' -> match
i=1: strs[0][1]='l', strs[1][1]='l', strs[2][1]='l' -> match
i=2: strs[0][2]='o', strs[1][2]='o', strs[2][2]='i' -> MISMATCH! Return strs[0].substr(0, 2) = "fl"

Result: "fl" ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        
        for (int i = 0; i < strs[0].length(); i++) {
            char c = strs[0][i];
            
            for (int j = 1; j < strs.size(); j++) {
                // If string ends or character mismatch occurs
                if (i == strs[j].length() || strs[j][i] != c) {
                    return strs[0].substr(0, i);
                }
            }
        }
        
        return strs[0];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(S)$ | Stops at the first mismatch column without scanning trailing characters. |
| **Space** | $O(1)$ | Stack-only index comparison. |

> **This is the one.** Minimal character reads with immediate early termination.

## Approach 3 — Sorting Lexicographical Extremes

### Intuition
Sort `strs` lexicographically. In a sorted array, the most dissimilar strings are `strs[0]` (first) and `strs[n-1]` (last). Any prefix shared between `strs[0]` and `strs[n-1]` must also be shared by all intermediate strings!

### C++ Implementation
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        sort(strs.begin(), strs.end());
        
        const string& first = strs.front();
        const string& last = strs.back();
        int i = 0;
        
        while (i < first.length() && i < last.length() && first[i] == last[i]) {
            i++;
        }
        
        return first.substr(0, i);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(N \log N \cdot M)$ | String sorting comparison overhead. |
| **Space** | $O(1)$ auxiliary | In-place sort. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single String** | `["a"]` | Inner loop does not run | Returns `"a"`. |
| **Empty String Present** | `["", "b"]` | Index out of bounds | `i == strs[0].length()` triggers immediately, returning `""`. |
| **Identical Strings** | `["test", "test"]` | Loop completion | Outer loop finishes, returns `"test"`. |

---

## Pattern Takeaways

1. **Vertical Scanning Dominance:**  
   When looking for common prefixes across multiple strings, vertical scanning avoids examining irrelevant suffix characters.
2. **Lexicographical Extremes Property:**  
   The common prefix of an entire sorted array of strings is simply the common prefix of its first and last elements.

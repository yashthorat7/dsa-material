## What are we solving?

Write a function to find the longest common prefix string amongst an array of strings. If there is no common prefix, return an empty string `""`.

The question is: **how do we compare characters vertically across all strings and terminate on the very first mismatch?**

**Example 1:**
```
Input:  strs = ["flower","flow","flight"]
Output: "fl"
```

**Example 2:**
```
Input:  strs = ["dog","racecar","car"]
Output: ""
Explanation: There is no common prefix among the input strings.
```

**Constraints:**
- $1 \le \text{strs.length} \le 200$
- $0 \le \text{strs}[i].\text{length} \le 200$
- `strs[i]` consists of only lowercase English letters.

## Approach 1 — Vertical Scanning ✅

**Key insight:** Scan character by character across the columns of all strings.
For index `i` of the first string `strs[0]`:
- Compare `strs[0][i]` with `strs[j][i]` for all strings `j = 1..n-1`.
- If `i == strs[j].length()` (string ran out of characters) or `strs[j][i] != strs[0][i]` (character mismatch): return `strs[0].substr(0, i)`.
If loop completes, return `strs[0]`.

```
strs = ["flower", "flow", "flight"]

i=0: strs[0][0]='f', strs[1][0]='f', strs[2][0]='f' -> match
i=1: strs[0][1]='l', strs[1][1]='l', strs[2][1]='l' -> match
i=2: strs[0][2]='o', strs[1][2]='o', strs[2][2]='i' -> MISMATCH! Return strs[0].substr(0, 2) = "fl"

Result: "fl" ✓
```

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.empty()) return "";
        for (int i = 0; i < strs[0].size(); i++) {
            char c = strs[0][i];
            for (int j = 1; j < strs.size(); j++) {
                if (i == strs[j].size() || strs[j][i] != c) {
                    return strs[0].substr(0, i);
                }
            }
        }
        return strs[0];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(S)$ where $S$ is the sum of characters across all strings | $O(1)$ |

> **This is the one.** Minimal character comparisons with immediate early exit.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single string `["a"]` | Inner loop does not execute | Returns `"a"` |
| Empty string in input `["", "abc"]` | Out of bounds | `i == strs[j].size()` returns `""` on first check |
| All strings identical `["apple", "apple"]` | Premature truncation | Returns full string `"apple"` |

---

## Pattern Takeaway

**Vertical Scanning** is optimal when a mismatch occurs early in the prefix, avoiding full scans of remaining strings.

## What are we solving?

Given two strings `s1` and `s2`, return `true` if `s2` contains a **permutation** of `s1`, or `false` otherwise. In other words, return `true` if one of `s1`'s permutations is the **substring** of `s2`.

The question is: **how can we maintain fixed-window character frequency matching in $O(1)$ per character step?**

**Example 1:**
```
Input:  s1 = "ab", s2 = "eidbaooo"
Output: true
Explanation: s2 contains one permutation of s1 ("ba").
```

**Example 2:**
```
Input:  s1 = "ab", s2 = "eidboaoo"
Output: false
```

**Constraints:**
- $1 \le s1.\text{length}, s2.\text{length} \le 10^4$
- `s1` and `s2` consist of lowercase English letters.

## Approach 1 — Fixed-Size Sliding Window with Frequency Counts ✅

**Key insight:** A substring in `s2` is a permutation of `s1` if and only if its character counts match `s1` exactly, with length equal to `s1.length()`.
1. Compute frequency array `count1[26]` for `s1`.
2. Slide a window of length `k = s1.length()` over `s2`, maintaining `count2[26]`.
3. If `count1 == count2`, return `true`. Array equality comparison takes $O(26) = O(1)$ time.

```
s1 = "ab" (len=2), s2 = "eidbaooo"
count1 = {a:1, b:1}

Window [0..1] ("ei"): count2={e:1, i:1} != count1
Window [1..2] ("id"): count2={i:1, d:1} != count1
Window [2..3] ("db"): count2={d:1, b:1} != count1
Window [3..4] ("ba"): count2={b:1, a:1} == count1 -> MATCH! Return true ✓
```

```cpp
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int n1 = s1.size(), n2 = s2.size();
        if (n1 > n2) return false;
        
        vector<int> count1(26, 0), count2(26, 0);
        for (int i = 0; i < n1; i++) {
            count1[s1[i] - 'a']++;
            count2[s2[i] - 'a']++;
        }
        
        if (count1 == count2) return true;
        
        for (int i = n1; i < n2; i++) {
            count2[s2[i] - 'a']++;
            count2[s2[i - n1] - 'a']--;
            if (count1 == count2) return true;
        }
        
        return false;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(26 \cdot n_2) = O(n_2)$ | $O(1)$ (26-element arrays) |

> **This is the one.** Fixed sliding window with $O(1)$ auxiliary memory.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `s1` longer than `s2` (`n1 > n2`) | Negative window sizes | Early return `false` |
| Permutation is at the very beginning `s1 = "ab", s2 = "abxxx"` | Initial window check | `if (count1 == count2)` check before the loop catches immediate match |
| Permutation is at the very end `s1 = "ab", s2 = "xxxab"` | Loop termination boundary | Final iteration inspects the last window |

---

## Pattern Takeaway

For fixed-length anagram/permutation substring search, a **fixed-size sliding window with a 26-element frequency vector** provides $O(1)$ step updates without dynamic allocations.

## What are we solving?

Given a collection of candidate numbers (`candidates`) and a target number (`target`), find all unique combinations in `candidates` where the candidate numbers sum to `target`.

Each number in `candidates` may only be used **once** in the combination. Note: The solution set must not contain duplicate combinations.

**Example 1:**
```
Input:  candidates = [10,1,2,7,6,1,5], target = 8
Output: [[1,1,6],[1,2,5],[1,7],[2,6]]
```

**Example 2:**
```
Input:  candidates = [2,5,2,1,2], target = 5
Output: [[1,2,2],[5]]
```

**Constraints:**
- $1 \le \text{candidates.length} \le 100$
- $1 \le \text{candidates}[i] \le 50$
- $1 \le \text{target} \le 30$

## Approach 1 — Backtracking with Single-Use + Sibling Pruning ✅

**Key insight:**
1. Sort `candidates`.
2. To use each number at most once: recurse with `start = i + 1`.
3. To avoid duplicate combinations: skip duplicate siblings at the same recursion level via `if (i > start && candidates[i] == candidates[i - 1]) continue;`.
4. Early break when `candidates[i] > remain`.

```
candidates = [1, 1, 2, 5, 6, 7, 10], target = 8 (sorted)
i=0 (1): remain=7
  i=1 (1): remain=6 -> [1, 1, 6] (sum=8) ✓
  i=2 (2): remain=5 -> [1, 2, 5] (sum=8) ✓
  i=5 (7): remain=0 -> [1, 7]    (sum=8) ✓
i=1 (1): i > start (1 > 0) && candidates[1]==candidates[0] -> SKIP!
i=2 (2): remain=6 -> [2, 6] (sum=8) ✓

Result: [[1,1,6], [1,2,5], [1,7], [2,6]] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, target, candidates, current, result);
        return result;
    }
private:
    void backtrack(int start, int remain, const vector<int>& candidates, vector<int>& current, vector<vector<int>>& result) {
        if (remain == 0) {
            result.push_back(current);
            return;
        }
        
        for (int i = start; i < candidates.size(); i++) {
            if (candidates[i] > remain) break; // early exit
            if (i > start && candidates[i] == candidates[i - 1]) continue; // skip duplicate branch
            
            current.push_back(candidates[i]);
            backtrack(i + 1, remain - candidates[i], candidates, current, result);
            current.pop_back();
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(2^n)$ | $O(n)$ |

> **This is the one.** Combines single-use `i + 1` with sibling duplicate pruning.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Duplicate candidate used multiple times legitimately `[1, 1, 6], target = 8` | Skipping valid depth duplicate | `i == start` allows the second `1` at depth 2 while skipping it at depth 1 |
| No combination sums to target | Output formatting | Returns `[]` |

---

## Pattern Takeaway

The condition **`i > start && candidates[i] == candidates[i-1]`** precisely differentiates between using identical elements across different recursion depths (allowed) vs starting duplicate branches at the same depth (pruned).

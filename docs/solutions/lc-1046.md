# 1046. Last Stone Weight

https://leetcode.com/problems/last-stone-weight

> **Easy** $\rightarrow$ **Heap / Priority Queue**


> **Companies:** Visa, Nvidia, Amazon, Salesforce, Flipkart, Ola, Cognizant

## What are we solving?

You are given an array of integers `stones` where `stones[i]` is the weight of the $i$-th stone.

We play a game with the stones. On each turn, we choose the **heaviest two stones** and smash them together. Suppose the heaviest two stones have weights $x$ and $y$ with $x \le y$:
- If $x == y$, both stones are destroyed.
- If $x \neq y$, the stone of weight $x$ is destroyed, and the stone of weight $y$ has new weight $y - x$.

At the end of the game, there is **at most one stone left**. Return the weight of this stone (or `0` if there are no stones left).

```
 Stones: [ 2, 7, 4, 1, 8, 1 ]
 
 Turn 1: Smash 8 and 7 -> 8 - 7 = 1 -> [ 2, 4, 1, 1, 1 ]
 Turn 2: Smash 4 and 2 -> 4 - 2 = 2 -> [ 2, 1, 1, 1 ]
 Turn 3: Smash 2 and 1 -> 2 - 1 = 1 -> [ 1, 1, 1 ]
 Turn 4: Smash 1 and 1 -> 1 - 1 = 0 -> [ 1 ]
 
 Last Remaining Stone: 1
 Output: 1
```

### Input & Output Contract
- **Input:**
  - `stones`: `vector<int>` ($1 \le n \le 30$, $1 \le \text{stones}[i] \le 1000$).
- **Output:**
  - `int`: Weight of the final stone, or `0`.

---

**Example 1:**
```
Input:  stones = [2,7,4,1,8,1]
Output: 1
```

**Example 2:**
```
Input:  stones = [1]
Output: 1
```

**Constraints:**
- $1 \le \text{stones.length} \le 30$
- $1 \le \text{stones}[i] \le 1000$

## Approach 1 — Sorting Simulation ($O(n^2 \log n)$)

### Intuition
Sort the array, pop the largest two stones ($y$ and $x$), push $y - x$ if non-zero, and re-sort until at most 1 stone remains.

### C++ Implementation
```cpp
class Solution {
public:
    int lastStoneWeight(vector<int>& stones) {
        while (stones.size() > 1) {
            sort(stones.begin(), stones.end());
            int y = stones.back(); stones.pop_back();
            int x = stones.back(); stones.pop_back();
            if (y > x) {
                stones.push_back(y - x);
            }
        }
        return stones.empty() ? 0 : stones[0];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2 \log n)$ | $n$ rounds of full vector sorting. |
| **Space** | $O(1)$ auxiliary | In-place modifications. |

## Approach 2 — Max-Heap Simulation (`priority_queue`) ✅

### Key Insight
1. Construct a `priority_queue<int>` from `stones` in $O(n)$ time using heapify.
2. While `pq.size() > 1`:
   - Pop the largest element: `int y = pq.top(); pq.pop();`.
   - Pop the second largest element: `int x = pq.top(); pq.pop();`.
   - If `y > x`: push `y - x` back into `pq`.
3. Return `pq.empty() ? 0 : pq.top()`.

```
stones = [2, 7, 4, 1, 8, 1]
maxHeap = [8, 7, 4, 2, 1, 1]

Round 1: y=8, x=7 -> diff=1 -> push 1 -> [4, 2, 1, 1, 1]
Round 2: y=4, x=2 -> diff=2 -> push 2 -> [2, 1, 1, 1]
Round 3: y=2, x=1 -> diff=1 -> push 1 -> [1, 1, 1]
Round 4: y=1, x=1 -> diff=0 -> [1]

Final stone: 1 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int lastStoneWeight(vector<int>& stones) {
        // Construct max-heap directly in O(n)
        priority_queue<int> pq(stones.begin(), stones.end());
        
        while (pq.size() > 1) {
            int y = pq.top(); pq.pop(); // Heaviest stone
            int x = pq.top(); pq.pop(); // Second heaviest stone
            
            if (y > x) {
                pq.push(y - x);
            }
        }
        
        return pq.empty() ? 0 : pq.top();
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Initial heap construction is $O(n)$; at most $n - 1$ smashes take $O(\log n)$ heap pushes/pops. |
| **Space** | $O(n)$ | Heap storage for $n$ stones. |

> **This is the one.** Clean, robust, optimal Max-Heap greedy simulation.

## Approach 3 — Counting / Bucket Array Simulation ($O(n + W)$)

### Intuition
Since weight $\le 1000$, use a bucket array `buckets[1001]` storing frequencies. Scan backwards from 1000 down to 1, pairing stones in $O(W)$ time without comparison sorting.

### C++ Implementation
```cpp
class Solution {
public:
    int lastStoneWeight(vector<int>& stones) {
        vector<int> buckets(1001, 0);
        for (int s : stones) buckets[s]++;
        
        int currentWeight = 1000;
        int maxWeight = 0;
        
        while (currentWeight > 0) {
            if (buckets[currentWeight] == 0) {
                currentWeight--;
            } else if (maxWeight == 0) {
                // If odd number of stones at current weight, 1 remains
                buckets[currentWeight] %= 2;
                if (buckets[currentWeight] == 1) {
                    maxWeight = currentWeight;
                    buckets[currentWeight] = 0;
                }
                currentWeight--;
            } else {
                // Smash maxWeight with currentWeight
                buckets[currentWeight]--;
                int diff = maxWeight - currentWeight;
                if (diff > currentWeight) {
                    maxWeight = diff;
                } else {
                    buckets[diff]++;
                    maxWeight = 0;
                }
            }
        }
        
        return maxWeight;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n + W)$ | Where $W = 1000$. |
| **Space** | $O(W)$ | Frequency array of size 1001. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Stone** | `[1]` | Loop doesn't run | `pq.size() == 1`, returns `pq.top() = 1`. |
| **All Stones Destroyed** | `[2, 2]` | Empty heap access | `pq.empty() ? 0 : pq.top()` returns 0 cleanly. |

## Pattern Takeaways

1. **Greedy Extreme Extraction:**  
   $$\text{Repeatedly smash largest 2 elements } \iff \text{Max-Heap priority queue extraction}$$
2. **Contrast with Last Stone Weight II:**  
   - **Last Stone Weight I (LC 1046):** Greedily smashes in fixed game order (Heap $O(n \log n)$).
   - **Last Stone Weight II (LC 1049):** Finds the optimal arbitrary smash sequence (Subset Sum Knapsack DP $O(n \cdot \text{sum})$).

## What are we solving?

Given an integer array `nums`, return `true` if you can partition the array into two subsets such that the sum of the elements in both subsets is **strictly equal**, or `false` otherwise.

```
 nums = [ 1, 5, 11, 5 ]
 Total Sum = 1 + 5 + 11 + 5 = 22
 
 Target per subset = 22 / 2 = 11
 
 Partition 1: [ 1, 5, 5 ]  -> Sum = 11
 Partition 2: [ 11 ]        -> Sum = 11
 
 Output: true
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 200$, $1 \le \text{nums}[i] \le 100$.
- **Output:**
  - `bool`: `true` if a subset with $\text{sum} = \text{totalSum} / 2$ exists; otherwise `false`.

### The Core Challenge
1. If `totalSum` is **odd**, it is mathematically impossible to divide an odd integer into two equal integer halves $\rightarrow$ return `false` immediately!
2. If `totalSum` is **even**, the problem reduces directly to the **0/1 Knapsack Decision Problem**:  
   *“Does there exist a subset of `nums` whose elements sum to exactly $\text{target} = \text{totalSum} / 2$?”*

---

**Example 1:**
```
Input:  nums = [1,5,11,5]
Output: true
Explanation: The array can be partitioned as [1, 5, 5] and [11].
```

**Example 2:**
```
Input:  nums = [1,2,3,5]
Output: false
Explanation: The array cannot be partitioned into equal sum subsets.
```

**Constraints:**
- $1 \le \text{nums.length} \le 200$
- $1 \le \text{nums}[i] \le 100$
- Maximum possible `target` $= 200 \times 100 / 2 = 10000$.

## Approach 1 — 2D Dynamic Programming (0/1 Knapsack Matrix)

### Intuition
Let `dp[i][j]` represent whether a sum of `j` can be formed using a subset of the first `i` numbers:
$$\text{dp}[i][j] = \text{dp}[i - 1][j] \lor \text{dp}[i - 1][j - \text{nums}[i - 1]]$$

### C++ Implementation
```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int totalSum = accumulate(nums.begin(), nums.end(), 0);
        if (totalSum % 2 != 0) return false;
        
        int target = totalSum / 2;
        int n = nums.size();
        vector<vector<bool>> dp(n + 1, vector<bool>(target + 1, false));
        
        // Base case: sum 0 is always achievable with empty subset
        for (int i = 0; i <= n; i++) dp[i][0] = true;
        
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= target; j++) {
                if (j >= nums[i - 1]) {
                    dp[i][j] = dp[i - 1][j] || dp[i - 1][j - nums[i - 1]];
                } else {
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        
        return dp[n][target];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \text{target})$ | Fills an $n \times \text{target}$ matrix ($200 \times 10000 = 2 \times 10^6$ ops). |
| **Space** | $O(n \cdot \text{target})$ | 2D table memory. |

## Approach 2 — 1D Space-Optimized 0/1 Knapsack (Backward Scan) ✅

### Key Insight
Because row $i$ only depends on row $i - 1$, we can collapse the 2D table into a **single 1D array `dp[target + 1]`**:
- **Iterate `j` backwards** from `target` down to `num`:
  $$\text{dp}[j] = \text{dp}[j] \lor \text{dp}[j - \text{num}]$$
- Backward iteration guarantees that `dp[j - num]` represents the value from the *previous* element iteration, preventing any element from being used more than once (the defining rule of 0/1 Knapsack).
- If `dp[target]` becomes `true`, early-exit immediately!

```
nums = [1, 5, 11, 5], totalSum = 22, target = 11
dp initialized: dp[0] = true, all others false

num = 1:  dp[1] = T
num = 5:  dp[6] = T, dp[5] = T
num = 11: dp[11] = T (since dp[11 - 11] = dp[0] == T) -> EARLY EXIT TRUE!

Result: true ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int totalSum = accumulate(nums.begin(), nums.end(), 0);
        
        // If total sum is odd, it cannot be partitioned into two equal integers
        if (totalSum % 2 != 0) {
            return false;
        }
        
        int target = totalSum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true;
        
        for (int num : nums) {
            // Traverse backwards to prevent reusing the same number multiple times
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
            
            // Early exit if target sum is already reachable
            if (dp[target]) {
                return true;
            }
        }
        
        return dp[target];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \text{target})$ | At most $200 \times 10000 = 2 \times 10^6$ operations. |
| **Space** | $O(\text{target})$ | 1D boolean array of size $\le 10001$. |

> **This is the one.** Clean, robust 1D space optimization with early termination.

## Approach 3 — Hardware Bitset Shift Optimization (`bitset`)

### Intuition
Represent the reachable sum state as a bitset `bitset<10001> dp`. For each `num`, update all reachable states simultaneously using a single bitwise shift and OR: `dp |= (dp << num)`.

### C++ Implementation
```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int totalSum = accumulate(nums.begin(), nums.end(), 0);
        if (totalSum % 2 != 0) return false;
        
        int target = totalSum / 2;
        bitset<10001> dp(1); // dp[0] = 1
        
        for (int num : nums) {
            dp |= (dp << num);
            if (dp[target]) return true;
        }
        
        return dp[target];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \text{target} / 64)$ | Bitwise 64-bit word parallelism makes execution virtually instantaneous (<1ms). |
| **Space** | $O(\text{target})$ | 10001 bits = ~1.2 KB of memory. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Odd Total Sum** | `[1, 2, 4]` (sum = 7) | Non-integer target | `totalSum % 2 != 0` immediately returns `false`. |
| **Single Element Array** | `[5]` | Partition requires 2 non-empty subsets | `totalSum` is odd, or `target = 0` / loop skips, returns `false`. |
| **Element Exceeds Target** | `[1, 2, 10]` | Negative index | `j >= num` bound prevents out-of-range memory access. |

---

## Pattern Takeaways

1. **0/1 Knapsack Backward Scan Invariant:**  
   `for (int j = target; j >= num; j--)` is the canonical technique to enforce single-use element constraints in 1D dynamic programming.
2. **Bitset Parallelism:**  
   When DP states are purely boolean and maximum capacity is fixed ($M \le 10^5$), `bitset |= (bitset << num)` accelerates state transitions by $64\times$.

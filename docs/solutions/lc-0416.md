## What are we solving?

Given an integer array `nums`, return `true` if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or `false` otherwise.

The reduction is: **can we find a subset summing to exactly $\text{sum} / 2$ (0/1 Knapsack)?**

**Example 1:**
```
Input:  nums = [1,5,11,5]
Output: true
Explanation: The array can be partitioned as [1, 5, 5] and [11].
```

**Example 2:**
```
Input:  nums = [1,2,3,5]
Output: false
Explanation: The array cannot be partitioned into equal sum subsets.
```

**Constraints:**
- $1 \le \text{nums.length} \le 200$
- $1 \le \text{nums}[i] \le 100$

## Approach 1 — 1D 0/1 Knapsack DP (Backward Iteration) ✅

**Key insight:**
1. Compute `totalSum = sum(nums)`. If `totalSum` is odd, return `false`.
2. `target = totalSum / 2`.
3. `dp[j]` boolean array of size `target + 1`: represents whether sum `j` is reachable.
4. Base case: `dp[0] = true`.
5. For each `num` in `nums`:
   - Iterate `j` backwards from `target` down to `num`: `dp[j] = dp[j] || dp[j - num]`.
   - Backward iteration ensures each element is used at most once (0/1 Knapsack).
6. Return `dp[target]`.

```
nums = [1, 5, 11, 5], totalSum = 22, target = 11
dp initialized: dp[0] = true

num=1: dp[1]=T
num=5: dp[6]=T, dp[5]=T
num=11: dp[11]=T (since dp[0]=T) -> REACHED TARGET!

Result: true ✓
```

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int totalSum = 0;
        for (int x : nums) totalSum += x;
        if (totalSum % 2 != 0) return false;
        
        int target = totalSum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true;
        
        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
            if (dp[target]) return true; // early exit
        }
        
        return dp[target];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot \text{target})$ | $O(\text{target})$ |

> **This is the one.** 1D boolean knapsack with early exit.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Odd total sum `[1, 2, 5]` (sum=8... wait, `[1, 2, 4]` sum=7) | Floating point division | `totalSum % 2 != 0` immediately returns `false` |
| Single element array `[5]` | Subset division | Odd sum or empty partition, returns `false` |

---

## Pattern Takeaway

In **0/1 Knapsack DP**, iterating the capacity loop **backwards (`j` from `target` down to `num`)** enables 1D space optimization without using the same element multiple times.

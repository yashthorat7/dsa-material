## What are we solving?

You are given a 0-indexed integer array `nums` of **even length** containing an equal number of positive and negative integers. Rearrange the elements of `nums` such that:
1. Every consecutive pair of integers have opposite signs.
2. For all integers of the same sign, the order in which they were present in `nums` is preserved (stable).
3. The rearranged array begins with a positive integer.

The question is: **how can we place each element at its exact target index in a single pass without extra sorting?**

**Example 1:**
```
Input:  nums = [3,1,-2,-5,2,-4]
Output: [3,-2,1,-5,2,-4]
Explanation: Positive: [3,1,2], Negative: [-2,-5,-4]. Interleaved starting with positive: [3,-2,1,-5,2,-4].
```

**Example 2:**
```
Input:  nums = [-1,1]
Output: [1,-1]
```

**Constraints:**
- $2 \le \text{nums.length} \le 2 \times 10^5$
- `nums.length` is even
- $1 \le |\text{nums}[i]| \le 10^5$
- `nums` consists of equal number of positive and negative integers.

## Approach 1 — Two Pointers Single Pass ✅

**Key insight:** Positive numbers will always occupy even indices `0, 2, 4, ...` and negative numbers will always occupy odd indices `1, 3, 5, ...`. We can initialize `posIdx = 0` and `negIdx = 1`, create a result vector of size $n$, and place each number at its respective pointer in a single pass.

```
nums = [3, 1, -2, -5, 2, -4]
ans = [0, 0, 0, 0, 0, 0]
posIdx = 0, negIdx = 1

x = 3 (>0):  ans[0] = 3,  posIdx -> 2
x = 1 (>0):  ans[2] = 1,  posIdx -> 4
x = -2 (<0): ans[1] = -2, negIdx -> 3
x = -5 (<0): ans[3] = -5, negIdx -> 5
x = 2 (>0):  ans[4] = 2,  posIdx -> 6
x = -4 (<0): ans[5] = -4, negIdx -> 7

Result: [3, -2, 1, -5, 2, -4] ✓
```

```cpp
class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n);
        int posIdx = 0, negIdx = 1;
        for (int num : nums) {
            if (num > 0) {
                result[posIdx] = num;
                posIdx += 2;
            } else {
                result[negIdx] = num;
                negIdx += 2;
            }
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Direct index placement in a single pass.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Minimal input `[-1, 1]` | Negative comes first in input | `posIdx=0` places `1` first, `negIdx=1` places `-1` second -> `[1, -1]` |
| Already alternating `[1, -1, 2, -2]` | Unnecessary shifts | Pointers advance predictably and maintain stability |
| All positives first `[1, 2, 3, -1, -2, -3]` | Out of bounds on posIdx | Guaranteed equal count means posIdx and negIdx will never exceed array bounds |

---

## Pattern Takeaway

When target positions are determined strictly by parity or category (even for positive, odd for negative), **dedicated index pointers** allow direct placement in $O(n)$ time without separate partitioning buffers.

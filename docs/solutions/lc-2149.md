# 2149. Rearrange Array Elements by Sign

> **Medium** $\rightarrow$ **Single-Pass Array Optimization**


> **Companies:** Amazon, Flipkart, Ola, Accenture

## What are we solving?

You are given a 0-indexed integer array `nums` of **even length** containing an equal number of positive and negative integers.

Rearrange the elements of `nums` such that:
1. Every consecutive pair of integers have opposite signs.
2. For all integers of the same sign, the order in which they were present in `nums` is preserved (stable partition).
3. The rearranged array begins with a **positive integer**.

```
 Input:  [ 3, 1, -2, -5, 2, -4 ]
 
 Positives in order: [ 3, 1, 2 ]
 Negatives in order: [ -2, -5, -4 ]
 
 Interleave starting with positive:
 Result: [ 3, -2, 1, -5, 2, -4 ]
 Output: [ 3, -2, 1, -5, 2, -4 ]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($2 \le n \le 2 \times 10^5$, $n$ is even, exactly $n/2$ positive and $n/2$ negative integers).
- **Output:**
  - `vector<int>` of length $n$ with interleaved signed numbers.

### The Index Invariant
Because the output must start with a positive number and strictly alternate:
- All **positive integers** must land on **even indices**: $0, 2, 4, 6, \dots$
- All **negative integers** must land on **odd indices**: $1, 3, 5, 7, \dots$
We can initialize two independent target write pointers `posIdx = 0` and `negIdx = 1`, and route every integer to its destination in a **single pass**!

---

**Example 1:**
```
Input:  nums = [3,1,-2,-5,2,-4]
Output: [3,-2,1,-5,2,-4]
Explanation: Positive: [3,1,2], Negative: [-2,-5,-4].
Interleaved starting with positive: [3,-2,1,-5,2,-4].
```

**Example 2:**
```
Input:  nums = [-1,1]
Output: [1,-1]
```

**Constraints:**
- $2 \le \text{nums.length} \le 2 \times 10^5$
- `nums.length` is even
- $1 \le |\text{nums}[i]| \le 10^5$
- `nums` consists of equal number of positive and negative integers.

## Approach 1 — Two Separate Vectors ($O(n)$ Space)

### Intuition
Split `nums` into two separate vectors `pos` and `neg`. Interleave elements from both into `result` at indices $2i$ and $2i + 1$.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        vector<int> pos, neg;
        for (int x : nums) {
            if (x > 0) pos.push_back(x);
            else neg.push_back(x);
        }
        
        vector<int> result(nums.size());
        for (int i = 0; i < pos.size(); i++) {
            result[2 * i] = pos[i];
            result[2 * i + 1] = neg[i];
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two sequential linear passes. |
| **Space** | $O(n)$ | Allocates two separate auxiliary buffers of size $n/2$. |

> **Verdict:** Suboptimal. Single-pass dual-pointer writing eliminates auxiliary buffers.

## Approach 2 — Single-Pass Dual Pointers (`posIdx = 0, negIdx = 1`) ✅

### Key Insight
1. Allocate `result` vector of size $n$.
2. Maintain `posIdx = 0` and `negIdx = 1`.
3. For each `num` in `nums`:
   - If `num > 0`: `result[posIdx] = num`, `posIdx += 2`.
   - If `num < 0`: `result[negIdx] = num`, `negIdx += 2`.
4. Return `result`.

```
nums = [3, 1, -2, -5, 2, -4]
result = [ _, _, _, _, _, _ ]
posIdx = 0, negIdx = 1

1. x = 3 (>0):  result[0] = 3,  posIdx = 2
2. x = 1 (>0):  result[2] = 1,  posIdx = 4
3. x = -2 (<0): result[1] = -2, negIdx = 3
4. x = -5 (<0): result[3] = -5, negIdx = 5
5. x = 2 (>0):  result[4] = 2,  posIdx = 6
6. x = -4 (<0): result[5] = -4, negIdx = 7

Result: [ 3, -2, 1, -5, 2, -4 ] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n);
        
        int posIdx = 0;
        int negIdx = 1;
        
        for (int num : nums) {
            if (num > 0) {
                result[posIdx] = num;
                posIdx += 2;
            } else {
                result[negIdx] = num;
                negIdx += 2;
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass over $n$ elements ($2 \times 10^5$ iterations max, <5ms). |
| **Space** | $O(n)$ | Output array buffer. |

> **This is the one.** Clean, single-pass direct pointer placement.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Negative Appears First in Input** | `[-1, 1]` | Misordering starting element | `posIdx=0` always places positive `1` first, `negIdx=1` places `-1` second $\implies [1, -1]$. |
| **All Positives Followed by All Negatives** | `[1, 2, -1, -2]` | Pointer overflow | Guaranteed equal count ($n/2$ of each) prevents out-of-bounds access. |

# 238. Product of Array Except Self

https://leetcode.com/problems/product-of-array-except-self

> **Medium** $\rightarrow$ **Prefix Sum**


> **Companies:** Amazon, Meta, Microsoft, Asana, Apple, Uber, Flipkart, Paytm, Wipro

## What are we solving?

Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the **product of all the elements of `nums` except `nums[i]`**.

The product of any prefix or suffix of `nums` is guaranteed to fit in a **32-bit integer**.

You must write an algorithm that runs in **$O(n)$ time** and **without using the division operation `/`**.

```
 Input:  nums = [1, 2, 3, 4]
 
 For index 0: 2 * 3 * 4     = 24
 For index 1: 1 * 3 * 4     = 12
 For index 2: 1 * 2 * 4     = 8
 For index 3: 1 * 2 * 3     = 6
 
 Output: [24, 12, 8, 6]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` with length $2 \le n \le 10^5$, $-30 \le \text{nums}[i] \le 30$.
- **Output:**
  - `vector<int>` where `answer[i]` is the product of all elements excluding `nums[i]`.
- **Constraints:**
  - Must run in strictly $O(n)$ time.
  - Division operator `/` is **strictly forbidden**.
  - Must achieve $O(1)$ auxiliary space (excluding the returned output array).

### The Core Challenge
Every `answer[i]` is the combination of two independent parts:
$$\text{answer}[i] = \underbrace{(\text{nums}[0] \times \dots \times \text{nums}[i-1])}_{\text{Prefix Product (Left of } i\text{)}} \times \underbrace{(\text{nums}[i+1] \times \dots \times \text{nums}[n-1])}_{\text{Suffix Product (Right of } i\text{)}}$$
The challenge is computing both prefix and suffix products for all $n$ positions in linear time without creating auxiliary $O(n)$ prefix and suffix arrays.

---

**Example 1:**
```
Input:  nums = [1,2,3,4]
Output: [24,12,8,6]
```

**Example 2:**
```
Input:  nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
```

**Constraints:**
- $2 \le \text{nums.length} \le 10^5$
- $-30 \le \text{nums}[i] \le 30$
- The product of any prefix or suffix of `nums` is guaranteed to fit in a 32-bit integer.

## Approach 1 — Total Product with Division (Disallowed Baseline)

### Intuition
Calculate the total product of all non-zero elements and count zeroes.
- If $>1$ zeroes: all answers are 0.
- If $1$ zero: the zero index gets the non-zero product; all others get 0.
- If $0$ zeroes: each index gets `totalProduct / nums[i]`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        long long totalProduct = 1;
        int zeroCount = 0;
        
        for (int x : nums) {
            if (x == 0) zeroCount++;
            else totalProduct *= x;
        }
        
        vector<int> result(n, 0);
        if (zeroCount > 1) return result;
        
        for (int i = 0; i < n; i++) {
            if (zeroCount == 1) {
                result[i] = (nums[i] == 0) ? totalProduct : 0;
            } else {
                result[i] = totalProduct / nums[i];
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two linear passes. |
| **Space** | $O(1)$ auxiliary | Output vector memory only. |

> **Verdict:** Violates the problem statement ("solve it without division").

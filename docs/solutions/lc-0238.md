## What are we solving?

Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the product of all the elements of `nums` except `nums[i]`. The product of any prefix or suffix of `nums` is guaranteed to fit in a **32-bit** integer. You must write an algorithm that runs in **$O(n)$ time** and without using the **division operation**.

The question is: **how can we combine left prefix products and right suffix products into the output array with $O(1)$ extra space?**

**Example 1:**
```
Input:  nums = [1,2,3,4]
Output: [24,12,8,6]
```

**Example 2:**
```
Input:  nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
```

**Constraints:**
- $2 \le \text{nums.length} \le 10^5$
- $-30 \le \text{nums}[i] \le 30$
- The product of any prefix or suffix of `nums` is guaranteed to fit in a 32-bit integer.

## Approach 1 — Prefix and Suffix Product in Output Array ✅

**Key insight:**
`answer[i] = (product of all elements left of i) * (product of all elements right of i)`.
1. First pass (left to right): Store prefix products in `answer`, where `answer[i]` is the product of all elements to the left of `i`.
2. Second pass (right to left): Maintain a running `suffix` product variable. Multiply `answer[i] *= suffix`, then update `suffix *= nums[i]`.
Output array is not counted towards extra space complexity.

```
nums = [1, 2, 3, 4]
answer = [1, 1, 1, 1]

Pass 1 (Prefix):
i=0: answer[0] = 1
i=1: answer[1] = answer[0] * nums[0] = 1 * 1 = 1
i=2: answer[2] = answer[1] * nums[1] = 1 * 2 = 2
i=3: answer[3] = answer[2] * nums[2] = 2 * 3 = 6
answer is now [1, 1, 2, 6]

Pass 2 (Suffix):
suffix = 1
i=3: answer[3] = 6 * 1 = 6,  suffix = 1 * 4 = 4
i=2: answer[2] = 2 * 4 = 8,  suffix = 4 * 3 = 12
i=1: answer[1] = 1 * 12 = 12, suffix = 12 * 2 = 24
i=0: answer[0] = 1 * 24 = 24, suffix = 24 * 1 = 24

Result: [24, 12, 8, 6] ✓
```

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(n, 1);
        
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }
        
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= suffix;
            suffix *= nums[i];
        }
        
        return answer;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ (output array excluded) |

> **This is the one.** Division-free, single allocation, optimal $O(1)$ auxiliary space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Contains a single zero `[1, 2, 0, 4]` | Zero propagation | Zero naturally sets all answers except the zero index to 0; zero index gets product of non-zero elements |
| Contains multiple zeroes `[0, 2, 0, 4]` | All values should be zero | Every position receives at least one zero factor, returning `[0, 0, 0, 0]` |
| Negative numbers `[-1, 1, -1, 1]` | Sign flips | Prefix/suffix multiplication preserves accurate algebraic sign |

---

## Pattern Takeaway

When division is forbidden or zeroes exist, **accumulating prefix and suffix accumulators** decomposes global aggregation into two independent linear passes.

## What are we solving?

Given the `head` of a singly linked list, return the **middle node** of the linked list. If there are two middle nodes, return the **second middle** node.

The question is: **how does Floyd's Tortoise and Hare algorithm find the center in a single pass?**

**Example 1:**
```
Input:  head = [1,2,3,4,5]
Output: [3,4,5]
Explanation: The middle node of the list is node 3.
```

**Example 2:**
```
Input:  head = [1,2,3,4,5,6]
Output: [4,5,6]
Explanation: Since the list has two middle nodes with values 3 and 4, we return the second one.
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 100]$.
- $1 \le \text{Node.val} \le 100$

## Approach 1 — Fast and Slow Pointer (Tortoise and Hare) ✅

**Key insight:**
- `slow` advances 1 step at a time (`slow = slow->next`).
- `fast` advances 2 steps at a time (`fast = fast->next->next`).
When `fast == nullptr` (even length) or `fast->next == nullptr` (odd length), `slow` is precisely at the middle node (or second middle node).

```
Odd length: [1, 2, 3, 4, 5]
Init: slow=1, fast=1
Step 1: slow=2, fast=3
Step 2: slow=3, fast=5 (fast->next == null -> stop)
Result: slow = 3 ✓

Even length: [1, 2, 3, 4, 5, 6]
Init: slow=1, fast=1
Step 1: slow=2, fast=3
Step 2: slow=3, fast=5
Step 3: slow=4, fast=null (fast == null -> stop)
Result: slow = 4 ✓
```

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        return slow;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Single pass, elegant $O(1)$ space.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single node `[1]` | Loop termination | `fast->next == null` stops immediately, returns node 1 |
| Two nodes `[1, 2]` | Returning first vs second middle | Takes 1 step, returns second node 2 |

---

## Pattern Takeaway

**2x Speed Pointer Differential** (`fast = fast->next->next`) lands the slow pointer exactly at $\lfloor n/2 \rfloor$ upon reaching the end.

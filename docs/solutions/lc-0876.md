## What are we solving?

Given the `head` of a singly linked list, return the **middle node** of the linked list.

If there are two middle nodes (i.e. even length), return the **second middle node**.

```
 Odd Length:
 (1) -> (2) -> [(3)] -> (4) -> (5)
 Middle Node: 3
 
 Even Length:
 (1) -> (2) -> (3) -> [(4)] -> (5) -> (6)
 Second Middle Node: 4
```

### Input & Output Contract
- **Input:**
  - `head`: `ListNode*` reference ($1 \le n \le 100$, $1 \le \text{Node.val} \le 100$).
- **Output:**
  - `ListNode*`: Pointer to the middle (or second middle) node.

---

**Example 1:**
```
Input:  head = [1,2,3,4,5]
Output: [3,4,5]
Explanation: The middle node of the list is node 3.
```

**Example 2:**
```
Input:  head = [1,2,3,4,5,6]
Output: [4,5,6]
Explanation: Since the list has two middle nodes with values 3 and 4, we return the second one.
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 100]$.
- $1 \le \text{Node.val} \le 100$

## Approach 1 — Two-Pass Counting Traversal

### Intuition
1. **Pass 1:** Count the total number of nodes $N$.
2. **Pass 2:** Traverse from `head` exactly $\lfloor N / 2 \rfloor$ steps and return the pointer.

### C++ Implementation
```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        int count = 0;
        ListNode* curr = head;
        while (curr != nullptr) {
            count++;
            curr = curr->next;
        }
        
        curr = head;
        for (int i = 0; i < count / 2; i++) {
            curr = curr->next;
        }
        
        return curr;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two passes over the linked list ($n + n/2$ steps). |
| **Space** | $O(1)$ | Single integer counter. |

## Approach 2 — Fast and Slow Pointers (Floyd's Tortoise and Hare) ✅

### Key Insight
Maintain two pointers starting at `head`:
- `slow` moves **1 node per step**: `slow = slow->next`.
- `fast` moves **2 nodes per step**: `fast = fast->next->next`.

When `fast` reaches the end of the list:
- If length is **odd**: `fast->next == nullptr`, `slow` is on the exact middle.
- If length is **even**: `fast == nullptr`, `slow` is on the **second middle**.

```
Odd length: [1, 2, 3, 4, 5]
Start: slow=1, fast=1
Step 1: slow=2, fast=3
Step 2: slow=3, fast=5 (fast->next == nullptr -> STOP!)
Result: Node 3 ✓

Even length: [1, 2, 3, 4, 5, 6]
Start: slow=1, fast=1
Step 1: slow=2, fast=3
Step 2: slow=3, fast=5
Step 3: slow=4, fast=nullptr (fast == nullptr -> STOP!)
Result: Node 4 ✓
```

### C++ Implementation
```cpp
/*
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};
*/

class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        
        // Fast moves twice as fast as slow
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        return slow;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass ($\approx n/2$ iterations). |
| **Space** | $O(1)$ | Two pointer registers. |

> **This is the one.** Clean, classic, single-pass pointer differential.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Node** | `[1]` | Loop termination | `fast->next == nullptr` terminates immediately, returns node 1. |
| **Two Nodes** | `[1, 2]` | Returning 1st vs 2nd middle | One step moves `slow` to node 2, `fast` to `nullptr`, returns node 2. |

---

## Pattern Takeaways

1. **2x Speed Pointer Differential:**  
   $$\text{Fast moves at } 2v, \text{ Slow moves at } v \implies \text{When Fast hits end, Slow is at } \lfloor N/2 \rfloor$$

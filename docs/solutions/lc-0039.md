## What are we solving?

Given an array of **distinct** integers `candidates` and a target integer `target`, return a list of all **unique combinations** of `candidates` where the chosen numbers sum to `target`. You may return the combinations in any order.

The **same** number may be chosen from `candidates` an **unlimited number of times**. Two combinations are unique if the frequency of at least one of the chosen numbers is different.

**Example 1:**
```
Input:  candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation: 2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times. 7 is a candidate, and 7 = 7. These are the only two combinations.
```

**Example 2:**
```
Input:  candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
```

**Example 3:**
```
Input:  candidates = [2], target = 1
Output: []
```

**Constraints:**
- $1 \le \text{candidates.length} \le 30$
- $2 \le \text{candidates}[i] \le 40$
- All elements of `candidates` are **distinct**.
- $1 \le \text{target} \le 40$

## Approach 1 — Backtracking with Element Reuse ✅

**Key insight:**
1. Sort `candidates` to allow early pruning when `candidate > remainingTarget`.
2. When choosing element `candidates[i]`, recurse with `start = i` (not `i + 1`) to allow the same element to be reused!
3. Base cases:
   - If `remain == 0`: add `current` to `result`.
   - If `candidates[i] > remain`: break early (since array is sorted).

```
candidates = [2, 3, 6, 7], target = 7

Choose 2: remain=5
  Choose 2: remain=3
    Choose 2: remain=1 -> all > 1, backtrack
    Choose 3: remain=0 -> MATCH! [2, 2, 3]
  Choose 3: remain=2 -> all > 2, backtrack
Choose 3: remain=4
  Choose 3: remain=1 -> backtrack
Choose 7: remain=0 -> MATCH! [7]

Result: [[2, 2, 3], [7]] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, target, candidates, current, result);
        return result;
    }
private:
    void backtrack(int start, int remain, const vector<int>& candidates, vector<int>& current, vector<vector<int>>& result) {
        if (remain == 0) {
            result.push_back(current);
            return;
        }
        
        for (int i = start; i < candidates.size(); i++) {
            if (candidates[i] > remain) break; // early pruning
            current.push_back(candidates[i]);
            backtrack(i, remain - candidates[i], candidates, current, result); // reuse index i
            current.pop_back();
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(N^{\text{target} / \min(\text{candidates})})$ | $O(\text{target} / \min(\text{candidates}))$ |

> **This is the one.** Passing `i` rather than `i + 1` allows unlimited reuse with no duplicates.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| No combination possible `candidates = [2], target = 1` | Infinite recursion | `candidates[0] > remain` breaks immediately, returns `[]` |
| Target is exactly a candidate element | Single element combination | Pushes `[target]` |

---

## Pattern Takeaway

To permit **unlimited element reuse** without generating duplicate permutations, pass **`i` (the current index)** into the recursive call instead of `i + 1`.

## What are we solving?

You are given an $m \times n$ integer array `obstacleGrid`. There is a robot initially located at the top-left corner (`obstacleGrid[0][0]`). The robot tries to move to the bottom-right corner (`obstacleGrid[m - 1][n - 1]`). The robot can only move either **down** or **right** at any point in time.

An obstacle and space are marked as `1` or `0` respectively in `obstacleGrid`. A path that the robot takes cannot include any cell that is an obstacle.

Return the number of possible **unique paths** that the robot can take to reach the bottom-right corner.

```
 Grid (3x3):
 [ 0,  0,  0 ]
 [ 0, (1), 0 ]   <-- (1, 1) is an obstacle
 [ 0,  0,  0 ]
 
 Paths:
 1. Right -> Right -> Down -> Down
 2. Down -> Down -> Right -> Right
 
 Output: 2 unique paths
```

### Input & Output Contract
- **Input:**
  - `obstacleGrid`: `vector<vector<int>>` where $1 \le m, n \le 100$, $\text{grid}[i][j] \in \{0, 1\}$.
- **Output:**
  - `int`: Total unique non-blocked paths.

### The Core Challenge
If cell $(r, c)$ contains an obstacle (`1`), it is an absorbing dead end $\implies \text{dp}[r][c] = 0$.  
Otherwise, paths arrive from either the cell above or the cell to the left:
$$\text{dp}[r][c] = \begin{cases} 0 & \text{if } \text{obstacleGrid}[r][c] == 1 \\ \text{dp}[r - 1][c] + \text{dp}[r][c - 1] & \text{otherwise} \end{cases}$$

---

**Example 1:**
```
Input:  obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
Output: 2
```

**Example 2:**
```
Input:  obstacleGrid = [[0,1],[0,0]]
Output: 1
```

**Constraints:**
- $m == \text{obstacleGrid.length}$
- $n == \text{obstacleGrid}[i].\text{length}$
- $1 \le m, n \le 100$
- `obstacleGrid[i][j]` is `0` or `1`.

## Approach 1 — 2D Dynamic Programming Table

### Intuition
Create a 2D table `dp[m][n]`. Base case: `dp[0][0] = (obstacleGrid[0][0] == 0) ? 1 : 0`. For any non-obstacle cell, sum paths from `dp[r - 1][c]` (Top) and `dp[r][c - 1]` (Left).

### C++ Implementation
```cpp
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();
        if (obstacleGrid[0][0] == 1 || obstacleGrid[m - 1][n - 1] == 1) return 0;
        
        vector<vector<long long>> dp(m, vector<long long>(n, 0));
        dp[0][0] = 1;
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (obstacleGrid[r][c] == 1) {
                    dp[r][c] = 0;
                    continue;
                }
                if (r > 0) dp[r][c] += dp[r - 1][c];
                if (c > 0) dp[r][c] += dp[r][c - 1];
            }
        }
        
        return dp[m - 1][n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Iterates through each cell once. |
| **Space** | $O(m \cdot n)$ | 2D matrix storage. |

## Approach 2 — 1D Space-Optimized DP (Obstacle Zeroing) ✅

### Key Insight
Because each state `dp[r][c]` only depends on `dp[r - 1][c]` (the previous value already stored at `dp[c]`) and `dp[r][c - 1]` (the left neighbor in the current row):
1. Allocate a 1D vector `dp(n, 0)`.
2. Initialize `dp[0] = (obstacleGrid[0][0] == 0 ? 1 : 0)`.
3. For each cell `(r, c)`:
   - If `obstacleGrid[r][c] == 1`: set `dp[c] = 0` (zero out path capacity).
   - Else if `c > 0`: `dp[c] += dp[c - 1]` (add left neighbor).
4. Return `dp[n - 1]`.

```
grid:
0 0 0
0 1 0
0 0 0

Row 0: [ 1, 1, 1 ]
Row 1:
- c=0: dp[0] = 1
- c=1: obstacle! -> dp[1] = 0
- c=2: dp[2] += dp[1](0) -> dp[2] = 1
-> dp = [ 1, 0, 1 ]
Row 2:
- c=0: dp[0] = 1
- c=1: dp[1] += dp[0](1) -> dp[1] = 1
- c=2: dp[2] += dp[1](1) -> dp[2] = 2
-> dp = [ 1, 1, 2 ]

Result: 2 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();
        
        // Use 64-bit integer to prevent temporary intermediate overflow
        vector<long long> dp(n, 0);
        dp[0] = (obstacleGrid[0][0] == 0) ? 1 : 0;
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (obstacleGrid[r][c] == 1) {
                    dp[c] = 0; // Obstacle absorbs and cancels all incoming paths
                } else if (c > 0) {
                    dp[c] += dp[c - 1]; // dp[c] holds top value, dp[c - 1] holds left value
                }
            }
        }
        
        return dp[n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Single pass over the grid. |
| **Space** | $O(n)$ | 1D vector of size $n$. |

> **This is the one.** Clean, space-efficient 1D DP with obstacle zeroing.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Obstacle at Starting Cell `(0, 0)`** | `[[1, 0]]` | `dp[0]` initialized to 1 incorrectly | `dp[0] = (grid[0][0] == 0 ? 1 : 0)` sets `dp[0] = 0`, returning 0. |
| **Obstacle at Target Cell `(m-1, n-1)`** | `[[0, 1]]` | Final answer extraction | `dp[n - 1]` is set to 0 in the final iteration, returning 0. |
| **Complete Wall of Obstacles** | Entire row 1 is `1`s | Paths jumping obstacles | All `dp` entries zeroed out, returning 0. |

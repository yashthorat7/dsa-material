## What are we solving?

Given a binary tree, determine if it is **height-balanced**.

A **height-balanced** binary tree is a binary tree in which the depth of the two subtrees of *every* node never differs by more than 1:
$$|\text{height}(\text{left}) - \text{height}(\text{right})| \le 1$$

```
 Balanced Tree:                    Unbalanced Tree:
        (3)                               (1)
       /   \                             /
     (9)   (20)                        (2)
           /  \                       /
         (15)  (7)                  (3)  <- Left height=3, Right height=0 (diff = 3 > 1)
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root of a binary tree ($0 \le \text{node count} \le 5000$, $-10^4 \le \text{Node.val} \le 10^4$).
- **Output:**
  - `bool`: `true` if all nodes in the tree satisfy the height-balance condition; otherwise `false`.

### The Core Challenge
If we calculate the height of left and right subtrees separately at each node from the top down, the height helper visits nodes repeatedly, resulting in $O(n^2)$ worst-case time. The challenge is computing subtree heights bottom-up in a single pass while immediately propagating an invalid sentinel (`-1`) as soon as any imbalance is detected.

---

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: true
```

**Example 2:**
```
Input:  root = [1,2,2,3,3,null,null,4,4]
Output: false
```

**Example 3:**
```
Input:  root = []
Output: true
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 5000]$.
- $-10^4 \le \text{Node.val} \le 10^4$

## Approach 1 — Top-Down Recursion (Brute Force Height Checks)

### Intuition
For each node:
1. Compute the height of `node->left` and `node->right` using a helper function `height(TreeNode*)`.
2. Check if `abs(height(left) - height(right)) <= 1`.
3. Recursively verify `isBalanced(node->left) && isBalanced(node->right)`.

### C++ Implementation
```cpp
class Solution {
public:
    bool isBalanced(TreeNode* root) {
        if (root == nullptr) return true;
        
        int leftH = height(root->left);
        int rightH = height(root->right);
        
        if (abs(leftH - rightH) > 1) return false;
        
        return isBalanced(root->left) && isBalanced(root->right);
    }

private:
    int height(TreeNode* node) {
        if (node == nullptr) return 0;
        return 1 + max(height(node->left), height(node->right));
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | In a skewed tree, `height()` runs on subtrees of size $n, n-1, \dots, 1$, resulting in $O(n^2)$ operations. |
| **Space** | $O(h)$ | Recursion stack depth bounded by tree height $h$. |

> **Verdict:** Suboptimal due to redundant top-down height recalculations.

## Approach 2 — Bottom-Up DFS with `-1` Sentinel Short-Circuit ✅

### Key Insight
Compute subtree heights in a **post-order (bottom-up)** DFS traversal:
- If a subtree is balanced, return its true height: $1 + \max(\text{leftH}, \text{rightH})$.
- If a subtree is **unbalanced** ($|\text{leftH} - \text{rightH}| > 1$ or any child returned `-1`), immediately return **`-1`**.
- As soon as `-1` is returned by any child, the parent immediately propagates `-1` upwards without doing extra work.

```
Tree: [1, 2, 2, 3, 3, null, null, 4, 4]

checkHeight(4) -> returns 1
checkHeight(3) -> leftH=1, rightH=0 -> diff=1 <= 1 -> returns 2
checkHeight(2) -> leftH=2 (from 3), rightH=0 -> diff = 2 > 1 -> IMBALANCE! Returns -1
Root (1) receives -1 from left child -> immediately returns -1!

checkHeight(root) != -1 evaluates to false ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool isBalanced(TreeNode* root) {
        return checkHeight(root) != -1;
    }

private:
    // Returns height of subtree if balanced, or -1 if unbalanced
    int checkHeight(TreeNode* node) {
        if (node == nullptr) {
            return 0;
        }
        
        int leftH = checkHeight(node->left);
        if (leftH == -1) return -1; // Short-circuit left
        
        int rightH = checkHeight(node->right);
        if (rightH == -1) return -1; // Short-circuit right
        
        // Height difference check
        if (abs(leftH - rightH) > 1) {
            return -1;
        }
        
        return 1 + max(leftH, rightH);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each node in the tree is visited at most once. |
| **Space** | $O(h)$ | Recursion stack depth equals tree height $h$ ($O(\log n)$ balanced, $O(n)$ worst-case skewed). |

> **This is the one.** Single-pass bottom-up evaluation with instantaneous short-circuiting.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Tree** | `root = nullptr` | Base case | `checkHeight(nullptr) = 0 != -1`, returns `true`. |
| **Single Node** | `root = [1]` | Height check | `leftH = 0, rightH = 0`, returns height 1, evaluates `true`. |
| **Deep Imbalance** | `[1, 2, 2, 3, 3, null, null, 4, 4]` | Imbalance deep below balanced root children | `-1` sentinel bubbles up all the way to root. |

---

## Pattern Takeaways

1. **The Error Sentinel Pattern:**  
   When combining depth calculation and validity checks in trees, return `-1` for invalid states and natural height integers for valid states.
2. **Post-Order Subtree Synthesis:**  
   Evaluating child states before making the parent decision guarantees strict $O(n)$ linear traversal across all tree properties.

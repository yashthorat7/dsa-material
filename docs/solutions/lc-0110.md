## What are we solving?

Given a binary tree, determine if it is **height-balanced**.

A height-balanced binary tree is a binary tree in which the depth of the two subtrees of every node never differs by more than one.

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: true
```

**Example 2:**
```
Input:  root = [1,2,2,3,3,null,null,4,4]
Output: false
```

**Example 3:**
```
Input:  root = []
Output: true
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 5000]$.
- $-10^4 \le \text{Node.val} \le 10^4$

## Approach 1 — Bottom-Up DFS with -1 Sentinel ✅

**Key insight:**
Instead of top-down $O(n^2)$ height calculations, compute heights bottom-up.
If any subtree is unbalanced (`|leftH - rightH| > 1` or either child returned `-1`), immediately return `-1` to prune and short-circuit.
Tree is balanced if `checkHeight(root) != -1`.

```
Tree: [1, 2, 2, 3, 3, null, null, 4, 4]
Leaf nodes return 1
Node 3 returns 2 (left has 4)
Node 2 leftH = 2, rightH = 0 -> diff = 2 > 1 -> returns -1 (unbalanced!)
Root receives -1 -> returns false ✓
```

```cpp
class Solution {
public:
    bool isBalanced(TreeNode* root) {
        return checkHeight(root) != -1;
    }
private:
    int checkHeight(TreeNode* node) {
        if (!node) return 0;
        
        int leftH = checkHeight(node->left);
        if (leftH == -1) return -1;
        
        int rightH = checkHeight(node->right);
        if (rightH == -1) return -1;
        
        if (abs(leftH - rightH) > 1) return -1;
        
        return 1 + max(leftH, rightH);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(h)$ |

> **This is the one.** Bottom-up $O(n)$ check with early termination sentinel.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty tree `root = nullptr` | Null check | Returns `true` |
| Root's children balanced but deeper node unbalanced | Only checking root | Sentinel `-1` bubbles up from deepest point |

---

## Pattern Takeaway

Returning a **sentinel error value (`-1`) on violation** avoids redundant $O(n^2)$ top-down height recalculations.

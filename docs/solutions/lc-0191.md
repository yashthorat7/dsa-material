## What are we solving?

Given a positive integer `n`, write a function that returns the number of **set bits** (1-bits, also known as the Hamming weight) in its binary representation.

```
 n = 11 (Decimal)
 Binary Representation: 00000000000000000000000000001011
 Set Bits (1s): 3
 
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `n`: `int` (or `uint32_t`) positive integer ($1 \le n \le 2^{31} - 1$).
- **Output:**
  - `int`: Count of set bits ($1 \dots 32$).

---

**Example 1:**
```
Input:  n = 11
Output: 3
Explanation: The input binary string 1011 has a total of three set bits.
```

**Example 2:**
```
Input:  n = 128
Output: 1
Explanation: The input binary string 10000000 has a total of one set bit.
```

**Example 3:**
```
Input:  n = 2147483645
Output: 30
```

**Constraints:**
- $1 \le n \le 2^{31} - 1$

## Approach 1 — Standard 32-Bit Scan

### Intuition
Inspect each of the 32 bits individually using bitwise AND (`n & 1`) and right-shift `n >>= 1`.

### C++ Implementation
```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        for (int i = 0; i < 32; i++) {
            if ((n >> i) & 1) {
                count++;
            }
        }
        return count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(1)$ | Exactly 32 loop iterations. |
| **Space** | $O(1)$ | Single counter. |

## Approach 2 — Brian Kernighan's Algorithm (`n & (n - 1)`) ✅

### Key Insight
Subtracting `1` from any binary integer flips all bits from the rightmost set bit up to the end:
$$n = 12 \ (1100_2), \quad n - 1 = 11 \ (1011_2) \implies n \ \& \ (n - 1) = 1000_2 \ (8)$$
**The operation `n &= (n - 1)` clears the lowest set bit (1-bit) of `n` in a single CPU instruction!**  
Instead of running 32 times, the loop executes **only as many times as there are 1-bits ($k \le 32$)**.

```
n = 11 (1011₂)

Iteration 1:
- n = 11 & 10 = 1011₂ & 1010₂ = 1010₂ (10)
- count = 1

Iteration 2:
- n = 10 & 9  = 1010₂ & 1001₂ = 1000₂ (8)
- count = 2

Iteration 3:
- n = 8 & 7   = 1000₂ & 0111₂ = 0000₂ (0)
- count = 3

Loop ends since n == 0.

Result: 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1); // Clears the lowest set bit
            count++;
        }
        return count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(k)$ | Where $k$ is the number of set bits ($k \le 32$). For powers of two, executes in 1 iteration! |
| **Space** | $O(1)$ | Register scalar variable. |

> **This is the one.** Minimizes loop iterations directly to the exact count of set bits.

## Approach 3 — Hardware Instruction (`__builtin_popcount` / `popcount`)

### Intuition
Modern x86 and ARM processors include dedicated `POPCNT` assembly instructions that calculate Hamming weight in 1 single CPU clock cycle.

### C++ Implementation
```cpp
class Solution {
public:
    int hammingWeight(int n) {
        return __builtin_popcount(static_cast<unsigned int>(n));
    }
};
```

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Power of Two** | `n = 128 (10000000₂)` | Redundant loops | Clears in exactly 1 iteration, returns 1. |
| **All Bits Set (`INT_MAX`)** | `n = 2147483647` | Overflow | Runs 31 times safely, returns 31. |

---

## Pattern Takeaways

1. **The Brian Kernighan Trick:**  
   `n & (n - 1)` clears the lowest set bit.
2. **Power of Two Check:**  
   An integer $n > 0$ is a power of two if and only if `(n & (n - 1)) == 0`.
3. **Lowest Set Bit Isolation:**  
   `n & (-n)` isolates the lowest set bit as a standalone value (crucial for Fenwick Trees / Binary Indexed Trees).

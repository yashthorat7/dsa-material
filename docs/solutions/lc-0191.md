## What are we solving?

Given a positive integer `n`, write a function that returns the number of set bits (also known as the Hamming weight) in its binary representation.

The question is: **how can Brian Kernighan's bit trick `n & (n - 1)` clear the lowest set bit in $O(\text{number of set bits})$ time?**

**Example 1:**
```
Input:  n = 11
Output: 3
Explanation: The input binary string 1011 has a total of three set bits.
```

**Example 2:**
```
Input:  n = 128
Output: 1
Explanation: The input binary string 10000000 has a total of one set bit.
```

**Example 3:**
```
Input:  n = 2147483645
Output: 30
```

**Constraints:**
- $1 \le n \le 2^{31} - 1$

## Approach 1 — Brian Kernighan's Bit Trick ✅

**Key insight:**
The operation `n & (n - 1)` always flips the **least significant set bit (1-bit)** of `n` to `0`.
Instead of looping 32 times, we loop only as many times as there are `1`s in `n`.

```
n = 11 (1011₂)
1. n = 11 & 10 = 1011₂ & 1010₂ = 1010₂ (10), count = 1
2. n = 10 & 9  = 1010₂ & 1001₂ = 1000₂ (8),  count = 2
3. n = 8 & 7   = 1000₂ & 0111₂ = 0000₂ (0),  count = 3
Loop ends.

Result: 3 ✓
```

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);
            count++;
        }
        return count;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(k)$ where $k$ is the number of set bits ($k \le 32$) | $O(1)$ |

> **This is the one.** Minimizes iterations to exact set-bit count.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Power of 2 `n = 128 (10000000₂)` | Multiple loop iterations | Clears in exactly 1 iteration |
| All 31 bits set `INT_MAX` | Overflow | Runs 31 times safely |

---

## Pattern Takeaway

**`n & (n - 1)`** clears the lowest set bit in $O(1)$. It is foundational for bit manipulation, Fenwick trees, and checking powers of 2 (`(n & (n-1)) == 0`).

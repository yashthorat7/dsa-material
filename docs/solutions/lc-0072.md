> **Companies:** Amazon, LinkedIn, Microsoft, Google, Apple, Bloomberg, Flipkart, Directi, TCS

## What are we solving?

Given two strings `word1` and `word2`, return the **minimum number of operations** required to convert `word1` to `word2`.

You have the following three operations permitted on a word:
1. **Insert** a character
2. **Delete** a character
3. **Replace** a character

```
 word1 = "horse",  word2 = "ros"
 
 Step 1: horse -> rorse  (replace 'h' with 'r')
 Step 2: rorse -> rose   (delete 'r')
 Step 3: rose  -> ros    (delete 'e')
 
 Total Operations = 3
```

### Input & Output Contract
- **Input:**
  - `word1`: `string` of length $0 \le m \le 500$, lowercase English letters.
  - `word2`: `string` of length $0 \le n \le 500$, lowercase English letters.
- **Output:**
  - `int`: Minimum edit operations (Levenshtein Distance).

### The Core Challenge
At any prefix indices $(i, j)$:
- If `word1[i-1] == word2[j-1]`: characters match $\rightarrow \text{cost} = \text{dp}[i-1][j-1]$ (0 operations).
- If characters differ: we must take $1 + \min$ among 3 choices:
  1. **Insert:** $\text{dp}[i][j-1]$ (matched `word2[j-1]` by inserting into `word1`).
  2. **Delete:** $\text{dp}[i-1][j]$ (deleted `word1[i-1]`).
  3. **Replace:** $\text{dp}[i-1][j-1]$ (replaced `word1[i-1]` with `word2[j-1]`).

---

**Example 1:**
```
Input:  word1 = "horse", word2 = "ros"
Output: 3
```

**Example 2:**
```
Input:  word1 = "intention", word2 = "execution"
Output: 5
```

**Constraints:**
- $0 \le \text{word1.length}, \text{word2.length} \le 500$
- `word1` and `word2` consist of lowercase English letters.

## Approach 1 — Top-Down Recursion with Memoization

### Intuition
Define `solve(i, j)` as the minimum operations to convert `word1[0..i-1]` to `word2[0..j-1]`.
- If `word1[i-1] == word2[j-1]`: cost is `solve(i - 1, j - 1)`.
- Else: take $1 + \min(\text{insert: } solve(i, j-1), \text{delete: } solve(i-1, j), \text{replace: } solve(i-1, j-1))$.
Memoize in a 2D vector `memo[m+1][n+1]`.

### C++ Implementation
```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        vector<vector<int>> memo(m + 1, vector<int>(n + 1, -1));
        return dfs(m, n, word1, word2, memo);
    }

private:
    int dfs(int i, int j, const string& w1, const string& w2, vector<vector<int>>& memo) {
        if (i == 0) return j; // Must insert all j characters
        if (j == 0) return i; // Must delete all i characters
        if (memo[i][j] != -1) return memo[i][j];
        
        if (w1[i - 1] == w2[j - 1]) {
            return memo[i][j] = dfs(i - 1, j - 1, w1, w2, memo);
        }
        
        int insertOp = dfs(i, j - 1, w1, w2, memo);
        int deleteOp = dfs(i - 1, j, w1, w2, memo);
        int replaceOp = dfs(i - 1, j - 1, w1, w2, memo);
        
        return memo[i][j] = 1 + min({insertOp, deleteOp, replaceOp});
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | $m \times n$ subproblems, each resolved in $O(1)$. |
| **Space** | $O(m \cdot n)$ | Memo table of size $(m+1) \times (n+1)$ plus recursion stack. |

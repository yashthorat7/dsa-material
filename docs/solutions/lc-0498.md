## What are we solving?

Given an `m x n` matrix `mat`, return an array of all the elements of the array in a **diagonal order**. The traversal alternates direction with each diagonal (up-right then down-left).

The invariant is: **all elements on the same diagonal have identical index sum `i + j = d`.**

**Example 1:**
```
Input:  mat = [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,4,7,5,3,6,8,9]
```

**Example 2:**
```
Input:  mat = [[1,2],[3,4]]
Output: [1,2,3,4]
```

**Constraints:**
- $m == \text{mat.length}$
- $n == \text{mat}[i].\text{length}$
- $1 \le m, n \le 10^4$
- $1 \le m \times n \le 10^4$
- $-10^5 \le \text{mat}[i][j] \le 10^5$

## Approach 1 — Diagonal Sum Grouping with Parity Reversal ✅

**Key insight:**
There are $(m + n - 1)$ diagonals, indexed by sum $d = i + j$ from $0$ to $m + n - 2$.
- When $d$ is **even**: diagonal goes **up-right** (increasing $j$, decreasing $i$).
- When $d$ is **odd**: diagonal goes **down-left** (increasing $i$, decreasing $j$).
We can either traverse directly using bounds or collect elements into diagonal buckets and reverse even-indexed buckets.

```
mat = [[1, 2, 3],
       [4, 5, 6],
       [7, 8, 9]]

d=0 (even): [1] -> [1]
d=1 (odd):  [2, 4] -> [2, 4]
d=2 (even): [7, 5, 3] -> up-right: [7, 5, 3]
d=3 (odd):  [6, 8] -> [6, 8]
d=4 (even): [9] -> [9]

Result: [1, 2, 4, 7, 5, 3, 6, 8, 9] ✓
```

```cpp
class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
        if (mat.empty()) return {};
        int m = mat.size(), n = mat[0].size();
        vector<int> result;
        
        for (int d = 0; d < m + n - 1; d++) {
            if (d % 2 == 0) {
                // Up-Right: start at lowest valid row
                int r = min(d, m - 1);
                int c = d - r;
                while (r >= 0 && c < n) {
                    result.push_back(mat[r][c]);
                    r--;
                    c++;
                }
            } else {
                // Down-Left: start at lowest valid col
                int c = min(d, n - 1);
                int r = d - c;
                while (c >= 0 && r < m) {
                    result.push_back(mat[r][c]);
                    r++;
                    c--;
                }
            }
        }
        
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(1)$ (output vector excluded) |

> **This is the one.** Direct mathematical index generation without auxiliary bucket buffers.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single row or column matrix `[[1, 2, 3]]` | Index bounds `r < m` and `c < n` | `min(d, m-1)` and boundary checks restrict traversal to valid dimensions |
| Square vs non-square matrix | Unequal m and n | `d < m + n - 1` covers all diagonal sums |

---

## Pattern Takeaway

Anti-diagonal elements are grouped by constant sum **$i + j = d$**, while main-diagonal elements are grouped by constant difference **$i - j = k$**.

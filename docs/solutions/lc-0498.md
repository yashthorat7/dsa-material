## What are we solving?

Given an $m \times n$ matrix `mat`, return an array of all the elements of the array in a **diagonal order**.

The traversal alternates direction with each diagonal (up-right, then down-left, and so forth).

```
 Input Matrix:
 [ [ 1, 2, 3 ],
   [ 4, 5, 6 ],
   [ 7, 8, 9 ] ]
   
 Diagonal 0 (Sum 0, Up-Right):    [ 1 ]
 Diagonal 1 (Sum 1, Down-Left):   [ 2, 4 ]
 Diagonal 2 (Sum 2, Up-Right):    [ 7, 5, 3 ]
 Diagonal 3 (Sum 3, Down-Left):   [ 6, 8 ]
 Diagonal 4 (Sum 4, Up-Right):    [ 9 ]
 
 Output: [ 1, 2, 4, 7, 5, 3, 6, 8, 9 ]
```

### Input & Output Contract
- **Input:**
  - `mat`: `vector<vector<int>>` ($1 \le m, n \le 10^4$, $1 \le m \times n \le 10^4$, $-10^5 \le \text{mat}[i][j] \le 10^5$).
- **Output:**
  - `vector<int>`: 1D array containing flattened diagonal order.

### The Diagonal Sum Invariant
In any 2D grid:
- All cells lying along the same anti-diagonal share the **exact same sum of indices**:
  $$\mathbf{d = r + c}$$
- There are exactly $m + n - 1$ total diagonals ($d \in [0 \dots m + n - 2]$).
- When $d$ is **even**: the diagonal travels **Up-Right** ($\nearrow$, decreasing row $r$, increasing col $c$).
- When $d$ is **odd**: the diagonal travels **Down-Left** ($\swarrow$, increasing row $r$, decreasing col $c$).

**Example 1:**
```
Input:  mat = [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,4,7,5,3,6,8,9]
```

**Example 2:**
```
Input:  mat = [[1,2],[3,4]]
Output: [1,2,3,4]
```

**Constraints:**
- $m == \text{mat.length}$
- $n == \text{mat}[i].\text{length}$
- $1 \le m, n \le 10^4$
- $1 \le m \times n \le 10^4$
- $-10^5 \le \text{mat}[i][j] \le 10^5$

## Approach 1 — Diagonal Buckets Grouping ($O(mn)$ Space)

### Intuition
Group all matrix cells by diagonal index $d = r + c$. Store elements of diagonal $d$ in a vector. Reverse even-indexed diagonals before concatenating into the final result.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
        if (mat.empty() || mat[0].empty()) return {};
        int m = mat.size(), n = mat[0].size();
        vector<vector<int>> diagonals(m + n - 1);
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                diagonals[r + c].push_back(mat[r][c]);
            }
        }
        
        vector<int> result;
        for (int d = 0; d < m + n - 1; d++) {
            if (d % 2 == 0) {
                reverse(diagonals[d].begin(), diagonals[d].end());
            }
            result.insert(result.end(), diagonals[d].begin(), diagonals[d].end());
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Linear bucket insertion and diagonal concatenation. |
| **Space** | $O(m \cdot n)$ | 2D vector storing all diagonal elements. |

> **Verdict:** Suboptimal space. Direct boundary bouncing requires $O(1)$ extra space.

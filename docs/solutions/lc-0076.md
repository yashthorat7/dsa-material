https://leetcode.com/problems/minimum-window-substring

> **Hard** $\rightarrow$ **Sliding Window**

## What are we solving?

Given two strings `s` and `t` of lengths `m` and `n` respectively, return the **minimum window substring** of `s` such that every character in `t` (including duplicate frequencies) is included in the window.

If there is no such substring, return the empty string `""`.

The testcases will be generated such that the answer is **unique**.

```
 s = " A  D  O  B  E  C  O  D  E  B  A  N  C ",  t = "ABC"
                           [--------------]
                            "B A N C"
                            Includes: 'B' (1), 'A' (1), 'C' (1)
                            Length: 4 (Minimum possible window)
                            
 Output: "BANC"
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of length $1 \le m \le 10^5$, containing uppercase and lowercase English letters.
  - `t`: `string` of length $1 \le n \le 10^5$, containing target characters.
- **Output:**
  - `string` representing the shortest contiguous substring in `s` that satisfies the character frequency contract of `t`.

### The Core Challenge
A naive check of all $\frac{m(m+1)}{2}$ substrings is $O(m^2 \cdot \Sigma)$, which easily TLEs when $m = 10^5$. We must maintain a dynamic window `[left, right]` where:
- Expanding `right` satisfies needed character deficits.
- Shrinking `left` minimizes the window while maintaining the validity condition in $O(1)$ per step.

---

**Example 1:**
```
Input:  s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
Explanation: The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.
```

**Example 2:**
```
Input:  s = "a", t = "a"
Output: "a"
```

**Example 3:**
```
Input:  s = "a", t = "aa"
Output: ""
Explanation: Both 'a's from t must be included. s only has one 'a', so return "".
```

**Constraints:**
- $m == s.\text{length}$
- $n == t.\text{length}$
- $1 \le m, n \le 10^5$
- `s` and `t` consist of uppercase and lowercase English letters.

## Approach 1 — Brute Force (Check All Substrings)

### Intuition
Examine every possible substring $s[i..j]$. Check if it contains all characters of $t$ with required frequencies. Track the shortest valid substring.

### C++ Implementation
```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        int m = s.size(), n = t.size();
        if (m < n) return "";
        
        vector<int> targetCount(128, 0);
        for (char c : t) targetCount[c]++;
        
        string minWin = "";
        int minLen = INT_MAX;
        
        for (int i = 0; i < m; i++) {
            vector<int> currentCount(128, 0);
            for (int j = i; j < m; j++) {
                currentCount[s[j]]++;
                
                // Check if window s[i..j] contains all chars of t
                bool valid = true;
                for (int k = 0; k < 128; k++) {
                    if (currentCount[k] < targetCount[k]) {
                        valid = false;
                        break;
                    }
                }
                
                if (valid) {
                    if (j - i + 1 < minLen) {
                        minLen = j - i + 1;
                        minWin = s.substr(i, minLen);
                    }
                    break; // Early break since j will only make window larger
                }
            }
        }
        
        return minWin;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m^2 \cdot 128) = O(m^2)$ | Quadratic substring generation with ASCII checks. TLEs for $m = 10^5$. |
| **Space** | $O(1)$ | 128-element frequency arrays. |

> **Verdict:** Suboptimal. Dynamic sliding window with match count tracking achieves $O(m + n)$ linear time.

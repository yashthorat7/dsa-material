# 743. Network Delay Time

https://leetcode.com/problems/network-delay-time

> **Medium** $\rightarrow$ **Graph Traversal**


> **Companies:** Google, Amazon, Ola, Swiggy, Infosys

## What are we solving?

You are given a network of $n$ nodes, labeled from $1$ to $n$. You are also given `times`, a list of travel times as directed edges `times[i] = [u, v, w]`, where $u$ is the source node, $v$ is the target node, and $w$ is the time it takes for a signal to travel from source to target.

We will send a signal from a given node $k$. Return the **minimum time** it takes for all $n$ nodes to receive the signal. If it is impossible for all $n$ nodes to receive the signal, return `-1`.

```
 Network:
     (2) --- 1 ---> (1)
      |
      1
      v
     (3) --- 1 ---> (4)
     
 Source k = 2
 Shortest arrival times:
 - Node 2: 0 ms
 - Node 1: 1 ms
 - Node 3: 1 ms
 - Node 4: 2 ms (via 2 -> 3 -> 4)
 
 All nodes receive signal at max(0, 1, 1, 2) = 2 ms
 Output: 2
```

### Input & Output Contract
- **Input:**
  - `times`: `vector<vector<int>>` ($1 \le |\text{times}| \le 6000$, non-negative weights $0 \le w \le 100$).
  - `n`: `int` number of nodes ($1 \le n \le 100$).
  - `k`: `int` source node ($1 \le k \le n$).
- **Output:**
  - `int`: Maximum shortest-path distance to all reachable nodes, or `-1` if any node is unreachable.

---

**Example 1:**
```
Input:  times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
Output: 2
```

**Example 2:**
```
Input:  times = [[1,2,1]], n = 2, k = 1
Output: 1
```

**Example 3:**
```
Input:  times = [[1,2,1]], n = 2, k = 2
Output: -1
```

**Constraints:**
- $1 \le k \le n \le 100$
- $1 \le \text{times.length} \le 6000$
- $\text{times}[i].\text{length} == 3$
- $1 \le u_i, v_i \le n$
- $u_i \neq v_i$
- $0 \le w_i \le 100$
- All the pairs $(u_i, v_i)$ are unique.

## Approach 1 — Dijkstra's Algorithm with Min-Heap ✅

### Key Insight
Because edge weights are non-negative ($w \ge 0$), **Dijkstra's Algorithm** computes single-source shortest paths greedily:
1. Maintain `dist` array of size $n + 1$ filled with `INT_MAX`, with `dist[k] = 0`.
2. Push `{0, k}` into a min-priority queue `pq` storing pairs `{distance, node}`.
3. While `pq` is not empty:
   - Extract `{d, u} = pq.top()`.
   - If `d > dist[u]`, discard (stale entry).
   - For every directed neighbor `{v, weight}` of $u$:
     - If `dist[u] + weight < dist[v]`:
       - `dist[v] = dist[u] + weight`
       - `pq.push({dist[v], v})`
4. The answer is $\max_{1 \le i \le n} \text{dist}[i]$. If any $\text{dist}[i] == \text{INT\_MAX}$, return `-1`.

```
times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
dist = [∞, ∞, 0, ∞, ∞]
pq = [ {0, 2} ]

Pop (0, 2):
- Relax to 1: dist[1] = 1, push {1, 1}
- Relax to 3: dist[3] = 1, push {1, 3}

Pop (1, 1): No outgoing edges
Pop (1, 3):
- Relax to 4: dist[4] = 1 + 1 = 2, push {2, 4}

Pop (2, 4): Done.

dist = [-, 1, 0, 1, 2]
Max delay = max(1, 0, 1, 2) = 2 ms ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        // Step 1: Build Adjacency List
        vector<vector<pair<int, int>>> adj(n + 1);
        for (const auto& t : times) {
            adj[t[0]].push_back({t[1], t[2]}); // {neighbor, weight}
        }
        
        // Step 2: Initialize Dijkstra distance table and Min-Heap
        vector<int> dist(n + 1, INT_MAX);
        priority_queue<pair<int, int>, 
                            vector<pair<int, int>>, 
                            greater<pair<int, int>>> pq;
        
        dist[k] = 0;
        pq.push({0, k}); // {time, node}
        
        // Step 3: Dijkstra Relaxation Loop
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            
            // Skip outdated heap entries
            if (d > dist[u]) continue;
            
            for (const auto& [v, weight] : adj[u]) {
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    pq.push({dist[v], v});
                }
            }
        }
        
        // Step 4: Find maximum delay to any node
        int maxDelay = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == INT_MAX) {
                return -1; // Node i is unreachable
            }
            maxDelay = max(maxDelay, dist[i]);
        }
        
        return maxDelay;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(E \log V)$ | Min-heap operations take $O(\log V)$ per edge relaxation. |
| **Space** | $O(V + E)$ | Adjacency list and distance array. |

> **This is the one.** Standard, optimal Single-Source Shortest Path solution.

## Approach 2 — Bellman-Ford Algorithm ($O(V \cdot E)$)

### Intuition
Relax all $E$ edges $n - 1$ times. If no distance improves in a round, terminate early.

### C++ Implementation
```cpp
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<int> dist(n + 1, INT_MAX);
        dist[k] = 0;
        
        for (int i = 1; i <= n - 1; i++) {
            bool updated = false;
            for (const auto& edge : times) {
                int u = edge[0], v = edge[1], w = edge[2];
                if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    updated = true;
                }
            }
            if (!updated) break;
        }
        
        int maxDelay = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == INT_MAX) return -1;
            maxDelay = max(maxDelay, dist[i]);
        }
        return maxDelay;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V \cdot E)$ | $100 \times 6000 = 6 \times 10^5$ operations. |
| **Space** | $O(V)$ | 1D distance array. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Disconnected Node** | `k = 2`, graph has isolated node 5 | Returning partial maximum | `dist[5] == INT_MAX` immediately triggers `-1`. |
| **Single Node Network** | `n = 1, k = 1, times = []` | Distance loop bounds | `dist[1] = 0`, returns 0. |

## Pattern Takeaways

1. **Dijkstra vs Bellman-Ford Selection:**  
   - Non-negative edge weights $\implies$ Use **Dijkstra** ($O(E \log V)$).
   - Negative edge weights $\implies$ Use **Bellman-Ford** ($O(V \cdot E)$).

## What are we solving?

You are given a network of `n` nodes, labeled from `1` to `n`. You are also given `times`, a list of travel times as directed edges `times[i] = [ui, vi, wi]`, where `ui` is the source node, `vi` is the target node, and `wi` is the time it takes for a signal to travel from source to target.

We will send a signal from a given node `k`. Return the **minimum time** it takes for all the `n` nodes to receive the signal. If it is impossible for all the `n` nodes to receive the signal, return `-1`.

**Example 1:**
```
Input:  times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
Output: 2
```

**Example 2:**
```
Input:  times = [[1,2,1]], n = 2, k = 1
Output: 1
```

**Example 3:**
```
Input:  times = [[1,2,1]], n = 2, k = 2
Output: -1
```

**Constraints:**
- $1 \le k \le n \le 100$
- $1 \le \text{times.length} \le 6000$
- $\text{times}[i].\text{length} == 3$
- $1 \le u_i, v_i \le n$
- $u_i \neq v_i$
- $0 \le w_i \le 100$
- All the pairs $(u_i, v_i)$ are **unique**.

## Approach 1 — Dijkstra's Shortest Path Algorithm ✅

**Key insight:**
This is finding the single-source shortest path from `k` to all other nodes.
1. Maintain `dist[n + 1]` initialized to $\infty$, with `dist[k] = 0`.
2. Min-heap `priority_queue` storing `{time, node}`.
3. Extract minimum `{d, u}`:
   - If `d > dist[u]`, skip (stale entry).
   - For each neighbor `{v, weight}`: if `dist[u] + weight < dist[v]`, update `dist[v] = dist[u] + weight` and push `{dist[v], v}`.
4. Total delay is $\max(\text{dist}[1..n])$. If any node has $\text{dist} = \infty$, return `-1`.

```
times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
dist = [∞, ∞, 0, ∞, ∞]
pq = [{0, 2}]

Pop (0, 2):
  relax to 1: dist[1] = 1, pq=[{1,1}]
  relax to 3: dist[3] = 1, pq=[{1,1}, {1,3}]
Pop (1, 1): leaf
Pop (1, 3):
  relax to 4: dist[4] = 1 + 1 = 2, pq=[{2,4}]
Pop (2, 4): done.

dist = [-, 1, 0, 1, 2] -> max delay = 2 ✓
```

```cpp
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int, int>>> adj(n + 1);
        for (const auto& t : times) {
            adj[t[0]].push_back({t[1], t[2]}); // {neighbor, weight}
        }
        
        vector<int> dist(n + 1, INT_MAX);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
        
        dist[k] = 0;
        pq.push({0, k}); // {time, node}
        
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            
            if (d > dist[u]) continue;
            
            for (auto& [v, w] : adj[u]) {
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.push({dist[v], v});
                }
            }
        }
        
        int maxDelay = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == INT_MAX) return -1;
            maxDelay = max(maxDelay, dist[i]);
        }
        
        return maxDelay;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(E \log V)$ | $O(V + E)$ |

> **This is the one.** Optimal Dijkstra's algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Unreachable nodes exist | Returning partial max | `dist[i] == INT_MAX` returns `-1` |
| Single node network `n = 1, k = 1` | Delay calculation | Returns 0 |

---

## Pattern Takeaway

**Dijkstra's Algorithm with a Min-Heap** finds single-source shortest paths in non-negative weighted graphs in $O(E \log V)$.

## What are we solving?

Given a root node reference of a BST and a `key`, delete the node with the given `key` in the BST. Return the **root node reference** (possibly updated) of the BST.

Basically, the deletion can be divided into two stages:
1. Search for a node to remove.
2. If the node is found, delete the node.

**Example 1:**
```
Input:  root = [5,3,6,2,4,null,7], key = 3
Output: [5,4,6,2,null,null,7]
Explanation: Given key to delete is 3. So we find the node with value 3 and delete it.
One valid answer is [5,4,6,2,null,null,7], shown in the above BST.
Please notice that another valid answer is [5,2,6,null,4,null,7] and it's also accepted.
```

**Example 2:**
```
Input:  root = [5,3,6,2,4,null,7], key = 0
Output: [5,3,6,2,4,null,7]
Explanation: The tree does not contain a node with value = 0.
```

**Example 3:**
```
Input:  root = [], key = 0
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-10^5 \le \text{Node.val} \le 10^5$
- Each node has a **unique** value.
- `root` is a valid binary search tree.
- $-10^5 \le \text{key} \le 10^5$

## Approach 1 — Recursive BST Deletion with In-Order Successor ✅

**Key insight:**
1. Search:
   - If `key < root->val`: `root->left = deleteNode(root->left, key)`.
   - If `key > root->val`: `root->right = deleteNode(root->right, key)`.
2. Delete (`root->val == key`):
   - Case 1 (0 or 1 child): If `!root->left`, return `root->right`; if `!root->right`, return `root->left`.
   - Case 2 (2 children): Find the **in-order successor** (smallest node in right subtree). Copy successor's value to `root->val`, then delete successor from right subtree: `root->right = deleteNode(root->right, successor->val)`.

```
Delete key = 3 from:
      5
     / \
    3   6
   / \   \
  2   4   7

1. Found node 3 (has 2 children 2 and 4).
2. In-order successor = 4 (leftmost node in right subtree).
3. Overwrite 3 with 4.
4. Delete 4 from right subtree -> right child of 4 becomes null.
Result: [5, 4, 6, 2, null, null, 7] ✓
```

```cpp
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (!root) return nullptr;
        
        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else if (key > root->val) {
            root->right = deleteNode(root->right, key);
        } else {
            // Node found
            if (!root->left) {
                TreeNode* rightChild = root->right;
                delete root;
                return rightChild;
            }
            if (!root->right) {
                TreeNode* leftChild = root->left;
                delete root;
                return leftChild;
            }
            
            // Node has 2 children: find in-order successor (min in right subtree)
            TreeNode* successor = root->right;
            while (successor->left) {
                successor = successor->left;
            }
            root->val = successor->val;
            root->right = deleteNode(root->right, successor->val);
        }
        
        return root;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(h)$ where $h$ is BST height | $O(h)$ |

> **This is the one.** Standard Hibbard deletion algorithm for BSTs.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Key not found in tree | Modifying tree | Searches to null and returns original tree unchanged |
| Deleting the root node | Root pointer assignment | Returns new replacement root node |

---

## Pattern Takeaway

Deleting a node with two children in a BST is reduced to **replacing its value with its In-Order Successor** and deleting that successor from the right subtree.

## What are we solving?

Given a root node reference of a BST and a `key`, delete the node with the given `key` in the BST. Return the **root node reference** (possibly updated) of the BST.

Basically, the deletion can be divided into two stages:
1. **Search** for the node to remove using BST ordering properties.
2. If the node is found, **delete** it while preserving all BST invariants ($L < \text{Root} < R$).

```
 Delete key = 3:
       5                     5
      / \                   / \
    (3)  6      --->       4   6
    / \   \               /     \
   2   4   7             2       7
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` root of a valid BST ($0 \le n \le 10^4$, $-10^5 \le \text{Node.val} \le 10^5$, all values unique).
  - `key`: `int` value to delete.
- **Output:**
  - `TreeNode*`: Updated BST root after deletion.

### The 3 Deletion Cases (Hibbard Deletion)
When the target node is located:
1. **Case 1 (Leaf node / No children):** Return `nullptr`.
2. **Case 2 (Single child):** Return the existing non-null child (`root->left` or `root->right`) to replace the target node.
3. **Case 3 (Two children):**
   - Find the **In-Order Successor** (the smallest value in the right subtree: leftmost node of `root->right`).
   - Copy the successor's value into the target node: `root->val = successor->val`.
   - Recursively delete the successor from the right subtree: `root->right = deleteNode(root->right, successor->val)`.

---

**Example 1:**
```
Input:  root = [5,3,6,2,4,null,7], key = 3
Output: [5,4,6,2,null,null,7]
Explanation: One valid answer is [5,4,6,2,null,null,7], shown in the above BST.
Another valid answer is [5,2,6,null,4,null,7].
```

**Example 2:**
```
Input:  root = [5,3,6,2,4,null,7], key = 0
Output: [5,3,6,2,4,null,7]
Explanation: The tree does not contain a node with value = 0.
```

**Example 3:**
```
Input:  root = [], key = 0
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-10^5 \le \text{Node.val} \le 10^5$
- Each node has a **unique** value.
- `root` is a valid binary search tree.
- $-10^5 \le \text{key} \le 10^5$

## Approach 1 — Recursive Hibbard Deletion (In-Order Successor) ✅

### Key Insight
1. **Search:**
   - If `key < root->val`: `root->left = deleteNode(root->left, key)`.
   - If `key > root->val`: `root->right = deleteNode(root->right, key)`.
2. **Delete (`root->val == key`):**
   - If `!root->left`: return `root->right`.
   - If `!root->right`: return `root->left`.
   - If both children exist: find `successor = root->right` (traverse left until `successor->left == nullptr`). Set `root->val = successor->val`, then call `root->right = deleteNode(root->right, successor->val)`.

```
Delete 3 from [5, 3, 6, 2, 4, null, 7]:

1. key (3) < root (5) -> recurse left
2. key (3) == root (3) -> Node found! Has 2 children (2 and 4).
3. Find successor in right subtree (4): successor->val = 4.
4. Overwrite root->val with 4.
5. Delete 4 from right subtree -> right child becomes null.
6. Returns updated node 4 to root 5.

Result: [5, 4, 6, 2, null, null, 7] ✓
```

### C++ Implementation
```cpp
/*
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
*/

class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (root == nullptr) return nullptr;
        
        // 1. Search for target node
        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else if (key > root->val) {
            root->right = deleteNode(root->right, key);
        } else {
            // 2. Target node located
            
            // Case 1 & 2: 0 or 1 child
            if (root->left == nullptr) {
                TreeNode* rightChild = root->right;
                delete root;
                return rightChild;
            }
            if (root->right == nullptr) {
                TreeNode* leftChild = root->left;
                delete root;
                return leftChild;
            }
            
            // Case 3: 2 children -> Find in-order successor (min in right subtree)
            TreeNode* successor = root->right;
            while (successor->left != nullptr) {
                successor = successor->left;
            }
            
            // Replace current value with successor value
            root->val = successor->val;
            
            // Delete the successor node from the right subtree
            root->right = deleteNode(root->right, successor->val);
        }
        
        return root;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(h)$ | Navigates down one path of height $h \le n$ ($h = \log n$ for balanced BST). |
| **Space** | $O(h)$ | Recursion stack depth equal to tree height. |

> **This is the one.** Standard, textbook BST deletion.

## Approach 2 — Iterative BST Node Deletion ($O(1)$ Extra Space)

### Intuition
Track parent pointer iteratively. Search for `curr` matching `key`. Rewire `parent`'s left/right pointer to bypass `curr` or attach its children.

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        TreeNode* curr = root;
        TreeNode* prev = nullptr;
        
        while (curr && curr->val != key) {
            prev = curr;
            if (key < curr->val) curr = curr->left;
            else curr = curr->right;
        }
        
        if (!curr) return root; // Key not found
        
        TreeNode* replacement = deleteRoot(curr);
        
        if (!prev) return replacement; // Deleted root node
        if (prev->left == curr) prev->left = replacement;
        else prev->right = replacement;
        
        return root;
    }

private:
    TreeNode* deleteRoot(TreeNode* root) {
        if (!root->left) return root->right;
        if (!root->right) return root->left;
        
        // Find rightmost node in left subtree
        TreeNode* rightmost = root->left;
        while (rightmost->right) rightmost = rightmost->right;
        
        rightmost->right = root->right;
        return root->left;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(h)$ | Traversal down branch. |
| **Space** | $O(1)$ | Pure pointer manipulation with zero stack memory. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Key Not in Tree** | `root = [5, 3, 6], key = 10` | Modifying tree | Searches to `nullptr`, returns original tree unmodified. |
| **Deleting the Root Node** | `root = [5, 3, 6], key = 5` | Return value handling | Root is replaced by successor (6), returns updated root. |
| **Empty Tree** | `root = [], key = 1` | Null dereference | Returns `nullptr` immediately. |

## Pattern Takeaways

1. **The In-Order Successor Invariant:**  
   $$\text{Successor} = \text{Leftmost node of Right Subtree } (\text{smallest value } > \text{target})$$
2. **BST Deletion Cases:**  
   - 0 children: delete directly.
   - 1 child: promote child.
   - 2 children: swap value with In-Order Successor / Predecessor and delete original leaf.

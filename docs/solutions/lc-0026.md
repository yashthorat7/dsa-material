## What are we solving?

Given an integer array `nums` sorted in **non-decreasing order**, remove the duplicates **in-place** such that each unique element appears only once. The relative order of the elements should be kept the same. Then return the number of unique elements in `nums`.

The challenge is: **how do we compress unique elements into the front of the array in $O(n)$ time without extra space?**

**Example 1:**
```
Input:  nums = [1,1,2]
Output: 2, nums = [1,2,_]
Explanation: Your function should return k = 2, with the first two elements of nums being 1 and 2 respectively.
```

**Example 2:**
```
Input:  nums = [0,0,1,1,1,2,2,3,3,4]
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Explanation: Your function should return k = 5, with the first five elements of nums being 0, 1, 2, 3, and 4 respectively.
```

**Constraints:**
- $1 \le \text{nums.length} \le 3 \times 10^4$
- $-100 \le \text{nums}[i] \le 100$
- `nums` is sorted in non-decreasing order.

## Approach 1 — Slow and Fast Two Pointers ✅

**Key insight:** Use a `slow` pointer to point to the last unique element placed, and a `fast` pointer to explore forward. Whenever `nums[fast] != nums[slow]`, increment `slow` and overwrite `nums[slow] = nums[fast]`.

```
nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
slow = 0

fast=1 (0 == nums[slow]): skip
fast=2 (1 != nums[slow]): slow=1, nums[1]=1
fast=3 (1 == nums[slow]): skip
fast=4 (1 == nums[slow]): skip
fast=5 (2 != nums[slow]): slow=2, nums[2]=2
fast=6 (2 == nums[slow]): skip
fast=7 (3 != nums[slow]): slow=3, nums[3]=3
fast=8 (3 == nums[slow]): skip
fast=9 (4 != nums[slow]): slow=4, nums[4]=4

Final unique count = slow + 1 = 5 ✓
```

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;
        int slow = 0;
        for (int fast = 1; fast < nums.size(); fast++) {
            if (nums[fast] != nums[slow]) {
                slow++;
                nums[slow] = nums[fast];
            }
        }
        return slow + 1;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** In-place two-pointer technique.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All elements unique `[1, 2, 3, 4]` | Redundant rewrites | `slow` advances with `fast`, returning $n$ correctly |
| All identical elements `[1, 1, 1, 1]` | `slow` advances mistakenly | `slow` never increments, returns 1 |
| Single element `[1]` | Loop does not execute | Returns 1 directly |

## Pattern Takeaway

The **Read/Write Two-Pointer** pattern is the fundamental building block for all in-place array transformations (Remove Element, Move Zeroes, Partitioning).

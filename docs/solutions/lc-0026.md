## What are we solving?

Given an integer array `nums` sorted in **non-decreasing order**, remove the duplicates **in-place** such that each unique element appears only once. The relative order of the elements must be kept the same.

Return the number of unique elements $k$. The first $k$ elements of `nums` should hold the final unique elements in their original sorted order.

```
 Input:  nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
                 ↑
               Write unique elements to front
               
 Output: k = 5,  nums = [0, 1, 2, 3, 4,  _, _, _, _, _]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>&` (passed by reference) sorted in non-decreasing order ($1 \le n \le 3 \times 10^4$, $-100 \le \text{nums}[i] \le 100$).
- **Output:**
  - `int` representing $k$ (the count of unique elements).
  - Mutates `nums` in-place such that `nums[0..k-1]` contains all distinct values.

### The Core Challenge
The modification **must be in-place** ($O(1)$ extra memory). We cannot allocate a new vector and reassign it. We need a reader/writer two-pointer strategy that overwrites duplicates as we scan.

```
Input:  nums = [1,1,2]
```

## Approach 1 — Auxiliary Set / Array (Out-of-Place Intuition)

### Intuition
If extra space were allowed, we could iterate through `nums`, filter unique values into a new array, and copy them back.

### C++ Implementation
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;
        
        vector<int> uniqueList;
        uniqueList.push_back(nums[0]);
        
        for (size_t i = 1; i < nums.size(); i++) {
            if (nums[i] != nums[i - 1]) {
                uniqueList.push_back(nums[i]);
            }
        }
        
        for (size_t i = 0; i < uniqueList.size(); i++) {
            nums[i] = uniqueList[i];
        }
        
        return uniqueList.size();
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | One pass to filter, one pass to copy back. |
| **Space** | $O(n)$ | Allocates an auxiliary vector of size up to $n$. |

> **Verdict:** Violates the $O(1)$ in-place memory constraint.

## Approach 2 — Two Pointers (Reader & Writer) In-Place Overwrite ✅

### Key Insight
Since `nums` is **already sorted**, all duplicate elements are strictly contiguous.  
We maintain two pointers:
1. `writeIndex`: points to the position where the *next distinct value* will be placed (starts at 1).
2. `readIndex`: scans through the array from index 1 to $n-1$.

Whenever `nums[readIndex] != nums[readIndex - 1]`, we have encountered a new unique value. Overwrite `nums[writeIndex] = nums[readIndex]` and advance `writeIndex++`.

```
nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
writeIndex = 1

readIndex = 1 (val = 0 == nums[0]): skip duplicate
readIndex = 2 (val = 1 != nums[1]): nums[1] = 1, writeIndex = 2
readIndex = 3 (val = 1 == nums[2]): skip duplicate
readIndex = 4 (val = 1 == nums[3]): skip duplicate
readIndex = 5 (val = 2 != nums[4]): nums[2] = 2, writeIndex = 3
readIndex = 6 (val = 2 == nums[5]): skip duplicate
readIndex = 7 (val = 3 != nums[6]): nums[3] = 3, writeIndex = 4
readIndex = 8 (val = 3 == nums[7]): skip duplicate
readIndex = 9 (val = 4 != nums[8]): nums[4] = 4, writeIndex = 5

Final Array: [0, 1, 2, 3, 4, ...], returns k = 5 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;
        
        int writeIndex = 1;
        
        for (int readIndex = 1; readIndex < nums.size(); readIndex++) {
            // Found a new distinct value
            if (nums[readIndex] != nums[readIndex - 1]) {
                nums[writeIndex] = nums[readIndex];
                writeIndex++;
            }
        }
        
        return writeIndex;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass. `readIndex` touches each element exactly once ($n - 1$ steps). |
| **Space** | $O(1)$ | Pure in-place modification using two index variables. |

> **This is the one.** Constant auxiliary space, single pass, cache-friendly sequential array writes.

## Approach 3 — Generalized $K$-Duplicates Allowed Pattern

### Intuition
This pattern generalizes to [LC 80: Remove Duplicates from Sorted Array II](file:///e:/Projects/dsa-notes/docs/solutions/lc-0080.md) (allowing up to $k$ duplicates).  
For $k = 1$: compare the candidate `nums[readIndex]` directly against `nums[writeIndex - 1]`.

### C++ Implementation
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int writeIndex = 0;
        for (int num : nums) {
            // For k=1: if we have fewer than 1 element or current num > previous written element
            if (writeIndex < 1 || num > nums[writeIndex - 1]) {
                nums[writeIndex++] = num;
            }
        }
        return writeIndex;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Range-based loop visits each element once. |
| **Space** | $O(1)$ | Constant memory. |

---

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Element** | `[1]` | Loop doesn't execute | `readIndex = 1 < 1` is false, returns initial `writeIndex = 1`. |
| **All Unique Elements** | `[1, 2, 3, 4, 5]` | Redundant writes `nums[i] = nums[i]` | Correctly keeps all elements, returns $n = 5$. |
| **All Identical Elements** | `[7, 7, 7, 7]` | `writeIndex` advancing incorrectly | Condition `nums[i] != nums[i-1]` never triggers, returns $k = 1$. |
| **Negative Numbers** | `[-10, -10, -5, 0, 0]` | Signed integer bugs | Direct equality comparison handles negative numbers seamlessly. |

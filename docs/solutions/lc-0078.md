## What are we solving?

Given an integer array `nums` of **unique elements**, return all possible **subsets** (the power set).

The solution set must **not contain duplicate subsets**. You may return the subsets in any order.

```
 Input: nums = [1, 2, 3]
 
 State Space Tree:
                    []
           /        |        \
        [1]        [2]       [3]
       /   \        |
    [1,2] [1,3]   [2,3]
      |
   [1,2,3]
   
 Output: [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]  (Total: 2³ = 8 subsets)
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` with length $1 \le n \le 10$, all numbers unique ($-10 \le \text{nums}[i] \le 10$).
- **Output:**
  - `vector<vector<int>>` containing all $2^n$ unique subsets.

### The Core Challenge
For an array of length $n$, each element can either be **included** or **excluded**, resulting in exactly $2^n$ distinct subsets. The challenge is systematically enumerating all subsets without duplicates while keeping memory allocation and backtracking overhead minimal.

---

**Example 1:**
```
Input:  nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Example 2:**
```
Input:  nums = [0]
Output: [[],[0]]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10$
- $-10 \le \text{nums}[i] \le 10$
- All the numbers of `nums` are unique.

## Approach 1 — Cascading / Iterative Generation

### Intuition
Start with the empty set `result = [[]]`. For each number `num` in `nums`:
- Take all existing subsets currently in `result`.
- Create a copy of each subset, append `num` to it, and add the new subset back to `result`.

```
Initial:  [[]]
num = 1:  [[]] + [[1]]              ==> [[], [1]]
num = 2:  [[], [1]] + [[2], [1,2]]  ==> [[], [1], [2], [1,2]]
num = 3:  [[], [1], [2], [1,2]] + [[3], [1,3], [2,3], [1,2,3]]
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result = {{}};
        
        for (int num : nums) {
            int currentSize = result.size();
            for (int i = 0; i < currentSize; i++) {
                vector<int> newSubset = result[i];
                newSubset.push_back(num);
                result.push_back(newSubset);
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | Generates $2^n$ subsets. Copying each subset of average length $n/2$ takes $O(n \cdot 2^n)$ operations. |
| **Space** | $O(n \cdot 2^n)$ | Stores all $2^n$ subsets in the output vector. |

> **Verdict:** Very simple and intuitive iterative expansion.

## Approach 2 — Backtracking (DFS State Space Exploration) ✅

### Key Insight
Use a recursive helper function `backtrack(start, current)`:
1. Every state reached in the recursion represents a valid subset $\rightarrow$ append `current` to `result`.
2. Loop `i` from `start` to $n-1$:
   - **Choose:** `current.push_back(nums[i])`
   - **Explore:** `backtrack(i + 1, current)`
   - **Unchoose (Backtrack):** `current.pop_back()`

```
nums = [1, 2, 3]

backtrack(0, []) -> result.push([])
 ├─ i=0: [1] -> result.push([1])
 │   ├─ i=1: [1, 2] -> result.push([1, 2])
 │   │   └─ i=2: [1, 2, 3] -> result.push([1, 2, 3])
 │   └─ i=2: [1, 3] -> result.push([1, 3])
 ├─ i=1: [2] -> result.push([2])
 │   └─ i=2: [2, 3] -> result.push([2, 3])
 └─ i=2: [3] -> result.push([3])

Total: 8 subsets ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, nums, current, result);
        return result;
    }

private:
    void backtrack(int start, const vector<int>& nums, vector<int>& current, vector<vector<int>>& result) {
        // Every prefix state in the tree is a valid subset
        result.push_back(current);
        
        for (int i = start; i < nums.size(); i++) {
            current.push_back(nums[i]);            // 1. Choose
            backtrack(i + 1, nums, current, result); // 2. Explore
            current.pop_back();                     // 3. Backtrack
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | Recursion visits all $2^n$ states, copying each subset into the output list. |
| **Space** | $O(n)$ auxiliary | Recursion call stack and `current` path buffer use at most $n$ frames. |

> **This is the one.** Standard backtracking template used across combinations, permutations, and power sets.

## Approach 3 — Bit Manipulation (Binary Bitmasking)

### Intuition
Every subset corresponds uniquely to an $n$-bit binary integer from $0$ to $2^n - 1$:
- If the $j$-th bit of mask $i$ is `1`, include `nums[j]`.
- If the $j$-th bit is `0`, exclude `nums[j]`.

```
nums = [1, 2, 3], n = 3 -> masks from 0 to 7 (000 to 111):
mask = 0 (000) -> []
mask = 1 (001) -> [1]
mask = 2 (010) -> [2]
mask = 3 (011) -> [1, 2]
mask = 4 (100) -> [3]
mask = 5 (101) -> [1, 3]
mask = 6 (110) -> [2, 3]
mask = 7 (111) -> [1, 2, 3]
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        int n = nums.size();
        int totalSubsets = 1 << n; // 2^n
        vector<vector<int>> result;
        result.reserve(totalSubsets);
        
        for (int mask = 0; mask < totalSubsets; mask++) {
            vector<int> subset;
            for (int j = 0; j < n; j++) {
                if (mask & (1 << j)) {
                    subset.push_back(nums[j]);
                }
            }
            result.push_back(subset);
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | Outer loop runs $2^n$ times; inner loop checks $n$ bits. |
| **Space** | $O(1)$ auxiliary | No recursion stack or backtracking buffers. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Element** | `nums = [0]` | Missing empty subset `[]` | Initial call pushes `[]`, loop adds `[0]`, outputs `[[], [0]]`. |
| **Maximum Constraints** | $n = 10$ | Bit shift overflow | `1 << 10 = 1024` fits effortlessly in standard integer types. |
| **Negative Numbers** | `[-1, -2, -3]` | Sign bit confusion | Elements are stored directly by index, unaffected by negative values. |

## Pattern Takeaways

1. **The Power Set Size Invariant:**  
   Any set with $n$ distinct elements has exactly $2^n$ subsets (including the empty set and the set itself).
2. **The `start` Index Invariant:**  
   Passing `i + 1` as the new `start` index prevents re-using previous elements and automatically avoids duplicate permutations.
3. **Generalization to Duplicates:**  
   When `nums` contains duplicate values ([LC 90: Subsets II](file:///e:/Projects/dsa-notes/docs/solutions/lc-0090.md)), sort first and add `if (i > start && nums[i] == nums[i-1]) continue;`.

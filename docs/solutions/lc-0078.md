## What are we solving?

Given an integer array `nums` of **unique** elements, return all possible subsets (the power set). The solution set must not contain duplicate subsets. Return the solution in any order.

The question is: **how does the standard Choose/Don't Choose backtracking pattern generate all $2^n$ subsets in $O(n \cdot 2^n)$ time?**

**Example 1:**
```
Input:  nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**Example 2:**
```
Input:  nums = [0]
Output: [[],[0]]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10$
- $-10 \le \text{nums}[i] \le 10$
- All the numbers of `nums` are unique.

## Approach 1 — Backtracking (DFS State Space Tree) ✅

**Key insight:**
At each step of the recursion `backtrack(start, currentList)`:
1. Add `currentList` to `result` (every prefix state is a valid subset).
2. Loop `i` from `start` to `nums.size() - 1`:
   - Include `nums[i]`: `currentList.push_back(nums[i])`.
   - Recurse: `backtrack(i + 1, currentList)`.
   - Backtrack: `currentList.pop_back()`.

```
nums = [1, 2, 3]
[]
 ├─ [1]
 │   ├─ [1, 2]
 │   │   └─ [1, 2, 3]
 │   └─ [1, 3]
 ├─ [2]
 │   └─ [2, 3]
 └─ [3]

Total subsets generated: 2^3 = 8 ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, nums, current, result);
        return result;
    }
private:
    void backtrack(int start, const vector<int>& nums, vector<int>& current, vector<vector<int>>& result) {
        result.push_back(current);
        for (int i = start; i < nums.size(); i++) {
            current.push_back(nums[i]);
            backtrack(i + 1, nums, current, result);
            current.pop_back(); // backtrack
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot 2^n)$ | $O(n)$ recursion stack |

> **This is the one.** Standard power set generation template.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty or single element array `[0]` | Missing empty set `[]` | Initial call pushes `[]`, then `[0]` |
| Max length array $n = 10$ | Time limits | $2^{10} = 1024$ subsets generated in $<1$ ms |

---

## Pattern Takeaway

The **Combination Backtracking Template** (`start` index advancing to `i + 1`) guarantees unique combinations in lexicographical order.

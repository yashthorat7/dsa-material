## What are we solving?

Given a general binary tree (not necessarily sorted), find the **Lowest Common Ancestor (LCA)** of two given nodes `p` and `q`.

According to the definition of LCA on Wikipedia:  
*“The lowest common ancestor is defined between two nodes `p` and `q` as the lowest node in `T` that has both `p` and `q` as descendants (where we allow **a node to be a descendant of itself**).”*

```
              (3)  <--- Lowest Common Ancestor of 5 & 1
             /   \
           (5)   (1)
          /  \   /  \
        (6)  (2)(0) (8)
            /  \
          (7)  (4)
          
 LCA(5, 1) = 3
 LCA(5, 4) = 5 (Node 5 is ancestor of node 4 and itself)
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root of a binary tree ($2 \le n \le 10^5$, $-10^9 \le \text{Node.val} \le 10^9$, all values unique).
  - `p`, `q`: Non-null `TreeNode*` references guaranteed to exist in the tree (`p != q`).
- **Output:**
  - `TreeNode*` pointing to the lowest common ancestor of `p` and `q`.

### The Core Challenge
Unlike a BST where node values guide us left or right, a general binary tree has no ordering invariants. We must search both left and right subtrees and synthesize the result bottom-up.

---

**Example 1:**
```
Input:  root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
Output: 3
Explanation: The LCA of nodes 5 and 1 is 3.
```

**Example 2:**
```
Input:  root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
Output: 5
Explanation: The LCA of nodes 5 and 4 is 5, since a node can be a descendant of itself.
```

**Constraints:**
- The number of nodes in the tree is in the range $[2, 10^5]$.
- $-10^9 \le \text{Node.val} \le 10^9$
- All `Node.val` are **unique**.
- `p != q`
- `p` and `q` will exist in the tree.

## Approach 1 — Recursive Post-Order Divide & Conquer ✅

### Key Insight
Process the tree with a **post-order DFS** function `lowestCommonAncestor(root, p, q)`:
1. **Base Cases:**
   - If `root == nullptr`, return `nullptr`.
   - If `root == p || root == q`, return `root` (found one of our targets!).
2. **Subtree Exploration:**
   - Search left: `left = lowestCommonAncestor(root->left, p, q)`.
   - Search right: `right = lowestCommonAncestor(root->right, p, q)`.
3. **Combine Results:**
   - If **both `left` and `right` are non-null**: `p` was found in one subtree and `q` in the other $\implies$ current `root` is their **Lowest Common Ancestor**!
   - If only one child returned non-null: propagate that non-null node upwards.
   - If both returned `nullptr`: return `nullptr`.

```
Tree: [3, 5, 1, 6, 2, 0, 8], p = 5, q = 1

At root 3:
├─ Left subtree at 5:
│   root == p (5 == 5) -> returns 5 immediately!
└─ Right subtree at 1:
    root == q (1 == 1) -> returns 1 immediately!

At root 3: both left (5) and right (1) are non-null!
-> Node 3 is the Lowest Common Ancestor! ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // Base case: null node or matched one of the targets
        if (root == nullptr || root == p || root == q) {
            return root;
        }
        
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        
        // If targets found in both left and right subtrees, root is the LCA
        if (left != nullptr && right != nullptr) {
            return root;
        }
        
        // Otherwise return whichever subtree found a target (or nullptr)
        return left != nullptr ? left : right;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | In the worst case, visits all $n$ nodes once. |
| **Space** | $O(h)$ | Recursion stack depth equals tree height $h$ ($O(\log n)$ balanced, $O(n)$ skewed). |

> **This is the one.** Classic, clean, 10-line divide-and-conquer algorithm.

## Approach 2 — Path Tracing with Parent Pointers (Iterative)

### Intuition
1. Use BFS or DFS with a hash map `unordered_map<TreeNode*, TreeNode*> parent` to record the parent of every node until both `p` and `q` are found.
2. Build an `unordered_set<TreeNode*> ancestors` by climbing from `p` up to the root.
3. Climb up from `q` using the `parent` map; the first node already present in `ancestors` is the LCA!

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        unordered_map<TreeNode*, TreeNode*> parent;
        stack<TreeNode*> st;
        
        parent[root] = nullptr;
        st.push(root);
        
        // Traverse until parents for both p and q are recorded
        while (!parent.count(p) || !parent.count(q)) {
            TreeNode* curr = st.top();
            st.pop();
            
            if (curr->left) {
                parent[curr->left] = curr;
                st.push(curr->left);
            }
            if (curr->right) {
                parent[curr->right] = curr;
                st.push(curr->right);
            }
        }
        
        // Collect all ancestors of p
        unordered_set<TreeNode*> ancestors;
        while (p != nullptr) {
            ancestors.insert(p);
            p = parent[p];
        }
        
        // First common ancestor encountered climbing from q is the LCA
        while (!ancestors.count(q)) {
            q = parent[q];
        }
        
        return q;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Traverses tree to locate parents, then climbs ancestor chain. |
| **Space** | $O(n)$ | Parent hash map and ancestor set store up to $n$ entries. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`p` is Ancestor of `q`** | `p = 5, q = 4` | Missing `q` under `p` | When `root == p`, returns `p` immediately. `q` is in `p`'s subtree so `right` returns `nullptr`, bubbling `p` all the way to top. |
| **Targets on Opposite Subtrees** | `p = 6, q = 8` | Deep node search | Left returns 6, right returns 8 $\rightarrow$ root returns 3. |

## Pattern Takeaways

1. **The Tree Synthesis Rule:**  
   `if (left && right) return root;` is the universal bottom-up signal that two independently discovered sub-tree features converge at the current node.

## What are we solving?

Given an integer array `nums` and an integer `k`, split `nums` into `k` non-empty subarrays such that the largest sum of any subarray is **minimized**. Return the **minimized largest sum** of the split.

A subarray is a contiguous part of the array.

**Example 1:**
```
Input:  nums = [7,2,5,10,8], k = 2
Output: 18
Explanation: There are four ways to split nums into two subarrays. The best way is to split it into [7,2,5] and [10,8], where the largest sum among the two subarrays is only 18.
```

**Example 2:**
```
Input:  nums = [1,2,3,4,5], k = 2
Output: 9
Explanation: There are four ways to split nums into two subarrays. The best way is to split it into [1,2,3] and [4,5], where the largest sum among the two subarrays is only 9.
```

**Constraints:**
- $1 \le \text{nums.length} \le 1000$
- $0 \le \text{nums}[i] \le 10^6$
- $1 \le k \le \min(50, \text{nums.length})$

## Approach 1 — Binary Search on Feasible Maximum Subarray Sum ✅

**Key insight:**
- Lower bound for max subarray sum: `low = max(nums)` (a subarray must contain at least one element).
- Upper bound for max subarray sum: `high = sum(nums)` (all elements in one subarray).
- Feasibility check: Greedily count how many subarrays are needed if no subarray sum exceeds `maxAllowed`.
- If `subarraysNeeded <= k`: feasible, try smaller sum -> `high = mid`.
- If `subarraysNeeded > k`: infeasible, increase allowed sum -> `low = mid + 1`.

```
nums = [7, 2, 5, 10, 8], k = 2
low = 10, high = 32

mid = 21: splits: [7,2,5] (14), [10,8] (18) -> 2 subarrays <= 2 (valid) -> high = 21
mid = 15: splits: [7,2,5] (14), [10] (10), [8] (8) -> 3 subarrays > 2 (too small) -> low = 16
mid = 18: splits: [7,2,5] (14), [10,8] (18) -> 2 subarrays <= 2 (valid) -> high = 18
...
Converges to low = 18.

Result: 18 ✓
```

```cpp
class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        long long low = 0, high = 0;
        for (int x : nums) {
            low = max(low, (long long)x);
            high += x;
        }
        
        while (low < high) {
            long long mid = low + (high - low) / 2;
            int count = 1;
            long long currentSum = 0;
            
            for (int x : nums) {
                if (currentSum + x > mid) {
                    count++;
                    currentSum = x;
                } else {
                    currentSum += x;
                }
            }
            
            if (count <= k) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        
        return low;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log(\text{sum} - \max))$ | $O(1)$ |

> **This is the one.** Optimal polynomial binary search on greedy partition.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `k = 1` | Single partition | Returns total array sum `high` |
| `k == nums.length` | Individual elements | Returns `max(nums)` |
| Large elements summing to $10^9$ | 32-bit overflow | `long long` prevents arithmetic overflow |

## Pattern Takeaway

The **'Minimax Subarray Partition'** problem family (Split Array Largest Sum, Painter's Partition, Book Allocation) is solved uniformly via **Binary Search on the Feasible Max Sum with Greedy Partitioning**.

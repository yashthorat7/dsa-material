## What are we solving?

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses at this place are **arranged in a circle**. That means the first house is the neighbor of the last one.

Given an integer array `nums` representing the amount of money of each house, return the **maximum amount of money** you can rob tonight without alerting the police.

**Example 1:**
```
Input:  nums = [2,3,2]
Output: 3
Explanation: You cannot rob house 1 (money = 2) and then rob house 3 (money = 2), because they are adjacent houses.
```

**Example 2:**
```
Input:  nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3). Total amount = 1 + 3 = 4.
```

**Example 3:**
```
Input:  nums = [1,2,3]
Output: 3
```

**Constraints:**
- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 1000$

## Approach 1 — Decompose Circle into Two Linear Subproblems ✅

**Key insight:**
Since house `0` and house `n-1` are adjacent, we can NEVER rob both!
This breaks into two mutually exclusive linear subproblems:
1. **Exclude last house:** Rob from index `0` to `n - 2`.
2. **Exclude first house:** Rob from index `1` to `n - 1`.
Return `max(robLinear(0, n - 2), robLinear(1, n - 1))`.

```
nums = [2, 3, 2]
Case 1: nums[0..1] = [2, 3] -> robLinear = 3
Case 2: nums[1..2] = [3, 2] -> robLinear = 3
Max(3, 3) = 3 ✓
```

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        return max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }
private:
    int robRange(const vector<int>& nums, int start, int end) {
        int prev2 = 0, prev1 = 0;
        for (int i = start; i <= end; i++) {
            int curr = max(prev1, nums[i] + prev2);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Clean circular decomposition into two linear House Robber runs.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single house `[7]` | Bounds `0..-1` and `1..0` | Handled by `if (n == 1) return nums[0];` |
| Two houses `[1, 3]` | Adjacent in circle | Picks `max(1, 3) = 3` |

---

## Pattern Takeaway

When a graph constraint has a **circular boundary condition on endpoints (0 and n-1)**, decompose it into **two linear slices: `[0..n-2]` and `[1..n-1]`**.

## What are we solving?

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses at this place are **arranged in a circle**. That means the first house is the direct neighbor of the last one.

Given an integer array `nums` representing the amount of money of each house, return the **maximum amount of money** you can rob tonight without alerting the police (adjacent houses cannot be broken into on the same night).

```
 Circular Street:
         (House 0: $2)
          /         \
   (House 2: $2)---(House 1: $3)
   
 Option A: Rob House 0 -> Cannot rob House 1 or House 2 -> Max = $2
 Option B: Rob House 1 -> Cannot rob House 0 or House 2 -> Max = $3 (Optimal!)
 
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 100$, $0 \le \text{nums}[i] \le 1000$.
- **Output:**
  - `int` representing the maximum robbable loot.

### The Core Challenge
Because house $0$ and house $n - 1$ are adjacent in a circle, we can **never rob both**.  
This circular constraint naturally decomposes into two standard linear [House Robber I (LC 198)](file:///e:/Projects/dsa-notes/docs/solutions/lc-0198.md) subproblems:
1. **Case A (Exclude House $n - 1$):** Rob among houses $[0 \dots n - 2]$.
2. **Case B (Exclude House $0$):** Rob among houses $[1 \dots n - 1]$.

The global answer is simply $\max(\text{Case A}, \text{Case B})$.

---

**Example 1:**
```
Input:  nums = [2,3,2]
Output: 3
Explanation: You cannot rob house 1 (money = 2) and then rob house 3 (money = 2), because they are adjacent houses.
```

**Example 2:**
```
Input:  nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3). Total amount = 1 + 3 = 4.
```

**Example 3:**
```
Input:  nums = [1,2,3]
Output: 3
```

**Constraints:**
- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 1000$

## Approach 1 — Naive Recursion with Circular Flag

### Intuition
Recurse through indices $0 \dots n - 1$. Pass a boolean flag `robbedFirst` indicating whether house 0 was robbed, preventing house $n - 1$ from being robbed.

### C++ Implementation
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        if (nums.empty()) return 0;
        if (nums.size() == 1) return nums[0];
        
        auto dfs = [&](auto& self, int i, bool robbedFirst) -> int {
            if (i >= nums.size()) return 0;
            if (i == nums.size() - 1 && robbedFirst) return 0; // Circular conflict
            
            int robCurr = nums[i] + self(self, i + 2, (i == 0) ? true : robbedFirst);
            int skipCurr = self(self, i + 1, (i == 0) ? false : robbedFirst);
            
            return max(robCurr, skipCurr);
        };
        
        return dfs(dfs, 0, false);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(2^n)$ | Exponential recursion tree without memoization. |
| **Space** | $O(n)$ | Call stack depth reaches $n$. |

> **Verdict:** Suboptimal. Breaking the circular array into two independent linear House Robber subproblems achieves $O(n)$ time and $O(1)$ space.

## What are we solving?

You are given an array `people` where `people[i]` is the weight of the $i$-th person, and an **infinite number of boats** where each boat can carry a maximum weight of `limit`. Each boat carries at most **two people** at the same time, provided the sum of the weight of those people is at most `limit`. Return the **minimum number of boats** to carry every given person.

The question is: **how do we pair the heaviest person with the lightest person possible to minimize boats?**

**Example 1:**
```
Input:  people = [1,2], limit = 3
Output: 1
Explanation: 1 boat (1, 2)
```

**Example 2:**
```
Input:  people = [3,2,2,1], limit = 3
Output: 3
Explanation: 3 boats (1, 2), (2) and (3)
```

**Example 3:**
```
Input:  people = [3,5,3,4], limit = 5
Output: 4
Explanation: 4 boats (3), (3), (4), (5)
```

**Constraints:**
- $1 \le \text{people.length} \le 5 \times 10^4$
- $1 \le \text{people}[i] \le \text{limit} \le 3 \times 10^4$

## Approach 1 — Greedy Two Pointers ✅

**Key insight:** Sort `people`. The heaviest person `people[right]` MUST take a boat. The best companion to fit into that boat is the lightest available person `people[left]`. If `people[left] + people[right] <= limit`, both ride in one boat (`left++`, `right--`). Otherwise, the heaviest rides alone (`right--`).

```
people = [3, 2, 2, 1], limit = 3
Sorted: [1, 2, 2, 3]
left = 0, right = 3, boats = 0

1. left(1) + right(3) = 4 > 3 -> 3 goes alone: right=2, boats=1
2. left(1) + right(2) = 3 <= 3 -> (1, 2) pair up: left=1, right=1, boats=2
3. left(2) + right(2) = 2 (same person): left <= right -> 2 goes alone: right=0, boats=3

Result: 3 boats ✓
```

```cpp
class Solution {
public:
    int numRescueBoats(vector<int>& people, int limit) {
        sort(people.begin(), people.end());
        int left = 0, right = people.size() - 1;
        int boats = 0;
        while (left <= right) {
            if (people[left] + people[right] <= limit) {
                left++;
            }
            right--;
            boats++;
        }
        return boats;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n)$ | $O(1)$ |

> **This is the one.** Greedy pairing with two pointers is provably optimal.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single person `people = [3], limit = 3` | Off-by-one pointer index | `left == right` loop condition ensures 1 boat counted |
| All people require full boat | Pairing failures | `right` decrements every step, allocating 1 boat per person |
| Everyone can pair up perfectly `[1, 1, 1, 1], limit = 2` | Overcounting | Takes exactly $n/2$ boats |

---

## Pattern Takeaway

When a container has a hard capacity limit of **at most 2 items**, greedy pairing between the **extremes (heaviest + lightest)** always yields the optimal bin-packing solution.

## What are we solving?

You are given an array `people` where `people[i]` is the weight of the $i$-th person, and an **infinite number of rescue boats** where each boat has a maximum weight capacity of `limit`.

Each boat can carry **at most two people** simultaneously, provided the sum of the weight of those people is $\le \text{limit}$.

Return the **minimum number of boats** needed to carry every given person.

```
 people = [ 3, 2, 2, 1 ],  limit = 3
 
 Sorted: [ 1, 2, 2, 3 ]
 
 Boat 1: Person with weight 3 (rides alone)
 Boat 2: Person with weight 2 + Person with weight 1 (sum = 3 <= 3)
 Boat 3: Person with weight 2 (rides alone)
 
 Minimum Boats = 3
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `people`: `vector<int>` ($1 \le n \le 5 \times 10^4$, $1 \le \text{people}[i] \le \text{limit} \le 3 \times 10^4$).
  - `limit`: `int` maximum weight per boat.
- **Output:**
  - `int`: Minimum number of boats required.

### The Greedy Pairing Property (2-Bin Packing)
Because each boat holds **at most 2 people**:
1. The **heaviest remaining person** `people[right]` **must** be allocated a boat.
2. The best possible co-passenger to accompany them in that same boat is the **lightest remaining person** `people[left]`.
3. If `people[left] + people[right] <= limit`, both fit in 1 boat $\implies$ `left++`, `right--`.
4. If they exceed `limit`, no one can share a boat with `people[right]`, so they must ride alone $\implies$ `right--`.

---

**Example 1:**
```
Input:  people = [1,2], limit = 3
Output: 1
Explanation: 1 boat (1, 2)
```

**Example 2:**
```
Input:  people = [3,2,2,1], limit = 3
Output: 3
Explanation: 3 boats (1, 2), (2) and (3)
```

**Example 3:**
```
Input:  people = [3,5,3,4], limit = 5
Output: 4
Explanation: 4 boats (3), (3), (4), (5)
```

**Constraints:**
- $1 \le \text{people.length} \le 5 \times 10^4$
- $1 \le \text{people}[i] \le \text{limit} \le 3 \times 10^4$

## Approach 1 — Sorting + Greedy Two Pointers ✅

### Key Insight
1. Sort `people` ascending.
2. Initialize `left = 0`, `right = people.size() - 1`, `boats = 0`.
3. While `left <= right`:
   - If `people[left] + people[right] <= limit`: `left++` (lightest person shares boat).
   - In all cases: `right--` (heaviest person boards boat), `boats++`.
4. Return `boats`.

```
people = [3, 2, 2, 1], limit = 3
Sorted: [1, 2, 2, 3]
left = 0, right = 3, boats = 0

Step 1: people[0] (1) + people[3] (3) = 4 > 3 -> 3 goes alone: right=2, boats=1
Step 2: people[0] (1) + people[2] (2) = 3 <= 3 -> (1, 2) share: left=1, right=1, boats=2
Step 3: people[1] (2) [left == right] -> 2 goes alone: right=0, boats=3

Result: boats = 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int numRescueBoats(vector<int>& people, int limit) {
        sort(people.begin(), people.end());
        
        int left = 0;
        int right = people.size() - 1;
        int boats = 0;
        
        while (left <= right) {
            // If the lightest and heaviest person can share a boat, include the lightest person
            if (people[left] + people[right] <= limit) {
                left++;
            }
            // Heaviest person always takes a boat
            right--;
            boats++;
        }
        
        return boats;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Sorting $n$ people dominates runtime; two-pointer scan is $O(n)$. |
| **Space** | $O(1)$ auxiliary | In-place sorting. |

> **This is the one.** Standard, optimal 2-passenger greedy bin packing.

## Approach 2 — Counting / Bucket Sort ($O(n + \text{limit})$)

### Intuition
Since $\text{weight} \le 30000$, use a frequency array `count[limit + 1]` to sort weights in $O(n + \text{limit})$ without comparison sorting. Use two pointers over the bucket array.

### C++ Implementation
```cpp
class Solution {
public:
    int numRescueBoats(vector<int>& people, int limit) {
        vector<int> count(limit + 1, 0);
        for (int p : people) count[p]++;
        
        int left = 1, right = limit;
        int boats = 0;
        
        while (left <= right) {
            while (left <= right && count[left] == 0) left++;
            while (left <= right && count[right] == 0) right--;
            if (left > right) break;
            
            if (left + right <= limit) {
                count[left]--;
            }
            count[right]--;
            boats++;
        }
        
        return boats;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n + \text{limit})$ | Linear counting sort and bucket sweep. |
| **Space** | $O(\text{limit})$ | Frequency array of size $\text{limit} + 1$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Person Remaining** | `left == right` | Pointer equality bounds | `while (left <= right)` includes the last person in their own boat. |
| **All Persons Weigh Exact Limit** | `people = [3, 3, 3], limit = 3` | Incompatible pairs | Every person rides alone, taking 3 boats. |
| **Everyone Pairs Perfectly** | `people = [1, 2, 1, 2], limit = 3` | Pairing mismatch | Greedily groups into 2 boats. |

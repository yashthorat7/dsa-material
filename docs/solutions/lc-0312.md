## What are we solving?

You are given `n` balloons, indexed from `0` to `n - 1`. Each balloon is painted with a number on it represented by an array `nums`. You are asked to burst all the balloons.

If you burst the $i$-th balloon, you will get `nums[i - 1] * nums[i] * nums[i + 1]` coins. If `i - 1` or `i + 1` goes out of bounds of the array, then treat it as if there is a balloon with a `1` painted on it.

Return the **maximum coins** you can collect by bursting the balloons wisely.

**Example 1:**
```
Input:  nums = [3,1,5,8]
Output: 167
Explanation: nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167.
```

**Example 2:**
```
Input:  nums = [1,5]
Output: 10
```

**Constraints:**
- $n == \text{nums.length}$
- $1 \le n \le 300$
- $0 \le \text{nums}[i] \le 100$

## Approach 1 — Reverse Interval DP (Last Balloon Burst) ✅

**Key insight:**
Thinking forward is hard because bursting a balloon changes the neighbors of remaining balloons.
**Think in reverse: which balloon is burst LAST in range `(i, j)`?**
If balloon `k` is burst LAST in range `(i, j)`:
- Its boundary neighbors are fixed at `nums[i]` and `nums[j]`!
- Coins from bursting `k` last: `nums[i] * nums[k] * nums[j]`.
- Total coins: `dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j]`.

Pad `nums` with `1` at both ends (`[1, ...nums, 1]`).
Recurrence: `dp[i][j] = max_{i < k < j} (dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j])`.

```
Padded nums: [1, 3, 1, 5, 8, 1] (size 6)
dp[i][j] stores max coins for bursting strictly inside (i, j):

Interval lengths from 2 to 5:
dp[0][5] evaluates all last burst candidates k ∈ {1, 2, 3, 4}.
Optimal sequence yields max coins = 167 ✓
```

```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        vector<int> A(n + 2, 1);
        for (int i = 0; i < n; i++) A[i + 1] = nums[i];
        
        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
        
        for (int len = 2; len <= n + 1; len++) {
            for (int i = 0; i <= n + 1 - len; i++) {
                int j = i + len;
                for (int k = i + 1; k < j; k++) {
                    int coins = dp[i][k] + dp[k][j] + A[i] * A[k] * A[j];
                    dp[i][j] = max(dp[i][j], coins);
                }
            }
        }
        
        return dp[0][n + 1];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n^3)$ | $O(n^2)$ |

> **This is the one.** Classic reverse Interval DP with sentinel padding.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single balloon `nums = [5]` | Boundary pad | Padded `[1, 5, 1]`, computes `1 * 5 * 1 = 5` |
| Two balloons `nums = [1, 5]` | Order | Computes `1*1*5 + 1*5*1 = 10` |

---

## Pattern Takeaway

When forward elimination mutates adjacent dependencies, **invert the problem to identify the LAST element remaining**, fixing its boundary neighbors to constants.

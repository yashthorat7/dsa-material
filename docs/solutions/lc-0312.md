## What are we solving?

You are given $n$ balloons, indexed from $0$ to $n - 1$. Each balloon is painted with a number represented by an array `nums`. You are asked to burst all the balloons.

If you burst the $i$-th balloon, you collect $\text{nums}[i - 1] \times \text{nums}[i] \times \text{nums}[i + 1]$ coins.
- If $i - 1$ or $i + 1$ goes out of bounds of the array, treat it as if there is a virtual boundary balloon with a `1` painted on it.

Return the **maximum coins** you can collect by bursting all balloons wisely.

```
 Padded Balloons: [ 1,  3, 1, 5, 8,  1 ]
 
 Optimal Burst Order:
 1. Burst 1 (val 1): coins = 3 * 1 * 5 = 15   -> [ 1, 3, 5, 8, 1 ]
 2. Burst 2 (val 5): coins = 3 * 5 * 8 = 120  -> [ 1, 3, 8, 1 ]
 3. Burst 1 (val 3): coins = 1 * 3 * 8 = 24   -> [ 1, 8, 1 ]
 4. Burst 1 (val 8): coins = 1 * 8 * 1 = 8    -> [ 1, 1 ]
 
 Total Coins = 15 + 120 + 24 + 8 = 167
 Output: 167
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 300$, $0 \le \text{nums}[i] \le 100$.
- **Output:**
  - `int`: Maximum total coins collectible.

### The Inverse Thinking Breakthrough
If we think forward ("which balloon do we burst first?"), the remaining balloons become adjacent, creating dynamic, unpredictable boundary dependencies.  
**Think in Reverse:**
- Ask: *"Which balloon $k$ is burst **LAST** in the open interval $(i, j)$?"*
- If balloon $k$ is the last to burst in $(i, j)$, then all other balloons in $(i, k)$ and $(k, j)$ have already been burst!
- Therefore, balloon $k$'s neighbors are **guaranteed to be the fixed boundaries $i$ and $j$**!
$$\mathbf{\text{dp}[i][j] = \max_{i < k < j} \Big( \text{dp}[i][k] + \text{dp}[k][j] + A[i] \times A[k] \times A[j] \Big)}$$

---

**Example 1:**
```
Input:  nums = [3,1,5,8]
Output: 167
Explanation: nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167.
```

**Example 2:**
```
Input:  nums = [1,5]
Output: 10
```

**Constraints:**
- $n == \text{nums.length}$
- $1 \le n \le 300$
- $0 \le \text{nums}[i] \le 100$

## Approach 1 — Top-Down Memoized Interval DP

### Intuition
Pad `nums` with `1`s on both ends. Define recursive helper `solve(i, j)` to return max coins collected in open interval $(i, j)$. Iterate over all possible last-burst choices $k \in [i + 1, j - 1]$ and memoize results.

### C++ Implementation
```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        vector<int> A(n + 2, 1);
        for (int i = 0; i < n; i++) A[i + 1] = nums[i];
        
        vector<vector<int>> memo(n + 2, vector<int>(n + 2, -1));
        return solve(0, n + 1, A, memo);
    }

private:
    int solve(int i, int j, const vector<int>& A, vector<vector<int>>& memo) {
        if (i + 1 >= j) return 0; // No balloons left between boundaries
        if (memo[i][j] != -1) return memo[i][j];
        
        int maxGain = 0;
        for (int k = i + 1; k < j; k++) {
            int coins = solve(i, k, A, memo) + solve(k, j, A, memo) + A[i] * A[k] * A[j];
            maxGain = max(maxGain, coins);
        }
        
        return memo[i][j] = maxGain;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | $\binom{n+2}{2}$ states, each evaluating $O(n)$ choices of $k$. |
| **Space** | $O(n^2)$ | 2D memoization matrix + recursion stack. |

## Approach 2 — Bottom-Up Interval DP Matrix ✅

### Key Insight
Iterate over window length `len` from 2 up to $n + 1$:
- For each starting left boundary $i \in [0 \dots n + 1 - \text{len}]$:
  - Right boundary $j = i + \text{len}$.
  - Test every last-balloon candidate $k \in [i + 1 \dots j - 1]$.
  - $\text{dp}[i][j] = \max(\text{dp}[i][j], \text{dp}[i][k] + \text{dp}[k][j] + A[i] \cdot A[k] \cdot A[j])$.
- Return `dp[0][n + 1]`.

```
Padded Array: [1, 3, 1, 5, 8, 1]

len = 2 (1 balloon):
- dp[0][2] (balloon 1, val 3): 1 * 3 * 1 = 3
- dp[1][3] (balloon 2, val 1): 3 * 1 * 5 = 15
- dp[2][4] (balloon 3, val 5): 1 * 5 * 8 = 40
- dp[3][5] (balloon 4, val 8): 5 * 8 * 1 = 40

... Grows to len = 5 -> dp[0][5] = 167 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        // Step 1: Pad with boundary sentinels 1 on both ends
        vector<int> A(n + 2, 1);
        for (int i = 0; i < n; i++) {
            A[i + 1] = nums[i];
        }
        
        // dp[i][j] stores max coins from bursting balloons strictly between i and j
        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
        
        // Step 2: Iterate over interval lengths
        for (int len = 2; len <= n + 1; len++) {
            for (int i = 0; i <= n + 1 - len; i++) {
                int j = i + len;
                
                // k is the balloon chosen to be burst LAST in interval (i, j)
                for (int k = i + 1; k < j; k++) {
                    int coins = dp[i][k] + dp[k][j] + A[i] * A[k] * A[j];
                    dp[i][j] = max(dp[i][j], coins);
                }
            }
        }
        
        return dp[0][n + 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | Three nested loops ($N \le 300 \implies \approx 2.7 \times 10^7 / 6 \approx 4.5 \times 10^6$ ops, runtime $<35$ms). |
| **Space** | $O(n^2)$ | 2D table of size $302 \times 302$. |

> **This is the one.** Classic, elegant Matrix Chain Multiplication style interval DP.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Balloon** | `[5]` | Out of bounds access | Padded to `[1, 5, 1]`, computes $1 \times 5 \times 1 = 5$. |
| **Two Balloons** | `[1, 5]` | Sub-interval sequencing | Computes $\max(1\cdot 1\cdot 5 + 1\cdot 5\cdot 1, 1\cdot 5\cdot 1 + 5\cdot 1\cdot 1) = 10$. |
| **Array with Zeroes** | `[0, 3, 0]` | Multiplication by 0 | Handled correctly by arithmetic properties. |

## Pattern Takeaways

1. **Reverse Interval DP Principle:**  
   When removing an element merges adjacent items dynamically, **invert the chronological order to choose the LAST element remaining**, which stabilizes boundary multipliers.

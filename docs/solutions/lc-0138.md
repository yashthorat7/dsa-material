## What are we solving?

A linked list of length `n` is given such that each node contains an additional random pointer, which could point to any node in the list, or `null`. Construct a **deep copy** of the list.

The question is: **how can we interweave copied nodes directly after their originals to clone both `next` and `random` pointers in $O(1)$ extra space?**

**Example 1:**
```
Input:  head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
Output: [[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**Example 2:**
```
Input:  head = [[1,1],[2,1]]
Output: [[1,1],[2,1]]
```

**Constraints:**
- $0 \le n \le 1000$
- $-10^4 \le \text{Node.val} \le 10^4$
- `Node.random` is `null` or is pointing to some node in the linked list.

## Approach 1 — 3-Pass In-Place Interweaving ✅

**Key insight:**
- **Pass 1 (Interweave):** For each original node `curr`, create its copy `copy` and insert it immediately after: `curr -> copy -> curr->next`.
- **Pass 2 (Assign Random):** For each original node `curr`, its copy's random pointer is: `curr->next->random = curr->random ? curr->random->next : nullptr`.
- **Pass 3 (Separate Lists):** Decouple the intertwined original and copied lists to restore original list and return cloned head.

```
Original: A -> B -> nullptr (A.random = B)

Pass 1 (Interweave):
A -> A' -> B -> B' -> nullptr

Pass 2 (Assign random):
A'->random = A->random->next = B'

Pass 3 (Decouple):
Original: A -> B -> nullptr
Clone:    A' -> B' -> nullptr ✓
```

```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* next;
    Node* random;
    Node(int _val) {
        val = _val;
        next = NULL;
        random = NULL;
    }
};
*/

class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        
        // Pass 1: Interweave cloned nodes
        Node* curr = head;
        while (curr) {
            Node* copy = new Node(curr->val);
            copy->next = curr->next;
            curr->next = copy;
            curr = copy->next;
        }
        
        // Pass 2: Connect random pointers
        curr = head;
        while (curr) {
            if (curr->random) {
                curr->next->random = curr->random->next;
            }
            curr = curr->next->next;
        }
        
        // Pass 3: Separate the lists
        curr = head;
        Node* cloneHead = head->next;
        while (curr) {
            Node* copy = curr->next;
            curr->next = copy->next;
            if (copy->next) {
                copy->next = copy->next->next;
            }
            curr = curr->next;
        }
        
        return cloneHead;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ auxiliary space (excluding cloned nodes) |

> **This is the one.** $O(1)$ auxiliary space deep copy without hash map overhead.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty list `head = nullptr` | Null dereference | Returns `nullptr` immediately |
| Node pointing `random` to itself `A.random = A` | Self-referencing copy | `A'->random = A->random->next = A'` works seamlessly |
| `random` is `nullptr` | Dereferencing null | `if (curr->random)` guards against null access |

---

## Pattern Takeaway

**Node Interweaving (`A -> A' -> B -> B'`)** pairs original nodes with cloned counterparts in the physical structure, replacing $O(n)$ hash map mapping with $O(1)$ relative pointer math.

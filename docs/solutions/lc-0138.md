# 138. Copy List with Random Pointer

https://leetcode.com/problems/copy-list-with-random-pointer

> **Medium** $\rightarrow$ **Linked List**


> **Companies:** Meta, Amazon, Microsoft, Bloomberg, Google, Apple, Flipkart, Microsoft India, TCS

---

## What are we solving?

A linked list of length $n$ is given such that each node contains an additional `random` pointer, which could point to any node in the list, or `nullptr`.

Construct a **deep copy** of the list:
- The deep copy should consist of exactly $n$ brand-new nodes.
- Both `next` and `random` pointers of the new nodes must point to new nodes in the copied list (never pointing to nodes in the original list).
- Return the `head` of the copied linked list.

```
 Original:
 (Node A) ---------> (Node B) ---------> (Node C)
    |                   ^                   |
    +--- random --------+                   +--- random ---> (Node A)
    
 Cloned Structure:
 (Node A') --------> (Node B') --------> (Node C')
    |                   ^                   |
    +--- random --------+                   +--- random ---> (Node A')
```

### Input & Output Contract
- **Input:**
  - `head`: `Node*` reference to the head of a linked list ($0 \le n \le 1000$, $-10^4 \le \text{Node.val} \le 10^4$).
- **Output:**
  - `Node*` reference to head of the cloned deep-copy list.

### The Core Challenge
Because `random` pointers can point arbitrarily forward, backward, or to `nullptr`, we cannot clone `random` pointers in a single pass without knowing where future clone nodes reside in memory. We can either map `original -> clone` using an $O(n)$ hash map, or weave cloned nodes directly into the original list for **$O(1)$ auxiliary space**!

---

**Example 1:**
```
Input:  head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
Output: [[7,null],[13,0],[11,4],[10,2],[1,0]]
```

**Example 2:**
```
Input:  head = [[1,1],[2,1]]
Output: [[1,1],[2,1]]
```

**Constraints:**
- $0 \le n \le 1000$
- $-10^4 \le \text{Node.val} \le 10^4$
- `Node.random` is `null` or points to some node in the list.

## Approach 1 — Hash Map Pointer Mapping ($O(n)$ Space)

### Intuition
1. **Pass 1:** Iterate through the original list, instantiate clone nodes without connections, and record `map[original] = clone`.
2. **Pass 2:** Rewire connections:
   - `map[curr]->next = map[curr->next]`
   - `map[curr]->random = map[curr->random]`
3. Return `map[head]`.

### C++ Implementation
```cpp
/*
class Node {
public:
    int val;
    Node* next;
    Node* random;
    Node(int _val) : val(_val), next(nullptr), random(nullptr) {}
};
*/

class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (head == nullptr) return nullptr;
        
        unordered_map<Node*, Node*> cloneMap;
        
        // Pass 1: Create all clone nodes
        Node* curr = head;
        while (curr != nullptr) {
            cloneMap[curr] = new Node(curr->val);
            curr = curr->next;
        }
        
        // Pass 2: Connect next and random pointers
        curr = head;
        while (curr != nullptr) {
            cloneMap[curr]->next = cloneMap[curr->next];
            cloneMap[curr]->random = cloneMap[curr->random];
            curr = curr->next;
        }
        
        return cloneMap[head];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two passes over $n$ nodes; map lookups are $O(1)$. |
| **Space** | $O(n)$ | Hash map stores $n$ node pointer mappings. |

## Approach 2 — 3-Pass In-Place Node Interweaving ✅

### Key Insight
Eliminate the hash map by weaving each cloned node directly behind its original counterpart in the list:
1. **Pass 1 (Interweave):** For each original node `curr`, instantiate `copy` and insert it immediately after:
   $$\text{curr} \longrightarrow \text{copy} \longrightarrow \text{curr}\rightarrow\text{next}$$
2. **Pass 2 (Wire Random Pointers):** The clone of any original node `curr` is located at `curr->next`. Therefore, the clone's random pointer is simply:
   $$\text{curr}\rightarrow\text{next}\rightarrow\text{random} = \text{curr}\rightarrow\text{random} \ ? \ \text{curr}\rightarrow\text{random}\rightarrow\text{next} : \text{nullptr}$$
3. **Pass 3 (Decouple Lists):** Split the intertwined list back into the original list and the cloned list.

```
Original: A -> B -> nullptr (where A.random = B)

Pass 1 (Interweave):
A -> A' -> B -> B' -> nullptr

Pass 2 (Assign random pointers):
A'->random = A->random->next = B'

Pass 3 (Decouple):
Original: A -> B -> nullptr
Clone:    A' -> B' -> nullptr ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (head == nullptr) return nullptr;
        
        // Pass 1: Interweave cloned nodes directly after originals
        Node* curr = head;
        while (curr != nullptr) {
            Node* copy = new Node(curr->val);
            copy->next = curr->next;
            curr->next = copy;
            curr = copy->next;
        }
        
        // Pass 2: Connect cloned random pointers
        curr = head;
        while (curr != nullptr) {
            if (curr->random != nullptr) {
                curr->next->random = curr->random->next;
            }
            curr = curr->next->next;
        }
        
        // Pass 3: Separate the intertwined lists
        curr = head;
        Node* cloneHead = head->next;
        while (curr != nullptr) {
            Node* copy = curr->next;
            curr->next = copy->next;
            if (copy->next != nullptr) {
                copy->next = copy->next->next;
            }
            curr = curr->next;
        }
        
        return cloneHead;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | 3 sequential linear passes. |
| **Space** | $O(1)$ auxiliary | Modifies pointers in-place without hash maps or recursion. |

> **This is the one.** Elegant in-place pointer math with zero auxiliary memory.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty List** | `head = nullptr` | Null dereference | Guard `if (!head) return nullptr;` returns `nullptr` immediately. |
| **Self-Referential Random Pointer** | `A.random = A` | Cyclic assignment | `A'->random = A->random->next` assigns `A'` cleanly. |
| **`random` is `nullptr`** | `A.random = nullptr` | Accessing `nullptr->next` | Guarded by `if (curr->random != nullptr)`. |

## Pattern Takeaways

1. **Physical Interweaving Pattern:**  
   When copying complex pointer graphs with $O(1)$ auxiliary space, inserting duplicate nodes directly adjacent to originals eliminates the need for pointer lookup tables.

## What are we solving?

Given the `root` of a binary tree, return the **level order traversal** of its nodes' values. (i.e., from left to right, level by level).

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
```

**Example 2:**
```
Input:  root = [1]
Output: [[1]]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 2000]$.
- $-1000 \le \text{Node.val} \le 1000$

## Approach 1 — Queue-Based BFS by Level Size ✅

**Key insight:**
Use a FIFO queue `queue<TreeNode*> q`.
At each level:
1. Snapshot current queue size `levelSize = q.size()`.
2. Process exactly `levelSize` nodes, collecting their values into `levelValues` and pushing their non-null children into `q`.
3. Push `levelValues` into `result`.

```
Tree: [3, 9, 20, 15, 7]
q = [3]

Level 0: size=1 -> process 3, push 9, 20 -> level = [3], q = [9, 20]
Level 1: size=2 -> process 9, 20, push 15, 7 -> level = [9, 20], q = [15, 7]
Level 2: size=2 -> process 15, 7 -> level = [15, 7], q = []

Result: [[3], [9, 20], [15, 7]] ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (!root) return {};
        vector<vector<int>> result;
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            int levelSize = q.size();
            vector<int> currentLevel;
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = q.front();
                q.pop();
                currentLevel.push_back(node->val);
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            result.push_back(currentLevel);
        }
        
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ for queue (max width) |

> **This is the one.** Standard BFS level-order iteration.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty tree `root = nullptr` | Queue with null | Returns `[]` |
| Single node | Loop termination | Returns `[[val]]` |

---

## Pattern Takeaway

Capturing **`levelSize = q.size()`** before the inner loop cleanly delineates tree levels in breadth-first search.

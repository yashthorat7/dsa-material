## What are we solving?

Given the `root` of a binary tree, return the **level order traversal** of its nodes' values (i.e., grouped from left to right, level by level).

```
            (3)             Level 0: [3]
           /   \
         (9)   (20)         Level 1: [9, 20]
               /  \
             (15)  (7)      Level 2: [15, 7]
             
 Output: [ [3], [9, 20], [15, 7] ]
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root of a binary tree ($0 \le \text{node count} \le 2000$, $-1000 \le \text{Node.val} \le 1000$).
- **Output:**
  - `vector<vector<int>>` where each inner vector represents values on a horizontal depth level.

### The Core Challenge
We need to group node values strictly by horizontal depth. The standard technique snapshots the queue's size (`levelSize = q.size()`) at the start of each level, processing that exact batch of nodes before moving to the next level.

---

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
```

**Example 2:**
```
Input:  root = [1]
Output: [[1]]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 2000]$.
- $-1000 \le \text{Node.val} \le 1000$

## Approach 1 — Iterative BFS with Queue Size Snapshot ✅

### Key Insight
Use a FIFO queue `queue<TreeNode*>`.
At the start of each level:
1. Snapshot `int levelSize = q.size()`.
2. Process exactly `levelSize` nodes in an inner `for` loop:
   - Dequeue `TreeNode* curr = q.front()`.
   - Append `curr->val` to the current level's vector.
   - Enqueue `curr->left` and `curr->right` if non-null.
3. Append the completed level vector to `result`.

```
Tree: [3, 9, 20, 15, 7]
q = [3]

Level 0: size=1 -> dequeue 3 (level: [3]), enqueue 9, 20 -> q: [9, 20]
Level 1: size=2 -> dequeue 9, 20 (level: [9, 20]), enqueue 15, 7 -> q: [15, 7]
Level 2: size=2 -> dequeue 15, 7 (level: [15, 7]) -> q: [] (empty)

Result: [[3], [9, 20], [15, 7]] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (root == nullptr) return {};
        
        vector<vector<int>> result;
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            int levelSize = q.size();
            vector<int> currentLevel;
            currentLevel.reserve(levelSize);
            
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = q.front();
                q.pop();
                
                currentLevel.push_back(node->val);
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            
            result.push_back(move(currentLevel));
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each node is enqueued and dequeued exactly once. |
| **Space** | $O(w)$ | Maximum queue size equals maximum width of the tree $w \le n/2$. |

> **This is the one.** Clean, robust, standard BFS level-order iteration.

## Approach 2 — Recursive DFS with Depth Index Tracking

### Intuition
Perform pre-order DFS while passing the current node's `depth` level (starting at 0):
- If `result.size() == depth`, create a new level vector: `result.push_back({})`.
- Append `node->val` to `result[depth]`.
- Recurse on `node->left` with `depth + 1` and `node->right` with `depth + 1`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        dfs(root, 0, result);
        return result;
    }

private:
    void dfs(TreeNode* node, int depth, vector<vector<int>>& result) {
        if (node == nullptr) return;
        
        // If entering a new level, allocate its container
        if (depth == result.size()) {
            result.push_back({});
        }
        
        result[depth].push_back(node->val);
        
        dfs(node->left, depth + 1, result);
        dfs(node->right, depth + 1, result);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits each node once. |
| **Space** | $O(h)$ | Recursion stack depth equals tree height $h$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Tree** | `root = nullptr` | Enqueueing null / accessing front | Guard `if (!root) return {};` returns empty vector `[]`. |
| **Single Node** | `root = [1]` | Loop bounds | Produces `[[1]]` in one iteration. |
| **Skewed List Structure** | `1 -> 2 -> 3` | Deep tree levels | Generates `[[1], [2], [3]]` correctly. |

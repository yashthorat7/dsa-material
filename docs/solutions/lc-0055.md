## What are we solving?

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true` if you can reach the last index, or `false` otherwise.

The question is: **how does tracking the maximum reachable index in a single pass determine reachability in $O(n)$ time and $O(1)$ space?**

**Example 1:**
```
Input:  nums = [2,3,1,1,4]
Output: true
Explanation: Jump 1 step from index 0 to 1, then 3 steps to the last index.
```

**Example 2:**
```
Input:  nums = [3,2,1,0,4]
Output: false
Explanation: You will always arrive at index 3 no matter what. Its maximum jump length is 0, which makes it impossible to reach the last index.
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^4$
- $0 \le \text{nums}[i] \le 10^5$

## Approach 1 — Greedy Max Reach Tracking ✅

**Key insight:**
Maintain `maxReach`, the furthest index we can currently reach.
Iterate `i` from `0` to `n - 1`:
- If `i > maxReach`: we got stuck and cannot reach index `i` $\rightarrow$ return `false`.
- Update `maxReach = max(maxReach, i + nums[i])`.
- If `maxReach >= n - 1`: we can already reach the end $\rightarrow$ return `true`.

```
nums = [2, 3, 1, 1, 4]
maxReach = 0

i=0: maxReach = max(0, 0+2) = 2
i=1: 1 <= 2 -> maxReach = max(2, 1+3) = 4 >= 4 (last index!) -> return true ✓
```

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int maxReach = 0;
        int n = nums.size();
        
        for (int i = 0; i < n; i++) {
            if (i > maxReach) return false;
            maxReach = max(maxReach, i + nums[i]);
            if (maxReach >= n - 1) return true;
        }
        
        return true;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Standard $O(n)$ greedy reachability.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single element `[0]` | Zero jump at start | Already at destination, `maxReach >= n-1` returns `true` |
| Array with zeroes `[3, 2, 1, 0, 4]` | Getting stuck | `maxReach = 3`, at `i = 4 > 3` returns `false` |

---

## Pattern Takeaway

In forward reachability problems, **tracking the maximum envelope boundary (`maxReach`)** in a single pass is provably equivalent to full reachability search.

## What are we solving?

Given the `root` of a binary tree, return the length of the **diameter** of the tree.

The **diameter** of a binary tree is the length of the longest path between any two nodes in a tree.
- This path **may or may not pass through the root**.
- The length of a path between two nodes is represented by the **number of edges** between them.

```
          1
         / \
        2   3
       / \
      4   5
      
 Longest Path: [4 -> 2 -> 1 -> 3] or [5 -> 2 -> 1 -> 3]
 Length (Number of Edges): 3
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` ($1 \le n \le 10^4$, $-100 \le \text{Node.val} \le 100$).
- **Output:**
  - `int`: Maximum diameter (edge count).

### The Core Invariant
At any given node $u$:
- **Diameter through node $u$:** $\text{leftDepth} + \text{rightDepth}$ (the longest path that turns at node $u$).
- **Depth returned to parent:** $1 + \max(\text{leftDepth}, \text{rightDepth})$ (the longest straight path upward).

---

**Example 1:**
```
Input:  root = [1,2,3,4,5]
Output: 3
Explanation: 3 is the length of the path [4,2,1,3] or [5,2,1,3].
```

**Example 2:**
```
Input:  root = [1,2]
Output: 1
```

**Constraints:**
- The number of nodes in the tree is in the range $[1, 10^4]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Naive Two-Pass Depth Calculation ($O(n^2)$)

### Intuition
For every node $u$, calculate `depth(u->left)` and `depth(u->right)` with top-down helper functions. The diameter passing through $u$ is $\text{leftDepth} + \text{rightDepth}$.

### C++ Implementation
```cpp
class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        if (!root) return 0;
        
        int currentDiameter = getDepth(root->left) + getDepth(root->right);
        int leftDiameter = diameterOfBinaryTree(root->left);
        int rightDiameter = diameterOfBinaryTree(root->right);
        
        return max({currentDiameter, leftDiameter, rightDiameter});
    }

private:
    int getDepth(TreeNode* node) {
        if (!node) return 0;
        return 1 + max(getDepth(node->left), getDepth(node->right));
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Re-traverses subtrees to calculate heights for every node. |
| **Space** | $O(h)$ | Recursion stack depth. |

## Approach 2 — Bottom-Up Post-Order DFS (Single Pass) ✅

### Key Insight
Combine height computation and diameter tracking into a **single post-order DFS**:
1. Helper function `int maxDepth(TreeNode* node, int& maxDiameter)`:
   - Base case: `if (!node) return 0;`
   - Recursively compute `leftH = maxDepth(node->left, maxDiameter)`.
   - Recursively compute `rightH = maxDepth(node->right, maxDiameter)`.
   - Update global maximum diameter:
     $$\mathbf{\text{maxDiameter} = \max(\text{maxDiameter}, \text{leftH} + \text{rightH})}$$
   - Return this node's branch depth to parent:
     $$\mathbf{\text{return } 1 + \max(\text{leftH}, \text{rightH})}$$
2. Call `maxDepth(root, maxDiameter)` and return `maxDiameter`.

```
Tree:
      1 (d = 2 + 1 = 3)
     / \
    2   3 (h=1)
   / \
  4   5 (h=1)

- Node 4: leftH=0, rightH=0 -> d=0, returns h=1
- Node 5: leftH=0, rightH=0 -> d=0, returns h=1
- Node 2: leftH=1, rightH=1 -> d=2, returns h=2
- Node 3: leftH=0, rightH=0 -> d=0, returns h=1
- Node 1: leftH=2, rightH=1 -> d=3, returns h=3

Max Diameter recorded = 3 ✓
```

### C++ Implementation
```cpp
/*
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};
*/

class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        int maxDiameter = 0;
        getDepth(root, maxDiameter);
        return maxDiameter;
    }

private:
    int getDepth(TreeNode* node, int& maxDiameter) {
        if (node == nullptr) return 0;
        
        int leftH = getDepth(node->left, maxDiameter);
        int rightH = getDepth(node->right, maxDiameter);
        
        // Longest path turning at current node
        maxDiameter = max(maxDiameter, leftH + rightH);
        
        // Depth passed upwards to parent
        return 1 + max(leftH, rightH);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits each node exactly once in post-order. |
| **Space** | $O(h)$ | Call stack depth ($O(\log n)$ balanced, $O(n)$ skewed). |

> **This is the one.** Elegant single-pass post-order tree path optimization.

## Approach 3 — Iterative Post-Order DFS with Depth Map

### Intuition
Perform an iterative post-order traversal using a stack. Maintain node depths in an `unordered_map<TreeNode*, int>` to compute diameters without recursion.

### C++ Implementation
```cpp
class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        if (!root) return 0;
        stack<TreeNode*> st;
        unordered_map<TreeNode*, int> depth;
        int maxDiameter = 0;
        st.push(root);
        
        while (!st.empty()) {
            TreeNode* curr = st.top();
            if (curr->left && !depth.count(curr->left)) {
                st.push(curr->left);
            } else if (curr->right && !depth.count(curr->right)) {
                st.push(curr->right);
            } else {
                st.pop();
                int l = depth[curr->left];
                int r = depth[curr->right];
                maxDiameter = max(maxDiameter, l + r);
                depth[curr] = 1 + max(l, r);
            }
        }
        
        return maxDiameter;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Traverses every node iteratively in post-order. |
| **Space** | $O(n)$ | Hash map and stack memory. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Node** | `[1]` | Returning 1 instead of 0 edges | `leftH = 0, rightH = 0 \implies \text{maxDiameter} = 0`. |
| **Path Bypasses Root** | Deep left branch has massive diameter | Assuming path must pass through root | `maxDiameter` updated globally at every subtree root. |

## Pattern Takeaways

1. **Tree Turn-Point vs Passthrough Value Invariant:**  
   $$\text{Turn Point (Global Update)} = \text{leftH} + \text{rightH}$$
   $$\text{Passthrough (Return Value)} = 1 + \max(\text{leftH}, \text{rightH})$$

## What are we solving?

Given the `root` of a binary tree, return the length of the **diameter** of the tree.

The **diameter** of a binary tree is the length of the longest path between any two nodes in a tree. This path may or may not pass through the root. The length of a path between two nodes is represented by the number of edges between them.

**Example 1:**
```
Input:  root = [1,2,3,4,5]
Output: 3
Explanation: 3 is the length of the path [4,2,1,3] or [5,2,1,3].
```

**Example 2:**
```
Input:  root = [1,2]
Output: 1
```

**Constraints:**
- The number of nodes in the tree is in the range $[1, 10^4]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Post-Order Height with Global Diameter Update ✅

**Key insight:**
At every node:
- The longest path passing *through* this node is `leftHeight + rightHeight`.
- Update global `maxDiameter = max(maxDiameter, leftHeight + rightHeight)`.
- Return this node's height `1 + max(leftHeight, rightHeight)` to its parent.

```
1 (d = 2 + 1 = 3)
     / \
    2   3 (h=1)
   / \
  4   5 (h=1)

Node 2: leftH=1, rightH=1 -> d = 2
Node 1: leftH=2, rightH=1 -> d = 3
Max diameter = 3 ✓
```

```cpp
class Solution {
public:
    int diameterOfBinaryTree(TreeNode* root) {
        int maxDiameter = 0;
        height(root, maxDiameter);
        return maxDiameter;
    }
private:
    int height(TreeNode* node, int& maxDiameter) {
        if (!node) return 0;
        int leftH = height(node->left, maxDiameter);
        int rightH = height(node->right, maxDiameter);
        maxDiameter = max(maxDiameter, leftH + rightH);
        return 1 + max(leftH, rightH);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(h)$ |

> **This is the one.** Computes diameter in a single post-order traversal.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Longest path does not pass through root | Only checking root's diameter | Global variable tracks diameter at every intermediate node |
| Single node `[1]` | Returning 1 instead of 0 edges | Left and right height 0 -> `maxDiameter = 0` |

---

## Pattern Takeaway

In binary tree path optimization, **differentiate between what you return to the parent (`1 + max(L, R)`) vs what you update globally (`L + R`)**.

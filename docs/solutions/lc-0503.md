## What are we solving?

Given a **circular integer array** `nums` (i.e., the next element of `nums[nums.length - 1]` is `nums[0]`), return the **next greater number** for every element in `nums`.

The next greater number of a number $x$ is the first greater number to its traversing-order next in the array, which means you could search circularly to find its next greater number. If it does not exist, return `-1` for this number.

```
 nums = [ 1, 2, 1 ] (Circular)
 
 nums[0] = 1 -> Next greater to right is 2
 nums[1] = 2 -> Largest in array -> -1
 nums[2] = 1 -> Wraps around to start -> Next greater is 2
 
 Output: [ 2, -1, 2 ]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($1 \le n \le 10^4$, $-10^9 \le \text{nums}[i] \le 10^9$).
- **Output:**
  - `vector<int>` of size $n$ containing circular next greater elements.

### The Circular Array Invariant
A circular array of length $n$ can be conceptually flattened into a **doubled array of length $2n$**:
$$\text{nums}' = [ \text{nums}[0], \dots, \text{nums}[n-1], \text{nums}[0], \dots, \text{nums}[n-1] ]$$
Instead of allocating a duplicate array in memory, we iterate $i$ from $0$ to $2n - 1$ and access elements virtually via `nums[i % n]`.

---

**Example 1:**
```
Input:  nums = [1,2,1]
Output: [2,-1,2]
Explanation: The first 1's next greater number is 2;
The number 2 can't find next greater number;
The second 1's next greater number needs to search circularly, which is also 2.
```

**Example 2:**
```
Input:  nums = [1,2,3,4,3]
Output: [2,3,4,-1,4]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^4$
- $-10^9 \le \text{nums}[i] \le 10^9$

## Approach 1 — Brute Force Circular Scan ($O(n^2)$)

### Intuition
For each index $i$, scan circularly through $(i + 1) \% n, (i + 2) \% n, \dots, (i + n - 1) \% n$ until a strictly greater element is found or the scan wraps around.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n, -1);
        
        for (int i = 0; i < n; i++) {
            for (int step = 1; step < n; step++) {
                int j = (i + step) % n;
                if (nums[j] > nums[i]) {
                    result[i] = nums[j];
                    break;
                }
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | For each of the $n$ elements, scans up to $n - 1$ neighbors. |
| **Space** | $O(1)$ auxiliary | Output vector memory only. |

> **Verdict:** Suboptimal. Monotonic stack with $2n$ virtual loop achieves $O(n)$ linear time.

## Approach 2 — Monotonic Stack with Virtual Array Doubling ($2n$ Modulo Scan) ✅

### Key Insight
1. Initialize `result` of size $n$ filled with `-1`.
2. Maintain a `stack<int> st` storing **indices** in monotonic decreasing order of values.
3. Loop $i$ from $0$ to $2n - 1$:
   - Current element is `num = nums[i % n]`.
   - While stack is not empty and `nums[st.top()] < num`:
     - `num` is the next circular greater element for index `st.top()`!
     - `result[st.top()] = num`.
     - `st.pop()`.
   - **Only push index $i$ during the first pass ($i < n$)**: indices are uniquely bounded in $[0 \dots n - 1]$.
4. Return `result`.

```
nums = [1, 2, 1], n = 3. Scan 2*n = 6 steps:
result = [-1, -1, -1], st = []

i=0 (num=1): push 0 -> st = [0]
i=1 (num=2): 2 > nums[0] (1) -> result[0] = 2, pop 0 -> push 1 -> st = [1]
i=2 (num=1): 1 <= nums[1] (2) -> push 2 -> st = [1, 2]
--- Wrap-around Pass 2 ---
i=3 (idx 0, num=1): 1 <= nums[2] (1) -> skip push
i=4 (idx 1, num=2): 2 > nums[2] (1) -> result[2] = 2, pop 2 -> skip push
i=5 (idx 2, num=1): skip push

Result: [ 2, -1, 2 ] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n, -1);
        stack<int> st; // Monotonic stack of indices
        
        // Loop through the virtual doubled array [0 ... 2n - 1]
        for (int i = 0; i < 2 * n; i++) {
            int num = nums[i % n];
            
            while (!st.empty() && nums[st.top()] < num) {
                result[st.top()] = num;
                st.pop();
            }
            
            // Only push indices during the first traversal pass
            if (i < n) {
                st.push(i);
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Total loop runs $2n$ steps; each element index is pushed at most once and popped at most once. |
| **Space** | $O(n)$ | Monotonic stack holds at most $n$ indices. |

> **This is the one.** Clean, robust virtual doubling technique.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Global Maximum Element** | `[5, 4, 3, 2, 1]` | Element matching with itself | Strict `<` condition prevents matching identical values; stays `-1`. |
| **All Identical Elements** | `[3, 3, 3]` | Erroneous self-match | No pop occurs; returns `[-1, -1, -1]`. |
| **Single Element** | `[1]` | Wrap around | Loop finishes, returns `[-1]`. |

## What are we solving?

Given a circular integer array `nums` (i.e., the next element of `nums[nums.length - 1]` is `nums[0]`), return the **next greater number** for every element in `nums`.

The **next greater number** of a number `x` is the first greater number to its traversing-order next in the array, which means you could search circularly to find its next greater number. If it doesn't exist, return `-1` for this number.

**Example 1:**
```
Input:  nums = [1,2,1]
Output: [2,-1,2]
Explanation: The first 1's next greater number is 2;
The number 2 can't find next greater number;
The second 1's next greater number needs to search circularly, which is also 2.
```

**Example 2:**
```
Input:  nums = [1,2,3,4,3]
Output: [2,3,4,-1,4]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^4$
- $-10^9 \le \text{nums}[i] \le 10^9$

## Approach 1 — Double-Pass Monotonic Stack with Modulo Indexing ✅

**Key insight:**
Simulate the circular array by looping from `i = 0` to `2 * n - 1` with index `i % n`.
Maintain a monotonic decreasing stack of indices:
- While `!st.empty() && nums[st.top()] < nums[i % n]`:
  - `result[st.top()] = nums[i % n]`
  - `st.pop()`
- Push `i % n` only during the first pass (`i < n`).

```
nums = [1, 2, 1], n = 3. Loop 2*n = 6 steps:
result = [-1, -1, -1]

i=0 (val 1): push 0 -> st=[0]
i=1 (val 2): 2 > nums[0] -> result[0]=2, pop 0 -> push 1 -> st=[1]
i=2 (val 1): push 2 -> st=[1, 2]
--- Pass 2 ---
i=3 (idx 0, val 1): 1 <= nums[top] -> don't push
i=4 (idx 1, val 2): 2 > nums[2] -> result[2]=2, pop 2 -> don't push
i=5 (idx 2, val 1): done.

Result: [2, -1, 2] ✓
```

```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n, -1);
        stack<int> st;
        
        for (int i = 0; i < 2 * n; i++) {
            int num = nums[i % n];
            while (!st.empty() && nums[st.top()] < num) {
                result[st.top()] = num;
                st.pop();
            }
            if (i < n) {
                st.push(i);
            }
        }
        
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Virtual doubled array in $O(n)$ time.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Max element in array `[5, 4, 3, 2, 1]` | Resolving max element with itself | Strict inequality `nums[st.top()] < num` leaves `-1` for the global maximum |
| All identical elements `[2, 2, 2]` | Self matching | Returns `[-1, -1, -1]` |

---

## Pattern Takeaway

Circular monotonic stack queries are solved cleanly by **iterating $2n$ steps with modulo arithmetic `i % n`**, pushing only in the first $n$ steps.

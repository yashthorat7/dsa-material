> **Companies:** Google, Amazon, Citadel

## What are we solving?

In the universe Earth C-137, Rick discovered a special form of magnetic force between two balls if they are put in his new invention. Rick has $n$ empty baskets, the $i$-th basket is at `position[i]`. Morty wants to distribute $m$ balls into the baskets such that the **minimum magnetic force between any two balls is maximized**.

Given the integer array `position` and the integer `m`, return the **maximum possible minimum magnetic force**.

```
 Baskets: [ 1, 2, 3, 4, 7 ],  m = 3 balls
 
 Placements for minimum distance = 3:
 - Ball 1 at basket 1
 - Ball 2 at basket 4  (dist = 4 - 1 = 3)
 - Ball 3 at basket 7  (dist = 7 - 4 = 3)
 
 Minimum force is 3.
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `position`: `vector<int>` ($2 \le m \le n \le 10^5$, distinct coordinates $1 \le \text{position}[i] \le 10^9$).
  - `m`: `int` number of balls to place.
- **Output:**
  - `int`: Maximum achievable minimum distance between any two placed balls.

### The Monotonic Search Property ("Aggressive Cows")
Let candidate minimum magnetic force be $F$:
- If it is possible to place $m$ balls with distance $\ge F$, then for any smaller force $F' < F$, it is also trivially possible.
- If it is impossible to place $m$ balls with distance $\ge F$, then no larger force $F'' > F$ can ever be achieved.
This strict monotonicity enables **Binary Search on the Answer Space $[1 \dots \text{maxPos} - \text{minPos}]$** in $O(n \log(\text{Range}))$ time.

---

**Example 1:**
```
Input:  position = [1,2,3,4,7], m = 3
Output: 3
Explanation: Distributing the 3 balls into baskets 1, 4 and 7 will make the magnetic force between balls [3, 3, 6].
The minimum magnetic force is 3.
```

**Example 2:**
```
Input:  position = [5,4,3,2,1,1000000000], m = 2
Output: 999999999
Explanation: We can use baskets 1 and 1000000000.
```

**Constraints:**
- $n == \text{position.length}$
- $2 \le n \le 10^5$
- $1 \le \text{position}[i] \le 10^9$
- All integers in `position` are distinct.
- $2 \le m \le \text{position.length}$

## Approach 1 — Linear Search on Distance ($O(n \cdot (\max - \min))$)

### Intuition
Sort positions and test every distance $d = 1, 2, 3, \dots$ with greedy placement until the first distance that cannot fit $m$ balls is reached.

### C++ Implementation
```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int maxDist = position.back() - position.front();
        int best = 1;
        
        for (int force = 1; force <= maxDist; force++) {
            int ballsPlaced = 1, lastPos = position[0];
            for (int i = 1; i < position.size(); i++) {
                if (position[i] - lastPos >= force) {
                    ballsPlaced++;
                    lastPos = position[i];
                }
            }
            if (ballsPlaced >= m) best = force;
            else break;
        }
        
        return best;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \text{maxRange})$ | Up to $10^5 \times 10^9 = 10^{14}$ operations (TLE). |
| **Space** | $O(1)$ | No memory allocated. |

> **Verdict:** Suboptimal. Binary Search on Answer achieves $O(n \log(\max - \min))$ time.

## Approach 2 — Binary Search on Answer (Aggressive Cows) ✅

### Key Insight
1. **Sort `position` ascending.**
2. Set search range: `low = 1`, `high = position.back() - position.front()`.
3. Greedy placement helper `canPlace(force)`:
   - Always place the 1st ball at `position[0]`.
   - Iterate through remaining baskets. Place the next ball at the first basket where $\text{position}[i] - \text{lastPos} \ge \text{force}$.
   - If $\ge m$ balls are placed, return `true`.
4. While `low <= high`:
   - `mid = low + (high - low) / 2`.
   - If `canPlace(mid)`: `ans = mid`, `low = mid + 1` (try to maximize distance).
   - Else: `high = mid - 1` (reduce distance requirement).
5. Return `ans`.

```
position = [1, 2, 3, 4, 7], m = 3
Sorted: [1, 2, 3, 4, 7]
low = 1, high = 6

Iteration 1:
- mid = 3: place at 1 -> next >= 4 (pick 4) -> next >= 7 (pick 7) -> 3 balls placed!
  Feasible -> ans = 3, low = 4

Iteration 2:
- mid = 5: place at 1 -> next >= 6 (pick 7) -> only 2 balls placed!
  Infeasible -> high = 4

Iteration 3:
- mid = 4: place at 1 -> next >= 5 (pick 7) -> only 2 balls placed!
  Infeasible -> high = 3

Loop terminates (low > high).
Result: ans = 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        
        int low = 1;
        int high = position.back() - position.front();
        int ans = 1;
        
        auto canPlace = [&](int force) -> bool {
            int ballsPlaced = 1;
            int lastPos = position[0];
            
            for (int i = 1; i < position.size(); i++) {
                if (position[i] - lastPos >= force) {
                    ballsPlaced++;
                    lastPos = position[i];
                    if (ballsPlaced >= m) {
                        return true;
                    }
                }
            }
            return false;
        };
        
        while (low <= high) {
            int mid = low + (high - low) / 2;
            
            if (canPlace(mid)) {
                ans = mid;      // Feasible force, record and attempt a larger spacing
                low = mid + 1;
            } else {
                high = mid - 1; // Spacing too large, reduce requirement
            }
        }
        
        return ans;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n + n \log(\text{maxPos} - \text{minPos}))$ | Sorting takes $O(n \log n)$; binary search over range $10^9$ takes $\approx 30$ checks $\times n = 3 \times 10^6$ ops (<15ms). |
| **Space** | $O(1)$ auxiliary | In-place sorting. |

> **This is the one.** Canonical 'Maximize the Minimum' Binary Search algorithm.

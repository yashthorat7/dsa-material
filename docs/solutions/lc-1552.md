## What are we solving?

In the universe Earth C-137, Rick discovered a special form of magnetic force between two balls if they are put in his new invention. Rick has `n` empty baskets, the $i$-th basket is at `position[i]`, Mortys wants to distribute `m` balls into the baskets such that the **minimum magnetic force** between any two balls is **maximum**.

Given the integer array `position` and the integer `m`. Return the maximum force.

**Example 1:**
```
Input:  position = [1,2,3,4,7], m = 3
Output: 3
Explanation: Distributing the 3 balls into baskets 1, 4 and 7 will make the magnetic force between balls [3, 3, 6]. The minimum magnetic force is 3. We cannot achieve a larger minimum force.
```

**Example 2:**
```
Input:  position = [5,4,3,2,1,1000000000], m = 2
Output: 999999999
Explanation: We can use baskets 1 and 1000000000.
```

**Constraints:**
- $n == \text{position.length}$
- $2 \le n \le 10^5$
- $1 \le \text{position}[i] \le 10^9$
- All integers in `position` are distinct.
- $2 \le m \le \text{position.length}$

## Approach 1 — Binary Search on Distance with Greedy Ball Placement ✅

**Key insight:**
1. Sort `position`.
2. Binary search over possible minimum force: `low = 1`, `high = position.back() - position.front()`.
3. Check function `canPlace(force)`:
   - Place first ball at `position[0]`.
   - Greedily place next ball at the first basket with `position[i] - lastPlaced >= force`.
   - If at least `m` balls placed: force is achievable -> search larger force: `ans = mid, low = mid + 1`.
   - Else: force too large -> `high = mid - 1`.

```
position = [1, 2, 3, 4, 7], m = 3
low = 1, high = 6

mid = 3: place at 1, next >= 1+3=4 (pick 4), next >= 4+3=7 (pick 7) -> 3 balls placed! (valid) -> ans=3, low=4
mid = 5: place at 1, next >= 6 (pick 7) -> only 2 balls placed (< 3) -> high=4
mid = 4: place at 1, next >= 5 (pick 7) -> 2 balls placed -> high=3 -> loop terminates!

Result: 3 ✓
```

```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int low = 1, high = position.back() - position.front();
        int ans = 1;
        
        auto canPlace = [&](int force) {
            int ballsPlaced = 1;
            int lastPos = position[0];
            for (int i = 1; i < position.size(); i++) {
                if (position[i] - lastPos >= force) {
                    ballsPlaced++;
                    lastPos = position[i];
                    if (ballsPlaced >= m) return true;
                }
            }
            return false;
        };
        
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (canPlace(mid)) {
                ans = mid;
                low = mid + 1; // try larger minimum force
            } else {
                high = mid - 1;
            }
        }
        
        return ans;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n + n \log(\text{maxPos} - \text{minPos}))$ | $O(1)$ |

> **This is the one.** Standard Aggressive Cows / Maximize Minimum Distance pattern.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `m = 2` (place 2 balls) | Testing intermediate positions | Picks the two furthest baskets `position.back() - position.front()` |
| Huge distances $10^9$ | 32-bit overflow | Distance values fit comfortably in integer limits |

## Pattern Takeaway

The **'Maximize the Minimum Distance'** template pairs sorting with a **greedy placement check inside a binary search loop**.

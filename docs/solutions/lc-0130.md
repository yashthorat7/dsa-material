# 130. Surrounded Regions

https://leetcode.com/problems/surrounded-regions

> **Medium** $\rightarrow$ **Graph Traversal**


> **Companies:** Google, Bloomberg, Uber, TikTok, Ola, Swiggy, Wipro

---

## What are we solving?

You are given an `m x n` matrix `board` containing `'X'` and `'O'`. Capture all regions that are **4-directionally surrounded** by `'X'`.

A region is captured by flipping all `'O'`s into `'X'`s in that surrounded region. An `'O'` on the boundary is not surrounded and cannot be captured.

**Example 1:**
```
Input:  board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
Output: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
Explanation: Notice that an 'O' should not be flipped if it is on the border, or it is adjacent to an 'O' on the border.
```

**Example 2:**
```
Input:  board = [["X"]]
Output: [["X"]]
```

**Constraints:**
- $m == \text{board.length}$
- $n == \text{board}[i].\text{length}$
- $1 \le m, n \le 200$
- `board[i][j]` is `'X'` or `'O'`.

## Approach 1 — Boundary-Connected Flood Fill (Inversion) ✅

**Key insight:**
Any `'O'` that connects to the **border** can NEVER be surrounded!
1. Run DFS from every `'O'` on the 4 borders (first/last row and column), marking them as safe (e.g. `'T'`).
2. After border DFS, scan the whole board:
   - If `'O'`: it is completely surrounded $\rightarrow$ change to `'X'`.
   - If `'T'`: it is safe $\rightarrow$ restore to `'O'`.

```
Board:
X X X X
X O O X
X X O X
X O X X (border 'O' at (3,1))

1. DFS from border (3,1): marks (3,1) as 'T'
2. Scan:
   (1,1) is 'O' -> 'X'
   (1,2) is 'O' -> 'X'
   (2,2) is 'O' -> 'X'
   (3,1) is 'T' -> 'O'

Result matches example ✓
```

```cpp
class Solution {
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty()) return;
        int m = board.size(), n = board[0].size();
        
        // 1. Mark border-connected 'O's as 'T'
        for (int r = 0; r < m; r++) {
            if (board[r][0] == 'O') dfs(board, r, 0, m, n);
            if (board[r][n - 1] == 'O') dfs(board, r, n - 1, m, n);
        }
        for (int c = 0; c < n; c++) {
            if (board[0][c] == 'O') dfs(board, 0, c, m, n);
            if (board[m - 1][c] == 'O') dfs(board, m - 1, c, m, n);
        }
        
        // 2. Flip surrounded 'O' -> 'X', and restore 'T' -> 'O'
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (board[r][c] == 'O') board[r][c] = 'X';
                else if (board[r][c] == 'T') board[r][c] = 'O';
            }
        }
    }
private:
    void dfs(vector<vector<char>>& board, int r, int c, int m, int n) {
        if (r < 0 || r >= m || c < 0 || c >= n || board[r][c] != 'O') return;
        board[r][c] = 'T';
        dfs(board, r + 1, c, m, n);
        dfs(board, r - 1, c, m, n);
        dfs(board, r, c + 1, m, n);
        dfs(board, r, c - 1, m, n);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(m \cdot n)$ |

> **This is the one.** Inverting the search from borders avoids complex interior cycle detection.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Board smaller than 3x3 | All cells are on borders | Border DFS preserves all 'O's safely |
| All 'O's connected to border | Accidental flip | All converted to 'T' and restored to 'O' |

---

## Pattern Takeaway

When identifying **enclosed regions**, invert the logic: **mark non-enclosed regions from the boundary outwards**, then flip whatever remains unvisited.

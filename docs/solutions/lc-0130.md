# 130. Surrounded Regions

https://leetcode.com/problems/surrounded-regions

> **Medium** $\rightarrow$ **Graph Traversal**


> **Companies:** Google, Bloomberg, Uber, TikTok, Ola, Swiggy, Wipro

---

## What are we solving?

You are given an $m \times n$ matrix `board` containing `'X'` and `'O'`. Capture all regions that are **4-directionally surrounded** by `'X'`.

A region is captured by flipping all `'O'`s into `'X'`s in that surrounded region. An `'O'` on the boundary (or connected to a boundary `'O'`) is **not surrounded** and cannot be captured.

```
 Original:                   Border-Safe Marked:         Final Captured:
 X  X  X  X                  X  X  X  X                  X  X  X  X
 X  O  O  X                  X  O  O  X                  X  X  X  X
 X  X  O  X       --->       X  X  O  X       --->       X  X  X  X
 X  O  X  X                  X (T) X  X                  X  O  X  X
```

### Input & Output Contract
- **Input:**
  - `board`: `vector<vector<char>>` where $1 \le m, n \le 200$, $\text{board}[i][j] \in \{'X', 'O'\}$.
- **Output:**
  - `void` (flips surrounded cells in place).

### The Core Challenge
Trying to determine if an interior `'O'` is surrounded by exploring outward requires checking whether every branch reaches a boundary before hitting `'X'`.  
**Inverse Key Insight:**  
Instead of searching from the inside out, **search from the outside in!** Any `'O'` connected to the 4 borders can never be surrounded.

---

**Example 1:**
```
Input:  board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
Output: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
Explanation: The 'O' in the bottom row (row 3, col 1) is on the border, so it is not flipped.
The three interior 'O's are completely surrounded by 'X's and are flipped to 'X's.
```

**Example 2:**
```
Input:  board = [["X"]]
Output: [["X"]]
```

**Constraints:**
- $m == \text{board.length}$
- $n == \text{board}[i].\text{length}$
- $1 \le m, n \le 200$
- `board[i][j]` is `'X'` or `'O'`.

## Approach 1 — Boundary-Connected DFS Flood Fill (Inversion) ✅

### Key Insight
1. **Pass 1 (Border Flood Fill):** Run DFS from every `'O'` on the 4 outer borders (rows $0, m-1$ and columns $0, n-1$). Mark all reachable `'O'` cells with temporary marker `'T'` (Safe/Trapped).
2. **Pass 2 (Grid Transformation):** Iterate through all $m \times n$ cells:
   - If cell is `'O'`: it was never reached from the boundary $\implies$ it is strictly surrounded $\rightarrow$ flip to `'X'`.
   - If cell is `'T'`: it is connected to a boundary $\implies$ restore back to `'O'`.

```
1. Border DFS marks border 'O' at (3, 1) as 'T'
2. Full Grid Scan:
   - (1, 1) is 'O' -> flip to 'X'
   - (1, 2) is 'O' -> flip to 'X'
   - (2, 2) is 'O' -> flip to 'X'
   - (3, 1) is 'T' -> restore to 'O'
All surrounded cells captured! ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty() || board[0].empty()) return;
        int m = board.size(), n = board[0].size();
        
        // 1. Mark border-connected 'O's with temporary marker 'T'
        for (int r = 0; r < m; r++) {
            if (board[r][0] == 'O') dfs(r, 0, m, n, board);
            if (board[r][n - 1] == 'O') dfs(r, n - 1, m, n, board);
        }
        for (int c = 0; c < n; c++) {
            if (board[0][c] == 'O') dfs(0, c, m, n, board);
            if (board[m - 1][c] == 'O') dfs(m - 1, c, m, n, board);
        }
        
        // 2. Flip interior 'O' -> 'X', and restore 'T' -> 'O'
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (board[r][c] == 'O') {
                    board[r][c] = 'X';
                } else if (board[r][c] == 'T') {
                    board[r][c] = 'O';
                }
            }
        }
    }

private:
    void dfs(int r, int c, int m, int n, vector<vector<char>>& board) {
        if (r < 0 || r >= m || c < 0 || c >= n || board[r][c] != 'O') {
            return;
        }
        
        board[r][c] = 'T'; // Mark as border-safe
        
        dfs(r + 1, c, m, n, board);
        dfs(r - 1, c, m, n, board);
        dfs(r, c + 1, m, n, board);
        dfs(r, c - 1, m, n, board);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Each cell is visited at most twice (once in DFS, once in final sweep). |
| **Space** | $O(m \cdot n)$ | Recursion stack depth in worst-case snake board. |

> **This is the one.** Inverting boundary logic eliminates complex cycle checks.

## Approach 2 — Boundary-Connected BFS Queue

### Intuition
Enqueue all border `'O'` coordinates into a FIFO queue `queue<pair<int,int>>`. Process BFS to mark all connected safe cells as `'T'`.

### C++ Implementation
```cpp
class Solution {
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty()) return;
        int m = board.size(), n = board[0].size();
        queue<pair<int, int>> q;
        
        for (int r = 0; r < m; r++) {
            if (board[r][0] == 'O') { board[r][0] = 'T'; q.push({r, 0}); }
            if (board[r][n - 1] == 'O') { board[r][n - 1] = 'T'; q.push({r, n - 1}); }
        }
        for (int c = 0; c < n; c++) {
            if (board[0][c] == 'O') { board[0][c] = 'T'; q.push({0, c}); }
            if (board[m - 1][c] == 'O') { board[m - 1][c] = 'T'; q.push({m - 1, c}); }
        }
        
        const int dr[] = {0, 0, 1, -1};
        const int dc[] = {1, -1, 0, 0};
        
        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d];
                int nc = c + dc[d];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && board[nr][nc] == 'O') {
                    board[nr][nc] = 'T';
                    q.push({nr, nc});
                }
            }
        }
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (board[r][c] == 'O') board[r][c] = 'X';
                else if (board[r][c] == 'T') board[r][c] = 'O';
            }
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Single linear BFS pass. |
| **Space** | $O(m \cdot n)$ | Queue stores boundary-connected cells. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Board Dimensions $\le 2$** | $2 \times 2$ grid `[["O","O"],["O","O"]]` | All cells are on boundary | Border DFS marks all 4 cells as `'T'`, none are flipped to `'X'`. |
| **No Border `'O'`s** | All borders `'X'`, interior `'O'` | False negative | Border DFS does not trigger, all interior `'O'`s flipped to `'X'`. |
| **$1 \times 1$ Matrix** | `[["X"]]` | Index out of bounds | Returns `[["X"]]` safely. |

1. **The Inversion Principle:**

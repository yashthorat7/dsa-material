## What are we solving?

You are given an $m \times n$ binary matrix `grid`. An island is a group of `1`'s (representing land) connected **4-directionally** (horizontal or vertical). You may assume all four edges of the grid are surrounded by water.

The **area** of an island is the number of cells with a value `1` in the island.

Return the **maximum area** of an island in `grid`. If there is no island, return `0`.

```
 Grid:
 [ [0, 0, (1), 0, 0],
   [0, (1),(1), 0, 0],
   [0, 0, (1), 0, 0] ]
   
 Island Area = 4 cells connected
 Output: 4
```

### Input & Output Contract
- **Input:**
  - `grid`: `vector<vector<int>>` ($1 \le m, n \le 50$, `grid[i][j]` is `0` or `1`).
- **Output:**
  - `int`: Maximum island area, or `0` if all water.

## Approach 1 — Recursive DFS Flood Fill (Sink Land) ✅

### Key Insight
1. Iterate over every cell $(r, c)$ in the $m \times n$ matrix.
2. If `grid[r][c] == 1`:
   - Launch `dfs(r, c)`.
   - `dfs` sinks the current land cell (`grid[r][c] = 0`), and recursively sums $1 + \sum \text{dfs(neighbors)}$.
   - Update `maxArea = max(maxArea, currentArea)`.
3. Sinking cells in place eliminates the need for an auxiliary visited table.

```
Connected 1s:
(0,0)=1, (0,1)=1, (1,0)=1

dfs(0,0):
  marks (0,0)=0
  returns 1 + dfs(0,1) + dfs(1,0)
  dfs(0,1): marks (0,1)=0 -> returns 1
  dfs(1,0): marks (1,0)=0 -> returns 1
Total Area = 1 + 1 + 1 = 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int maxAreaOfIsland(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        int maxArea = 0;
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    maxArea = max(maxArea, dfs(r, c, m, n, grid));
                }
            }
        }
        
        return maxArea;
    }

private:
    int dfs(int r, int c, int m, int n, vector<vector<int>>& grid) {
        if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] != 1) {
            return 0;
        }
        
        // Sink the current cell to mark as visited
        grid[r][c] = 0;
        
        return 1 + dfs(r + 1, c, m, n, grid)
                 + dfs(r - 1, c, m, n, grid)
                 + dfs(r, c + 1, m, n, grid)
                 + dfs(r, c - 1, m, n, grid);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Each cell is visited at most 5 times (once in loop + 4 from neighbors). |
| **Space** | $O(m \cdot n)$ | Recursion stack depth in the worst-case snake island. |

> **This is the one.** Standard, optimal in-place DFS flood fill.

## Approach 2 — Iterative BFS Flood Fill

### Intuition
For each unvisited `1`, enqueue $(r, c)$, sink to `0`, and increment area as each connected neighbor is dequeued from a `queue`.

### C++ Implementation
```cpp
class Solution {
public:
    int maxAreaOfIsland(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int maxArea = 0;
        const int dr[] = {0, 0, 1, -1};
        const int dc[] = {1, -1, 0, 0};
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    int area = 0;
                    queue<pair<int, int>> q;
                    grid[r][c] = 0;
                    q.push({r, c});
                    
                    while (!q.empty()) {
                        auto [cr, cc] = q.front(); q.pop();
                        area++;
                        for (int d = 0; d < 4; d++) {
                            int nr = cr + dr[d], nc = cc + dc[d];
                            if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                                grid[nr][nc] = 0;
                                q.push({nr, nc});
                            }
                        }
                    }
                    maxArea = max(maxArea, area);
                }
            }
        }
        return maxArea;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Linear grid traversal. |
| **Space** | $O(\min(m, n))$ | BFS queue width. |

## Approach 3 — Disjoint Set Union (DSU with Component Sizes)

### Intuition
Map each grid cell $(r, c)$ to 1D index $r \cdot n + c$. Initialize DSU where each land cell has size 1. For each land cell with adjacent land (down or right), unite their sets and track `max(sz[root])`.

### C++ Implementation
```cpp
class Solution {
    struct DSU {
        vector<int> parent, sz;
        int maxComp;
        DSU(int n) : parent(n), sz(n, 1), maxComp(0) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int i) {
            if (parent[i] == i) return i;
            return parent[i] = find(parent[i]);
        }
        void unite(int i, int j) {
            int rootI = find(i), rootJ = find(j);
            if (rootI != rootJ) {
                if (sz[rootI] < sz[rootJ]) swap(rootI, rootJ);
                parent[rootJ] = rootI;
                sz[rootI] += sz[rootJ];
                maxComp = max(maxComp, sz[rootI]);
            }
        }
    };

public:
    int maxAreaOfIsland(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        DSU dsu(m * n);
        bool hasLand = false;
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    hasLand = true;
                    int idx = r * n + c;
                    dsu.maxComp = max(dsu.maxComp, 1);
                    if (r + 1 < m && grid[r + 1][c] == 1) dsu.unite(idx, (r + 1) * n + c);
                    if (c + 1 < n && grid[r][c + 1] == 1) dsu.unite(idx, r * n + c + 1);
                }
            }
        }
        
        return hasLand ? dsu.maxComp : 0;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(mn \cdot \alpha(mn))$ | Near-linear grid DSU unifications. |
| **Space** | $O(mn)$ | DSU parent and size arrays. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **All Water** | `[[0, 0], [0, 0]]` | Returning uninitialized | `maxArea` remains 0. |
| **Single Land Cell** | `[[1]]` | Base case recursion | Sinks cell and returns area 1. |
| **All Land Grid** | $50 \times 50$ of 1s | Call stack overflow | Standard recursion handles depth 2500 cleanly. |

## What are we solving?

Given an array of integers `nums` and an integer `k`, return the **total number of continuous subarrays** whose sum equals to `k`.

A subarray is a contiguous non-empty sequence of elements within an array.

```
 nums = [ 1, 1, 1 ],  k = 2
 
 Subarrays:
 - [nums[0], nums[1]] = [1, 1] -> sum = 2  (Valid)
 - [nums[1], nums[2]] = [1, 1] -> sum = 2  (Valid)
 
 Output: 2
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($1 \le n \le 2 \times 10^4$, $-1000 \le \text{nums}[i] \le 1000$).
  - `k`: `int` ($-10^7 \le k \le 10^7$).
- **Output:**
  - `int`: Total count of valid subarrays.

### Why Sliding Window FAILS Here
Because `nums` can contain **negative numbers** and **zeroes**, the window sum is **not monotonic**:
- Expanding `right` can *decrease* the sum.
- Shrinking `left` can *increase* the sum.
Therefore, two-pointer sliding window cannot work. Instead, we use the **Prefix Sum Identity**:
$$\mathbf{\text{Sum}(i \dots j) = \text{prefixSum}[j] - \text{prefixSum}[i - 1] = k \iff \text{prefixSum}[i - 1] = \text{prefixSum}[j] - k}$$

---

**Example 1:**
```
Input:  nums = [1,1,1], k = 2
Output: 2
Explanation: Subarrays [1,1] at index [0,1] and [1,2] both sum to 2.
```

**Example 2:**
```
Input:  nums = [1,2,3], k = 3
Output: 2
Explanation: [1,2] and [3] both sum to 3.
```

**Constraints:**
- $1 \le \text{nums.length} \le 2 \times 10^4$
- $-1000 \le \text{nums}[i] \le 1000$
- $-10^7 \le k \le 10^7$

## Approach 1 — Brute Force Nested Accumulation ($O(n^2)$)

### Intuition
For every starting index $i \in [0, n - 1]$, iterate ending index $j \in [i, n - 1]$, accumulating sum $S = \sum_{k=i}^j \text{nums}[k]$. Whenever $S == k$, increment answer.

### C++ Implementation
```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        int count = 0;
        
        for (int i = 0; i < n; i++) {
            int currentSum = 0;
            for (int j = i; j < n; j++) {
                currentSum += nums[j];
                if (currentSum == k) {
                    count++;
                }
            }
        }
        
        return count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Quadratic pairs $(i, j)$ evaluation. |
| **Space** | $O(1)$ | Pure scalar accumulators. |

> **Verdict:** Suboptimal. Prefix sum hash map achieves $O(n)$ linear time.

## Approach 2 — Prefix Sum + Hash Map Frequency Tracking ✅

### Key Insight
1. Maintain running sum `runningSum = 0` and frequency map `prefixCount` storing the occurrences of each prefix sum seen so far.
2. **Base Case:** `prefixCount[0] = 1` accounts for subarrays starting at index 0 whose total sum equals $k$.
3. For each number in `nums`:
   - `runningSum += num`
   - Look for complement: `needed = runningSum - k`.
   - If `needed` exists in `prefixCount`, add its stored frequency `prefixCount[needed]` to `totalCount`.
   - Increment `prefixCount[runningSum]++`.
4. Return `totalCount`.

```
nums = [ 1, 1, 1 ], k = 2
prefixCount = {0: 1}, runningSum = 0, totalCount = 0

i=0 (num=1): runningSum = 1.
             needed = 1 - 2 = -1 (not found).
             prefixCount = {0: 1, 1: 1}

i=1 (num=1): runningSum = 2.
             needed = 2 - 2 = 0 (found! count of 0 is 1) -> totalCount += 1 = 1.
             prefixCount = {0: 1, 1: 1, 2: 1}

i=2 (num=1): runningSum = 3.
             needed = 3 - 2 = 1 (found! count of 1 is 1) -> totalCount += 1 = 2.
             prefixCount = {0: 1, 1: 1, 2: 1, 3: 1}

Result: totalCount = 2 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> prefixCount;
        prefixCount[0] = 1; // Base case: an empty prefix has sum 0
        
        int runningSum = 0;
        int totalSubarrays = 0;
        
        for (int num : nums) {
            runningSum += num;
            
            // If (runningSum - k) was observed previously, those prefix boundaries form sum k
            int complement = runningSum - k;
            auto it = prefixCount.find(complement);
            if (it != prefixCount.end()) {
                totalSubarrays += it->second;
            }
            
            // Record the current prefix sum frequency
            prefixCount[runningSum]++;
        }
        
        return totalSubarrays;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass with $O(1)$ average hash map lookups. |
| **Space** | $O(n)$ | Hash map stores at most $n + 1$ unique prefix sums. |

> **This is the one.** Foundational prefix sum counting pattern.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Subarray Starts at Index 0** | `[2, 3], k = 5` | Missing whole-prefix match | `prefixCount[0] = 1` triggers when `runningSum - k = 0`. |
| **Negative Numbers and Zeroes** | `[1, -1, 0], k = 0` | Zero-sum loops | Map tallies each valid boundary: `[1, -1]`, `[0]`, `[1, -1, 0]`. |
| **All Zeroes** | `[0, 0, 0], k = 0` | Combinatorial count | Prefix 0 frequency accumulates: $1 + 2 + 3 = 6$ subarrays. |

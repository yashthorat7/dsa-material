## What are we solving?

Given an array of integers `nums` and an integer `k`, return the total number of subarrays whose sum equals to `k`. A subarray is a contiguous non-empty sequence of elements within an array.

The question is: **how can we count matching prefix sum differences in $O(n)$ time when numbers can be negative (rendering sliding window invalid)?**

**Example 1:**
```
Input:  nums = [1,1,1], k = 2
Output: 2
Explanation: Subarrays [1,1] at index [0,1] and [1,2] both sum to 2.
```

**Example 2:**
```
Input:  nums = [1,2,3], k = 3
Output: 2
Explanation: [1,2] and [3] both sum to 3.
```

**Constraints:**
- $1 \le \text{nums.length} \le 2 \times 10^4$
- $-1000 \le \text{nums}[i] \le 1000$
- $-10^7 \le k \le 10^7$

## Approach 1 — Prefix Sum + Hash Map (Frequency Tracking) ✅

**Key insight:**
Sum of subarray `nums[i..j]` is `prefixSum[j] - prefixSum[i-1]`.
We want `prefixSum[j] - prefixSum[i-1] == k`, which rearranges to:
`prefixSum[i-1] == prefixSum[j] - k`.

As we compute the running prefix sum:
1. Check how many times `prefixSum - k` has appeared previously in our hash map.
2. Add that frequency to `count`.
3. Increment the frequency of the current `prefixSum` in the map.
4. Base case: `prefixCount[0] = 1` handles subarrays starting at index 0.

```
nums = [1, 1, 1], k = 2
prefixCount = {0: 1}, runningSum = 0, count = 0

i=0 (num=1): runningSum = 1. Need 1 - 2 = -1 (not in map). prefixCount = {0: 1, 1: 1}
i=1 (num=1): runningSum = 2. Need 2 - 2 = 0 (seen 1 time!) -> count = 1. prefixCount = {0: 1, 1: 1, 2: 1}
i=2 (num=1): runningSum = 3. Need 3 - 2 = 1 (seen 1 time!) -> count = 2. prefixCount = {0: 1, 1: 1, 2: 1, 3: 1}

Result: count = 2 ✓
```

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> prefixCount;
        prefixCount[0] = 1; // base case for subarrays starting at index 0
        int runningSum = 0;
        int count = 0;
        
        for (int num : nums) {
            runningSum += num;
            if (prefixCount.count(runningSum - k)) {
                count += prefixCount[runningSum - k];
            }
            prefixCount[runningSum]++;
        }
        return count;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Optimal $O(n)$ frequency map approach.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Negative numbers `nums = [1, -1, 0], k = 0` | Sliding window fails with negatives | Prefix sum hash map handles negative values and zeroes seamlessly |
| Subarray starts at index 0 | Missing `prefixSum == k` | `prefixCount[0] = 1` initialization accounts for complete prefix subarrays |
| All zeroes `[0, 0, 0], k = 0` | Combinatorial counts | Frequency increments accurately tally all $\frac{n(n+1)}{2}$ combinations |

---

## Pattern Takeaway

Whenever a problem asks for **count of contiguous subarrays summing to K** with potentially **negative** numbers, **Prefix Sum + Hash Map** is the definitive pattern.

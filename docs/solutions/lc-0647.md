## What are we solving?

Given a string `s`, return the **number of palindromic substrings** in it.

A string is a **palindrome** when it reads the same backward as forward.  
A **substring** is a contiguous sequence of characters within the string.

```
 s = " a a a "
 
 Palindromic Substrings:
 - Length 1: "a" (idx 0), "a" (idx 1), "a" (idx 2)
 - Length 2: "aa" (idx 0..1), "aa" (idx 1..2)
 - Length 3: "aaa" (idx 0..2)
 
 Total Count: 6
 Output: 6
```

### Input & Output Contract
- **Input:**
  - `s`: `string` ($1 \le |s| \le 1000$, lowercase English letters).
- **Output:**
  - `int`: Total count of palindromic substrings.

### The Center Expansion Symmetry
Every palindrome has a center of symmetry:
- **Odd length palindromes:** Centered at a single character ($i, i$) $\implies n$ centers.
- **Even length palindromes:** Centered between two adjacent characters ($i, i + 1$) $\implies n - 1$ centers.
There are a total of $2n - 1$ possible centers. Expanding outward from each center until characters mismatch finds and counts **all palindromic substrings** in $O(n^2)$ time and $O(1)$ space.

---

**Example 1:**
```
Input:  s = "abc"
Output: 3
Explanation: Three palindromic strings: "a", "b", "c".
```

**Example 2:**
```
Input:  s = "aaa"
Output: 6
Explanation: Six palindromic strings: "a", "a", "a", "aa", "aa", "aaa".
```

**Constraints:**
- $1 \le s.\text{length} \le 1000$
- `s` consists of lowercase English letters.

## Approach 1 — 2D Dynamic Programming Table ($O(n^2)$ Space)

### Intuition
Let `dp[i][j]` be `true` if substring $s[i \dots j]$ is a palindrome.
- Base cases: `dp[i][i] = true`, and `dp[i][i+1] = (s[i] == s[i+1])`.
- General: `dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`.
- Count all `true` entries in `dp`.

### C++ Implementation
```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.length();
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        int count = 0;
        
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s[i] == s[j]) {
                    if (len <= 2 || dp[i + 1][j - 1]) {
                        dp[i][j] = true;
                        count++;
                    }
                }
            }
        }
        
        return count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Fills half of $n \times n$ table. |
| **Space** | $O(n^2)$ | 2D boolean DP table. |

## Approach 2 — Expand Around Center (Odd & Even Centroids) ✅

### Key Insight
1. Initialize `totalCount = 0`.
2. For each index $i \in [0 \dots n - 1]$:
   - **Odd expansion:** `expand(i, i)` (single-char centers like `"aba"`).
   - **Even expansion:** `expand(i, i + 1)` (two-char centers like `"abba"`).
3. Inside `expand(l, r)`:
   - While `l >= 0 && r < n && s[l] == s[r]`:
     - Increment `totalCount++`.
     - Move outward: `l--`, `r++`.
4. Return `totalCount`.

```
s = "aaa"

i=0:
- Odd expand(0, 0): "a" (count=1)
- Even expand(0, 1): "aa" (count=2)

i=1:
- Odd expand(1, 1): "a" (count=3), "aaa" (count=4)
- Even expand(1, 2): "aa" (count=5)

i=2:
- Odd expand(2, 2): "a" (count=6)
- Even expand(2, 3): out of bounds

Total Count = 6 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.length();
        int totalCount = 0;
        
        auto expand = [&](int l, int r) {
            while (l >= 0 && r < n && s[l] == s[r]) {
                totalCount++;
                l--;
                r++;
            }
        };
        
        for (int i = 0; i < n; i++) {
            expand(i, i);     // Odd-length palindromes (1, 3, 5...)
            expand(i, i + 1); // Even-length palindromes (2, 4, 6...)
        }
        
        return totalCount;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Evaluates $2n - 1$ centers, each expanding at most $O(n)$ steps. |
| **Space** | $O(1)$ | Zero auxiliary allocations; purely pointer manipulation. |

> **This is the one.** Clean, space-optimal, and fast.

## Approach 3 — Manacher's Algorithm ($O(n)$ Linear Time)

### Intuition
Transform string $s$ with `#` sentinels to unify odd and even palindromes. Maintain the current palindrome center $C$ and right boundary $R$. Re-use mirror values to calculate palindrome radii $P[i]$ in strictly linear $O(n)$ time. Summing $\lfloor (P[i] + 1) / 2 \rfloor$ yields the total palindromic substring count!

### C++ Implementation
```cpp
class Solution {
public:
    int countSubstrings(string s) {
        string t = "^";
        for (char c : s) {
            t += "#";
            t += c;
        }
        t += "#$";
        
        int n = t.size();
        vector<int> p(n, 0);
        int c = 0, r = 0;
        int totalPalindromes = 0;
        
        for (int i = 1; i < n - 1; i++) {
            int iMirror = 2 * c - i;
            if (r > i) {
                p[i] = min(r - i, p[iMirror]);
            }
            
            // Expand around center i
            while (t[i + 1 + p[i]] == t[i - 1 - p[i]]) {
                p[i]++;
            }
            
            if (i + p[i] > r) {
                c = i;
                r = i + p[i];
            }
            
            totalPalindromes += (p[i] + 1) / 2;
        }
        
        return totalPalindromes;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Strictly linear scan via palindrome radius reuse. |
| **Space** | $O(n)$ | Transformed string and radius array. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Character** | `"a"` | 0 count | `expand(0, 0)` executes once, returning 1. |
| **No Multi-Character Palindromes** | `"abc"` | False expansion | Only length-1 palindromes succeed, returning 3. |
| **All Same Characters** | `"aaaa"` | High volume | Tally counts $\frac{4 \times 5}{2} = 10$ substrings properly. |

## Pattern Takeaways

1. **Center Expansion Counting:**  
   $$\text{Total Palindromic Substrings} = \sum_{\text{centers } c} (\text{Expansion Steps at } c)$$

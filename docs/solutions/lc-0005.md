## What are we solving?

Given a string `s`, return the longest **palindromic substring** in `s`.

The challenge is: **how do we expand around potential centers in $O(n^2)$ time with $O(1)$ auxiliary space?**

**Example 1:**
```
Input:  s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

**Example 2:**
```
Input:  s = "cbbd"
Output: "bb"
```

**Constraints:**
- $1 \le s.\text{length} \le 1000$
- `s` consist of only digits and English letters.

## Approach 1 — Expand Around Centers ✅

**Key insight:** A palindrome mirrors around its center.
There are $2n - 1$ centers:
- $n$ odd-length centers (single character center `expand(i, i)`).
- $n - 1$ even-length centers (between two characters `expand(i, i + 1)`).
From each center, expand `left` and `right` while `s[left] == s[right]`. Keep track of the maximum length and start index.

```
s = "babad"
Center i=0 ('b'): "b" (len 1)
Center i=1 ('a'): expand(1,1) -> "bab" (len 3), expand(1,2) -> ""
Center i=2 ('b'): expand(2,2) -> "aba" (len 3)
Center i=3 ('a'): expand(3,3) -> "a"
Max palindrome found: "bab" (or "aba") of length 3 ✓
```

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        if (s.empty()) return "";
        int start = 0, maxLen = 0;
        
        auto expand = [&](int l, int r) {
            while (l >= 0 && r < s.size() && s[l] == s[r]) {
                l--;
                r++;
            }
            // Length is (r - 1) - (l + 1) + 1 = r - l - 1
            if (r - l - 1 > maxLen) {
                maxLen = r - l - 1;
                start = l + 1;
            }
        };
        
        for (int i = 0; i < s.size(); i++) {
            expand(i, i);       // Odd length
            expand(i, i + 1);   // Even length
        }
        
        return s.substr(start, maxLen);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n^2)$ | $O(1)$ |

> **This is the one.** Clean, space-optimal $O(1)$ expansion.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single character string `"a"` | Off-by-one substring calculation | Returns `"a"` |
| Entire string is palindrome `"racecar"` | Boundary termination | Expands to string edges and returns full string |
| All identical characters `"aaaa"` | Even vs odd length selection | Both expansions tested, selects maximal length |

---

## Pattern Takeaway

**Center Expansion** tests all $2n - 1$ potential palindrome midpoints in $O(1)$ memory without constructing an $O(n^2)$ DP table.

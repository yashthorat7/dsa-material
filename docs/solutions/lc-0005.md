## What are we solving?

Given a string `s`, return the **longest palindromic substring** in `s`.

A string is palindromic if it reads the same forward and backward. A substring is a contiguous sequence of characters within a string.

```
 String:  " b   a   b   a   d "
           [-------]
           "bab" -> length 3 (Palindromic!)
               [-------]
               "aba" -> length 3 (Palindromic!)
               
 Longest Palindromic Substring: "bab" (or "aba")
```

### Input & Output Contract
- **Input:**
  - `s`: `string` containing alphanumeric characters ($1 \le n \le 1000$).
- **Output:**
  - `string` representing the longest contiguous substring that forms a palindrome.

### The Core Challenge
Every palindrome mirrors around its center. An odd-length palindrome (e.g. `"aba"`) has a single-character center, while an even-length palindrome (e.g. `"abba"`) has a center between two identical characters. With $n$ characters, there are exactly $2n - 1$ possible centers. The challenge is expanding outwards from all centers in $O(n^2)$ time with **$O(1)$ extra space**.

---

**Example 1:**
```
Input:  s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

**Example 2:**
```
Input:  s = "cbbd"
Output: "bb"
```

**Constraints:**
- $1 \le s.\text{length} \le 1000$
- `s` consists of only digits and English letters.

## Approach 1 — Brute Force (Check All Substrings)

### Intuition
Generate every possible substring `s[i..j]` ($O(n^2)$ pairs) and verify whether each substring is a palindrome by checking two pointers converging from both ends ($O(n)$ verification).

### C++ Implementation
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.length();
        int maxLen = 0, start = 0;
        
        auto isPalindrome = [&](int l, int r) {
            while (l < r) {
                if (s[l++] != s[r--]) return false;
            }
            return true;
        };
        
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                if (j - i + 1 > maxLen && isPalindrome(i, j)) {
                    maxLen = j - i + 1;
                    start = i;
                }
            }
        }
        
        return s.substr(start, maxLen);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | $O(n^2)$ substrings $\times O(n)$ palindrome checks. TLEs for $n \ge 1000$. |
| **Space** | $O(1)$ | No extra memory allocated. |

> **Verdict:** Too slow.

## Approach 2 — 2D Dynamic Programming Table

### Intuition
Define `dp[i][j] = true` if substring `s[i..j]` is a palindrome:
- Base Case: `dp[i][i] = true` (length 1).
- Base Case: `dp[i][i+1] = (s[i] == s[i+1])` (length 2).
- Recurrence: `dp[i][j] = (s[i] == s[j] && dp[i+1][j-1])` (length $\ge 3$).

### C++ Implementation
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.length();
        if (n <= 1) return s;
        
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        int start = 0, maxLen = 1;
        
        // Substrings of length 1
        for (int i = 0; i < n; i++) dp[i][i] = true;
        
        // Substrings of length 2
        for (int i = 0; i < n - 1; i++) {
            if (s[i] == s[i + 1]) {
                dp[i][i + 1] = true;
                start = i;
                maxLen = 2;
            }
        }
        
        // Substrings of length 3 to n
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (s[i] == s[j] && dp[i + 1][j - 1]) {
                    dp[i][j] = true;
                    start = i;
                    maxLen = len;
                }
            }
        }
        
        return s.substr(start, maxLen);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Fills an $n \times n$ table in bottom-up length order. |
| **Space** | $O(n^2)$ | $n \times n$ boolean matrix. |

> **Verdict:** Substantially faster than brute force, but uses $O(n^2)$ memory table.

## Approach 3 — Expand Around Centers (Odd & Even) ✅

### Key Insight
A palindrome always mirrors outwards symmetrically from its center.
There are $2n - 1$ total centers:
1. **$n$ Odd Centers:** Single character centers at `expand(i, i)`.
2. **$n - 1$ Even Centers:** Between two characters at `expand(i, i + 1)`.

From each center, expand `left--` and `right++` while `s[left] == s[right]`.
When the expansion stops:
- The valid palindrome starts at `left + 1`.
- The length of the palindrome is `(right - 1) - (left + 1) + 1 = right - left - 1`.

```
s = "babad"

Center 0 ('b'): expand(0,0) -> "b" (len 1)
Center 1 ('a'): expand(1,1) -> s[0]=='b' == s[2]=='b' -> "bab" (len 3)
Center 2 ('b'): expand(2,2) -> s[1]=='a' == s[3]=='a' -> "aba" (len 3)
Center 3 ('a'): expand(3,3) -> "a" (len 1)
Center 4 ('d'): expand(4,4) -> "d" (len 1)

Max Palindrome: "bab" (len 3) ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        if (s.empty()) return "";
        
        int start = 0;
        int maxLen = 0;
        int n = s.length();
        
        auto expandAroundCenter = [&](int left, int right) {
            while (left >= 0 && right < n && s[left] == s[right]) {
                left--;
                right++;
            }
            // Length of valid palindrome after loop ends is (right - left - 1)
            int len = right - left - 1;
            if (len > maxLen) {
                maxLen = len;
                start = left + 1;
            }
        };
        
        for (int i = 0; i < n; i++) {
            expandAroundCenter(i, i);     // Odd length centers ("aba")
            expandAroundCenter(i, i + 1); // Even length centers ("abba")
        }
        
        return s.substr(start, maxLen);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | $2n - 1$ centers, each expands at most $O(n)$ steps. |
| **Space** | $O(1)$ | Pure index variables; zero table allocation. |

> **This is the one.** Space-optimal $O(1)$, fast cache locality, clean and concise.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Character** | `"a"` | Substring index calculations | Expands at (0,0), returns `"a"`. |
| **Two Distinct Characters** | `"ab"` | Even expansion mismatch | `expand(0,1)` stops immediately; returns `"a"`. |
| **Two Identical Characters** | `"bb"` | Even expansion boundary | `expand(0,1)` matches, returns `"bb"`. |
| **All Identical Characters** | `"aaaa"` | Mixed even/odd lengths | Both odd and even expansions explore to edges, returns full string `"aaaa"`. |

---

## Pattern Takeaways

1. **The $2n - 1$ Center Expansion Pattern:**  
   Every palindromic substring problem can be reduced to expanding from $n$ odd centers and $n-1$ even centers in $O(1)$ space.
2. **Length Formula:**  
   When the expansion loop `while (s[l] == s[r]) { l--; r++; }` breaks, the actual palindrome span is `[l + 1, r - 1]`, with length `r - l - 1`.

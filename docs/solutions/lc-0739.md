## What are we solving?

Given an array of integers `temperatures` represents the daily temperatures, return an array `answer` such that `answer[i]` is the number of days you have to wait after the $i$-th day to get a warmer temperature. If there is no future day for which this is possible, keep `answer[i] == 0` instead.

The question is: **how does a monotonic stack of indices calculate wait distances in $O(n)$ time?**

**Example 1:**
```
Input:  temperatures = [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]
```

**Example 2:**
```
Input:  temperatures = [30,40,50,60]
Output: [1,1,1,0]
```

**Example 3:**
```
Input:  temperatures = [30,60,90]
Output: [1,1,0]
```

**Constraints:**
- $1 \le \text{temperatures.length} \le 10^5$
- $30 \le \text{temperatures}[i] \le 100$

## Approach 1 — Monotonic Decreasing Stack of Indices ✅

**Key insight:**
Store indices in a stack with temperatures in decreasing order.
When visiting day `i` with temperature `T[i]`:
- While stack is non-empty and `T[i] > T[st.top()]`:
  - `prevDay = st.top()`, `st.pop()`
  - `answer[prevDay] = i - prevDay` (wait distance)
- Push current day `i` onto stack.
Unresolved days remain `0` by default.

```
T = [73, 74, 75, 71, 69, 72, 76, 73]
st = [], ans = [0]*8

i=0 (73): push 0 -> st=[0]
i=1 (74): 74 > 73 -> ans[0] = 1-0 = 1, pop 0 -> push 1 -> st=[1]
i=2 (75): 75 > 74 -> ans[1] = 2-1 = 1, pop 1 -> push 2 -> st=[2]
i=3 (71): push 3 -> st=[2, 3]
i=4 (69): push 4 -> st=[2, 3, 4]
i=5 (72): 72 > 69 -> ans[4] = 5-4 = 1; 72 > 71 -> ans[3] = 5-3 = 2 -> push 5 -> st=[2, 5]
i=6 (76): 76 > 72 -> ans[5] = 6-5 = 1; 76 > 75 -> ans[2] = 6-2 = 4 -> push 6 -> st=[6]
i=7 (73): push 7 -> st=[6, 7]

Result: [1, 1, 4, 2, 1, 1, 0, 0] ✓
```

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> answer(n, 0);
        stack<int> st; // stores indices
        
        for (int i = 0; i < n; i++) {
            while (!st.empty() && temperatures[i] > temperatures[st.top()]) {
                int prevDay = st.top();
                st.pop();
                answer[prevDay] = i - prevDay;
            }
            st.push(i);
        }
        
        return answer;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Classic Monotonic Stack index-distance calculation.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Strictly decreasing temperatures `[90, 80, 70]` | All values stay 0 | Stack retains indices, returns `[0, 0, 0]` |
| Single day `[30]` | Single iteration | Returns `[0]` |

---

## Pattern Takeaway

When calculating the **distance to the next greater element**, store **array indices** in the monotonic stack rather than values.

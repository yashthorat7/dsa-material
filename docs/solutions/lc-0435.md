## What are we solving?

Given an array of intervals `intervals` where `intervals[i] = [starti, endi]`, return the **minimum number of intervals** you need to remove to make the rest of the intervals non-overlapping.

Note that intervals which only touch at a point are non-overlapping. For example, `[1, 2]` and `[2, 3]` are non-overlapping.

```
 Intervals: [ [1, 2], [2, 3], [3, 4], [1, 3] ]
 
 Timeline:
 [1===2]
       [2===3]
             [3===4]
 [1=========3]  <--- Overlaps with [1, 2] and [2, 3] -> REMOVE!
 
 Minimum Removals: 1 (Remove [1, 3])
 Remaining Non-Overlapping: [[1, 2], [2, 3], [3, 4]]
```

### Input & Output Contract
- **Input:**
  - `intervals`: `vector<vector<int>>` where $1 \le n \le 10^5$, $-5 \times 10^4 \le \text{start}_i < \text{end}_i \le 5 \times 10^4$.
- **Output:**
  - `int` representing the minimum count of deleted intervals.

### The Core Challenge
$$\text{Minimum Removals} \equiv n - \text{Maximum Non-Overlapping Intervals (Activity Selection)}$$
To maximize the number of compatible intervals we can keep, which interval should we greedily choose whenever a conflict arises? The interval that **finishes earliest (`end`)**, because it leaves the maximum possible remaining timeline for subsequent intervals.

---

**Example 1:**
```
Input:  intervals = [[1,2],[2,3],[3,4],[1,3]]
Output: 1
Explanation: [1,3] can be removed and the rest of the intervals are non-overlapping.
```

**Example 2:**
```
Input:  intervals = [[1,2],[1,2],[1,2]]
Output: 2
Explanation: You need to remove two [1,2] to make the rest of the intervals non-overlapping.
```

**Example 3:**
```
Input:  intervals = [[1,2],[2,3]]
Output: 0
```

**Constraints:**
- $1 \le \text{intervals.length} \le 10^5$
- $\text{intervals}[i].\text{length} == 2$
- $-5 \times 10^4 \le \text{start}_i < \text{end}_i \le 5 \times 10^4$

## Approach 1 — Dynamic Programming ($O(n^2)$ LIS Variant)

### Intuition
Sort intervals by start time. Let `dp[i]` be the maximum number of non-overlapping intervals in prefix $[0..i]$ that includes `intervals[i]`.
$$\text{dp}[i] = 1 + \max_{j < i, \text{intervals}[j][1] \le \text{intervals}[i][0]} \text{dp}[j]$$
Answer is $n - \max(\text{dp})$.

### C++ Implementation
```cpp
class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        int n = intervals.size();
        if (n <= 1) return 0;
        
        sort(intervals.begin(), intervals.end());
        vector<int> dp(n, 1);
        int maxChain = 1;
        
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (intervals[j][1] <= intervals[i][0]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            maxChain = max(maxChain, dp[i]);
        }
        
        return n - maxChain;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Quadratic nested loops like Longest Increasing Subsequence. TLE on $n = 10^5$. |
| **Space** | $O(n)$ | 1D DP table. |

> **Verdict:** Suboptimal. Greedy earliest-deadline-first achieves $O(n \log n)$ time.

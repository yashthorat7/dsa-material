## What are we solving?

Given an integer array `nums` that may contain **duplicates**, return all possible subsets (the power set). The solution set must not contain duplicate subsets. Return the solution in any order.

The question is: **how do we skip identical sibling choices at the same recursion depth after sorting?**

**Example 1:**
```
Input:  nums = [1,2,2]
Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

**Example 2:**
```
Input:  nums = [0]
Output: [[],[0]]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10$
- $-10 \le \text{nums}[i] \le 10$

## Approach 1 — Sort + Sibling Duplicate Pruning ✅

**Key insight:**
1. Sort `nums` so identical elements are adjacent.
2. When iterating `i` from `start` to `nums.size() - 1`:
   - If `i > start && nums[i] == nums[i - 1]`, **continue** (skip).
   - This prevents picking the same value multiple times at the *same level* of the decision tree, while still allowing duplicate elements to be chosen at deeper levels.

```
nums = [1, 2, 2] (sorted)
start=0:
  []
  i=0 (1): [1] -> i=1 (2): [1,2] -> i=2 (2): [1,2,2]
                  i=2 (2): i > start (2 > 1) && nums[2]==nums[1] -> SKIP!
  i=1 (2): [2] -> i=2 (2): [2,2]
  i=2 (2): i > start (2 > 0) && nums[2]==nums[1] -> SKIP!

Subsets: [], [1], [1,2], [1,2,2], [1], [2], [2,2] (6 distinct subsets) ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, nums, current, result);
        return result;
    }
private:
    void backtrack(int start, const vector<int>& nums, vector<int>& current, vector<vector<int>>& result) {
        result.push_back(current);
        for (int i = start; i < nums.size(); i++) {
            if (i > start && nums[i] == nums[i - 1]) continue; // prune sibling duplicates
            current.push_back(nums[i]);
            backtrack(i + 1, nums, current, result);
            current.pop_back();
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot 2^n)$ | $O(n)$ |

> **This is the one.** Clean sibling pruning condition `i > start && nums[i] == nums[i-1]`.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All elements identical `[2, 2, 2]` | Generating duplicate `[2]` or `[2, 2]` | Pruning ensures only `[]`, `[2]`, `[2,2]`, `[2,2,2]` are produced |
| No duplicates | Accidental skipping | `nums[i] == nums[i-1]` check only triggers on actual duplicates |

---

## Pattern Takeaway

**Sibling Duplicate Pruning (`if (i > start && nums[i] == nums[i-1]) continue;`)** is the universal pattern for duplicate-free combinations and permutations.

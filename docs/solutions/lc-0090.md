## What are we solving?

Given an integer array `nums` that may contain **duplicate elements**, return all possible **subsets** (the power set).

The solution set **must not contain duplicate subsets**. Return the solution in **any order**.

```
 nums = [ 1, 2, 2 ]
 
 Subsets:
 [], [1], [2], [1, 2], [2, 2], [1, 2, 2]
 
 Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 10$, $-10 \le \text{nums}[i] \le 10$.
- **Output:**
  - `vector<vector<int>>` containing all unique power set subsets.

### The Core Challenge
With duplicate input numbers (like two `2`s), naive branching generates identical subsets (e.g. picking the first `2` vs picking the second `2` generates duplicate `[2]` and `[1, 2]`). We must sort the array and prune horizontal duplicate choices.

---

**Example 1:**
```
Input:  nums = [1,2,2]
Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

**Example 2:**
```
Input:  nums = [0]
Output: [[],[0]]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10$
- $-10 \le \text{nums}[i] \le 10$

## Approach 1 — Iterative Cascading with Boundary Tracking

### Intuition
1. Sort `nums`.
2. Start with `result = {{}}`.
3. When processing `nums[i]`:
   - If `nums[i]` is identical to `nums[i - 1]`, only append `nums[i]` to subsets created in the **previous iteration** (from `startIndex` to `endIndex`).
   - Otherwise, append `nums[i]` to **all existing subsets** in `result`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> result = {{}};
        int startIndex = 0, endIndex = 0;
        
        for (int i = 0; i < nums.size(); i++) {
            startIndex = 0;
            // If duplicate, only clone to subsets added in previous step
            if (i > 0 && nums[i] == nums[i - 1]) {
                startIndex = endIndex;
            }
            endIndex = result.size();
            
            for (int j = startIndex; j < endIndex; j++) {
                vector<int> subset = result[j];
                subset.push_back(nums[i]);
                result.push_back(subset);
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | Generates at most $2^n$ subsets of length up to $n$. |
| **Space** | $O(1)$ auxiliary | Generates result iteratively without call stack memory. |

## Approach 2 — Sort + Sibling Duplicate Pruning Backtracking ✅

### Key Insight
1. **Sort `nums`** so duplicates sit next to each other.
2. In the recursion:
   - At each step, append current state `current` to `result`.
   - Loop `i` from `start` to $n - 1$:
     - If `i > start && nums[i] == nums[i - 1]`, **`continue`**!  
       This prunes horizontal sibling duplicate branches at the same tree depth while permitting duplicate elements at deeper depths (e.g. `[2, 2]`).
     - Push `nums[i]`, recurse on `i + 1`, and pop `nums[i]` to backtrack.

```
nums = [1, 2, 2] (sorted)

backtrack(start=0, current=[]):
- push []
- i=0 (1): current=[1] -> backtrack(start=1)
  - push [1]
  - i=1 (2): current=[1,2] -> backtrack(start=2)
    - push [1,2]
    - i=2 (2): current=[1,2,2] -> backtrack(start=3) -> push [1,2,2]
  - i=2 (2): i > start (2 > 1) && nums[2]==nums[1] -> SKIP DUPLICATE!
- i=1 (2): current=[2] -> backtrack(start=2)
  - push [2]
  - i=2 (2): current=[2,2] -> push [2,2]
- i=2 (2): i > start (2 > 0) && nums[2]==nums[1] -> SKIP DUPLICATE!

Subsets: [], [1], [1,2], [1,2,2], [2], [2,2] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end()); // Essential for duplicate grouping
        vector<vector<int>> result;
        vector<int> current;
        backtrack(0, nums, current, result);
        return result;
    }

private:
    void backtrack(int start, const vector<int>& nums,
                   vector<int>& current, vector<vector<int>>& result) {
        result.push_back(current);
        
        for (int i = start; i < nums.size(); i++) {
            // Prune duplicate sibling choices at the same recursion depth
            if (i > start && nums[i] == nums[i - 1]) continue;
            
            current.push_back(nums[i]);
            backtrack(i + 1, nums, current, result);
            current.pop_back(); // Backtrack
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot 2^n)$ | Generates unique subsets and copies them to result. |
| **Space** | $O(n)$ | Call stack depth bounded by $n = \text{nums.length} \le 10$. |

> **This is the one.** Elegant in-place pruning using `i > start && nums[i] == nums[i-1]`.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **All Identical Elements** | `[2, 2, 2]` | Generating duplicate `[2]` or `[2, 2]` | Correctly generates only `[]`, `[2]`, `[2, 2]`, `[2, 2, 2]`. |
| **Single Element** | `[0]` | Base cases | Returns `[[], [0]]`. |
| **No Duplicates** | `[1, 2, 3]` | Erroneous skipping | `nums[i] == nums[i-1]` is never true, generates all 8 standard subsets. |

## Pattern Takeaways

1. **The Sibling Pruning Rule:**  
   `if (i > start && nums[i] == nums[i-1]) continue;` is the universal template for duplicate elimination across Subsets II, Combination Sum II, and Permutations II.

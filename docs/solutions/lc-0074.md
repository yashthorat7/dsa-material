## What are we solving?

You are given an `m x n` integer matrix `matrix` with the following two properties:
1. Each row is sorted in non-decreasing order.
2. The first integer of each row is greater than the last integer of the previous row.

Given an integer `target`, return `true` if `target` is in `matrix` or `false` otherwise. You must write a solution in **$O(\log(m \cdot n))$ time**.

**Example 1:**
```
Input:  matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
Output: true
```

**Example 2:**
```
Input:  matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
Output: false
```

**Constraints:**
- $m == \text{matrix.length}$
- $n == \text{matrix}[i].\text{length}$
- $1 \le m, n \le 100$
- $-10^4 \le \text{matrix}[i][j], \text{target} \le 10^4$

## Approach 1 — Flattened Virtual 1D Binary Search ✅

**Key insight:**
Because each row's first element exceeds the previous row's last element, the entire 2D matrix can be viewed as a single sorted 1D array of length $m \cdot n$.
For any 1D index `mid`:
- `row = mid / n`
- `col = mid % n`
Binary search over range `[0, m * n - 1]` in $O(\log(m \cdot n))$ time!

```
matrix = [[1, 3, 5, 7],
          [10, 11, 16, 20],
          [23, 30, 34, 60]] (m=3, n=4, total=12), target = 3

low = 0, high = 11
1. mid = 5 -> row = 5/4 = 1, col = 5%4 = 1 -> val = matrix[1][1] = 11. 11 > 3 -> high = 4
2. mid = 2 -> row = 2/4 = 0, col = 2%4 = 2 -> val = matrix[0][2] = 5. 5 > 3 -> high = 1
3. mid = 0 -> row = 0, col = 0 -> val = matrix[0][0] = 1. 1 < 3 -> low = 1
4. mid = 1 -> row = 0, col = 1 -> val = matrix[0][1] = 3. 3 == 3 -> MATCH! Return true ✓
```

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        if (matrix.empty()) return false;
        int m = matrix.size(), n = matrix[0].size();
        int low = 0, high = m * n - 1;
        
        while (low <= high) {
            int mid = low + (high - low) / 2;
            int r = mid / n, c = mid % n;
            if (matrix[r][c] == target) {
                return true;
            } else if (matrix[r][c] < target) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        
        return false;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(\log(m \cdot n))$ | $O(1)$ |

> **This is the one.** Virtual index mapping gives optimal single-pass binary search.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| 1x1 matrix `[[5]], target = 5` | Single element | `mid = 0`, finds element |
| Target outside matrix bounds (`< min` or `> max`) | Unnecessary iterations | Binary search eliminates bounds in logarithmic steps |

---

## Pattern Takeaway

When 2D data is strictly sorted across rows and columns sequentially, **index mapping `r = idx / cols, c = idx % cols`** flattens the 2D grid into standard 1D binary search.

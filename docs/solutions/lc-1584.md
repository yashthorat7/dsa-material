# 1584. Min Cost to Connect All Points

https://leetcode.com/problems/min-cost-to-connect-all-points

> **Medium** $\rightarrow$ **Graph Traversal**


> **Companies:** Amazon, Google, Uber, Meta

---

## What are we solving?

You are given an array `points` representing integer coordinates of some points on a 2D-plane, where `points[i] = [xi, yi]`.

The cost of connecting two points $[x_i, y_i]$ and $[x_j, y_j]$ is the **Manhattan distance** between them:
$$\text{dist}(i, j) = |x_i - x_j| + |y_i - y_j|$$

Return the **minimum cost** to make all points connected. All points are connected if there is exactly one simple path between any two points (i.e. finding a **Minimum Spanning Tree (MST)**).

```
 Points: [ [0,0], [2,2], [3,10], [5,2], [7,0] ]
 
 Connections in MST:
 - (0,0) to (2,2)   -> cost = |0-2| + |0-2| = 4
 - (2,2) to (5,2)   -> cost = |2-5| + |2-2| = 3
 - (5,2) to (7,0)   -> cost = |5-7| + |2-0| = 4
 - (2,2) to (3,10)  -> cost = |2-3| + |2-10| = 9
 
 Total Cost = 4 + 3 + 4 + 9 = 20
 Output: 20
```

### Input & Output Contract
- **Input:**
  - `points`: `vector<vector<int>>` ($1 \le n \le 1000$, $-10^6 \le x_i, y_i \le 10^6$, all points distinct).
- **Output:**
  - `int`: Minimum total edge weight connecting all $n$ points into an MST.

### Complete Graph Selection: Prim's vs Kruskal's
Because every point can connect to every other point, this is a **Complete Graph with $E = \frac{n(n - 1)}{2} \approx \frac{10^6}{2}$ edges**:
- **Kruskal's / Min-Heap Prim's:** Takes $O(E \log E) = O(n^2 \log n)$ time and requires $O(n^2)$ memory to store all edges.
- **Array-Based Prim's Algorithm:** Selects the next closest node with a simple linear scan in $O(n)$ per step $\implies \mathbf{O(n^2) \text{ Total Time and } O(n) \text{ Space}}$, which is optimal for dense graphs!

## Approach 1 — Kruskal's Algorithm with DSU ($O(n^2 \log n)$)

### Intuition
Construct all $\frac{n(n - 1)}{2}$ edges with their Manhattan distances. Sort edges ascending and greedily union connected components with DSU until $n - 1$ edges are chosen.

### C++ Implementation
```cpp
class Solution {
    struct DSU {
        vector<int> parent;
        DSU(int n) : parent(n) { iota(parent.begin(), parent.end(), 0); }
        int find(int i) { return (parent[i] == i) ? i : (parent[i] = find(parent[i])); }
        bool unite(int i, int j) {
            int rootI = find(i), rootJ = find(j);
            if (rootI == rootJ) return false;
            parent[rootI] = rootJ;
            return true;
        }
    };

public:
    int minCostConnectPoints(vector<vector<int>>& points) {
        int n = points.size();
        vector<array<int, 3>> edges; // {dist, u, v}
        
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int dist = abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1]);
                edges.push_back({dist, i, j});
            }
        }
        
        sort(edges.begin(), edges.end());
        DSU dsu(n);
        int totalCost = 0, edgesUsed = 0;
        
        for (const auto& [dist, u, v] : edges) {
            if (dsu.unite(u, v)) {
                totalCost += dist;
                edgesUsed++;
                if (edgesUsed == n - 1) break;
            }
        }
        
        return totalCost;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2 \log n)$ | Sorting $\frac{n(n-1)}{2}$ edges. |
| **Space** | $O(n^2)$ | Edge list memory. |

## Approach 2 — Prim's Algorithm for Dense Graphs (Array-Based Selection) ✅

### Key Insight
1. Maintain two arrays of size $n$:
   - `minDist[i]`: The minimum distance from node $i$ to any vertex currently in the MST (initialized to `INT_MAX`, with `minDist[0] = 0`).
   - `inMST[i]`: Boolean flag indicating if node $i$ has been added to the MST.
2. For $n$ iterations:
   - Find the unvisited node $u$ with the minimum `minDist[u]`.
   - Add $u$ to MST: `inMST[u] = true`, `totalCost += minDist[u]`.
   - For every remaining unvisited node $v$:
     $$\text{dist} = |x_u - x_v| + |y_u - y_v|$$
     $$\text{minDist}[v] = \min(\text{minDist}[v], \text{dist})$$
3. Return `totalCost`.

```
points = [[0,0],[2,2],[3,10],[5,2],[7,0]] (n=5)
Start at node 0:
- Add node 0: cost=0. Update minDist: [-, 4, 13, 7, 7]
- Pick node 1 (cost 4): Update minDist: [-, -, 9, 3, 7]
- Pick node 3 (cost 3): Update minDist: [-, -, 10, -, 4]
- Pick node 4 (cost 4): Update minDist: [-, -, 14, -, -]
- Pick node 2 (cost 9): Done.

Total MST Cost = 4 + 3 + 4 + 9 = 20 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int minCostConnectPoints(vector<vector<int>>& points) {
        int n = points.size();
        vector<int> minDist(n, INT_MAX);
        vector<bool> inMST(n, false);
        minDist[0] = 0;
        int totalCost = 0;
        
        for (int step = 0; step < n; step++) {
            int u = -1;
            
            // Pick unvisited node with minimum distance to current tree
            for (int i = 0; i < n; i++) {
                if (!inMST[i] && (u == -1 || minDist[i] < minDist[u])) {
                    u = i;
                }
            }
            
            inMST[u] = true;
            totalCost += minDist[u];
            
            // Relax distances to all unvisited neighbors
            for (int v = 0; v < n; v++) {
                if (!inMST[v]) {
                    int dist = abs(points[u][0] - points[v][0]) + 
                               abs(points[u][1] - points[v][1]);
                    minDist[v] = min(minDist[v], dist);
                }
            }
        }
        
        return totalCost;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | $n$ outer steps $\times 2n$ inner loop operations $\approx 2 \times 10^6$ ops (<15ms). |
| **Space** | $O(n)$ | Two 1D vectors of size $n$; avoids allocating 500,000 edge structs. |

> **This is the one.** Clean, space-optimal $O(n)$ memory dense MST implementation.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Point** | `[[0, 0]]` | 0 edge count | Loop runs 1 step, adds `minDist[0] = 0`, returns 0. |
| **Collinear Points** | `[[0,0],[1,0],[2,0]]` | Multiple parallel segments | Greedily chooses consecutive adjacent segments (cost = 2). |

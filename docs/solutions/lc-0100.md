## What are we solving?

Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not. Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Example 1:**
```
Input:  p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**
```
Input:  p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**
```
Input:  p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints:**
- The number of nodes in both trees is in the range $[0, 100]$.
- $-10^4 \le \text{Node.val} \le 10^4$

## Approach 1 — Simultaneous Recursive DFS ✅

**Key insight:**
1. If both `p` and `q` are null: `return true`.
2. If only one is null or `p->val != q->val`: `return false`.
3. Recurse: `isSameTree(p->left, q->left) && isSameTree(p->right, q->right)`.

```
Compare p = [1,2,3], q = [1,2,3]:
p->val(1) == q->val(1)
  left: p->val(2) == q->val(2) -> true
  right: p->val(3) == q->val(3) -> true
Result: true ✓
```

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (!p && !q) return true;
        if (!p || !q || p->val != q->val) return false;
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(h)$ |

> **This is the one.** Elegant 3-line structural comparison.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Both null trees | Null check | Returns `true` |
| One null, one non-null | Null dereference | `!p || !q` catches structure mismatch |

---

## Pattern Takeaway

Simultaneous tree traversal compares **structure (`!p || !q`) and values (`p->val == q->val`)** in tandem.

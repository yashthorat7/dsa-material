## What are we solving?

Given the roots of two binary trees `p` and `q`, write a function to check if they are the **same or not**.

Two binary trees are considered the **same** if and only if:
1. They are **structurally identical** (every node has the same children arrangement).
2. All corresponding nodes possess **identical values**.

```
 Tree p:       (1)              Tree q:       (1)
              /   \                          /   \
            (2)   (3)                      (2)   (3)
            
 Output: true (Structurally and numerically identical)
 
 Tree p:       (1)              Tree q:       (1)
              /                                  \
            (2)                                  (2)
            
 Output: false (Structural mismatch: left child vs right child)
```

### Input & Output Contract
- **Input:**
  - `p`: `TreeNode*` pointing to root of first binary tree ($0 \le \text{nodes} \le 100$, $-10^4 \le \text{Node.val} \le 10^4$).
  - `q`: `TreeNode*` pointing to root of second binary tree ($0 \le \text{nodes} \le 100$, $-10^4 \le \text{Node.val} \le 10^4$).
- **Output:**
  - `bool`: `true` if identical; `false` otherwise.

### The Core Challenge
We must verify both structural equality (null pointers matching null pointers) and value equality across all $n$ nodes simultaneously.

---

**Example 1:**
```
Input:  p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**
```
Input:  p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**
```
Input:  p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints:**
- The number of nodes in both trees is in the range $[0, 100]$.
- $-10^4 \le \text{Node.val} \le 10^4$

## Approach 1 — Simultaneous Recursive DFS ✅

### Intuition
Compare `p` and `q` simultaneously:
1. If both `p` and `q` are `nullptr`: return `true`.
2. If only one is `nullptr` OR `p->val != q->val`: return `false`.
3. Recursively check both left and right subtrees:
   `isSameTree(p->left, q->left) && isSameTree(p->right, q->right)`.

```
Compare p = [1,2,3] and q = [1,2,3]:
1. Root: p(1) == q(1) ✓
2. Left: isSameTree(p->left(2), q->left(2)) -> p(2) == q(2) ✓
3. Right: isSameTree(p->right(3), q->right(3)) -> p(3) == q(3) ✓
All subtrees match -> return true ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        // Both nodes are null -> identical structure
        if (p == nullptr && q == nullptr) return true;
        
        // One is null or values differ -> mismatch
        if (p == nullptr || q == nullptr || p->val != q->val) {
            return false;
        }
        
        // Recurse on left and right children
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(\min(N, M))$ | Visits each node in the smaller tree at most once. |
| **Space** | $O(h)$ | Recursion call stack depth bounded by tree height $h$. |

> **This is the one.** Clean 4-line recursive equivalence.

## Approach 2 — Iterative BFS (Parallel Queue)

### Intuition
Enqueue pairs of corresponding nodes `(pNode, qNode)` into a `queue`. Dequeue and verify structural and value equality at each step.

### C++ Implementation
```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        queue<pair<TreeNode*, TreeNode*>> que;
        que.push({p, q});
        
        while (!que.empty()) {
            auto [n1, n2] = que.front();
            que.pop();
            
            if (n1 == nullptr && n2 == nullptr) continue;
            if (n1 == nullptr || n2 == nullptr || n1->val != n2->val) return false;
            
            que.push({n1->left, n2->left});
            que.push({n1->right, n2->right});
        }
        
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Enqueues and dequeues each node pair once. |
| **Space** | $O(w)$ | Maximum queue size bounded by tree width $w$. |

## Approach 3 — Iterative DFS (Parallel Stack)

### Intuition
Use an explicit `stack` to perform simultaneous pre-order traversal without recursion stack memory.

### C++ Implementation
```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        stack<pair<TreeNode*, TreeNode*>> st;
        st.push({p, q});
        
        while (!st.empty()) {
            auto [n1, n2] = st.top();
            st.pop();
            
            if (n1 == nullptr && n2 == nullptr) continue;
            if (n1 == nullptr || n2 == nullptr || n1->val != n2->val) return false;
            
            st.push({n1->right, n2->right});
            st.push({n1->left, n2->left});
        }
        
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Pushes and pops each pair once. |
| **Space** | $O(h)$ | Stack size bounded by height $h$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Both Empty Trees** | `p = nullptr, q = nullptr` | Null dereference | `p == nullptr && q == nullptr` returns `true`. |
| **One Tree Empty, One Non-Empty** | `p = [1], q = nullptr` | Structure mismatch | `p == nullptr || q == nullptr` catches mismatch, returns `false`. |
| **Mirrored Structure (Same Values)** | `p = [1, 2], q = [1, null, 2]` | Value match but structure mismatch | `p->left` vs `q->left` (non-null vs null) returns `false`. |

## Pattern Takeaways

1. **Dual Tree Traversal Invariant:**  
   Always check `if (!n1 && !n2) continue;` followed by `if (!n1 || !n2 || n1->val != n2->val) return false;`.

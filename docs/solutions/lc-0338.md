## What are we solving?

Given an integer `n`, return an array `ans` of length `n + 1` such that for each `i` (`0 <= i <= n`), `ans[i]` is the **number of 1's** in the binary representation of `i`.

You must solve it in linear time $O(n)$ without calling built-in popcount functions for each number.

**Example 1:**
```
Input:  n = 2
Output: [0,1,1]
Explanation: 0 --> 0
1 --> 1
2 --> 10
```

**Example 2:**
```
Input:  n = 5
Output: [0,1,1,2,1,2]
Explanation: 0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

**Constraints:**
- $0 \le n \le 10^5$

## Approach 1 — Dynamic Programming (Bit Shift Relation) ✅

**Key insight:**
Notice that shifting `i` right by 1 (`i >> 1`) removes its least significant bit.
Therefore:
`ans[i] = ans[i >> 1] + (i & 1)`
The number of set bits in `i` equals the number of set bits in `i / 2`, plus 1 if `i` is odd.

```
ans = [0] * 6
i=0: ans[0] = 0
i=1: ans[1] = ans[0] + (1 & 1) = 0 + 1 = 1
i=2: ans[2] = ans[1] + (2 & 1) = 1 + 0 = 1
i=3: ans[3] = ans[1] + (3 & 1) = 1 + 1 = 2
i=4: ans[4] = ans[2] + (4 & 1) = 1 + 0 = 1
i=5: ans[5] = ans[2] + (5 & 1) = 1 + 1 = 2

Result: [0, 1, 1, 2, 1, 2] ✓
```

```cpp
class Solution {
public:
    vector<int> countBits(int n) {
        vector<int> ans(n + 1, 0);
        for (int i = 1; i <= n; i++) {
            ans[i] = ans[i >> 1] + (i & 1);
        }
        return ans;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ (excluding output array) |

> **This is the one.** Elegant 1D DP transition in true linear time.

## Pattern Takeaway

Bit count subproblems exhibit optimal substructure: **`count(i) = count(i >> 1) + (i & 1)`**.

## What are we solving?

Given an integer `n`, return an array `ans` of length $n + 1$ such that for each $i$ ($0 \le i \le n$), `ans[i]` is the **number of 1's (set bits)** in the binary representation of $i$.

You must solve it in linear time **$O(n)$** in a single pass without using built-in popcount functions for each integer individually.

```
 n = 5
 
 i = 0 (000_2) -> 0 ones
 i = 1 (001_2) -> 1 one
 i = 2 (010_2) -> 1 one
 i = 3 (011_2) -> 2 ones
 i = 4 (100_2) -> 1 one
 i = 5 (101_2) -> 2 ones
 
 Output: [ 0, 1, 1, 2, 1, 2 ]
```

### Input & Output Contract
- **Input:**
  - `n`: `int` ($0 \le n \le 10^5$).
- **Output:**
  - `vector<int>` of size $n + 1$ containing set bit counts.

### The Bitwise DP Invariant
Notice the fundamental relationship between a number $i$ and its right-shifted version $i >> 1$:
$$i \gg 1 = \lfloor i / 2 \rfloor$$
- Shifting $i$ to the right removes its least significant bit (`i & 1`).
- Therefore, the number of 1s in $i$ is simply the count in $\lfloor i / 2 \rfloor$, plus $1$ if $i$ is odd!
$$\mathbf{\text{ans}[i] = \text{ans}[i \gg 1] + (i \ \& \ 1)}$$

## Approach 1 — Brute Force Popcount ($O(n \log n)$)

### Intuition
For every integer $i \in [0, n]$, count its set bits using bitwise shift `i >>= 1` or builtin `__builtin_popcount(i)`.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> countBits(int n) {
        vector<int> ans(n + 1);
        for (int i = 0; i <= n; i++) {
            int count = 0, num = i;
            while (num > 0) {
                count += (num & 1);
                num >>= 1;
            }
            ans[i] = count;
        }
        return ans;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Each number takes $O(\log n)$ bit iterations. |
| **Space** | $O(1)$ auxiliary | Output vector memory only. |

> **Verdict:** Suboptimal. DP transitions achieve $O(n)$ linear time.

## What are we solving?

Implement a first in first out (FIFO) queue using only two standard LIFO stacks.

The implemented queue must support all normal queue operations:
- `void push(int x)`: Pushes element $x$ to the back of the queue.
- `int pop()`: Removes and returns the element from the front of the queue.
- `int peek()`: Returns the element at the front of the queue without removing it.
- `bool empty()`: Returns `true` if the queue is empty, `false` otherwise.

```
 Target FIFO Queue:
 Push 1 -> Push 2 -> Push 3
 Front is 1. Pop() returns 1.
 
 Dual LIFO Stack Strategy:
 inStack:  Top [ 3, 2, 1 ] Bottom (Reverse of FIFO)
 Pouring inStack -> outStack:
 outStack: Top [ 1, 2, 3 ] Bottom (Direct FIFO!)
```

### Input & Output Contract
- **Input:**
  - Standard stack operations: `push()`, `pop()`, `top()`, `size()`, `empty()`.
- **Output:**
  - Standard FIFO queue behavior.
- **Constraints:** At most 100 calls, all calls to `pop` and `peek` are valid.

---

**Example 1:**
```
Input:
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]

Output:
[null, null, null, 1, 1, false]
```

**Constraints:**
- $1 \le x \le 9$
- At most 100 calls will be made to `push`, `pop`, `peek`, and `empty`.
- All calls to `pop` and `peek` are valid.

## Approach 1 — Two Stacks (Push $O(n)$, Pop $O(1)$)

### Intuition
Maintain elements in `s1` in queue order (front of queue at top of `s1`). On `push(x)`, transfer all elements from `s1` to `s2`, push `x` onto `s1`, and transfer everything back from `s2` to `s1`.

### C++ Implementation
```cpp
class MyQueue {
private:
    stack<int> s1, s2;

public:
    MyQueue() {}
    
    void push(int x) {
        while (!s1.empty()) {
            s2.push(s1.top());
            s1.pop();
        }
        s1.push(x);
        while (!s2.empty()) {
            s1.push(s2.top());
            s2.pop();
        }
    }
    
    int pop() {
        int val = s1.top();
        s1.pop();
        return val;
    }
    
    int peek() {
        return s1.top();
    }
    
    bool empty() {
        return s1.empty();
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | Push $O(n)$, Pop $O(1)$, Peek $O(1)$ | Eagerly maintains queue order on every push. |
| **Space** | $O(n)$ | Two LIFO stacks. |

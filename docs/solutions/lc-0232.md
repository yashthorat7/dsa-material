## What are we solving?

Implement a first in first out (FIFO) queue using only two stacks. The implemented queue should support all the functions of a normal queue (`push`, `peek`, `pop`, and `empty`).

The question is: **how do two LIFO stacks achieve amortized $O(1)$ FIFO behavior via lazy transfer?**

**Example 1:**
```
Input:  ["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]
Output: [null, null, null, 1, 1, false]
Explanation: MyQueue myQueue = new MyQueue();
myQueue.push(1); // queue is: [1]
myQueue.push(2); // queue is: [1, 2] (leftmost is front)
myQueue.peek(); // return 1
myQueue.pop(); // return 1, queue is [2]
myQueue.empty(); // return false
```

**Constraints:**
- $1 \le \text{x} \le 9$
- At most $100$ calls will be made to `push`, `pop`, `peek`, and `empty`.
- All the calls to `pop` and `peek` are valid.

## Approach 1 — In-Stack and Out-Stack (Amortized O(1)) ✅

**Key insight:**
Use two stacks: `inStack` for incoming elements and `outStack` for outgoing elements.
- `push(x)`: push directly onto `inStack` ($O(1)$).
- `pop()` / `peek()`:
  - If `outStack` is empty: pop all elements from `inStack` and push them onto `outStack` (reversing the order to FIFO!).
  - Return / pop from `outStack`.
Each element is moved between stacks at most once, giving **amortized $O(1)$ time per operation**.

```
push(1): inStack = [1], outStack = []
push(2): inStack = [1, 2], outStack = []
peek():  outStack is empty -> transfer inStack:
         outStack = [2, 1], inStack = []
         returns outStack.top() = 1
pop():   pops 1 from outStack -> outStack = [2]
empty(): inStack.empty() && outStack.empty() -> false ✓
```

```cpp
class MyQueue {
private:
    stack<int> inStack, outStack;
    
    void transfer() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
    }
public:
    MyQueue() {}
    
    void push(int x) {
        inStack.push(x);
    }
    
    int pop() {
        transfer();
        int val = outStack.top();
        outStack.pop();
        return val;
    }
    
    int peek() {
        transfer();
        return outStack.top();
    }
    
    bool empty() {
        return inStack.empty() && outStack.empty();
    }
};
```

| Time | Space |
|:-----|:------|
| Amortized $O(1)$ for all operations ($O(1)$ worst case push, $O(1)$ amortized pop/peek) | $O(n)$ |

> **This is the one.** Classic double-stack FIFO design.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Interleaved push and pop | Premature transfers | Only transfer when `outStack` is completely empty to preserve FIFO order |
| Check `empty()` after partial pops | Only checking one stack | `inStack.empty() && outStack.empty()` checks both |

---

## Pattern Takeaway

Pouring elements from one LIFO stack into another **reverses their order**, transforming LIFO into FIFO with amortized $O(1)$ cost.

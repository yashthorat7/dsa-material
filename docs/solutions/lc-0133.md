> **Companies:** Meta, Amazon, Bloomberg, Google, Microsoft, Pinterest, Ola, Swiggy, Accenture

## What are we solving?

Given a reference to a node in a **connected undirected graph**, return a **deep copy (clone)** of the entire graph.

Each node in the graph contains an integer value (`val`) and a list (`vector<Node*> neighbors`) of its adjacent neighbor nodes.

```
 Original Graph:                      Cloned Graph (New Heap Nodes):
      (1) --------- (2)                    (1') --------- (2')
       |             |                      |              |
       |             |                      |              |
      (4) --------- (3)                    (4') --------- (3')
```

### Input & Output Contract
- **Input:**
  - `node`: `Node*` reference to a node in a connected graph ($0 \le V \le 100$, $1 \le \text{Node.val} \le 100$, unique values, no self-loops or multi-edges).
- **Output:**
  - `Node*` reference to the cloned root node (deep copy with completely new memory allocations).

### The Core Challenge
Graphs can contain **cycles** (e.g. $1 \rightarrow 2 \rightarrow 3 \rightarrow 1$). If we clone recursively without tracking already-created nodes, the traversal will cycle infinitely. We must maintain a mapping `unordered_map<Node*, Node*>` associating each original node with its unique cloned counterpart.

---

**Example 1:**
```
Input:  adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: There are 4 nodes in the graph.
Node 1's value is 1, and its neighbors are node 2 and 4.
Node 2's value is 2, and its neighbors are node 1 and 3.
Node 3's value is 3, and its neighbors are node 2 and 4.
Node 4's value is 4, and its neighbors are node 1 and 3.
```

**Example 2:**
```
Input:  adjList = [[]]
Output: [[]]
Explanation: Graph contains a single isolated node with val = 1 and no neighbors.
```

**Example 3:**
```
Input:  adjList = []
Output: []
Explanation: Graph is empty (null reference).
```

**Constraints:**
- The number of nodes in the graph is in the range $[0, 100]$.
- $1 \le \text{Node.val} \le 100$
- `Node.val` is unique for each node.
- There are no repeated edges and no self-loops in the graph.
- The Graph is connected and all nodes can be visited starting from the given node.

## Approach 1 — Depth-First Search (DFS with Hash Map) ✅

### Intuition
Maintain an `unordered_map<Node*, Node*> clonedMap`:
1. Base case: If `node == nullptr`, return `nullptr`.
2. If `node` has already been cloned (`clonedMap.count(node)`), return the cached cloned node `clonedMap[node]`.
3. Create a new copy: `Node* clone = new Node(node->val)`.
4. **Register the clone in the map immediately** before recursing on neighbors: `clonedMap[node] = clone`.
5. For each neighbor in `node->neighbors`, recursively clone it and attach to `clone->neighbors`.
6. Return `clone`.

```
Clone node 1:
- Create 1' -> clonedMap[1] = 1'
- For neighbor 2:
  - Create 2' -> clonedMap[2] = 2'
  - For neighbor 1: clonedMap[1] exists -> returns 1' (Cycle broken!)
  - 2'->neighbors = [1', ...]
- 1'->neighbors = [2', ...]

Deep copy preserved with zero infinite loops ✓
```

### C++ Implementation
```cpp
/*
class Node {
public:
    int val;
    vector<Node*> neighbors;
    Node() : val(0), neighbors() {}
    Node(int _val) : val(_val), neighbors() {}
    Node(int _val, vector<Node*> _neighbors) : val(_val), neighbors(_neighbors) {}
};
*/

class Solution {
private:
    unordered_map<Node*, Node*> clonedMap;
public:
    Node* cloneGraph(Node* node) {
        if (node == nullptr) return nullptr;
        
        // Return existing clone if already visited
        if (clonedMap.count(node)) {
            return clonedMap[node];
        }
        
        // Allocate clone and register in map BEFORE exploring neighbors
        Node* clone = new Node(node->val);
        clonedMap[node] = clone;
        
        for (Node* neighbor : node->neighbors) {
            clone->neighbors.push_back(cloneGraph(neighbor));
        }
        
        return clone;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V + E)$ | Each vertex $V$ and edge $E$ is traversed exactly once. |
| **Space** | $O(V)$ | Hash map stores $V$ mapping pairs; recursion stack depth is $V$. |

> **This is the one.** Elegant recursive deep copy with cycle prevention.

## Approach 2 — Breadth-First Search (BFS with Queue & Hash Map)

### Intuition
Use an explicit queue `queue<Node*>` to traverse the graph level by level:
1. Clone the starting node and insert into `clonedMap[node] = clone`.
2. Enqueue `node` into `q`.
3. While `q` is not empty:
   - Dequeue original node `curr = q.front()`.
   - For each `neighbor` in `curr->neighbors`:
     - If `neighbor` is not in `clonedMap`: create its clone, register in `clonedMap`, and enqueue `neighbor`.
     - Append `clonedMap[neighbor]` to `clonedMap[curr]->neighbors`.

### C++ Implementation
```cpp
class Solution {
public:
    Node* cloneGraph(Node* node) {
        if (node == nullptr) return nullptr;
        
        unordered_map<Node*, Node*> clonedMap;
        queue<Node*> q;
        
        // Clone root node and enqueue
        clonedMap[node] = new Node(node->val);
        q.push(node);
        
        while (!q.empty()) {
            Node* curr = q.front();
            q.pop();
            
            for (Node* neighbor : curr->neighbors) {
                // If neighbor not yet cloned, instantiate and enqueue
                if (!clonedMap.count(neighbor)) {
                    clonedMap[neighbor] = new Node(neighbor->val);
                    q.push(neighbor);
                }
                
                // Link cloned neighbor to cloned curr
                clonedMap[curr]->neighbors.push_back(clonedMap[neighbor]);
            }
        }
        
        return clonedMap[node];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V + E)$ | Every node is queued and dequeued once; all adjacent edges are visited. |
| **Space** | $O(V)$ | Queue and hash map store up to $V$ nodes. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Graph** | `node = nullptr` | Dereferencing null pointer | `if (node == nullptr) return nullptr;` returns `nullptr` immediately. |
| **Single Isolated Node** | `adjList = [[]]` | Empty neighbors list | Clones node, loop finishes without inserting neighbors, returns clone. |
| **Complete Graph with Multi-Way Cycles** | Fully interconnected 4-node graph | Infinite recursive loop | Early registration `clonedMap[node] = clone` intercepts cyclic backward edges. |

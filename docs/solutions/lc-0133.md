## What are we solving?

Given a reference of a node in a **connected** undirected graph. Return a **deep copy** (clone) of the graph.

Each node in the graph contains a value (`int`) and a list (`List[Node]`) of its neighbors.

**Example 1:**
```
Input:  adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: There are 4 nodes in the graph.
```

**Example 2:**
```
Input:  adjList = [[]]
Output: [[]]
```

**Example 3:**
```
Input:  adjList = []
Output: []
```

**Constraints:**
- The number of nodes in the graph is in the range $[0, 100]$.
- $1 \le \text{Node.val} \le 100$
- `Node.val` is unique for each node.
- There are no repeated edges and no self-loops in the graph.
- The Graph is connected and all nodes can be visited starting from the given node.

## Approach 1 — DFS with Hash Map Memoization ✅

**Key insight:**
Maintain an `unordered_map<Node*, Node*> cloned` to map original nodes to their cloned instances.
1. Base cases: If `!node`, return `nullptr`. If `cloned.count(node)`, return `cloned[node]`.
2. Create clone: `copy = new Node(node->val)`.
3. Register clone: `cloned[node] = copy`.
4. For each `neighbor` in `node->neighbors`:
   - `copy->neighbors.push_back(cloneGraph(neighbor))`.
5. Return `copy`.

```
Clone node 1:
create 1' -> cloned[1]=1'
for neighbor 2:
  clone 2 -> create 2' -> cloned[2]=2'
    for neighbor 1: cloned.count(1) is true -> return 1'
    2'->neighbors = [1']
1'->neighbors = [2'] ✓
```

```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> neighbors;
    Node() { val = 0; neighbors = vector<Node*>(); }
    Node(int _val) { val = _val; neighbors = vector<Node*>(); }
    Node(int _val, vector<Node*> _neighbors) { val = _val; neighbors = _neighbors; }
};
*/

class Solution {
private:
    unordered_map<Node*, Node*> cloned;
public:
    Node* cloneGraph(Node* node) {
        if (!node) return nullptr;
        if (cloned.count(node)) return cloned[node];
        
        Node* copy = new Node(node->val);
        cloned[node] = copy;
        
        for (Node* neighbor : node->neighbors) {
            copy->neighbors.push_back(cloneGraph(neighbor));
        }
        
        return copy;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(V + E)$ | $O(V)$ |

> **This is the one.** Clean recursive graph duplication with mapping.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty graph `node = nullptr` | Null dereference | Returns `nullptr` immediately |
| Single isolated node `[[]]` | Empty neighbors loop | Clones node and returns with empty neighbor list |

---

## Pattern Takeaway

Graph cloning requires **memoizing mapped copies (`original -> clone`)** before traversing neighbors to avoid infinite cycles in cyclic graphs.

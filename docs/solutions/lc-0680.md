## What are we solving?

Given a string `s`, return `true` if `s` can be a palindrome after deleting **at most one character** from it.

```
 s = " a b c a "
 
 Two Pointers:
 left = 0 ('a'), right = 3 ('a') -> MATCH!
 left = 1 ('b'), right = 2 ('c') -> MISMATCH!
 
 Branch 1 (Delete 'b'): Check "c" -> Palindrome!
 Branch 2 (Delete 'c'): Check "b" -> Palindrome!
 
 Output: true
```

### Input & Output Contract
- **Input:**
  - `s`: `string` ($1 \le |s| \le 10^5$, lowercase English letters).
- **Output:**
  - `bool`: `true` if `s` can become a palindrome with 0 or 1 deletion; otherwise `false`.

### The Greedy Invariant
As long as `s[left] == s[right]`, those symmetric characters **must** be kept in any valid palindrome:
- Upon encountering the **first mismatch** `s[left] != s[right]`:
  - Exactly one of `s[left]` or `s[right]` must be deleted.
  - Test if substring $s[\text{left} + 1 \dots \text{right}]$ is a strict palindrome OR if substring $s[\text{left} \dots \text{right} - 1]$ is a strict palindrome.
  - If either is `true`, the answer is `true`. Otherwise, it's impossible to form a palindrome with $\le 1$ deletion.

---

**Example 1:**
```
Input:  s = "aba"
Output: true
```

**Example 2:**
```
Input:  s = "abca"
Output: true
Explanation: You could delete the character 'c'.
```

**Example 3:**
```
Input:  s = "abc"
Output: false
```

**Constraints:**
- $1 \le s.\text{length} \le 10^5$
- `s` consists of lowercase English letters.

## Approach 1 — Brute Force ($O(n^2)$)

### Intuition
Try deleting each character $i \in [0, n - 1]$ one by one, forming a new string $s' = s[0..i-1] + s[i+1..n-1]$, and check if $s'$ is a palindrome.

### C++ Implementation
```cpp
class Solution {
public:
    bool validPalindrome(string s) {
        if (isPalin(s, 0, s.size() - 1)) return true;
        int n = s.size();
        for (int i = 0; i < n; i++) {
            string t = s.substr(0, i) + s.substr(i + 1);
            if (isPalin(t, 0, t.size() - 1)) return true;
        }
        return false;
    }

private:
    bool isPalin(const string& s, int l, int r) {
        while (l < r) {
            if (s[l++] != s[r--]) return false;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | $n$ string deletions $\times O(n)$ palindrome checks. TLE on $n = 10^5$. |
| **Space** | $O(n)$ | Substring string allocation. |

## Approach 3 — Generalized $K$-Deletions Recursion

### Intuition
Generalize to at most $k$ deletions using recursive branching. When $s[l] \neq s[r]$, branch into `solve(l + 1, r, k - 1)` and `solve(l, r - 1, k - 1)`.

### C++ Implementation
```cpp
class Solution {
public:
    bool validPalindrome(string s) {
        return check(s, 0, s.size() - 1, 1);
    }

private:
    bool check(const string& s, int l, int r, int k) {
        while (l < r) {
            if (s[l] != s[r]) {
                if (k == 0) return false;
                return check(s, l + 1, r, k - 1) || check(s, l, r - 1, k - 1);
            }
            l++;
            r--;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ for $k = 1$ | Branches at most once. |
| **Space** | $O(k)$ | Recursion stack depth bounded by $k$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Already a Palindrome** | `"racecar"` | Triggering branch | Loop exits cleanly without mismatch, returns `true`. |
| **Two Characters** | `"ab"` | Index bounds | Deleting either character results in single-char palindrome, returns `true`. |
| **Three Distinct Characters** | `"abc"` | Both branches fail | Both sub-palindromes fail, returns `false`. |

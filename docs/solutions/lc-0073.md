## What are we solving?

Given an $m \times n$ integer matrix `matrix`, if an element is `0`, set its entire row and column to `0`'s.

You must do it **in place** (achieve $O(1)$ auxiliary memory).

```
 Original:                     Zeroed Rows & Columns:
 [ 1,  1,  1 ]                 [ 1, (0),  1 ]
 [ 1, (0), 1 ]       --->      [ 0,  0,   0 ]
 [ 1,  1,  1 ]                 [ 1, (0),  1 ]
```

### Input & Output Contract
- **Input:**
  - `matrix`: `vector<vector<int>>&` where $1 \le m, n \le 200$, $-2^{31} \le \text{matrix}[i][j] \le 2^{31} - 1$.
- **Output:**
  - `void` (modifies `matrix` in place).
- **Space Constraint:** Must use $O(1)$ auxiliary memory.

### The Core Challenge
If you overwrite cells with `0` immediately upon encountering a zero, you will create false zeroes that propagate throughout the entire matrix until every cell becomes `0`!  
We must record which rows and columns require zeroing without allocating additional $O(m + n)$ memory by **repurposing the 0-th row and 0-th column as our in-place flag arrays**.

---

**Example 1:**
```
Input:  matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```

**Example 2:**
```
Input:  matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

**Constraints:**
- $m == \text{matrix.length}$
- $n == \text{matrix}[0].\text{length}$
- $1 \le m, n \le 200$
- $-2^{31} \le \text{matrix}[i][j] \le 2^{31} - 1$

## Approach 1 — Auxiliary Row & Column Vectors ($O(m + n)$ Space)

### Intuition
Maintain two boolean vectors: `rowZero[m]` and `colZero[n]`.
1. Pass 1: If `matrix[r][c] == 0`, mark `rowZero[r] = true` and `colZero[c] = true`.
2. Pass 2: Iterate over all cells $(r, c)$. If `rowZero[r] || colZero[c]`, set `matrix[r][c] = 0`.

### C++ Implementation
```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<bool> rowZero(m, false);
        vector<bool> colZero(n, false);
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (matrix[r][c] == 0) {
                    rowZero[r] = true;
                    colZero[c] = true;
                }
            }
        }
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (rowZero[r] || colZero[c]) {
                    matrix[r][c] = 0;
                }
            }
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Two linear sweeps through the matrix. |
| **Space** | $O(m + n)$ | Requires separate tracking vectors of size $m$ and $n$. |

> **Verdict:** Functional, but using the first row and column as marker storage reduces space to $O(1)$.

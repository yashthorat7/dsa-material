## What are we solving?

Given an `m x n` integer matrix `matrix`, if an element is `0`, set its entire row and column to `0`'s. You must do it **in place**.

The challenge is: **how can we use the matrix's first row and column as markers to achieve $O(1)$ extra space without overwriting data prematurely?**

**Example 1:**
```
Input:  matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```

**Example 2:**
```
Input:  matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

**Constraints:**
- $m == \text{matrix.length}$
- $n == \text{matrix}[0].\text{length}$
- $1 \le m, n \le 200$
- $-2^{31} \le \text{matrix}[i][j] \le 2^{31} - 1$

## Approach 1 — Using First Row and Column as In-Place Flags ✅

**Key insight:**
Instead of allocating $O(m + n)$ separate flag arrays:
1. Use `matrix[i][0]` to store whether row `i` should be zeroed.
2. Use `matrix[0][j]` to store whether col `j` should be zeroed.
3. Since `matrix[0][0]` overlaps both, use a separate boolean variable `firstColHasZero` to track column 0, while `matrix[0][0]` tracks row 0.
4. Pass 1: Scan matrix and set markers.
5. Pass 2: Update cells from `(1,1)` to `(m-1, n-1)` based on markers.
6. Pass 3: Update row 0 and col 0 if flagged.

```
matrix = [[1, 1, 1],
          [1, 0, 1],
          [1, 1, 1]]

Pass 1: (1,1) is 0 -> matrix[1][0] = 0, matrix[0][1] = 0
Markers:
Row 0: [1, 0, 1]
Col 0: [1, 0, 1]

Pass 2: Update inner cells (1..2, 1..2):
(1,1) -> 0
(1,2) -> matrix[1][0]=0 -> 0
(2,1) -> matrix[0][1]=0 -> 0

Pass 3: Update boundaries.
Result:
[[1, 0, 1],
 [0, 0, 0],
 [1, 0, 1]] ✓
```

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        bool firstColZero = false;
        
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) firstColZero = true;
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        
        if (matrix[0][0] == 0) {
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        }
        
        if (firstColZero) {
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(1)$ |

> **This is the one.** True $O(1)$ in-place state encoding.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| First row or first column itself contains zero | Overwriting marker states early | Separate `firstColZero` boolean and bottom-up/delayed boundary zeroing prevents corruption |
| 1x1 matrix `[[0]]` or `[[1]]` | Out of bounds on inner loop | Inner loop skipped, boundary check handles single cell correctly |
| Entire matrix already zeroes | Redundant assignments | Correctly remains all zeroes |

---

## Pattern Takeaway

To achieve $O(1)$ auxiliary space in matrix transformation problems, repurpose the **first row and first column as internal marker arrays**.

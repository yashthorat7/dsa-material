## What are we solving?

There is an $m \times n$ rectangular island that borders both the **Pacific Ocean** and **Atlantic Ocean**:
- The **Pacific Ocean** touches the island's **top** and **left** edges.
- The **Atlantic Ocean** touches the island's **bottom** and **right** edges.

Rain water can flow to neighboring cells (4-directionally) if the neighboring cell's height is **less than or equal to** the current cell's height ($\text{height}_{\text{neighbor}} \le \text{height}_{\text{current}}$).

Return a 2D list of grid coordinates `result` where `result[i] = [r, c]` denotes that rain water can flow from cell `(r, c)` to **both** the Pacific and Atlantic oceans.

```
       Pacific Ocean (Top)
       ~  ~  ~  ~  ~  ~  ~
   P [ 1, 2, 2, 3, (5) ] A
   a [ 3, 2, 3, (4),(4)] t
   c [ 2, 4,(5), 3,  1 ] l
   i [(6),(7), 1, 4, 5 ] a
   f [(5), 1, 1, 2, 4 ] n
       ~  ~  ~  ~  ~  ~  ~
      Atlantic Ocean (Bottom)
      
 Cells with dual ocean flow: [[0,4], [1,3], [1,4], [2,2], [3,0], [3,1], [4,0]]
```

### Input & Output Contract
- **Input:**
  - `heights`: `vector<vector<int>>` where $1 \le m, n \le 200$, $0 \le \text{heights}[r][c] \le 10^5$.
- **Output:**
  - `vector<vector<int>>`: Coordinates `[r, c]` reachable by both oceans.

### The Inverse Insight (Reverse Flow Uphill)
Checking downhill from every interior cell requires running up to $m \cdot n$ separate traversals ($O((m \cdot n)^2)$).  
**Reverse the Flow:**  
- Start from the Pacific ocean border and **flow uphill** ($\text{height}_{\text{next}} \ge \text{height}_{\text{curr}}$) to find all cells that can reach the Pacific (`pacific[r][c] == true`).
- Start from the Atlantic ocean border and flow uphill to find all cells that can reach the Atlantic (`atlantic[r][c] == true`).
- The **intersection** `pacific[r][c] && atlantic[r][c]` is our exact answer in linear $O(m \cdot n)$ time!

```
Input:  heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
Output: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

```
Output: [[0,0]]
```

**Constraints:**
- $m == \text{heights.length}$
- $n == \text{heights}[r].\text{length}$
- $1 \le m, n \le 200$
- $0 \le \text{heights}[r][c] \le 10^5$

## Approach 1 — Naive Downhill Search from Every Cell ($O((mn)^2)$)

### Intuition
From every single grid cell $(r, c)$, run independent DFS/BFS to determine if it can reach the Pacific ocean and the Atlantic ocean by strictly stepping on equal or lower heights.

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> pacificAtlantic(vector<vector<int>>& heights) {
        int m = heights.size(), n = heights[0].size();
        vector<vector<int>> result;
        
        auto canReach = [&](int sr, int sc, bool checkPacific) -> bool {
            vector<vector<bool>> visited(m, vector<bool>(n, false));
            queue<pair<int, int>> q;
            q.push({sr, sc});
            visited[sr][sc] = true;
            const int dr[] = {0, 0, 1, -1};
            const int dc[] = {1, -1, 0, 0};
            
            while (!q.empty()) {
                auto [r, c] = q.front(); q.pop();
                if (checkPacific && (r == 0 || c == 0)) return true;
                if (!checkPacific && (r == m - 1 || c == n - 1)) return true;
                
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && !visited[nr][nc]) {
                        if (heights[nr][nc] <= heights[r][c]) {
                            visited[nr][nc] = true;
                            q.push({nr, nc});
                        }
                    }
                }
            }
            return false;
        };
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (canReach(r, c, true) && canReach(r, c, false)) {
                    result.push_back({r, c});
                }
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O((m \cdot n)^2)$ | $m \cdot n$ starting cells $\times O(m \cdot n)$ reachability search. TLEs for $200 \times 200$. |
| **Space** | $O(m \cdot n)$ | Visited grid per cell search. |

> **Verdict:** Suboptimal. Reverse uphill search from oceans achieves $O(m \cdot n)$ linear grid time.

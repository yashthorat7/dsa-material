## What are we solving?

There is an `m x n` rectangular island that borders both the **Pacific Ocean** and **Atlantic Ocean**. The Pacific Ocean touches the island's top and left edges, and the Atlantic Ocean touches the island's bottom and right edges.

Rain water can flow to neighboring cells (up, down, left, right) if the neighboring cell's height is **less than or equal to** the current cell's height.

Return a 2D list of grid coordinates `result` where `result[i] = [ri, ci]` denotes that rain water can flow from cell `(ri, ci)` to **both** the Pacific and Atlantic oceans.

**Example 1:**
```
Input:  heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
Output: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

**Example 2:**
```
Input:  heights = [[1]]
Output: [[0,0]]
```

**Constraints:**
- $m == \text{heights.length}$
- $n == \text{heights}[r].\text{length}$
- $1 \le m, n \le 200$
- $0 \le \text{heights}[r][c] \le 10^5$

## Approach 1 — Reverse Flow DFS from Ocean Boundaries ✅

**Key insight:**
Instead of searching downhill from every interior cell:
**Flow uphill from the oceans!**
1. `pacific[m][n]` boolean matrix: DFS uphill (`nextHeight >= currHeight`) from top and left borders.
2. `atlantic[m][n]` boolean matrix: DFS uphill from bottom and right borders.
3. Intersection: any cell where `pacific[r][c] && atlantic[r][c]` can reach both oceans!

```
Pacific borders: Top row + Left col
Atlantic borders: Bottom row + Right col

DFS uphill from Pacific reaches set P.
DFS uphill from Atlantic reaches set A.
Intersection P ∩ A gives all dual-flowing cells ✓
```

```cpp
class Solution {
public:
    vector<vector<int>> pacificAtlantic(vector<vector<int>>& heights) {
        int m = heights.size(), n = heights[0].size();
        vector<vector<bool>> pacific(m, vector<bool>(n, false));
        vector<vector<bool>> atlantic(m, vector<bool>(n, false));
        
        for (int r = 0; r < m; r++) {
            dfs(heights, pacific, r, 0, m, n);
            dfs(heights, atlantic, r, n - 1, m, n);
        }
        for (int c = 0; c < n; c++) {
            dfs(heights, pacific, 0, c, m, n);
            dfs(heights, atlantic, m - 1, c, m, n);
        }
        
        vector<vector<int>> result;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (pacific[r][c] && atlantic[r][c]) {
                    result.push_back({r, c});
                }
            }
        }
        return result;
    }
private:
    void dfs(const vector<vector<int>>& heights, vector<vector<bool>>& ocean, int r, int c, int m, int n) {
        ocean[r][c] = true;
        int dr[4] = {0, 0, 1, -1};
        int dc[4] = {1, -1, 0, 0};
        
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && !ocean[nr][nc]) {
                if (heights[nr][nc] >= heights[r][c]) { // uphill condition
                    dfs(heights, ocean, nr, nc, m, n);
                }
            }
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(m \cdot n)$ |

> **This is the one.** Reverse uphill reachability avoids repeated full-grid scans.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| 1x1 grid `[[1]]` | Boundary sharing | Touches both oceans, returns `[[0, 0]]` |
| Flat terrain `all equal heights` | Water flows everywhere | All cells reach both oceans, returns entire grid |

---

## Pattern Takeaway

**Reverse Search Uphill** transforms a multi-target search with $O((m \cdot n)^2)$ worst-case into two linear $O(m \cdot n)$ boundary traversals.

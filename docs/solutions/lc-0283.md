## What are we solving?

Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements. You must do this **in-place** without making a copy of the array.

The question is: **how do we bubble non-zero elements to the front while preserving relative order?**

**Example 1:**
```
Input:  nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

**Example 2:**
```
Input:  nums = [0]
Output: [0]
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^4$
- $-2^{31} \le \text{nums}[i] \le 2^{31} - 1$

## Approach 1 — Two Pointer Swap ✅

**Key insight:** Maintain a `insertPos` pointer. Whenever the loop index `i` encounters a non-zero element, swap `nums[i]` with `nums[insertPos]` and increment `insertPos`. Zeroes naturally accumulate after `insertPos`.

```
nums = [0, 1, 0, 3, 12]
insertPos = 0

i=0 (0): skip
i=1 (1): swap(nums[1], nums[0]) -> [1, 0, 0, 3, 12], insertPos = 1
i=2 (0): skip
i=3 (3): swap(nums[3], nums[1]) -> [1, 3, 0, 0, 12], insertPos = 2
i=4 (12): swap(nums[4], nums[2]) -> [1, 3, 12, 0, 0], insertPos = 3

Result: [1, 3, 12, 0, 0] ✓
```

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int insertPos = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != 0) {
                swap(nums[insertPos], nums[i]);
                insertPos++;
            }
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Minimizes operations and stays completely in-place.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| No zeroes in array `[1, 2, 3]` | Self-swaps | Elements swap with themselves harmlessly without corruption |
| All zeroes `[0, 0, 0]` | insertPos advancing | insertPos never increments, stays at 0 |
| Zeroes already at the end `[1, 2, 0, 0]` | Shifting back | Preserves relative order |

---

## Pattern Takeaway

Using **swap with write-pointer** ensures that the subarray before `insertPos` always contains non-zero elements, while elements between `insertPos` and `i` are guaranteed to be zero.

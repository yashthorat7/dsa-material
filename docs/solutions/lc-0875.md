## What are we solving?

Koko loves to eat bananas. There are `n` piles of bananas, where the $i$-th pile has `piles[i]` bananas. The guards have gone and will return in `h` hours.

Koko can decide her bananas-per-hour eating speed of `k`. Each hour, she chooses some pile and eats `k` bananas from that pile. If the pile has less than `k` bananas, she eats all of them and will **not** eat any more bananas during that hour.

Return the **minimum integer `k`** such that she can eat all the bananas within `h` hours.

```
 piles = [ 3,  6,  7, 11 ],  h = 8 hours
 
 Test Speed k = 4:
 - Pile 3:  ceil(3/4)  = 1 hour
 - Pile 6:  ceil(6/4)  = 2 hours
 - Pile 7:  ceil(7/4)  = 2 hours
 - Pile 11: ceil(11/4) = 3 hours
 Total Hours = 1 + 2 + 2 + 3 = 8 hours <= 8 -> VALID SPEED!
 
 Minimum Valid Speed k = 4
```

### Input & Output Contract
- **Input:**
  - `piles`: `vector<int>` where $1 \le n \le 10^4$, $1 \le \text{piles}[i] \le 10^9$.
  - `h`: `int` available hours ($n \le h \le 10^9$).
- **Output:**
  - `int`: Minimum integer eating speed $k \ge 1$.

### The Core Challenge
The total hours required to consume all piles at speed $k$ is:
$$\text{Total Hours}(k) = \sum_{i=0}^{n-1} \left\lceil \frac{\text{piles}[i]}{k} \right\rceil = \sum_{i=0}^{n-1} \left\lfloor \frac{\text{piles}[i] + k - 1}{k} \right\rfloor$$
This function is **monotonically non-increasing** with respect to $k$:
- Increasing speed $k$ strictly decreases or maintains total hours.
- We can binary search over the candidate speed range $k \in [1, \max(\text{piles})]$ in $O(n \log(\max(\text{piles})))$ time!

## Approach 1 — Linear Scan on Speed (Brute Force)

### Intuition
Test integer eating speed $k$ starting from $1, 2, 3, \dots$ upwards until the first speed that finishes all bananas within $h$ hours is found.

### C++ Implementation
```cpp
class Solution {
public:
    int minEatingSpeed(vector<int>& piles, int h) {
        int maxPile = 0;
        for (int p : piles) maxPile = max(maxPile, p);
        
        for (int speed = 1; speed <= maxPile; speed++) {
            long long hours = 0;
            for (int p : piles) {
                hours += (p + speed - 1) / speed;
            }
            if (hours <= h) return speed;
        }
        
        return maxPile;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \max(\text{piles}))$ | Linear search over range up to $10^9$. TLE on large piles. |
| **Space** | $O(1)$ | No memory allocated. |

> **Verdict:** Suboptimal. Binary search on speed achieves $O(n \log(\max))$ time.

## What are we solving?

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. The only constraint stopping you from robbing all of them is that **adjacent houses have connected security systems**: if two adjacent houses are broken into on the same night, the system will automatically alert the police.

Given an integer array `nums` representing the amount of money at each house, return the **maximum amount of money** you can rob tonight **without alerting the police**.

```
 Houses:   [2]     [7]     [9]     [3]     [1]
            ↑               ↑               ↑
          Rob 1           Rob 3           Rob 5
          
 Total Loot = 2 + 9 + 1 = 12 (No two robbed houses are adjacent!)
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 100$, $0 \le \text{nums}[i] \le 400$.
- **Output:**
  - `int` representing the maximum sum of non-adjacent elements.

### The Core Challenge
At each house $i$, we must make a binary decision:
1. **Rob house $i$:** We collect `nums[i]`, but we **cannot** rob house $i - 1$. Our maximum loot is `nums[i] + DP[i - 2]`.
2. **Skip house $i$:** We collect nothing at house $i$, so our maximum loot is whatever we could steal up to house $i - 1$ (`DP[i - 1]`).

This leads to the classical 1D Dynamic Programming recurrence:
$$\text{DP}[i] = \max(\text{DP}[i - 1], \ \text{nums}[i] + \text{DP}[i - 2])$$

---

**Example 1:**
```
Input:  nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3). Total = 1 + 3 = 4.
```

**Example 2:**
```
Input:  nums = [2,7,9,3,1]
Output: 12
Explanation: Rob house 1 (2), house 3 (9), and house 5 (1). Total = 2 + 9 + 1 = 12.
```

**Constraints:**
- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 400$

## Approach 1 — Naive Recursion (Brute Force Tree)

### Intuition
Express the decision tree as a recursive function `robFrom(i)` returning the max loot starting from index $i$:
`robFrom(i) = max(nums[i] + robFrom(i + 2), robFrom(i + 1))`.

```
                    rob(0)
                  /        \
          rob(1) [Skip]   nums[0] + rob(2) [Rob]
          /    \               /    \
      rob(2)  rob(3)       rob(3)  rob(4)
```

### C++ Implementation
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        return helper(nums, 0);
    }

private:
    int helper(const vector<int>& nums, int i) {
        if (i >= nums.size()) return 0;
        int robCurrent = nums[i] + helper(nums, i + 2);
        int skipCurrent = helper(nums, i + 1);
        return max(robCurrent, skipCurrent);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(2^n)$ | Binary decision tree of depth $n$ without caching. TLEs for $n \ge 40$. |
| **Space** | $O(n)$ | Call stack depth reaches $n$. |

## Approach 2 — Top-Down DP (Memoization)

### Intuition
Cache the result of `helper(i)` in a memo table `memo` initialized to `-1`.

### C++ Implementation
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        vector<int> memo(nums.size(), -1);
        return helper(nums, 0, memo);
    }

private:
    int helper(const vector<int>& nums, int i, vector<int>& memo) {
        if (i >= nums.size()) return 0;
        if (memo[i] != -1) return memo[i];
        
        int robCurrent = nums[i] + helper(nums, i + 2, memo);
        int skipCurrent = helper(nums, i + 1, memo);
        
        return memo[i] = max(robCurrent, skipCurrent);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each index $0 \le i < n$ is evaluated once. |
| **Space** | $O(n)$ | Memo vector of size $n$ plus $O(n)$ recursion stack. |

## Approach 3 — Bottom-Up DP (1D Table)

### Intuition
Build a table `dp` where `dp[i]` represents the maximum loot possible up to house $i$:
- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`
- `dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])`

### C++ Implementation
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        
        vector<int> dp(n);
        dp[0] = nums[0];
        dp[1] = max(nums[0], nums[1]);
        
        for (int i = 2; i < n; i++) {
            dp[i] = max(dp[i - 1], nums[i] + dp[i - 2]);
        }
        
        return dp[n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass linear loop. |
| **Space** | $O(n)$ | 1D vector of length $n$. |

## Approach 4 — Space-Optimized Rolling Variables ✅

### Key Insight
Notice that `dp[i]` depends strictly on the two immediately preceding values: `dp[i - 1]` and `dp[i - 2]`. We can replace the full table with two rolling scalar variables:
- `prev1`: maximum money stolen up to house $i - 1$.
- `prev2`: maximum money stolen up to house $i - 2$.

```
nums = [2, 7, 9, 3, 1]
prev2 = 0, prev1 = 0

x = 2: curr = max(0, 2 + 0)  = 2  -> prev2 = 0,  prev1 = 2
x = 7: curr = max(2, 7 + 0)  = 7  -> prev2 = 2,  prev1 = 7
x = 9: curr = max(7, 9 + 2)  = 11 -> prev2 = 7,  prev1 = 11
x = 3: curr = max(11, 3 + 7) = 11 -> prev2 = 11, prev1 = 11
x = 1: curr = max(11, 1 + 11)= 12 -> prev2 = 11, prev1 = 12

Result: 12 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0; // max loot up to i - 2
        int prev1 = 0; // max loot up to i - 1
        
        for (int x : nums) {
            int curr = max(prev1, x + prev2);
            prev2 = prev1;
            prev1 = curr;
        }
        
        return prev1;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass through the array. |
| **Space** | $O(1)$ | Purely two scalar variables on the stack. |

> **This is the one.** Clean, space-optimal $O(n)$ time and $O(1)$ space.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single House** | `nums = [5]` | Loop bounds | Loop runs once, `curr = max(0, 5+0) = 5`, returns 5. |
| **Two Houses** | `nums = [2, 9]` | Adjacency conflict | `curr = max(2, 9+0) = 9`, picks largest single house. |
| **All Zeroes** | `nums = [0, 0, 0]` | Zero identity | Accumulates 0 without underflow. |
| **Alternating Peaks** | `nums = [10, 1, 1, 10]` | Blind odd/even parity selection | Recurrence correctly chooses houses 0 and 3 ($10 + 10 = 20$). |

## What are we solving?

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed, the only constraint stopping you from robbing each of them is that adjacent houses have security systems connected and **it will automatically contact the police if two adjacent houses were broken into on the same night**.

Given an integer array `nums` representing the amount of money of each house, return the **maximum amount of money** you can rob tonight **without alerting the police**.

**Example 1:**
```
Input:  nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3). Total amount you can rob = 1 + 3 = 4.
```

**Example 2:**
```
Input:  nums = [2,7,9,3,1]
Output: 12
Explanation: Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1). Total amount = 2 + 9 + 1 = 12.
```

**Constraints:**
- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 400$

## Approach 1 — 1D DP with Space Optimization ✅

**Key insight:**
At each house `i`:
- Option 1 (Rob house `i`): get `nums[i] + rob(i - 2)`.
- Option 2 (Skip house `i`): get `rob(i - 1)`.
Recurrence: `dp[i] = max(dp[i-1], nums[i] + dp[i-2])`.
Compress to two variables: `prev1` (max up to previous house) and `prev2` (max up to two houses back).

```
nums = [2, 7, 9, 3, 1]
prev2 = 0, prev1 = 0

x = 2: curr = max(0, 2 + 0) = 2 -> prev2=0, prev1=2
x = 7: curr = max(2, 7 + 0) = 7 -> prev2=2, prev1=7
x = 9: curr = max(7, 9 + 2) = 11 -> prev2=7, prev1=11
x = 3: curr = max(11, 3 + 7) = 11 -> prev2=11, prev1=11
x = 1: curr = max(11, 1 + 11) = 12 -> prev2=11, prev1=12

Result: 12 ✓
```

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0, prev1 = 0;
        for (int x : nums) {
            int curr = max(prev1, x + prev2);
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Non-adjacent selection DP in constant space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single house `[5]` | Loop termination | Returns 5 |
| Two houses `[2, 9]` | Adjacency conflict | Picks `max(2, 9) = 9` |

## Pattern Takeaway

The **Non-Adjacent Choice pattern (`dp[i] = max(dp[i-1], val + dp[i-2])`)** is the building block for House Robber, Delete and Earn, and Maximum Weight Independent Set on paths.

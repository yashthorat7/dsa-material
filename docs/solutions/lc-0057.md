## What are we solving?

You are given an array of non-overlapping intervals `intervals` where `intervals[i] = [starti, endi]` represents the start and end of the $i$-th interval, and `intervals` is sorted in ascending order by $\text{start}_i$. You are also given an interval `newInterval = [start, end]` representing the start and end of another interval.

Insert `newInterval` into `intervals` such that `intervals` is still sorted in ascending order by $\text{start}_i$ and `intervals` still does not have any overlapping intervals (merge overlapping intervals if necessary).

Return `intervals` after the insertion.

```
 intervals = [[1,3],[6,9]], newInterval = [2,5]
 Merge [1,3] and [2,5] -> [1,5]
 
 Output: [[1,5],[6,9]]
```

### Input & Output Contract
- **Input:**
  - `intervals`: `vector<vector<int>>` sorted by start time, non-overlapping ($0 \le n \le 10^4$).
  - `newInterval`: `vector<int>` of size 2.
- **Output:**
  - `vector<vector<int>>` containing all non-overlapping merged intervals.

---

**Example 1:**
```
Input: intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]
```

**Example 2:**
```
Input: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
Explanation: Because the new interval [4,8] overlaps with [3,5],[6,7],[8,10].
```

**Constraints:**
- $0 \le \text{intervals.length} \le 10^4$
- $\text{intervals}[i].\text{length} == 2$
- $0 \le \text{start}_i \le \text{end}_i \le 10^5$
- `intervals` is sorted by $\text{start}_i$ in ascending order.
- `newInterval.length == 2`

## Approach 1 — Append and Full Merge Sort ($O(n \log n)$)

### Intuition
Insert `newInterval` into the `intervals` vector, sort all intervals by start time in $O(n \log n)$, and then execute standard interval merging (LC 56).

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<int>> insert(vector<vector<int>>& intervals, vector<int>& newInterval) {
        intervals.push_back(newInterval);
        sort(intervals.begin(), intervals.end());
        
        vector<vector<int>> merged;
        for (const auto& interval : intervals) {
            if (merged.empty() || merged.back()[1] < interval[0]) {
                merged.push_back(interval);
            } else {
                merged.back()[1] = max(merged.back()[1], interval[1]);
            }
        }
        
        return merged;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Sorting $n + 1$ intervals dominates runtime. |
| **Space** | $O(n)$ | Merged output vector. |

> **Verdict:** Suboptimal. Since the original array is already sorted, a single-pass $O(n)$ linear scan is optimal.

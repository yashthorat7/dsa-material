## What are we solving?

Given an integer array `nums`, find the subarray with the largest sum, and return its sum. A subarray is a **contiguous** non-empty sequence of elements within an array.

This classic problem asks: **when should we extend the current running sum, and when should we discard it and start fresh?**

**Example 1:**
```
Input:  nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: The subarray [4,-1,2,1] has the largest sum 6.
```

**Example 2:**
```
Input:  nums = [1]
Output: 1
Explanation: The subarray [1] has the largest sum 1.
```

**Example 3:**
```
Input:  nums = [5,4,-1,7,8]
Output: 23
Explanation: The subarray [5,4,-1,7,8] has the largest sum 23.
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^5$
- $-10^4 \le \text{nums}[i] \le 10^4$

## Approach 1 — Kadane's Algorithm (Greedy / DP) ✅

**Key insight:** As we scan the array, we maintain a running `currentSum`. If `currentSum` ever drops below zero, adding it to any future element will only make that future element smaller! So we reset `currentSum = 0` whenever it becomes negative.

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
maxSum = -2, currentSum = 0

num = -2: currentSum = -2 -> maxSum = -2, currentSum < 0 -> reset to 0
num =  1: currentSum =  1 -> maxSum =  1
num = -3: currentSum = -2 -> maxSum =  1, reset to 0
num =  4: currentSum =  4 -> maxSum =  4
num = -1: currentSum =  3 -> maxSum =  4
num =  2: currentSum =  5 -> maxSum =  5
num =  1: currentSum =  6 -> maxSum =  6
num = -5: currentSum =  1 -> maxSum =  6
num =  4: currentSum =  5 -> maxSum =  6

Result: 6 ✓
```

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int maxSum = nums[0];
        int currentSum = 0;
        for (int x : nums) {
            currentSum = max(x, currentSum + x);
            maxSum = max(maxSum, currentSum);
        }
        return maxSum;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Kadane's algorithm is optimal in both time and space.

## Approach 2 — Divide and Conquer

Split the array into left and right halves. The max subarray is either: (1) entirely in left half, (2) entirely in right half, or (3) crossing the midpoint. Combine step computes left and right max suffixes/prefixes in $O(n)$.

```
Recurrence: T(n) = 2T(n/2) + O(n) -> O(n log n) by Master Theorem.
```

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        return helper(nums, 0, nums.size() - 1);
    }
private:
    int helper(vector<int>& nums, int left, int right) {
        if (left == right) return nums[left];
        int mid = left + (right - left) / 2;
        int leftMax = helper(nums, left, mid);
        int rightMax = helper(nums, mid + 1, right);
        
        int crossLeft = INT_MIN, sum = 0;
        for (int i = mid; i >= left; i--) {
            sum += nums[i];
            crossLeft = max(crossLeft, sum);
        }
        int crossRight = INT_MIN; sum = 0;
        for (int i = mid + 1; i <= right; i++) {
            sum += nums[i];
            crossRight = max(crossRight, sum);
        }
        return max({leftMax, rightMax, crossLeft + crossRight});
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n)$ | $O(\log n)$ |

> Great conceptual exercise in divide-and-conquer, but Kadane's $O(n)$ is preferred for interviews.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All negative numbers `[-5, -2, -8]` | Resetting `currentSum` to 0 might return 0 instead of the least negative number | `currentSum = max(x, currentSum + x)` properly picks `x` when `currentSum` is negative, keeping `maxSum = -2` |
| Single element array `[-1]` | Returning 0 | `maxSum` initialized to `nums[0] = -1` |
| All positive numbers `[1, 2, 3]` | Accidental reset | Running sum accumulates all elements to return total sum |

---

## Pattern Takeaway

**Kadane's Algorithm** is the archetype for prefix-extension problems. If accumulating a previous sequence hinders the future (sum < 0), drop it and start over. Used in Maximum Product Subarray, 2D Maximum Submatrix sum, and circular subarray variations.

## What are we solving?

Given two strings `text1` and `text2`, return the length of their **longest common subsequence**. If there is no common subsequence, return `0`.

A **subsequence** of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters (e.g., `"ace"` is a subsequence of `"abcde"`).

A **common subsequence** of two strings is a subsequence that appears in both strings.

```
 text1 = " a  b  c  d  e "
 text2 = " a     c     e "
 
 Common Subsequence: "ace" (Length = 3)
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `text1`: `string` of lowercase English letters ($1 \le m \le 1000$).
  - `text2`: `string` of lowercase English letters ($1 \le n \le 1000$).
- **Output:**
  - `int`: Maximum length of any common subsequence.

### The Core Challenge
At any prefix indices $(i, j)$:
- If `text1[i-1] == text2[j-1]`: the character matches, extending the optimal subsequence: $1 + \text{dp}[i-1][j-1]$.
- If characters differ: we take the best choice between skipping from `text1` or skipping from `text2`: $\max(\text{dp}[i-1][j], \text{dp}[i][j-1])$.

---

**Example 1:**
```
Input:  text1 = "abcde", text2 = "ace"
Output: 3
Explanation: The longest common subsequence is "ace" and its length is 3.
```

**Example 2:**
```
Input:  text1 = "abc", text2 = "abc"
Output: 3
Explanation: The longest common subsequence is "abc" and its length is 3.
```

**Example 3:**
```
Input:  text1 = "abc", text2 = "def"
Output: 0
Explanation: There is no such common subsequence, so the result is 0.
```

**Constraints:**
- $1 \le \text{text1.length}, \text{text2.length} \le 1000$
- `text1` and `text2` consist of only lowercase English characters.

## Approach 1 — Top-Down Recursion with Memoization

### Intuition
Define `lcs(i, j)` as the LCS length for prefixes `text1[0..i]` and `text2[0..j]`.
- If `text1[i] == text2[j]`: $1 + \text{lcs}(i - 1, j - 1)$.
- Else: $\max(\text{lcs}(i - 1, j), \text{lcs}(i, j - 1))$.
Memoize in a 2D vector `memo[m][n]`.

### C++ Implementation
```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<vector<int>> memo(m, vector<int>(n, -1));
        
        auto dfs = [&](auto& self, int i, int j) -> int {
            if (i < 0 || j < 0) return 0;
            if (memo[i][j] != -1) return memo[i][j];
            
            if (text1[i] == text2[j]) {
                return memo[i][j] = 1 + self(self, i - 1, j - 1);
            }
            return memo[i][j] = max(self(self, i - 1, j), self(self, i, j - 1));
        };
        
        return dfs(dfs, m - 1, n - 1);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | $m \times n$ subproblems resolved in $O(1)$. |
| **Space** | $O(m \cdot n)$ | 2D memo table plus recursion stack. |

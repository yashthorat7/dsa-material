## What are we solving?

Given the `root` of a binary tree, imagine yourself standing on the **right side** of it. Return the values of the nodes you can see ordered from **top to bottom**.

```
          (1)  <--- View: 1
         /   \
       (2)   (3) <--- View: 3
        \      \
        (5)    (4) <--- View: 4
        
 Right Side View: [ 1, 3, 4 ]
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root of a binary tree ($0 \le \text{node count} \le 100$, $-100 \le \text{Node.val} \le 100$).
- **Output:**
  - `vector<int>` containing the rightmost visible value at each depth level.

### The Core Challenge
A node on the left can still be visible from the right if the right subtree is shallower! For example, if a tree has right child `3` with no children, and left child `2` with deep child `5`, then `5` is visible at depth 2 from the right. We must select the rightmost existing node at every horizontal level.

---

**Example 1:**
```
Input:  root = [1,2,3,null,5,null,4]
Output: [1,3,4]
```

**Example 2:**
```
Input:  root = [1,null,3]
Output: [1,3]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 100]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — BFS Level Order Traversal (Pick Last Element)

### Intuition
Execute standard level-order BFS using a queue. For each level of size `levelSize`, the last dequeued node (`i == levelSize - 1`) is the rightmost node of that level.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        if (root == nullptr) return {};
        
        vector<int> result;
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            int levelSize = q.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode* curr = q.front();
                q.pop();
                
                // If last element in this level, it is visible from the right
                if (i == levelSize - 1) {
                    result.push_back(curr->val);
                }
                
                if (curr->left)  q.push(curr->left);
                if (curr->right) q.push(curr->right);
            }
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Enqueues and dequeues each node once. |
| **Space** | $O(w)$ | Queue stores at most max level width $w \le n/2$. |

## Approach 2 — Right-First DFS (Depth Level Matching) ✅

### Key Insight
Traverse the tree using DFS in **Root $\rightarrow$ Right $\rightarrow$ Left** order:
- Maintain current `depth` (starting at 0).
- If `depth == result.size()`: this is the **first time we have ever visited this depth level**, and since we prioritize the right child first, this node is guaranteed to be the rightmost visible node!
- Append `node->val` to `result`.
- Recurse on `node->right` first, then `node->left`.

```
Tree: [1, 2, 3, null, 5, null, 4]

1. Visit 1 (depth 0): result.size()=0 == depth -> add 1 (result: [1])
2. Visit 3 (depth 1): result.size()=1 == depth -> add 3 (result: [1, 3])
3. Visit 4 (depth 2): result.size()=2 == depth -> add 4 (result: [1, 3, 4])
4. Backtrack to left child 2 (depth 1): result.size()=3 != 1 -> Ignore!
5. Left child of 2 is 5 (depth 2): result.size()=3 != 2 -> Ignore!

Result: [1, 3, 4] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        dfs(root, 0, result);
        return result;
    }

private:
    void dfs(TreeNode* node, int depth, vector<int>& result) {
        if (node == nullptr) return;
        
        // If visiting this depth for the first time, record rightmost node
        if (depth == result.size()) {
            result.push_back(node->val);
        }
        
        // Prioritize right subtree exploration first
        dfs(node->right, depth + 1, result);
        dfs(node->left, depth + 1, result);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits each node once. |
| **Space** | $O(h)$ | Recursion stack depth equals tree height $h$ ($O(\log n)$ balanced, $O(n)$ skewed). |

> **This is the one.** Right-first DFS with minimal $O(h)$ memory overhead.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Left Subtree Deeper Than Right** | `[1, 2, 3, 4]` (4 under 2) | Missing lower left nodes | DFS finishes right branch, then discovers depth 2 under left branch and appends 4. |
| **Empty Tree** | `root = nullptr` | Dereferencing null pointer | Returns empty list `[]`. |
| **Single Node** | `[1]` | Loop bounds | Returns `[1]`. |

---

## Pattern Takeaways

1. **Pre-Order Traversal Inversion:**  
   - Root $\rightarrow$ Left $\rightarrow$ Right gives Left Side View.
   - Root $\rightarrow$ Right $\rightarrow$ Left gives Right Side View.
2. **`depth == result.size()` Invariant:**  
   Guarantees that exactly one representative node is captured per horizontal level.

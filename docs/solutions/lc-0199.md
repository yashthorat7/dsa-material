## What are we solving?

Given the `root` of a binary tree, imagine yourself standing on the **right side** of it, return the values of the nodes you can see ordered from top to bottom.

**Example 1:**
```
Input:  root = [1,2,3,null,5,null,4]
Output: [1,3,4]
```

**Example 2:**
```
Input:  root = [1,null,3]
Output: [1,3]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 100]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Right-First DFS (Depth Check) ✅

**Key insight:**
Traverse with DFS in **Root $\rightarrow$ Right $\rightarrow$ Left** order.
Pass current `depth` (starting at 0).
If `depth == result.size()`, this is the **first node we have ever encountered at this level**, which is guaranteed to be the rightmost visible node! Add `node->val` to `result`.

```
Tree: [1, 2, 3, null, 5, null, 4]
1. Root 1 (depth 0): result.size()=0 == depth -> add 1 (result=[1])
2. Right 3 (depth 1): result.size()=1 == depth -> add 3 (result=[1, 3])
3. Right child of 3 (4, depth 2): result.size()=2 == depth -> add 4 (result=[1, 3, 4])
4. Backtrack to 2 -> left subtrees are visited at depth <= 2, ignored.

Result: [1, 3, 4] ✓
```

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        dfs(root, 0, result);
        return result;
    }
private:
    void dfs(TreeNode* node, int depth, vector<int>& result) {
        if (!node) return;
        if (depth == result.size()) {
            result.push_back(node->val);
        }
        dfs(node->right, depth + 1, result);
        dfs(node->left, depth + 1, result);
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(h)$ |

> **This is the one.** Right-first DFS with $O(h)$ stack space.

---

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Left subtree deeper than right subtree | Missing lower left nodes visible from right | Right-first DFS visits right subtree first, then captures deeper left subtree nodes when `depth == result.size()` |
| Empty tree | Null check | Returns `[]` |

---

## Pattern Takeaway

**Right-first DFS with `depth == result.size()`** picks the first visible node at each depth level in $O(h)$ auxiliary stack memory.

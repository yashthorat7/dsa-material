## What are we solving?

Given two non-negative integers `num1` and `num2` represented as strings, return the product of `num1` and `num2`, also represented as a string.

You must not use any built-in BigInteger library or convert the inputs to integers directly.

```
       1  2  3   (num1, length m = 3)
  x    4  5  6   (num2, length n = 3)
  ------------
       7  3  8   (123 * 6)
    6  1  5  0   (123 * 50)
 4  9  2  0  0   (123 * 400)
 -------------
 5  6  0  8  8   (Total Product, max length m + n = 6)
```

### Input & Output Contract
- **Input:**
  - `num1`: `string` containing digits `'0'-'9'` ($1 \le m \le 200$).
  - `num2`: `string` containing digits `'0'-'9'` ($1 \le n \le 200$).
  - No leading zeroes except `"0"`.
- **Output:**
  - `string` representing the exact arithmetic product.

### The Arithmetic Insight
For any two numbers with $m$ and $n$ digits respectively:
1. The product can have at most $\mathbf{m + n}$ **digits**.
2. When multiplying digit $\text{num1}[i]$ by digit $\text{num2}[j]$, their product contributes directly to index positions:
   - **Units / Remainder:** `p2 = i + j + 1`
   - **Carry:** `p1 = i + j`

---

**Example 1:**
```
Input:  num1 = "2", num2 = "3"
Output: "6"
```

**Example 2:**
```
Input:  num1 = "123", num2 = "456"
Output: "56088"
```

**Constraints:**
- $1 \le \text{num1.length}, \text{num2.length} \le 200$
- `num1` and `num2` consist of digits only.
- Both `num1` and `num2` do not contain any leading zero, except the number `0` itself.

## Approach 1 — Positional Digit Accumulation ✅

### Key Insight
1. If either number is `"0"`, return `"0"` immediately.
2. Initialize an integer vector `pos` of size $m + n$ with zeroes.
3. Iterate $i$ from $m - 1$ down to $0$, and $j$ from $n - 1$ down to $0$:
   - `mul = (num1[i] - '0') * (num2[j] - '0')`
   - `sum = mul + pos[i + j + 1]`
   - `pos[i + j + 1] = sum % 10`
   - `pos[i + j] += sum / 10` (carry)
4. Convert `pos` into a string, skipping any leading zeroes.

```
num1 = "12", num2 = "3" (m=2, n=1, pos size=3: [0, 0, 0])

i=1 (2), j=0 (3):
- mul = 2 * 3 = 6
- sum = 6 + pos[2] = 6
- pos[2] = 6, pos[1] += 0 -> pos = [0, 0, 6]

i=0 (1), j=0 (3):
- mul = 1 * 3 = 3
- sum = 3 + pos[1] = 3
- pos[1] = 3, pos[0] += 0 -> pos = [0, 3, 6]

Skip leading 0 -> Result = "36" ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";
        
        int m = num1.length();
        int n = num2.length();
        vector<int> pos(m + n, 0);
        
        // Multiply each digit and accumulate at (i + j) and (i + j + 1)
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1[i] - '0') * (num2[j] - '0');
                int p1 = i + j;
                int p2 = i + j + 1;
                
                int sum = mul + pos[p2];
                pos[p2] = sum % 10;
                pos[p1] += sum / 10;
            }
        }
        
        // Build result string skipping leading zeroes
        string result = "";
        for (int digit : pos) {
            if (!(result.empty() && digit == 0)) {
                result.push_back(digit + '0');
            }
        }
        
        return result.empty() ? "0" : result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Nested loops multiply each pair of digits. For $200 \times 200 = 40,000$ operations. |
| **Space** | $O(m + n)$ | Vector of size $m + n \le 400$. |

> **This is the one.** Standard grade-school positional multiplication.

## Approach 2 — Shifted Partial Products Addition

### Intuition
Simulate grade-school manual multiplication row by row: multiply `num1` by each single digit of `num2`, append appropriate trailing `'0'`s according to column place value, and sum up all partial product strings using a big integer addition helper.

### C++ Implementation
```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";
        string result = "0";
        
        for (int j = num2.size() - 1; j >= 0; j--) {
            int d2 = num2[j] - '0';
            string partial = "";
            int carry = 0;
            
            // Add trailing zeroes for place value
            for (int k = 0; k < num2.size() - 1 - j; k++) partial += '0';
            
            for (int i = num1.size() - 1; i >= 0 || carry; i--) {
                int d1 = (i >= 0) ? (num1[i] - '0') : 0;
                int prod = d1 * d2 + carry;
                partial += to_string(prod % 10);
                carry = prod / 10;
            }
            reverse(partial.begin(), partial.end());
            result = addStrings(result, partial);
        }
        
        return result;
    }

private:
    string addStrings(string num1, string num2) {
        string res = "";
        int i = num1.size() - 1, j = num2.size() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0) sum += num1[i--] - '0';
            if (j >= 0) sum += num2[j--] - '0';
            res += to_string(sum % 10);
            carry = sum / 10;
        }
        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(M \cdot N + N^2)$ | Generates $N$ strings and performs string additions. |
| **Space** | $O(M + N)$ | Auxiliary memory for string building. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Multiply by Zero** | `"0" * "456"` | Outputting `"0000"` | Early check `if (num1 == "0" || num2 == "0") return "0";`. |
| **Highest Digit Has No Carry** | `"2" * "3" = 6` | Leading zero in index 0 | `if (!(result.empty() && digit == 0))` drops leading 0. |
| **Maximum 200 Digits** | 200 digits $\times$ 200 digits | Integer overflow | Vector of single-digit integers avoids machine integer limits. |

## What are we solving?

Given two non-negative integers `num1` and `num2` represented as strings, return the product of `num1` and `num2`, also represented as a string.

Note: You must not use any built-in BigInteger library or convert the inputs to integer directly.

The arithmetic insight is: **multiplying digit `num1[i]` by `num2[j]` contributes to output index positions `i + j` and `i + j + 1`.**

**Example 1:**
```
Input:  num1 = "2", num2 = "3"
Output: "6"
```

**Example 2:**
```
Input:  num1 = "123", num2 = "456"
Output: "56088"
```

**Constraints:**
- $1 \le \text{num1.length}, \text{num2.length} \le 200$
- `num1` and `num2` consist of digits only.
- Both `num1` and `num2` do not contain any leading zero, except the number `0` itself.

## Approach 1 — Grade School Multiplication (Positional Accumulation) ✅

**Key insight:**
For two numbers of length `m` and `n`, the product has at most `m + n` digits.
Create an array `pos[m + n]` initialized to 0.
Iterate backwards:
- `mul = (num1[i] - '0') * (num2[j] - '0')`
- `p1 = i + j`, `p2 = i + j + 1`
- `sum = mul + pos[p2]`
- `pos[p2] = sum % 10`
- `pos[p1] += sum / 10` (carry)
Convert `pos` array to string, skipping leading zeroes.

```
num1 = "12", num2 = "3" (m=2, n=1, pos size=3)
i=1 (2), j=0 (3): mul=6, sum=6 -> pos[2]=6, pos[1]=0
i=0 (1), j=0 (3): mul=3, sum=3+0=3 -> pos[1]=3, pos[0]=0
pos = [0, 3, 6] -> skip leading 0 -> "36" ✓
```

```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") return "0";
        int m = num1.size(), n = num2.size();
        vector<int> pos(m + n, 0);
        
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int mul = (num1[i] - '0') * (num2[j] - '0');
                int p1 = i + j, p2 = i + j + 1;
                int sum = mul + pos[p2];
                
                pos[p2] = sum % 10;
                pos[p1] += sum / 10;
            }
        }
        
        string result = "";
        for (int p : pos) {
            if (!(result.empty() && p == 0)) {
                result.push_back(p + '0');
            }
        }
        
        return result.empty() ? "0" : result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(m + n)$ |

> **This is the one.** Standard grade-school positional multiplication algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Multiplication by zero `"0" * "1234"` | Returning `"0000"` | Early check `if (num1 == "0" || num2 == "0") return "0";` |
| No carry on highest position | Leading zero in result | Leading zeroes skipped when building output string |
| Large 200-digit multiplication | Integer type overflow | Digit-by-digit vector avoids standard primitive type limits |

---

## Pattern Takeaway

Elementary positional multiplication maps digit product `(i, j)` to indices `i + j` (carry) and `i + j + 1` (remainder) in an array of size `m + n`.

## What are we solving?

Given a **non-empty** array of integers `nums`, every element appears **twice** except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

The question is: **how does bitwise XOR cancel out identical pairs and isolate the unique element in $O(n)$ time and $O(1)$ space?**

**Example 1:**
```
Input:  nums = [2,2,1]
Output: 1
```

**Example 2:**
```
Input:  nums = [4,1,2,1,2]
Output: 4
```

**Example 3:**
```
Input:  nums = [1]
Output: 1
```

**Constraints:**
- $1 \le \text{nums.length} \le 3 \times 10^4$
- $-3 \times 10^4 \le \text{nums}[i] \le 3 \times 10^4$
- Each element in the array appears twice except for one element which appears only once.

## Approach 1 — Bitwise XOR Accumulator ✅

**Key insight:**
XOR ($\oplus$) has two fundamental properties:
1. $a \oplus a = 0$ (any number XORed with itself is zero).
2. $a \oplus 0 = a$ (any number XORed with zero is unchanged).
3. XOR is associative and commutative.
XORing all numbers together cancels every paired number, leaving only the unique single number!

```
nums = [4, 1, 2, 1, 2]
acc = 0 ^ 4 = 4
acc = 4 ^ 1
acc = (4 ^ 1) ^ 2
acc = (4 ^ 1 ^ 2) ^ 1 = 4 ^ (1 ^ 1) ^ 2 = 4 ^ 0 ^ 2 = 4 ^ 2
acc = (4 ^ 2) ^ 2 = 4 ^ (2 ^ 2) = 4 ^ 0 = 4

Result: 4 ✓
```

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int result = 0;
        for (int num : nums) {
            result ^= num;
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** $O(n)$ time with strictly $O(1)$ extra space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single element array `[1]` | Loop termination | `0 ^ 1 = 1` returned immediately |
| Negative numbers `[-1, -1, -2]` | Two's complement sign bit | Bitwise XOR operates identically on two's complement bit patterns |

---

## Pattern Takeaway

Bitwise **XOR cancellation ($x \oplus x = 0$)** is the classic trick for isolating un-paired or odd-frequency elements in constant space.

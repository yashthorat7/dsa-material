## What are we solving?

You are given the heads of two sorted linked lists `list1` and `list2`. Merge the two lists into one **sorted** list. The list should be made by splicing together the nodes of the first two lists. Return the head of the merged linked list.

The question is: **how to stitch nodes using a dummy pre-head in $O(m + n)$ time and $O(1)$ space?**

**Example 1:**
```
Input:  list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
```

**Example 2:**
```
Input:  list1 = [], list2 = []
Output: []
```

**Example 3:**
```
Input:  list1 = [], list2 = [0]
Output: [0]
```

**Constraints:**
- The number of nodes in both lists is in the range $[0, 50]$.
- $-100 \le \text{Node.val} \le 100$
- Both `list1` and `list2` are sorted in non-decreasing order.

## Approach 1 — Iterative Splice with Dummy Head ✅

**Key insight:**
Maintain a `dummy` node and `tail = &dummy`.
While both `list1` and `list2` are non-null:
- Attach the node with the smaller value: `tail->next = (list1->val <= list2->val ? list1 : list2)`.
- Advance the chosen list pointer and `tail`.
Attach the remaining non-null list directly: `tail->next = list1 ? list1 : list2`.
Return `dummy.next`.

```
list1 = [1, 2, 4], list2 = [1, 3, 4]
dummy -> nullptr, tail = dummy

1. list1(1) <= list2(1) -> tail->next = list1(1), list1 = [2, 4], tail = 1
2. list2(1) < list1(2)  -> tail->next = list2(1), list2 = [3, 4], tail = 1
3. list1(2) < list2(3)  -> tail->next = list1(2), list1 = [4],    tail = 2
4. list2(3) < list1(4)  -> tail->next = list2(3), list2 = [4],    tail = 3
5. list1(4) <= list2(4) -> tail->next = list1(4), list1 = null,   tail = 4
list1 is null -> tail->next = list2(4).

Result: 1 -> 1 -> 2 -> 3 -> 4 -> 4 ✓
```

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        
        while (list1 && list2) {
            if (list1->val <= list2->val) {
                tail->next = list1;
                list1 = list1->next;
            } else {
                tail->next = list2;
                list2 = list2->next;
            }
            tail = tail->next;
        }
        
        tail->next = list1 ? list1 : list2;
        return dummy.next;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m + n)$ | $O(1)$ |

> **This is the one.** Optimal iterative pointer splicing.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| One or both lists empty | Null checks | `tail->next = list1 ? list1 : list2` attaches non-empty list directly |
| Lists of different lengths | Trailing elements lost | Direct pointer assignment attaches entire remaining tail in $O(1)$ |

---

## Pattern Takeaway

Merging two sorted lists with **`tail->next = list1 ? list1 : list2`** splices the entire remaining chain in a single $O(1)$ pointer assignment.

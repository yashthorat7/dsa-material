## What are we solving?

Given the `head` of a singly linked list, return `true` if it is a **palindrome** or `false` otherwise.

Can you do it in **$O(n)$ time** and **$O(1)$ space**?

**Example 1:**
```
Input:  head = [1,2,2,1]
Output: true
```

**Example 2:**
```
Input:  head = [1,2]
Output: false
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 10^5]$.
- $0 \le \text{Node.val} \le 9$

## Approach 1 — Find Midpoint + Reverse Second Half + Compare ✅

**Key insight:**
1. Find middle of list using fast/slow pointers.
2. Reverse the second half in-place.
3. Compare first half (`p1 = head`) and second half (`p2 = reversedHead`).
4. (Optional) Restore list by reversing second half back.
Constant space $O(1)$ without creating copies.

```
List: 1 -> 2 -> 2 -> 1
1. Midpoint: slow points to 2 (first 2)
2. Reverse second half: 1 -> 2 -> (1 -> 2)
3. Compare:
   p1=1, p2=1 -> match
   p1=2, p2=2 -> match
Result: true ✓
```

```cpp
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        if (!head || !head->next) return true;
        
        // 1. Find midpoint
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next && fast->next->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        // 2. Reverse second half
        ListNode* secondHalf = reverseList(slow->next);
        
        // 3. Compare halves
        ListNode* p1 = head;
        ListNode* p2 = secondHalf;
        bool isPal = true;
        while (p2 != nullptr) {
            if (p1->val != p2->val) {
                isPal = false;
                break;
            }
            p1 = p1->next;
            p2 = p2->next;
        }
        
        return isPal;
    }
private:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr) {
            ListNode* nxt = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nxt;
        }
        return prev;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** In-place $O(1)$ memory palindrome check.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Odd length `[1, 2, 3, 2, 1]` | Middle element comparison | `slow` lands at first 2, second half `[2, 1]` reverses to `[1, 2]`, matches prefix |
| Single node `[1]` | Null dereference | Returns `true` immediately |

---

## Pattern Takeaway

Tri-step pipeline: **Find Middle (Fast/Slow) $\rightarrow$ Reverse Suffix $\rightarrow$ Two-Pointer Comparison** achieves $O(1)$ space for linked list palindrome validation.

## What are we solving?

Given the `head` of a singly linked list, return `true` if it is a **palindrome** or `false` otherwise.

Could you do it in **$O(n)$ time** and **$O(1)$ extra space**?

```
 Input:  (1) -> (2) -> (2) -> (1)
 
 Step 1: Find midpoint using Slow & Fast pointers (slow reaches node 2)
 Step 2: Reverse second half: (1) -> (2) -> (1) <- (2)
 Step 3: Compare first half and reversed second half:
         (1) == (1), (2) == (2) -> ALL MATCH!
         
 Output: true
```

### Input & Output Contract
- **Input:**
  - `head`: `ListNode*` reference ($1 \le n \le 10^5$, $0 \le \text{Node.val} \le 9$).
- **Output:**
  - `bool`: `true` if the values form a palindrome; otherwise `false`.
- **Constraint:** $O(n)$ time, $O(1)$ extra memory.

---

**Example 1:**
```
Input:  head = [1,2,2,1]
Output: true
```

**Example 2:**
```
Input:  head = [1,2]
Output: false
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 10^5]$.
- $0 \le \text{Node.val} \le 9$

## Approach 1 — Array Copy + Two Pointers ($O(n)$ Space)

### Intuition
Copy all linked list values sequentially into an array `vals`, then use two pointers `left = 0` and `right = vals.size() - 1` to verify symmetry.

### C++ Implementation
```cpp
class Solution {
public:
    bool isPalindrome(ListNode* head) {
        vector<int> vals;
        while (head != nullptr) {
            vals.push_back(head->val);
            head = head->next;
        }
        
        int l = 0, r = vals.size() - 1;
        while (l < r) {
            if (vals[l++] != vals[r--]) return false;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear copy and two-pointer sweep. |
| **Space** | $O(n)$ | Vector stores $n$ node values. |

## Approach 2 — Recursive Call Stack Inversion ($O(n)$ Space)

### Intuition
Use system recursion to reach the tail of the list. Compare the tail with a global pointer advancing from the `head` as the call stack unwinds.

### C++ Implementation
```cpp
class Solution {
private:
    ListNode* frontPointer;

    bool recursivelyCheck(ListNode* currentNode) {
        if (currentNode != nullptr) {
            if (!recursivelyCheck(currentNode->next)) return false;
            if (currentNode->val != frontPointer->val) return false;
            frontPointer = frontPointer->next;
        }
        return true;
    }

public:
    bool isPalindrome(ListNode* head) {
        frontPointer = head;
        return recursivelyCheck(head);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Traverses every node once. |
| **Space** | $O(n)$ | Call stack depth reaches $n$. |

## What are we solving?

Given an $m \times n$ `grid` filled with non-negative numbers, find a path from top-left (`grid[0][0]`) to bottom-right (`grid[m - 1][n - 1]`) which **minimizes the sum of all numbers along its path**.

Note: You can only move either **down** or **right** at any point in time.

```
 Grid (3x3):
 [ (1), (3), (1) ]
 [  1,   5,  (1) ]
 [  4,   2,  (1) ]
 
 Optimal Path: 1 -> 3 -> 1 -> 1 -> 1
 Minimum Path Sum = 1 + 3 + 1 + 1 + 1 = 7
 
 Output: 7
```

### Input & Output Contract
- **Input:**
  - `grid`: `vector<vector<int>>` ($1 \le m, n \le 200$, $0 \le \text{grid}[i][j] \le 200$).
- **Output:**
  - `int`: Minimum total path sum from $(0, 0)$ to $(m - 1, n - 1)$.

### The Core Recurrence
To reach cell $(r, c)$, we must have come from either $(r - 1, c)$ [above] or $(r, c - 1)$ [left]:
$$\text{dp}[r][c] = \text{grid}[r][c] + \min(\text{dp}[r - 1][c], \text{dp}[r][c - 1])$$

---

**Example 1:**
```
Input:  grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Explanation: Because the path 1 -> 3 -> 1 -> 1 -> 1 minimizes the sum.
```

**Example 2:**
```
Input:  grid = [[1,2,3],[4,5,6]]
Output: 12
```

**Constraints:**
- $m == \text{grid.length}$
- $n == \text{grid}[i].\text{length}$
- $1 \le m, n \le 200$
- $0 \le \text{grid}[i][j] \le 200$

## Approach 1 — 2D Dynamic Programming Matrix

### Intuition
Construct a 2D matrix `dp[m][n]`. Initialize `dp[0][0] = grid[0][0]`, fill the 0-th row with horizontal prefix sums, fill the 0-th column with vertical prefix sums, then fill inner cells via $\text{grid}[r][c] + \min(\text{dp}[r-1][c], \text{dp}[r][c-1])$.

### C++ Implementation
```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        vector<vector<int>> dp(m, vector<int>(n, 0));
        
        dp[0][0] = grid[0][0];
        for (int c = 1; c < n; c++) dp[0][c] = dp[0][c - 1] + grid[0][c];
        for (int r = 1; r < m; r++) dp[r][0] = dp[r - 1][0] + grid[r][0];
        
        for (int r = 1; r < m; r++) {
            for (int c = 1; c < n; c++) {
                dp[r][c] = grid[r][c] + min(dp[r - 1][c], dp[r][c - 1]);
            }
        }
        
        return dp[m - 1][n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Fills each cell once. |
| **Space** | $O(m \cdot n)$ | 2D vector storage. |

## Approach 2 — 1D Space-Optimized Rolling Array ✅

### Key Insight
To compute cell $(r, c)$, we only need `dp[c]` (the minimum path sum from the cell directly above in row $r - 1$) and `dp[c - 1]` (the minimum path sum from the cell to the left in row $r$):
- Allocate a 1D vector `dp(n)`.
- Initialize `dp` with the prefix sums of `grid[0]`.
- For subsequent rows:
  - `dp[0] += grid[r][0]`
  - For $c = 1 \dots n - 1$: `dp[c] = grid[r][c] + min(dp[c], dp[c - 1])`.

```
grid:
1 3 1
1 5 1
4 2 1

Row 0: [ 1, 4, 5 ]
Row 1: [ 1+1=2, min(2, 4)+5=7, min(7, 5)+1=6 ] -> [ 2, 7, 6 ]
Row 2: [ 2+4=6, min(6, 7)+2=8, min(8, 6)+1=7 ] -> [ 6, 8, 7 ]

Result: dp[n - 1] = 7 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        vector<int> dp(n, 0);
        
        // Base case: initialize with row 0 cumulative sums
        dp[0] = grid[0][0];
        for (int c = 1; c < n; c++) {
            dp[c] = dp[c - 1] + grid[0][c];
        }
        
        // Process subsequent rows
        for (int r = 1; r < m; r++) {
            dp[0] += grid[r][0]; // First column can only come from top
            for (int c = 1; c < n; c++) {
                dp[c] = grid[r][c] + min(dp[c], dp[c - 1]);
            }
        }
        
        return dp[n - 1];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(m \cdot n)$ | Single pass over all cells. |
| **Space** | $O(n)$ | 1D vector of size $n$. |

> **This is the one.** Clean, robust 1D space optimization.

## Approach 3 — In-Place Grid Dynamic Programming

### Intuition
If modifying the input is permitted, we can directly update `grid[r][c] += min(grid[r - 1][c], grid[r][c - 1])` without any extra arrays ($O(1)$ space).

### C++ Implementation
```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (r == 0 && c == 0) continue;
                if (r == 0) grid[r][c] += grid[r][c - 1];
                else if (c == 0) grid[r][c] += grid[r - 1][c];
                else grid[r][c] += min(grid[r - 1][c], grid[r][c - 1]);
            }
        }
        
        return grid[m - 1][n - 1];
    }
};
```

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **$1 \times 1$ Grid** | `[[5]]` | Outer loops not executing | Initialized directly and returns 5. |
| **Single Column Grid** | `[[1], [2], [3]]` | Inner loop skipped | `dp[0] += grid[r][0]` sums column vertically. |
| **All Zeroes Grid** | `[[0, 0], [0, 0]]` | Zero values | Returns 0 correctly. |

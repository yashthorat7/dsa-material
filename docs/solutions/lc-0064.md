## What are we solving?

Given a `m x n` `grid` filled with non-negative numbers, find a path from top left to bottom right, which minimizes the sum of all numbers along its path.

Note: You can only move either down or right at any point in time.

**Example 1:**
```
Input:  grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Explanation: Because the path 1 -> 3 -> 1 -> 1 -> 1 minimizes the sum.
```

**Example 2:**
```
Input:  grid = [[1,2,3],[4,5,6]]
Output: 12
```

**Constraints:**
- $m == \text{grid.length}$
- $n == \text{grid}[i].\text{length}$
- $1 \le m, n \le 200$
- $0 \le \text{grid}[i][j] \le 200$

## Approach 1 — 1D DP Rolling Row Optimization ✅

**Key insight:**
Let `dp[c]` be minimum cost to reach current row at column `c`.
- Top-left corner: `dp[0] = grid[0][0]`.
- First row initialization: `dp[c] = dp[c - 1] + grid[0][c]`.
- Subsequent rows:
  - `dp[0] += grid[r][0]` (can only come from top)
  - `dp[c] = grid[r][c] + min(dp[c], dp[c - 1])` (min of top and left)

```
grid:
1 3 1
1 5 1
4 2 1

Row 0: [1, 4, 5]
Row 1: [1+1=2, min(2,4)+5=7, min(7,5)+1=6] -> [2, 7, 6]
Row 2: [2+4=6, min(6,7)+2=8, min(8,6)+1=7] -> [6, 8, 7]

Result: 7 ✓
```

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> dp(n, 0);
        
        dp[0] = grid[0][0];
        for (int c = 1; c < n; c++) {
            dp[c] = dp[c - 1] + grid[0][c];
        }
        
        for (int r = 1; r < m; r++) {
            dp[0] += grid[r][0];
            for (int c = 1; c < n; c++) {
                dp[c] = grid[r][c] + min(dp[c], dp[c - 1]);
            }
        }
        
        return dp[n - 1];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(n)$ |

> **This is the one.** Optimal $O(n)$ auxiliary space path sum.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| 1x1 grid `[[5]]` | Loop boundaries | Returns 5 |
| Single column grid | Only top moves allowed | `dp[0] += grid[r][0]` accumulates column sum |

---

## Pattern Takeaway

Accumulating `grid[r][c] + min(top, left)` directly in a **1D rolling vector** minimizes grid path sums in $O(n)$ space.

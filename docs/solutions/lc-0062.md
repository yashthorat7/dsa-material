## What are we solving?

There is a robot on an `m x n` grid. The robot is initially located at the **top-left corner** (`grid[0][0]`). The robot tries to move to the **bottom-right corner** (`grid[m - 1][n - 1]`). The robot can only move either **down** or **right** at any point in time.

Given the two integers `m` and `n`, return the number of possible unique paths that the robot can take to reach the bottom-right corner.

**Example 1:**
```
Input:  m = 3, n = 7
Output: 28
```

**Example 2:**
```
Input:  m = 3, n = 2
Output: 3
Explanation: From the top-left corner, there are a total of 3 ways to reach the bottom-right corner:
1. Right -> Down -> Down
2. Down -> Down -> Right
3. Down -> Right -> Down
```

**Constraints:**
- $1 \le m, n \le 100$

## Approach 1 — 1D DP Rolling Row ✅

**Key insight:**
To reach cell `(r, c)`, you must arrive from either top `(r-1, c)` or left `(r, c-1)`:
`dp[c] = dp[c] (from top) + dp[c - 1] (from left)`.
Initialize `dp` array of size `n` with all `1`s (representing first row).
Update `m - 1` times.

```
m = 3, n = 3
Row 0: [1, 1, 1]
Row 1: [1, 1+1=2, 2+1=3]
Row 2: [1, 1+2=3, 3+3=6]

Result: 6 ✓
```

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);
        for (int r = 1; r < m; r++) {
            for (int c = 1; c < n; c++) {
                dp[c] += dp[c - 1];
            }
        }
        return dp[n - 1];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(m \cdot n)$ | $O(n)$ |

> **This is the one.** Rolling 1D array grid DP.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `m = 1` or `n = 1` | Loop does not execute | Returns 1 (only 1 straight line path) |
| Square grid `m = 3, n = 3` | Symmetry | Returns 6 |

---

## Pattern Takeaway

Grid path counts represent Pascal's triangle in disguise: **`dp[c] += dp[c - 1]`** reduces 2D grid DP to a 1D vector.

## What are we solving?

In this problem, a tree is an undirected graph that is connected and has no cycles.

You are given a graph that started as a tree with $n$ nodes labeled from $1$ to $n$, with **one additional edge added** (creating a single simple cycle).

Return an edge that can be removed so that the resulting graph is a valid tree of $n$ nodes. If there are multiple answers, return the answer that occurs **last in the input**.

```
 Input: edges = [ [1, 2], [1, 3], [2, 3] ]
 
 Graph:
     1
    / \
   2---3  (Edge [2, 3] creates a cycle!)
   
 Output: [ 2, 3 ]
```

### Input & Output Contract
- **Input:**
  - `edges`: `vector<vector<int>>` ($n$ edges, $3 \le n \le 1000$, 1-indexed vertices $1 \dots n$).
- **Output:**
  - `vector<int>` of size 2: The redundant edge that formed a cycle.

### The DSU Cycle Criterion
In an undirected forest:
- An edge $(u, v)$ connects two separate components if $\text{find}(u) \neq \text{find}(v)$.
- An edge $(u, v)$ creates a cycle if and only if **$\text{find}(u) == \text{find}(v)$** prior to adding the edge!

---

**Example 1:**
```
Input:  edges = [[1,2],[1,3],[2,3]]
Output: [2,3]
```

**Example 2:**
```
Input:  edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]
Output: [1,4]
```

**Constraints:**
- $n == \text{edges.length}$
- $3 \le n \le 1000$
- $\text{edges}[i].\text{length} == 2$
- $1 \le a_i < b_i \le \text{edges.length}$
- $a_i \neq b_i$
- There are no repeated edges.
- The given graph is connected.

## Approach 1 — DFS Reachability on Dynamic Graph ($O(n^2)$)

### Intuition
Build the graph edge by edge. Before adding edge $(u, v)$, run DFS reachability from $u$ to $v$. If $v$ is already reachable from $u$, adding $(u, v)$ creates a cycle $\implies$ return $(u, v)$.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> findRedundantConnection(vector<vector<int>>& edges) {
        int n = edges.size();
        vector<vector<int>> adj(n + 1);
        
        auto hasPath = [&](auto& self, int curr, int target, vector<bool>& visited) -> bool {
            if (curr == target) return true;
            visited[curr] = true;
            for (int next : adj[curr]) {
                if (!visited[next]) {
                    if (self(self, next, target, visited)) return true;
                }
            }
            return false;
        };
        
        for (const auto& e : edges) {
            int u = e[0], v = e[1];
            vector<bool> visited(n + 1, false);
            if (!adj[u].empty() && !adj[v].empty() && hasPath(hasPath, u, v, visited)) {
                return e; // Redundant edge
            }
            adj[u].push_back(v);
            adj[v].push_back(u);
        }
        
        return {};
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | $n$ edges $\times O(n)$ DFS reachability checks. |
| **Space** | $O(n)$ | Adjacency list and visited vector. |

## Approach 2 — Disjoint Set Union (DSU with Path Compression) ✅

### Key Insight
1. Initialize a DSU parent array of size $n + 1$ where `parent[i] = i`.
2. For each edge `[u, v]` in the input order:
   - Compute `rootU = find(u)` and `rootV = find(v)`.
   - If `rootU == rootV`: nodes $u$ and $v$ are already connected in the same tree component. Adding `[u, v]` creates a cycle $\implies$ **return `[u, v]` immediately**!
   - Else: merge the two components via `parent[rootU] = rootV`.

```
edges = [[1, 2], [1, 3], [2, 3]]
parent: {1:1, 2:2, 3:3}

1. [1, 2]: find(1)=1 != find(2)=2 -> unite: parent[1] = 2
2. [1, 3]: find(1)=2 != find(3)=3 -> unite: parent[2] = 3
3. [2, 3]: find(2)=3 == find(3)=3 -> SAME COMPONENT! CYCLE DETECTED!

Result: [ 2, 3 ] ✓
```

### C++ Implementation
```cpp
class Solution {
    struct DSU {
        vector<int> parent;
        vector<int> rank;
        
        DSU(int n) : parent(n + 1), rank(n + 1, 0) {
            iota(parent.begin(), parent.end(), 0);
        }
        
        int find(int i) {
            if (parent[i] == i) return i;
            return parent[i] = find(parent[i]); // Path compression
        }
        
        bool unite(int i, int j) {
            int rootI = find(i);
            int rootJ = find(j);
            if (rootI == rootJ) return false; // Cycle detected
            
            // Union by rank
            if (rank[rootI] < rank[rootJ]) {
                parent[rootI] = rootJ;
            } else if (rank[rootI] > rank[rootJ]) {
                parent[rootJ] = rootI;
            } else {
                parent[rootJ] = rootI;
                rank[rootI]++;
            }
            return true;
        }
    };

public:
    vector<int> findRedundantConnection(vector<vector<int>>& edges) {
        int n = edges.size();
        DSU dsu(n);
        
        for (const auto& edge : edges) {
            if (!dsu.unite(edge[0], edge[1])) {
                return edge; // First edge that fails to unite causes the cycle
            }
        }
        
        return {};
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \alpha(n)) \approx O(n)$ | Path compression and union-by-rank guarantee nearly $O(1)$ operations per edge. |
| **Space** | $O(n)$ | Parent and rank arrays of size $n + 1$. |

> **This is the one.** Clean, near-instant cycle detection with DSU.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Multiple Cycle Edges** | Multiple possible edges in cycle | Returning earlier edge | Iterating in input order guarantees returning the exact edge specified last in input. |
| **Star/Hub Topology** | Root connected to all leaves | Deep recursion | Path compression flattens tree structure into $O(1)$ lookups. |

## What are we solving?

You are given an integer array `nums` and an integer `target`.

You want to build an expression out of `nums` by adding one of the symbols `'+'` or `'-'` before each integer in `nums` and then concatenating all the integers.

Return the **number of different expressions** that evaluate to `target`.

```
 nums = [ 1, 1, 1, 1, 1 ],  target = 3
 
 Valid Assignments:
 1. -1 + 1 + 1 + 1 + 1 = 3
 2. +1 - 1 + 1 + 1 + 1 = 3
 3. +1 + 1 - 1 + 1 + 1 = 3
 4. +1 + 1 + 1 - 1 + 1 = 3
 5. +1 + 1 + 1 + 1 - 1 = 3
 
 Total Ways: 5
 Output: 5
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($1 \le n \le 20$, $0 \le \text{nums}[i] \le 1000$, $\sum \text{nums}[i] \le 1000$).
  - `target`: `int` ($-1000 \le \text{target} \le 1000$).
- **Output:**
  - `int`: Total number of valid expression combinations.

### The Mathematical Transformation (Subset Sum Reduction)
Let $P$ be the sum of numbers assigned a `'+'` sign, and $N$ be the sum of numbers assigned a `'-'` sign:
$$P - N = \text{target}$$
$$P + N = \text{totalSum}$$
Adding the two equations:
$$2P = \text{totalSum} + \text{target} \implies \mathbf{P = \frac{\text{totalSum} + \text{target}}{2}}$$

$$\mathbf{\text{Target Sum Problem} \equiv \text{Count the Number of Subsets with Sum Equal to } P}$$
- If `totalSum + target < 0` or `(totalSum + target) % 2 != 0`, no valid integer subset sum can exist $\implies$ return `0` immediately!

## Approach 1 — Recursive Backtracking ($O(2^n)$)

### Intuition
Branch at every index $i$ into two recursive calls: adding `+nums[i]` or `-nums[i]`. When reaching the end, check if `currentSum == target`.

### C++ Implementation
```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int count = 0;
        
        auto backtrack = [&](auto& self, int i, int currentSum) -> void {
            if (i == nums.size()) {
                if (currentSum == target) count++;
                return;
            }
            self(self, i + 1, currentSum + nums[i]);
            self(self, i + 1, currentSum - nums[i]);
        };
        
        backtrack(backtrack, 0, 0);
        return count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(2^n)$ | Binary decision tree of depth $n$. |
| **Space** | $O(n)$ | Call stack depth. |

## Approach 2 — Top-Down 2D Memoization

### Intuition
Cache `(index, currentSum)` states in an `unordered_map<string, int>` or 2D array offset by total sum to handle negative values.

### C++ Implementation
```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int n = nums.size();
        int totalSum = 0;
        for (int x : nums) totalSum += x;
        if (abs(target) > totalSum) return 0;
        
        vector<vector<int>> memo(n, vector<int>(2 * totalSum + 1, -1));
        
        auto dp = [&](auto& self, int i, int currentSum) -> int {
            if (i == n) return (currentSum == target) ? 1 : 0;
            if (memo[i][currentSum + totalSum] != -1) return memo[i][currentSum + totalSum];
            
            int add = self(self, i + 1, currentSum + nums[i]);
            int subtract = self(self, i + 1, currentSum - nums[i]);
            
            return memo[i][currentSum + totalSum] = add + subtract;
        };
        
        return dp(dp, 0, 0);
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \text{totalSum})$ | Evaluates each `(i, currentSum)` state once. |
| **Space** | $O(n \cdot \text{totalSum})$ | 2D memo table. |

## Approach 3 — Mathematical Reduction to 0/1 Subset Sum DP (1D Vector) ✅

### Key Insight
1. Compute `totalSum = sum(nums)`.
2. Check feasibility:
   - If `abs(target) > totalSum` or `(totalSum + target) % 2 != 0`, return `0`.
3. Set subset sum target: $P = (\text{totalSum} + \text{target}) / 2$.
4. Allocate 1D DP table `dp(P + 1, 0)` with base case `dp[0] = 1`.
5. For each `num` in `nums`:
   - Iterate `j` backwards from $P$ down to `num`:
     $$\text{dp}[j] += \text{dp}[j - \text{num}]$$
6. Return `dp[P]`.

```
nums = [1, 1, 1, 1, 1], target = 3
totalSum = 5
P = (5 + 3) / 2 = 4

dp initialized: dp[0] = 1, all others 0

After num=1 (1st): dp = [1, 1, 0, 0, 0]
After num=1 (2nd): dp = [1, 2, 1, 0, 0]
After num=1 (3rd): dp = [1, 3, 3, 1, 0]
After num=1 (4th): dp = [1, 4, 6, 4, 1]
After num=1 (5th): dp = [1, 5, 10, 10, 5]

dp[4] = 5 ways! ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int totalSum = accumulate(nums.begin(), nums.end(), 0);
        
        // Target is mathematically unreachable
        if (abs(target) > totalSum || (totalSum + target) % 2 != 0) {
            return 0;
        }
        
        int subsetTarget = (totalSum + target) / 2;
        vector<int> dp(subsetTarget + 1, 0);
        dp[0] = 1; // Base case: 1 way to form sum 0 (empty subset)
        
        for (int num : nums) {
            // Traverse backwards to enforce single-use 0/1 knapsack rule
            for (int j = subsetTarget; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        
        return dp[subsetTarget];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot P)$ | Where $P \le 1000$. Performs at most $20 \times 1000 = 20,000$ operations (<1ms). |
| **Space** | $O(P)$ | 1D vector of size $P + 1 \le 1001$. |

> **This is the one.** Mathematically elegant reduction from sign exploration to polynomial subset counting.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`target > totalSum`** | `nums = [1], target = 2` | Unreachable sum | `abs(target) > totalSum` returns 0 immediately. |
| **Odd Parity Sum** | `nums = [1, 2], target = 0` (sum = 3) | Non-integer $P$ | `(totalSum + target) % 2 != 0` returns 0. |
| **Zeroes in Input** | `nums = [0, 0, 1], target = 1` | Zero creating multiple $\pm 0$ expressions | `dp[j] += dp[j - 0]` correctly doubles the ways for each zero ($2^2 \times 1 = 4$). |

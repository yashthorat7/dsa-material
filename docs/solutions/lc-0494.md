## What are we solving?

You are given an integer array `nums` and an integer `target`. You want to build an expression out of nums by adding one of the symbols `'+'` and `'-'` before each integer in nums and then concatenate all the integers.

Return the number of different expressions that you can build, which evaluates to `target`.

**Example 1:**
```
Input:  nums = [1,1,1,1,1], target = 3
Output: 5
Explanation: There are 5 ways to assign symbols to make the sum of nums be target 3:
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

**Example 2:**
```
Input:  nums = [1], target = 1
Output: 1
```

**Constraints:**
- $1 \le \text{nums.length} \le 20$
- $0 \le \text{nums}[i] \le 1000$
- $0 \le \sum \text{nums}[i] \le 1000$
- $-1000 \le \text{target} \le 1000$

## Approach 1 — Reduction to 0/1 Subset Sum Counting ✅

**Key insight:**
Let $P$ be subset of numbers with `+` sign and $N$ be subset with `-` sign.
- $P - N = \text{target}$
- $P + N = \text{totalSum}$
- Adding equations: $2P = \text{totalSum} + \text{target} \implies P = (\text{totalSum} + \text{target}) / 2$.
The problem reduces to: **Count the number of subsets with sum exactly $P$!**
If `totalSum + target` is odd or `< 0`, return `0`.

```
nums = [1, 1, 1, 1, 1], target = 3
totalSum = 5
P = (5 + 3) / 2 = 4

Count subsets summing to 4:
5 choose 4 = 5 combinations.

Result: 5 ✓
```

```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int totalSum = 0;
        for (int x : nums) totalSum += x;
        
        if (abs(target) > totalSum || (totalSum + target) % 2 != 0) return 0;
        
        int s1 = (totalSum + target) / 2;
        vector<int> dp(s1 + 1, 0);
        dp[0] = 1;
        
        for (int num : nums) {
            for (int j = s1; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        
        return dp[s1];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot s_1)$ | $O(s_1)$ |

> **This is the one.** Converts exponential $O(2^n)$ signs into polynomial 0/1 Subset Sum DP.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `target > totalSum` or `(totalSum + target)` odd | Integer division truncating parity | Returns 0 immediately |
| Array contains zeroes `nums = [0, 0, 0, 1], target = 1` | Zero contributing multiple combinations | `dp[j] += dp[j - 0]` doubles the count for each zero correctly ($2^3 \times 1 = 8$) |

---

## Pattern Takeaway

Mathematical transformation: **$P = (\text{totalSum} + \text{target}) / 2$** converts +/- partition assignment directly into **Subset Sum Counting**.

## What are we solving?

Given the `head` of a singly linked list, reverse the list so that the original tail becomes the new head, and all pointer directions are reversed. Return the head of the reversed list.

```
 Original: [1] -> [2] -> [3] -> [4] -> [5] -> nullptr
 
 Reversed: [5] -> [4] -> [3] -> [2] -> [1] -> nullptr
```

### Input & Output Contract
- **Input:**
  - `head`: `ListNode*` pointing to the first node of a singly linked list ($0 \le \text{length} \le 5000$).
- **Output:**
  - `ListNode*` pointing to the new head of the reversed list (or `nullptr` if the input was empty).

### The Core Challenge
In a singly linked list, each node only points to its successor (`next`). When we redirect `curr->next` to point backwards to `prev`, we instantly lose our reference to the rest of the list unless we temporarily cache `curr->next` first.

---

**Example 1:**
```
Input:  head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

**Example 2:**
```
Input:  head = [1,2]
Output: [2,1]
```

**Example 3:**
```
Input:  head = []
Output: []
```

**Constraints:**
- The number of nodes in the list is the range $[0, 5000]$.
- $-5000 \le \text{Node.val} \le 5000$

## Approach 1 — Iterative 3-Pointer Reversal ✅

### Intuition
Maintain three pointer references as we slide across the list:
1. `prev`: the node behind `curr` (initially `nullptr`).
2. `curr`: the node currently being rewired (initially `head`).
3. `nextTemp`: the node ahead of `curr` to preserve forward progress.

### Step-by-Step Algorithm
1. Initialize `prev = nullptr`, `curr = head`.
2. While `curr != nullptr`:
   - Store next node: `nextTemp = curr->next`.
   - Invert pointer: `curr->next = prev`.
   - Advance previous: `prev = curr`.
   - Advance current: `curr = nextTemp`.
3. Return `prev` (which now points to the last non-null node, i.e., the new head).

```
Initial:
prev = nullptr, curr = 1 -> 2 -> 3 -> nullptr

Iteration 1:
- nextTemp = 2
- 1->next = nullptr
- prev = 1, curr = 2
[nullptr <- 1]   [2 -> 3 -> nullptr]

Iteration 2:
- nextTemp = 3
- 2->next = 1
- prev = 2, curr = 3
[nullptr <- 1 <- 2]   [3 -> nullptr]

Iteration 3:
- nextTemp = nullptr
- 3->next = 2
- prev = 3, curr = nullptr
[nullptr <- 1 <- 2 <- 3]

curr == nullptr -> return prev (node 3) ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        
        while (curr != nullptr) {
            ListNode* nextTemp = curr->next; // 1. Cache forward pointer
            curr->next = prev;               // 2. Invert link
            prev = curr;                     // 3. Advance prev
            curr = nextTemp;                 // 4. Advance curr
        }
        
        return prev;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Each of the $n$ nodes is visited and rewired exactly once. |
| **Space** | $O(1)$ | Uses only three pointer variables on the stack. |

> **This is the one.** Constant auxiliary space, clean loop, universally standard.

## Approach 2 — Recursive Reversal

### Intuition
Think recursively: to reverse a list `1 -> 2 -> 3 -> 4 -> 5`, assume the sublist starting at `2` is already reversed: `1 -> 2 <- 3 <- 4 <- 5`.  
All that remains is to make `2` point to `1` (`head->next->next = head`) and sever `1`'s forward pointer (`head->next = nullptr`).

```
reverseList(1 -> 2 -> 3)
 └─ reverseList(2 -> 3)
     └─ reverseList(3) -> Base case: returns 3
     └─ 2->next->next = 2 (makes 3 point to 2)
     └─ 2->next = nullptr
 └─ 1->next->next = 1 (makes 2 point to 1)
 └─ 1->next = nullptr
Returns new head: 3 -> 2 -> 1 -> nullptr ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // Base case: empty list or last remaining node
        if (head == nullptr || head->next == nullptr) {
            return head;
        }
        
        // Recursively reverse remainder of list
        ListNode* newHead = reverseList(head->next);
        
        // Rewire current head to become tail of reversed sublist
        head->next->next = head;
        head->next = nullptr;
        
        return newHead;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits every node in the recursive descent and ascent. |
| **Space** | $O(n)$ | Recursion stack has $n$ frames. |

> **Verdict:** Elegant mathematical expression of induction, but risks stack overflow on very large lists ($n > 10^5$).

## Approach 3 — Stack / LIFO Auxiliary Collection

### Intuition
If we push all nodes onto an explicit stack, popping them gives the nodes in reverse order. We can then link them consecutively.

### C++ Implementation
```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head) return nullptr;
        
        stack<ListNode*> st;
        ListNode* curr = head;
        while (curr != nullptr) {
            st.push(curr);
            curr = curr->next;
        }
        
        ListNode* newHead = st.top();
        st.pop();
        curr = newHead;
        
        while (!st.empty()) {
            curr->next = st.top();
            st.pop();
            curr = curr->next;
        }
        curr->next = nullptr; // Ensure tail points to null
        
        return newHead;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | One pass to push, one pass to pop and link. |
| **Space** | $O(n)$ | Stores $n$ node pointers in the stack. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty List** | `head = []` | Dereferencing null pointer | Iterative loop never runs, returns `prev = nullptr`. |
| **Single Node** | `[1]` | Losing sole node or creating cycle | `curr->next = nullptr`, `prev = 1`, loop exits, returns `1`. |
| **Two Nodes** | `[1, 2]` | Creating cycle between 1 and 2 | `1->next` is explicitly set to `nullptr` during iteration 1. |

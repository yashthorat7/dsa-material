## What are we solving?

Given the `head` of a singly linked list, reverse the list, and return the reversed list.

The question is: **how do we flip next pointers iteratively using 3 pointers (`prev`, `curr`, `nextTemp`) in $O(n)$ time and $O(1)$ space?**

**Example 1:**
```
Input:  head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

**Example 2:**
```
Input:  head = [1,2]
Output: [2,1]
```

**Example 3:**
```
Input:  head = []
Output: []
```

**Constraints:**
- The number of nodes in the list is the range $[0, 5000]$.
- $-5000 \le \text{Node.val} \le 5000$

## Approach 1 — Iterative 3-Pointer Reversal ✅

**Key insight:** Maintain `prev = nullptr` and `curr = head`.
In each step:
1. Save `nextTemp = curr->next`.
2. Flip the pointer: `curr->next = prev`.
3. Advance `prev = curr`.
4. Advance `curr = nextTemp`.
When `curr` reaches `nullptr`, `prev` points to the new head.

```
1 -> 2 -> 3 -> nullptr
prev = nullptr, curr = 1

1. nextTemp = 2, 1->next = nullptr, prev = 1, curr = 2
2. nextTemp = 3, 2->next = 1, prev = 2, curr = 3
3. nextTemp = nullptr, 3->next = 2, prev = 3, curr = nullptr

Result: 3 -> 2 -> 1 -> nullptr (prev = 3) ✓
```

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr != nullptr) {
            ListNode* nextTemp = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Clean, in-place, standard iterative reversal.

## Approach 2 — Recursive Reversal

Base case: if `head == nullptr || head->next == nullptr`, return `head`. Recursively reverse the rest of the list (`newHead = reverseList(head->next)`). Then make `head->next->next = head` and `head->next = nullptr`.

```
reverseList(1 -> 2 -> 3)
  reverseList(2 -> 3)
    reverseList(3) -> returns 3
    2->next->next = 2 (3 -> 2), 2->next = nullptr
  1->next->next = 1 (2 -> 1), 1->next = nullptr
Returns 3 -> 2 -> 1 ✓
```

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode* newHead = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return newHead;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ (call stack) |

> Elegant recursion, but uses $O(n)$ stack space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty list `head = []` | Null pointer dereference | Loop does not execute, returns `prev = nullptr` |
| Single node `[1]` | Single node reversal | Returns `[1]` directly |
| Two nodes `[1, 2]` | Cycle creation | `1->next` set to `nullptr` correctly |

## Pattern Takeaway

The **3-Pointer Iterative Reversal** is a core primitive required in Palindrome Linked List, Reverse Nodes in k-Group, and Reorder List.

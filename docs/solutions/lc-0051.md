## What are we solving?

The **n-queens** puzzle is the problem of placing `n` queens on an `n x n` chessboard such that no two queens attack each other.

Given an integer `n`, return all distinct solutions to the **n-queens puzzle**. You may return the answer in **any order**.

Each solution contains a distinct board configuration of the n-queens' placement, where `'Q'` and `'.'` indicate a queen and an empty space, respectively.

```
 n = 4:
 Solution 1:               Solution 2:
 [ ". Q . ." ]             [ ". . Q ." ]
 [ ". . . Q" ]             [ "Q . . ." ]
 [ "Q . . ." ]             [ ". . . Q" ]
 [ ". . Q ." ]             [ ". Q . ." ]
```

### Input & Output Contract
- **Input:**
  - `n`: `int` chessboard dimension ($1 \le n \le 9$).
- **Output:**
  - `vector<vector<string>>` containing all valid full-board arrangements.

### The Core Challenge
Queens attack horizontally along **rows**, vertically along **columns**, and diagonally in all 4 directions:
- Placing exactly one queen per row automatically satisfies the horizontal row constraint.
- Vertical column conflicts: duplicate column `c`.
- Main diagonal ($\backslash$) conflicts: cells sharing a constant difference $(r - c)$.
- Anti-diagonal ($/$) conflicts: cells sharing a constant sum $(r + c)$.

---

**Example 1:**
```
Input: n = 4
Output: [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
```

**Example 2:**
```
Input: n = 1
Output: [["Q"]]
```

**Constraints:**
- $1 \le n \le 9$

## Approach 1 — Backtracking with $O(1)$ Diagonal Lookup Arrays ✅

### Key Insight
Place queens row by row from $r = 0$ to $n - 1$.  
For each column $c \in [0, n - 1]$ in row $r$:
- Column occupancy: `cols[c]`
- Main diagonal ($\backslash$): `diag1[r - c + n]` (offset by $+n$ to prevent negative array indices).
- Anti-diagonal ($/$): `diag2[r + c]`

If none of these three flags are set, place `'Q'`, set all 3 flags to `true`, recurse on $r + 1$, and backtrack!

```
Row r = 0, n = 4:
- Place Q at (0, 1) -> cols[1]=T, diag1[0-1+4=3]=T, diag2[0+1=1]=T
- Next Row r = 1:
  - (1, 0): diag2[1+0=1] is occupied! (attacked by Q at (0,1)) -> Skip!
  - (1, 3): clear -> Place Q at (1, 3)
  ...
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> result;
        vector<string> board(n, string(n, '.'));
        
        vector<bool> cols(n, false);
        vector<bool> diag1(2 * n, false); // r - c + n (main diagonal \)
        vector<bool> diag2(2 * n, false); // r + c     (anti diagonal /)
        
        backtrack(0, n, board, cols, diag1, diag2, result);
        return result;
    }

private:
    void backtrack(int r, int n, vector<string>& board,
                   vector<bool>& cols, vector<bool>& diag1, vector<bool>& diag2,
                   vector<vector<string>>& result) {
        if (r == n) {
            result.push_back(board);
            return;
        }
        
        for (int c = 0; c < n; c++) {
            int d1 = r - c + n;
            int d2 = r + c;
            
            if (cols[c] || diag1[d1] || diag2[d2]) continue;
            
            // Place Queen
            board[r][c] = 'Q';
            cols[c] = diag1[d1] = diag2[d2] = true;
            
            backtrack(r + 1, n, board, cols, diag1, diag2, result);
            
            // Backtrack
            board[r][c] = '.';
            cols[c] = diag1[d1] = diag2[d2] = false;
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(N!)$ | Row by row placement with aggressive $O(1)$ diagonal pruning. |
| **Space** | $O(N^2)$ | Output board storage and recursion stack of depth $N$. |

> **This is the one.** Clean $O(1)$ diagonal checks without nested board scanning.

## Approach 2 — Bitmask Backtracking ($O(1)$ Space Optimization)

### Intuition
Replace the lookup boolean vectors with 3 integer bitmasks:
- `cols`: bits represent occupied columns.
- `diags`: bits represent occupied main diagonals ($r - c$).
- `antiDiags`: bits represent occupied anti-diagonals ($r + c$).
All validity checks and state updates reduce to instantaneous CPU bitwise operations (`&`, `|`, `^`).

### C++ Implementation
```cpp
class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> result;
        vector<string> board(n, string(n, '.'));
        solve(0, n, 0, 0, 0, board, result);
        return result;
    }

private:
    void solve(int r, int n, int cols, int diags, int antiDiags, 
               vector<string>& board, vector<vector<string>>& result) {
        if (r == n) {
            result.push_back(board);
            return;
        }
        
        // Bitmask of available safe positions in row r
        int available = ((1 << n) - 1) & ~(cols | diags | antiDiags);
        
        while (available) {
            int p = available & -available; // Extract lowest set bit
            int c = __builtin_ctz(p);        // Column index
            available ^= p;
            
            board[r][c] = 'Q';
            solve(r + 1, n, cols | p, (diags | p) << 1, (antiDiags | p) >> 1, board, result);
            board[r][c] = '.';
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(N!)$ | Fastest constant factor among all backtracking solutions. |
| **Space** | $O(N)$ | Recursion stack and board representation. |

## Pattern Takeaways

1. **Diagonal Indexing Equations:**  
   - Main diagonal (top-left to bottom-right): $r - c + n$.
   - Anti-diagonal (top-right to bottom-left): $r + c$.
2. **One-Queen-Per-Row Invariant:**  
   Advancing $r + 1$ directly enforces the single-queen-per-row rule and reduces the search space from $N^2$ to $N!$.

## What are we solving?

You are given a string `s` and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times. Return the length of the **longest substring containing the same letter** you can get after performing the above operations.

The question is: **how do we determine if a window can be made uniform with at most $k$ replacements in $O(1)$ time?**

**Example 1:**
```
Input:  s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.
```

**Example 2:**
```
Input:  s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA". The substring "BBBB" has the longest repeating letters, which is 4.
```

**Constraints:**
- $1 \le s.\text{length} \le 10^5$
- `s` consists of only uppercase English letters.
- $0 \le k \le s.\text{length}$

## Approach 1 — Sliding Window Tracking Max Frequency ✅

**Key insight:** In any window `s[left..right]`:
- The majority character occurs `maxFreq` times.
- The number of characters that need to be replaced is: `(window length) - maxFreq = (right - left + 1) - maxFreq`.
- If `(right - left + 1) - maxFreq > k`, the window is invalid! We must increment `left` and decrement `count[s[left]]`.
- Note: We do NOT need to decrement `maxFreq` when shrinking `left` because a smaller `maxFreq` would never produce a larger valid window than what we've already achieved.

```
s = "AABABBA", k = 1
counts = [0]*26, maxFreq = 0, left = 0, maxLen = 0

right=0 ('A'): count['A']=1, maxFreq=1, len=1, replacements=1-1=0 <= 1 -> maxLen=1
right=1 ('A'): count['A']=2, maxFreq=2, len=2, replacements=2-2=0 <= 1 -> maxLen=2
right=2 ('B'): count['B']=1, maxFreq=2, len=3, replacements=3-2=1 <= 1 -> maxLen=3
right=3 ('A'): count['A']=3, maxFreq=3, len=4, replacements=4-3=1 <= 1 -> maxLen=4
right=4 ('B'): count['B']=2, maxFreq=3, len=5, replacements=5-3=2 > 1 -> invalid! shrink left: remove 'A', left=1
right=5 ('B'): count['B']=3, maxFreq=3, len=5, replacements=5-3=2 > 1 -> invalid! shrink left: remove 'A', left=2
right=6 ('A'): count['A']=2, maxFreq=3, len=5, replacements=5-3=2 > 1 -> invalid! shrink left: remove 'B', left=3

Result: maxLen = 4 ✓
```

```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int maxFreq = 0;
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.size(); right++) {
            count[s[right] - 'A']++;
            maxFreq = max(maxFreq, count[s[right] - 'A']);
            
            while ((right - left + 1) - maxFreq > k) {
                count[s[left] - 'A']--;
                left++;
            }
            
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ (26-element array) |

> **This is the one.** Non-shrinking / linear sliding window.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `k = 0` (no replacements allowed) | Window shrinkage | Finds the longest run of consecutive identical characters |
| `k >= s.length()` | Full string replacement | Returns full string length `s.size()` |
| Alternating string `"ABABAB", k = 1` | Max window detection | Correctly expands window to length 3 |

---

## Pattern Takeaway

The invariant `windowLength - maxFrequency <= k` enables flexible character conversions to be validated in $O(1)$ time.

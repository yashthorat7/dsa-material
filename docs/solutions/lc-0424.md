## What are we solving?

You are given a string `s` consisting of uppercase English letters and an integer `k`. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most `k` times.

Return the length of the **longest substring containing the same letter** you can get after performing at most `k` operations.

```
 s = " A  A  B  A  B  B  A ",  k = 1
       [--------------]
       " A  A  B  A " -> Change 'B' to 'A' -> " A  A  A  A " (Length = 4)
             [--------------]
             " B  A  B  B " -> Change 'A' to 'B' -> " B  B  B  B " (Length = 4)
             
 Output: 4
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of uppercase English characters ($1 \le n \le 10^5$).
  - `k`: `int` maximum allowed replacements ($0 \le k \le n$).
- **Output:**
  - `int` representing the maximum valid contiguous window length.

### The Core Challenge
For any substring window `s[left...right]`:
- The most frequent character occurs `maxFreq` times.
- To make all characters in the window identical to the most frequent character, we need to replace:
$$\text{replacementsNeeded} = (\text{windowLength}) - \text{maxFreq} = (\text{right} - \text{left} + 1) - \text{maxFreq}$$
The window is valid if and only if $\text{replacementsNeeded} \le k$.

---

**Example 1:**
```
Input:  s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.
```

**Example 2:**
```
Input:  s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' to form "AABBBBA". Substring "BBBB" has length 4.
```

**Constraints:**
- $1 \le s.\text{length} \le 10^5$
- `s` consists of only uppercase English letters.
- $0 \le k \le s.\text{length}$

## Approach 1 — Brute Force (All Substrings)

### Intuition
Examine every substring $s[i \dots j]$, count frequencies of all 26 uppercase letters, determine the maximum frequency `maxF`, and verify if $(j - i + 1) - \text{maxF} \le k$.

### C++ Implementation
```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        int n = s.size();
        int maxLen = 0;
        
        for (int i = 0; i < n; i++) {
            vector<int> freq(26, 0);
            int maxF = 0;
            for (int j = i; j < n; j++) {
                freq[s[j] - 'A']++;
                maxF = max(maxF, freq[s[j] - 'A']);
                
                int len = j - i + 1;
                if (len - maxF <= k) {
                    maxLen = max(maxLen, len);
                }
            }
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Quadratic pairs $(i, j)$ evaluation. TLEs for $n = 10^5$. |
| **Space** | $O(1)$ | 26-element integer vector. |

> **Verdict:** Suboptimal. Dynamic sliding window achieves $O(n)$ linear time.

## Approach 2 — Standard Sliding Window (While Loop Shrink)

### Intuition
Expand `right` and increment `count[s[right]]`. Maintain `maxFreq`. When the replacement condition $(\text{right} - \text{left} + 1) - \text{maxFreq} > k$ is violated, increment `left++` and decrement `count[s[left]]` until valid again.

### C++ Implementation
```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int maxFreq = 0;
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            count[s[right] - 'A']++;
            maxFreq = max(maxFreq, count[s[right] - 'A']);
            
            // Shrink window while replacements exceed k
            while ((right - left + 1) - maxFreq > k) {
                count[s[left] - 'A']--;
                left++;
            }
            
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Both `left` and `right` advance monotonically at most $n$ times. |
| **Space** | $O(1)$ | Fixed 26-element array. |

## Approach 3 — Non-Shrinking Max Window Optimization ✅

### Key Insight
We do **not** need a `while` loop or to decrement `maxFreq` when shrinking `left`!
- We are only seeking the **maximum** window size.
- Once a valid window of size $W$ is achieved, a smaller `maxFreq` cannot possibly yield a valid window of size $> W$.
- If the window becomes invalid, we simply shift `left++` by 1 step (maintaining the current maximum window size) without shrinking the window below its historical maximum!
- At the end, the final answer is simply `right - left = s.length() - left`.

```
s = "AABABBA", k = 1

right=0 ('A'): count['A']=1, maxFreq=1, len=1 (valid)
right=1 ('A'): count['A']=2, maxFreq=2, len=2 (valid)
right=2 ('B'): count['B']=1, maxFreq=2, len=3 (3 - 2 = 1 <= 1, valid)
right=3 ('A'): count['A']=3, maxFreq=3, len=4 (4 - 3 = 1 <= 1, valid)
right=4 ('B'): count['B']=2, maxFreq=3, len=5 (5 - 3 = 2 > 1, invalid) -> left++ (left=1)
right=5 ('B'): count['B']=3, maxFreq=3, len=5 (5 - 3 = 2 > 1, invalid) -> left++ (left=2)
right=6 ('A'): count['A']=2, maxFreq=3, len=5 (5 - 3 = 2 > 1, invalid) -> left++ (left=3)

Total Max Length = right - left = 7 - 3 = 4 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int maxFreq = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            count[s[right] - 'A']++;
            maxFreq = max(maxFreq, count[s[right] - 'A']);
            
            // If window is invalid, slide the whole window to the right by 1
            if ((right - left + 1) - maxFreq > k) {
                count[s[left] - 'A']--;
                left++;
            }
        }
        
        return s.length() - left;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Strictly single pass, single `if` statement per character, zero inner loops. |
| **Space** | $O(1)$ | Stack array of size 26. |

> **This is the one.** Cleanest non-shrinking window invariant.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`k = 0` (Zero Replacements)** | `s = "AABA", k = 0` | Window size calculation | Finds the longest contiguous run of identical characters (`"AA"` = 2). |
| **`k >= s.length()`** | `s = "ABC", k = 5` | Over replacement | Window never invalidates, returns full length 3. |
| **All Characters Unique** | `"ABCDE", k = 1` | `maxFreq` stays 1 | Yields window of length $1 + 1 = 2$. |

## Pattern Takeaways

1. **The Replacement Formula:**  
   `windowSize - maxFrequency <= k` converts complex character substitution into a simple arithmetic validity invariant.
2. **The Non-Shrinking Window Template:**  
   When maximizing window size, replacing `while` with `if` preserves the maximum window length and computes the answer directly as `n - left`.

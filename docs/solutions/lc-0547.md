## What are we solving?

There are $n$ cities. Some of them are connected directly by roads, while some are not. If city `a` is connected directly with city `b`, and city `b` is connected directly with city `c`, then city `a` is connected **indirectly** with city `c`.

A **province** is a group of directly or indirectly connected cities and no other cities outside of the group (a connected component in graph theory).

You are given an $n \times n$ adjacency matrix `isConnected` where `isConnected[i][j] = 1` if city $i$ and city $j$ are directly connected, and `0` otherwise.

Return the **total number of provinces**.

```
 isConnected Matrix:
 [ [1, 1, 0],
   [1, 1, 0],
   [0, 0, 1] ]
   
 Components:
 Province 1: {0, 1}
 Province 2: {2}
 
 Total Provinces: 2
 Output: 2
```

### Input & Output Contract
- **Input:**
  - `isConnected`: `vector<vector<int>>` ($1 \le n \le 200$, symmetric, `isConnected[i][i] == 1`).
- **Output:**
  - `int`: Total number of disconnected components.

---

**Example 1:**
```
Input:  isConnected = [[1,1,0],[1,1,0],[0,0,1]]
Output: 2
```

**Example 2:**
```
Input:  isConnected = [[1,0,0],[0,1,0],[0,0,1]]
Output: 3
```

**Constraints:**
- $1 \le n \le 200$
- $n == \text{isConnected.length}$
- $n == \text{isConnected}[i].\text{length}$
- `isConnected[i][j]` is `1` or `0`.
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`

## Approach 1 — Depth-First Search (DFS Component Counting) ✅

### Key Insight
1. Maintain a 1D boolean array `visited` of size $n$, initialized to `false`.
2. Initialize `provinces = 0`.
3. Iterate $i$ from $0$ to $n - 1$:
   - If `!visited[i]`:
     - Increment `provinces++`.
     - Launch `dfs(i)` to mark all nodes reachable from $i$ through matrix edges `isConnected[u][v] == 1`.
4. Return `provinces`.

```
Cities:
[1, 1, 0]
[1, 1, 0]
[0, 0, 1]

i=0: visited[0]=false -> provinces=1. DFS visits 0 -> 1. visited = {T, T, F}
i=1: visited[1]=true -> skipped
i=2: visited[2]=false -> provinces=2. DFS visits 2. visited = {T, T, T}

Result: 2 provinces ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<bool> visited(n, false);
        int provinces = 0;
        
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                dfs(i, n, isConnected, visited);
            }
        }
        
        return provinces;
    }

private:
    void dfs(int u, int n, const vector<vector<int>>& isConnected, vector<bool>& visited) {
        visited[u] = true;
        for (int v = 0; v < n; v++) {
            if (isConnected[u][v] == 1 && !visited[v]) {
                dfs(v, n, isConnected, visited);
            }
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | The entire $n \times n$ adjacency matrix is examined. |
| **Space** | $O(n)$ | 1D visited vector and recursion stack depth $\le n$. |

> **This is the one.** Standard, optimal graph component discovery.

## Approach 2 — Breadth-First Search (BFS Queue)

### Intuition
Iterate from city $0 \dots n - 1$. For each unvisited city, increment `provinces`, push into a BFS queue, and mark all transitively reachable cities as visited.

### C++ Implementation
```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<bool> visited(n, false);
        int provinces = 0;
        
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                queue<int> q;
                q.push(i);
                visited[i] = true;
                
                while (!q.empty()) {
                    int u = q.front(); q.pop();
                    for (int v = 0; v < n; v++) {
                        if (isConnected[u][v] == 1 && !visited[v]) {
                            visited[v] = true;
                            q.push(v);
                        }
                    }
                }
            }
        }
        
        return provinces;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Inspects each entry of the $n \times n$ adjacency matrix once. |
| **Space** | $O(n)$ | BFS queue and visited vector. |

## Approach 3 — Disjoint Set Union (DSU with Path Compression)

### Intuition
Initialize $n$ individual disjoint sets (`count = n`). For every pair $(i, j)$ where $i < j$ and `isConnected[i][j] == 1`, perform `unionSets(i, j)`. If they belong to different components, merge them and decrement `count--`.

### C++ Implementation
```cpp
class Solution {
    struct DSU {
        vector<int> parent, rank;
        int count;
        DSU(int n) : parent(n), rank(n, 0), count(n) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int i) {
            if (parent[i] == i) return i;
            return parent[i] = find(parent[i]);
        }
        bool unite(int i, int j) {
            int rootI = find(i), rootJ = find(j);
            if (rootI == rootJ) return false;
            if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
            else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
            else { parent[rootJ] = rootI; rank[rootI]++; }
            count--;
            return true;
        }
    };
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        DSU dsu(n);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) {
                    dsu.unite(i, j);
                }
            }
        }
        return dsu.count;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2 \cdot \alpha(n))$ | Iterates $n(n - 1) / 2$ edges with inverse Ackermann $\alpha(n) \approx O(1)$. |
| **Space** | $O(n)$ | DSU parent and rank arrays. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Completely Disconnected** | Identity matrix `I_n` | Merging disconnected nodes | Visited flag / DSU preserves $n$ distinct provinces. |
| **Fully Connected Graph** | All entries 1 | Overcounting components | Single traversal marks all cities visited, returns 1. |
| **Single City** | `[[1]]` | Base case | Returns 1 province. |

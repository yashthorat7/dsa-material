## What are we solving?

There are `n` cities. Some of them are connected, while some are not. If city `a` is connected directly with city `b`, and city `b` is connected directly with city `c`, then city `a` is connected indirectly with city `c`.

A **province** is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an `n x n` matrix `isConnected` where `isConnected[i][j] = 1` if the $i$-th city and the $j$-th city are directly connected, and `isConnected[i][j] = 0` otherwise. Return the **total number of provinces**.

**Example 1:**
```
Input:  isConnected = [[1,1,0],[1,1,0],[0,0,1]]
Output: 2
```

**Example 2:**
```
Input:  isConnected = [[1,0,0],[0,1,0],[0,0,1]]
Output: 3
```

**Constraints:**
- $1 \le n \le 200$
- $n == \text{isConnected.length}$
- $n == \text{isConnected}[i].\text{length}$
- `isConnected[i][j]` is `1` or `0`.
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`

## Approach 1 — DFS / Disjoint Set Union (DSU) ✅

**Key insight:**
Count connected components in the adjacency matrix.
Maintain `visited[n]` initialized to `false`.
For each city `i`:
- If `!visited[i]`:
  - `provinces++`
  - Launch `dfs(i)` to visit all reachable cities connected via `isConnected[i][j] == 1`.

```
Cities:
[1, 1, 0]
[1, 1, 0]
[0, 0, 1]

i=0: visited[0]=false -> provinces=1. DFS visits 0, 1 -> visited = {0:T, 1:T, 2:F}
i=1: visited[1]=true -> skip
i=2: visited[2]=false -> provinces=2. DFS visits 2 -> visited = {0:T, 1:T, 2:T}

Result: 2 provinces ✓
```

```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<bool> visited(n, false);
        int provinces = 0;
        
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                dfs(isConnected, visited, i, n);
            }
        }
        
        return provinces;
    }
private:
    void dfs(const vector<vector<int>>& isConnected, vector<bool>& visited, int u, int n) {
        visited[u] = true;
        for (int v = 0; v < n; v++) {
            if (isConnected[u][v] == 1 && !visited[v]) {
                dfs(isConnected, visited, v, n);
            }
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n^2)$ | $O(n)$ |

> **This is the one.** Standard connected component counting.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| No connections (identity matrix) | Overclustering | Returns `n` provinces |
| Fully connected graph | Multiple counts | Returns 1 province |

## Pattern Takeaway

Adjacency matrix connected components are solved in $O(n^2)$ using a **1D visited vector with DFS**.

## What are we solving?

There are a total of `numCourses` courses you have to take, labeled from `0` to `numCourses - 1`. You are given an array `prerequisites` where `prerequisites[i] = [ai, bi]` indicates that you **must** take course `bi` first if you want to take course `ai`.

Return `true` if you can finish all courses. Otherwise, return `false` (i.e. check if the directed graph contains a cycle).

**Example 1:**
```
Input:  numCourses = 2, prerequisites = [[1,0]]
Output: true
Explanation: There are a total of 2 courses to take. To take course 1 you should have finished course 0. So it is possible.
```

**Example 2:**
```
Input:  numCourses = 2, prerequisites = [[1,0],[0,1]]
Output: false
Explanation: To take course 1 you should have finished course 0, and to take course 0 you should also have finished course 1. So it is impossible.
```

**Constraints:**
- $1 \le \text{numCourses} \le 2000$
- $0 \le \text{prerequisites.length} \le 5000$
- $\text{prerequisites}[i].\text{length} == 2$
- $0 \le a_i, b_i < \text{numCourses}$
- All the pairs prerequisites[i] are **unique**.

## Approach 1 — Kahn's Algorithm (BFS Topological Sort) ✅

**Key insight:**
1. Build adjacency list `adj` and compute in-degrees `inDegree[u]` (number of prerequisites).
2. Enqueue all courses with `inDegree[u] == 0` (courses with no prerequisites).
3. While `!q.empty()`:
   - Pop course `u`, increment `processedCourses++`.
   - For each neighbor `v` in `adj[u]`: decrement `inDegree[v]--`. If `inDegree[v] == 0`, push `v` to `q`.
4. If `processedCourses == numCourses`, all courses can be taken (no cycle); else `false`.

```
numCourses = 2, prereqs = [[1,0],[0,1]]
adj: 0 -> 1, 1 -> 0
inDegree: {0: 1, 1: 1}

No node has inDegree == 0 -> queue is empty!
processedCourses = 0 != 2 -> CYCLE DETECTED!
Result: false ✓
```

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> adj(numCourses);
        vector<int> inDegree(numCourses, 0);
        
        for (const auto& p : prerequisites) {
            adj[p[1]].push_back(p[0]);
            inDegree[p[0]]++;
        }
        
        queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) q.push(i);
        }
        
        int processed = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            processed++;
            
            for (int v : adj[u]) {
                if (--inDegree[v] == 0) {
                    q.push(v);
                }
            }
        }
        
        return processed == numCourses;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(V + E)$ | $O(V + E)$ |

> **This is the one.** Kahn's algorithm cycle detection.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| No prerequisites `prerequisites = []` | Queue processing | All courses have in-degree 0, processed = numCourses -> `true` |
| Disjoint graphs with isolated components | Component connectivity | Kahn's algorithm handles disconnected components seamlessly |

## Pattern Takeaway

**Kahn's Algorithm (Topological Sort via BFS In-Degrees)** detects directed cycles in $O(V + E)$ time.

## What are we solving?

There are a total of `numCourses` courses you have to take, labeled from `0` to `numCourses - 1`. You are given an array `prerequisites` where `prerequisites[i] = [ai, bi]` indicates that you **must** take course `bi` before taking course `ai` ($b_i \rightarrow a_i$).

Return `true` if you can finish all courses. Otherwise, return `false`.

```
 Prerequisites: [ [1, 0], [2, 1], [3, 2] ]
 Graph: (0) -> (1) -> (2) -> (3)
 Topological Order: 0 -> 1 -> 2 -> 3 (No cycles! Output: true)
 
 Prerequisites: [ [1, 0], [0, 1] ]
 Graph: (0) <---> (1)  (Deadlock / Mutual Dependency! Output: false)
```

### Input & Output Contract
- **Input:**
  - `numCourses`: `int` number of vertices labeled $0$ to $V-1$ ($1 \le V \le 2000$).
  - `prerequisites`: `vector<vector<int>>` where each element is a directed edge $[a_i, b_i]$ meaning $b_i \rightarrow a_i$ ($0 \le E \le 5000$).
- **Output:**
  - `bool`: `true` if a valid topological ordering exists (graph is a Directed Acyclic Graph - DAG); otherwise `false`.

### The Core Challenge
A schedule is possible if and only if the directed graph contains **no directed cycles**. We can detect cycles using either **Kahn's Algorithm (BFS In-Degree)** or **DFS 3-State Coloring**.

---

**Example 1:**
```
Input:  numCourses = 2, prerequisites = [[1,0]]
Output: true
Explanation: Total 2 courses. Course 0 has no prerequisites, take 0 then take 1.
```

**Example 2:**
```
Input:  numCourses = 2, prerequisites = [[1,0],[0,1]]
Output: false
Explanation: Course 1 requires 0, and Course 0 requires 1 (circular dependency).
```

**Constraints:**
- $1 \le \text{numCourses} \le 2000$
- $0 \le \text{prerequisites.length} \le 5000$
- $\text{prerequisites}[i].\text{length} == 2$
- $0 \le a_i, b_i < \text{numCourses}$
- All prerequisite pairs are **unique**.

## Approach 1 — Kahn's Algorithm (BFS Topological Sort) ✅

### Intuition
1. Build adjacency list `adj` where edge is $b \rightarrow a$ (prereq $\rightarrow$ course).
2. Maintain array `inDegree[numCourses]` where `inDegree[u]` is the number of prerequisites required before course `u`.
3. Enqueue all courses with `inDegree[u] == 0` (courses ready to be taken immediately).
4. Process queue:
   - Dequeue course `u`, increment `completedCourses++`.
   - For each dependent course `v` in `adj[u]`: decrement `inDegree[v]--`.
   - If `inDegree[v] == 0`, enqueue `v`.
5. If `completedCourses == numCourses`, all courses can be finished without deadlock $\rightarrow$ return `true`.

```
numCourses = 4, prereqs = [[1,0], [2,0], [3,1], [3,2]]
adj: 0 -> [1, 2], 1 -> [3], 2 -> [3]
inDegree: {0:0, 1:1, 2:1, 3:2}

Queue starts with 0: q = [0]
- Pop 0: completed=1. Decrement inDegree[1]=0, inDegree[2]=0 -> q = [1, 2]
- Pop 1: completed=2. Decrement inDegree[3]=1
- Pop 2: completed=3. Decrement inDegree[3]=0 -> q = [3]
- Pop 3: completed=4.
completed == 4 == numCourses -> return true ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> adj(numCourses);
        vector<int> inDegree(numCourses, 0);
        
        // Build directed graph: b -> a
        for (const auto& edge : prerequisites) {
            int course = edge[0];
            int prereq = edge[1];
            adj[prereq].push_back(course);
            inDegree[course]++;
        }
        
        // Push all zero-prerequisite courses into queue
        queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                q.push(i);
            }
        }
        
        int completed = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            completed++;
            
            for (int v : adj[u]) {
                inDegree[v]--;
                if (inDegree[v] == 0) {
                    q.push(v);
                }
            }
        }
        
        return completed == numCourses;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V + E)$ | Builds graph in $O(E)$; each node and edge processed at most once in BFS. |
| **Space** | $O(V + E)$ | Adjacency list $O(V + E)$, inDegree array and queue $O(V)$. |

> **This is the one.** Standard, robust, intuitive cycle detection.

## Approach 2 — DFS 3-Color Cycle Detection

### Intuition
Assign 3 states to each node during DFS:
- **0 (White / Unvisited):** Node has not been visited.
- **1 (Gray / Visiting):** Node is in current active recursion stack. If we encounter a node in state 1, a **back-edge cycle exists**!
- **2 (Black / Visited):** Node and all its descendants have been fully processed without cycles.

### C++ Implementation
```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> adj(numCourses);
        for (const auto& edge : prerequisites) {
            adj[edge[1]].push_back(edge[0]);
        }
        
        // 0: Unvisited, 1: Visiting (in recursion stack), 2: Visited
        vector<int> state(numCourses, 0);
        
        for (int i = 0; i < numCourses; i++) {
            if (state[i] == 0) {
                if (hasCycleDFS(i, adj, state)) {
                    return false; // Cycle detected
                }
            }
        }
        
        return true;
    }

private:
    bool hasCycleDFS(int u, const vector<vector<int>>& adj, vector<int>& state) {
        state[u] = 1; // Mark as currently visiting
        
        for (int v : adj[u]) {
            if (state[v] == 1) return true; // Found back-edge to ancestor -> CYCLE!
            if (state[v] == 0 && hasCycleDFS(v, adj, state)) return true;
        }
        
        state[u] = 2; // Mark as fully processed
        return false;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V + E)$ | Traverses every vertex and edge once. |
| **Space** | $O(V + E)$ | Adjacency list + state vector + recursion stack of depth $V$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Prerequisites** | `prerequisites = []` | Empty queue initialization | All $V$ nodes start with `inDegree = 0`, queue processes all, returns `true`. |
| **Direct Mutual Cycle** | `[[1, 0], [0, 1]]` | Infinite loop | Neither node has inDegree 0; queue is empty; returns `false`. |
| **Disconnected Components** | `4 courses, [[1, 0]]` | Missing unlinked nodes | Independent courses `2` and `3` have inDegree 0 and process cleanly. |

## Pattern Takeaways

1. **DAG / Cycle Equivalence:**  
   Topological Sort is possible **if and only if** the graph is a Directed Acyclic Graph (DAG).
2. **Kahn's In-Degree Rule:**  
   If `completed < numCourses` at queue exhaustion, any unprocessed nodes are guaranteed to be trapped within cycles.

## What are we solving?

Given the `root` of a binary tree, **invert the tree** (create its mirror image), and return its root.

```
 Original Binary Tree:                   Inverted Binary Tree:
 
            (4)                                   (4)
          /     \                               /     \
        (2)     (7)                           (7)     (2)
       /   \   /   \                         /   \   /   \
     (1)   (3)(6)  (9)                     (9)   (6)(3)  (1)
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root node of the binary tree ($0 \le \text{node count} \le 100$, $-100 \le \text{Node.val} \le 100$).
- **Output:**
  - `TreeNode*` pointing to the root of the modified, inverted binary tree.

### The Core Challenge
For every node in the binary tree, we must swap its `left` pointer and `right` pointer, and recursively repeat this mirroring process across all descendant subtrees in $O(n)$ time.

---

**Example 1:**
```
Input:  root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
```

**Example 2:**
```
Input:  root = [2,1,3]
Output: [2,3,1]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 100]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Recursive DFS (Pre-Order / Post-Order Swap) ✅

### Intuition
For any node:
1. Base case: If `root == nullptr`, return `nullptr`.
2. Swap the left child pointer with the right child pointer: `swap(root->left, root->right)`.
3. Recursively call `invertTree` on the newly assigned left and right subtrees.
4. Return `root`.

```
invertTree(4):
 1. Swap children 2 and 7 -> 4.left = 7, 4.right = 2
 2. invertTree(7):
    - Swap children 6 and 9 -> 7.left = 9, 7.right = 6
    - invertTree(9) -> returns 9
    - invertTree(6) -> returns 6
 3. invertTree(2):
    - Swap children 1 and 3 -> 2.left = 3, 2.right = 1
    - invertTree(3) -> returns 3
    - invertTree(1) -> returns 1
Returns root 4 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) {
            return nullptr;
        }
        
        // Swap left and right child pointers
        swap(root->left, root->right);
        
        // Invert both subtrees
        invertTree(root->left);
        invertTree(root->right);
        
        return root;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits every node in the binary tree once. |
| **Space** | $O(h)$ | Recursion stack depth equals tree height $h$ ($O(\log n)$ balanced, $O(n)$ worst-case skewed). |

> **This is the one.** Canonical, elegant, in-place pointer swapping.

## Approach 2 — Iterative BFS (Level-Order Queue Swap)

### Intuition
Use a `queue<TreeNode*>` to perform standard breadth-first exploration.  
For each dequeued node:
- Swap its `left` and `right` child pointers.
- Push non-null children into the queue for subsequent processing.

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            TreeNode* curr = q.front();
            q.pop();
            
            // Swap children
            swap(curr->left, curr->right);
            
            // Enqueue children if present
            if (curr->left != nullptr) q.push(curr->left);
            if (curr->right != nullptr) q.push(curr->right);
        }
        
        return root;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Enqueues and dequeues each node exactly once. |
| **Space** | $O(w)$ | Maximum queue size equals maximum width of tree $w \le n/2$. |

> **Verdict:** Avoids recursion stack overhead; safe for extremely deep trees.

## Approach 3 — Iterative DFS (Explicit Stack)

### Intuition
Emulate pre-order traversal using an explicit `stack<TreeNode*>`.

### C++ Implementation
```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        
        stack<TreeNode*> st;
        st.push(root);
        
        while (!st.empty()) {
            TreeNode* curr = st.top();
            st.pop();
            
            swap(curr->left, curr->right);
            
            if (curr->left != nullptr) st.push(curr->left);
            if (curr->right != nullptr) st.push(curr->right);
        }
        
        return root;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Pushes and pops each node once. |
| **Space** | $O(h)$ | Stack size bounded by height $h$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Tree** | `root = nullptr` | Null pointer dereference | `if (root == nullptr) return nullptr;` exits immediately. |
| **Single Node** | `[1]` | Swapping null children | `swap(nullptr, nullptr)` safely maintains node without error. |
| **Asymmetric / Skewed Tree** | `1 -> 2 -> 3` (all left) | Missing right child checks | Swaps `left` to `right`, flipping left-skewed tree to right-skewed tree. |

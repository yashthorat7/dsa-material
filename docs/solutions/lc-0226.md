## What are we solving?

Given the `root` of a binary tree, invert the tree, and return its root.

The question is: **how do we swap left and right subtrees recursively for every node in $O(n)$ time?**

**Example 1:**
```
Input:  root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
```

**Example 2:**
```
Input:  root = [2,1,3]
Output: [2,3,1]
```

**Example 3:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 100]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Post-Order / Pre-Order DFS Recursion ✅

**Key insight:**
For any tree rooted at `root`:
1. Base case: `if (!root) return nullptr;`
2. Swap the left child and right child pointers: `swap(root->left, root->right)`.
3. Recursively invert both subtrees: `invertTree(root->left)`, `invertTree(root->right)`.
4. Return `root`.

```
4
   / \
  2   7
 / \ / \
1  3 6  9

Swap 2 and 7:
    4
   / \
  7   2

Recurse on 7: swap 6 and 9 -> 7 has children 9, 6
Recurse on 2: swap 1 and 3 -> 2 has children 3, 1

Result: [4, 7, 2, 9, 6, 3, 1] ✓
```

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;
        swap(root->left, root->right);
        invertTree(root->left);
        invertTree(root->right);
        return root;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ (visits every node once) | $O(h)$ where $h$ is tree height |

> **This is the one.** Clean 4-line recursive tree inversion.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty tree `root = nullptr` | Null dereference | Returns `nullptr` immediately |
| Single node `[1]` | Swapping null children | Swaps null with null safely, returns `[1]` |

## Pattern Takeaway

Tree inversion is a **bottom-up or top-down recursive subtree swap** across all $n$ nodes.

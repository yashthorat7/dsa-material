## What are we solving?

Given a string `s` containing only three types of characters: `'('`, `')'`, and `'*'`, return `true` if `s` is **valid**.

The following rules define a valid string:
1. Any left parenthesis `'('` must have a corresponding right parenthesis `')'`.
2. Any right parenthesis `')'` must have a corresponding left parenthesis `'('`.
3. Left parenthesis `'('` must go before the corresponding right parenthesis `')'`.
4. `'*'` could be treated as a single right parenthesis `')'` or a single left parenthesis `'('` or an empty string `""`.

```
 s = " ( * ) ) "
 
 Interpreting '*' as '(':
 " ( ( ) ) " -> PERFECTLY VALID!
 
 Output: true
```

### Input & Output Contract
- **Input:**
  - `s`: `string` ($1 \le n \le 100$, composed of `'('`, `')'`, `'*'`).
- **Output:**
  - `bool`: `true` if any valid interpretation of `'*'` forms a balanced parenthesis string.

### The Interval Range Compression Insight
Because each `'*'` can be `'('` ($+1$), `')'` ($-1$), or `""` ($0$), the number of open left parentheses is not a single scalar, but a continuous **range $[c_{\min}, c_{\max}]$**:
- $c_{\max}$: The maximum possible number of open `'('` (assuming all `'*'` act as `'('`).
- $c_{\min}$: The minimum possible number of open `'('` (assuming all `'*'` act as `')'`).
- If $c_{\max} < 0$: even under the most optimistic interpretation, there are too many `')'` $\implies$ return `false`!
- At the end of the string, it is valid if and only if **$c_{\min} == 0$** (a completely balanced configuration is achievable).

```
Input:  s = "()"
Output: true
```

**Example 2:**
```
Input:  s = "(*)"
Output: true
```

**Example 3:**

Input:  s = "(*))"
Output: true

- `s[i]` is `'('`, `')'` or `'*'`.

## Approach 1 — Two Stacks (Indices of `(` and `*`)

### Intuition
Maintain two stacks storing indices: `openSt` for `'('` and `starSt` for `'*'`.
1. For each `s[i]`:
   - If `'('`: `openSt.push(i)`.
   - If `'*'`: `starSt.push(i)`.
   - If `')'`: pop `openSt` first if available; else pop `starSt`; if both empty, return `false`.
2. After the loop, match remaining `'('` with `'*'`:
   - While `!openSt.empty() && !starSt.empty()`:
     - If `openSt.top() > starSt.top()`: the `'*'` appears *before* `'('`, so it cannot close it $\implies$ return `false`.
     - Pop both.
3. Return `openSt.empty()`.

### C++ Implementation
```cpp
class Solution {
public:
    bool checkValidString(string s) {
        stack<int> openSt, starSt;
        
        for (int i = 0; i < s.length(); i++) {
            if (s[i] == '(') {
                openSt.push(i);
            } else if (s[i] == '*') {
                starSt.push(i);
            } else { // ')'
                if (!openSt.empty()) {
                    openSt.pop();
                } else if (!starSt.empty()) {
                    starSt.pop();
                } else {
                    return false;
                }
            }
        }
        
        // Match leftover '(' with '*' that appear strictly to the right
        while (!openSt.empty() && !starSt.empty()) {
            if (openSt.top() > starSt.top()) {
                return false;
            }
            openSt.pop();
            starSt.pop();
        }
        
        return openSt.empty();
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear scan + stack matching. |
| **Space** | $O(n)$ | Two auxiliary stacks. |

## Approach 2 — Greedy Balance Range $[c_{\min}, c_{\max}]$ ✅

### Key Insight
Track `[cmin, cmax]` in a single pass with $O(1)$ memory:
- `'('`: `cmin++`, `cmax++`
- `')'`: `cmin--`, `cmax--`
- `'*'`: `cmin--` (acts as `')'`), `cmax++` (acts as `'('`)
- **Clamping:**
  - If `cmax < 0`: Too many `')'` $\implies$ return `false`.
  - `cmin = max(cmin, 0)`: We will never greedily force `'*'` to be `')'` if it causes open count to drop below 0.
- At the end: return `cmin == 0`.

```
s = " ( * ) ) "
cmin = 0, cmax = 0

1. '(': cmin = 1, cmax = 1
2. '*': cmin = 0, cmax = 2
3. ')': cmin = -1 -> 0, cmax = 1
4. ')': cmin = -1 -> 0, cmax = 0

Loop finishes. cmin == 0 -> Valid!
Result: true ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    bool checkValidString(string s) {
        int cmin = 0; // Minimum possible count of open '('
        int cmax = 0; // Maximum possible count of open '('
        
        for (char c : s) {
            if (c == '(') {
                cmin++;
                cmax++;
            } else if (c == ')') {
                cmin--;
                cmax--;
            } else { // c == '*'
                cmin--; // '*' acting as ')'
                cmax++; // '*' acting as '('
            }
            
            // If even the maximum possible '(' count is negative, excessive ')' exists
            if (cmax < 0) {
                return false;
            }
            
            // Minimum open count cannot drop below 0 (we can always treat '*' as empty string)
            cmin = max(cmin, 0);
        }
        
        // Valid if 0 open parentheses is within reachable range [cmin, cmax]
        return cmin == 0;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass over string. |
| **Space** | $O(1)$ | Two integer variables. |

> **This is the one.** Clean, space-optimal $O(1)$ interval range tracking.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Excess Right Parenthesis Early** | `")("` | `cmax` turning negative | `cmax < 0` immediately returns `false`. |
| **Star Before Open Parenthesis** | `"*( )"` | Index ordering | Both stacks and interval tracking correctly validate right-hand closure. |
| **All Wildcards** | `"***"` | Ambiguity | `cmin = 0, cmax = 3`, valid at end (`cmin == 0`). |

## Pattern Takeaways

1. **State Compression via Min/Max Bounds:**  
   When non-deterministic tokens branch choices by $\pm 1$ or $0$, maintain the **continuous interval of possible states $[S_{\min}, S_{\max}]$** in $O(1)$ memory.

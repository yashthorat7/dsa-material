## What are we solving?

Given a string `s` containing only three types of characters: `'('`, `')'` and `'*'`, return `true` if `s` is **valid**.

The following rules define a valid string:
1. Any left parenthesis `'('` must have a corresponding right parenthesis `')'`.
2. Any right parenthesis `')'` must have a corresponding left parenthesis `'('`.
3. Left parenthesis `'('` must go before the corresponding right parenthesis `')'`.
4. `'*'` could be treated as a single right parenthesis `')'` or a single left parenthesis `'('` or an empty string `""`.

**Example 1:**
```
Input:  s = "()"
Output: true
```

**Example 2:**
```
Input:  s = "(*)"
Output: true
```

**Example 3:**
```
Input:  s = "(*))"
Output: true
```

**Constraints:**
- $1 \le s.\text{length} \le 100$
- `s[i]` is `'('`, `')'` or `'*'`.

## Approach 1 — Greedy Open Parentheses Range [cmin, cmax] ✅

**Key insight:**
Track the range of possible open left parentheses counts: `[cmin, cmax]`.
For each character:
- If `'('`: `cmin++`, `cmax++`
- If `')'`: `cmin--`, `cmax--`
- If `'*'`: could be `)` (`cmin--`), `(` (`cmax++`), or `""` (`cmin` and `cmax` stay same) $\rightarrow$ `cmin--`, `cmax++`.
- If `cmax < 0`: too many `')'` even if all `*` were `'('` $\rightarrow$ return `false`.
- `cmin = max(cmin, 0)`: we will never choose `*` to be `)` if it makes open count negative.
At the end, string is valid if `cmin == 0`.

```
s = "(*))"
cmin = 0, cmax = 0

1. '(': cmin=1, cmax=1
2. '*': cmin=0, cmax=2
3. ')': cmin=-1 -> 0, cmax=1
4. ')': cmin=-1 -> 0, cmax=0
At end: cmin == 0 -> valid!

Result: true ✓
```

```cpp
class Solution {
public:
    bool checkValidString(string s) {
        int cmin = 0, cmax = 0;
        
        for (char c : s) {
            if (c == '(') {
                cmin++;
                cmax++;
            } else if (c == ')') {
                cmin--;
                cmax--;
            } else { // c == '*'
                cmin--;
                cmax++;
            }
            
            if (cmax < 0) return false;
            cmin = max(cmin, 0);
        }
        
        return cmin == 0;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Interval tracking handles non-deterministic wildcards in $O(1)$ space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Excess closing brackets `")("` | cmax turning negative | `cmax < 0` immediately catches invalid prefix |
| All wildcards `"***"` | Range validation | `cmin = 0, cmax = 3`, valid at end (`cmin == 0`) |

---

## Pattern Takeaway

When wildcard choices branch exponentially, **tracking the minimum and maximum possible balance `[cmin, cmax]`** compresses the state space to $O(1)$.

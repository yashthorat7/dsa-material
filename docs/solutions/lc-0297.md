## What are we solving?

Serialization is the process of converting a data structure or object into a sequence of bits so that it can be stored in a file or memory buffer, or transmitted across a network.

Design an algorithm to serialize and deserialize a binary tree. There is no restriction on how your serialization/deserialization algorithm should work. You just need to ensure that a binary tree can be serialized to a string and this string can be deserialized to the original tree structure.

**Example 1:**
```
Input:  root = [1,2,3,null,null,4,5]
Output: [1,2,3,null,null,4,5]
```

**Example 2:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-1000 \le \text{Node.val} \le 1000$

## Approach 1 — Pre-Order Traversal with Null Markers ✅

**Key insight:**
- **Serialize:** Pre-order traversal (Root $\rightarrow$ Left $\rightarrow$ Right). Append node value and delimiter `,`. If node is null, append `#,`.
- **Deserialize:** Read tokens sequentially from a `stringstream`. If token is `#`, return `nullptr`. Otherwise, create node `new TreeNode(stoi(token))`, then recursively deserialize left and right children.

```
Tree: [1, 2, 3, null, null, 4, 5]

Serialize:
"1,2,#,#,3,4,#,#,5,#,#,"

Deserialize (token stream):
- "1" -> node(1)
  - "2" -> node(2)
    - "#" -> left is null
    - "#" -> right is null
  - "3" -> node(3)
    - "4" -> node(4), children null
    - "5" -> node(5), children null
Restores original tree structure ✓
```

```cpp
class Codec {
public:
    // Encodes a tree to a single string.
    string serialize(TreeNode* root) {
        if (!root) return "#,";
        return to_string(root->val) + "," + serialize(root->left) + serialize(root->right);
    }

    // Decodes your encoded data to tree.
    TreeNode* deserialize(string data) {
        stringstream ss(data);
        return buildTree(ss);
    }
private:
    TreeNode* buildTree(stringstream& ss) {
        string val;
        if (!getline(ss, val, ',')) return nullptr;
        if (val == "#") return nullptr;
        
        TreeNode* node = new TreeNode(stoi(val));
        node->left = buildTree(ss);
        node->right = buildTree(ss);
        return node;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ for serialize and deserialize | $O(n)$ |

> **This is the one.** Clean, robust pre-order encoding with `stringstream`.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty tree `root = nullptr` | Encoding empty | Encodes as `"#,"` and deserializes to `nullptr` |
| Negative node values | Parsing negative integers | `stoi` correctly handles negative sign |

---

## Pattern Takeaway

**Pre-order DFS with null delimiters (`#`)** uniquely identifies binary tree topology without requiring both pre-order and in-order traversals.

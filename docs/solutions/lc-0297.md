## What are we solving?

Serialization is the process of converting a data structure or object into a sequence of bits/characters so that it can be stored in a file or memory buffer, or transmitted across a network connection.

Design an algorithm to **serialize and deserialize a binary tree**.
- `serialize(TreeNode* root)`: Encodes a tree to a single `string`.
- `deserialize(string data)`: Decodes your encoded string back into the exact original binary tree structure.

```
 Tree:
        1
       / \
      2   3
         / \
        4   5
        
 Serialized Format (Pre-Order with '#' for null):
 "1,2,#,#,3,4,#,#,5,#,#,"
 
 Deserialized Tree matches original perfectly!
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` reference ($0 \le n \le 10^4$, $-1000 \le \text{Node.val} \le 1000$).
- **Output:**
  - `serialize`: `string`
  - `deserialize`: `TreeNode*` root reconstructed in memory.

### The Core Challenge
Usually, reconstructing a binary tree requires **both** pre-order and in-order traversals because null pointers are not recorded.  
However, by **explicitly recording null pointers with sentinel markers (`#`)**, a **single pre-order (or level-order) traversal uniquely defines the binary tree structure!**

---

**Example 1:**
```
Input:  root = [1,2,3,null,null,4,5]
Output: [1,2,3,null,null,4,5]
```

**Example 2:**
```
Input:  root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-1000 \le \text{Node.val} \le 1000$

## Approach 1 — Pre-Order Traversal (DFS with Null Sentinels) ✅

### Key Insight
1. **Serialize (DFS):**
   - Traverse in pre-order (`Root -> Left -> Right`).
   - If node is `nullptr`, append `"#,"`.
   - Otherwise, append `to_string(node->val) + ","`, then recurse on `node->left` and `node->right`.
2. **Deserialize (StringStream Token Stream):**
   - Read comma-separated tokens sequentially via `getline(ss, val, ',')`.
   - If token is `"#"` or stream is empty, return `nullptr`.
   - Otherwise, create `TreeNode* node = new TreeNode(stoi(val))`.
   - Recursively build:
     - `node->left = buildTree(ss)`
     - `node->right = buildTree(ss)`
   - Return `node`.

```
Tree: [1, 2, 3, null, null, 4, 5]

Serialize Stream:
"1,2,#,#,3,4,#,#,5,#,#,"

Deserialize Steps:
1. Token "1" -> create node(1)
   - Token "2" -> create node(2)
     - Token "#" -> left child is nullptr
     - Token "#" -> right child is nullptr
   - Token "3" -> create node(3)
     - Token "4" -> create node(4)
       - Token "#" -> null
       - Token "#" -> null
     - Token "5" -> create node(5)
       - Token "#" -> null
       - Token "#" -> null

Root node(1) returned with exact original structure! ✓
```

### C++ Implementation
```cpp
/*
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
*/

class Codec {
public:
    // Encodes a tree to a single string.
    string serialize(TreeNode* root) {
        if (root == nullptr) return "#,";
        return to_string(root->val) + "," + serialize(root->left) + serialize(root->right);
    }

    // Decodes your encoded data to tree.
    TreeNode* deserialize(string data) {
        stringstream ss(data);
        return buildTree(ss);
    }

private:
    TreeNode* buildTree(stringstream& ss) {
        string val;
        if (!getline(ss, val, ',')) {
            return nullptr;
        }
        if (val == "#") {
            return nullptr;
        }
        
        TreeNode* node = new TreeNode(stoi(val));
        node->left = buildTree(ss);
        node->right = buildTree(ss);
        return node;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ for both `serialize` and `deserialize` | Visits every node and null sentinel exactly once. |
| **Space** | $O(n)$ | Serialized string of length $\approx 3n$, recursion stack depth $O(h)$. |

> **This is the one.** Clean, robust recursive DFS encoding.

## Approach 2 — Level-Order Traversal (BFS with Queue)

### Intuition
1. **Serialize:** Use a queue to traverse level-by-level. Push `nullptr` nodes as `"#,"` and real nodes as `"val,"`.
2. **Deserialize:** Tokenize the string, create the root node, push it to a queue, and attach pairs of tokens as left and right children.

### C++ Implementation
```cpp
class Codec {
public:
    string serialize(TreeNode* root) {
        if (!root) return "";
        string s = "";
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            TreeNode* curr = q.front();
            q.pop();
            
            if (curr) {
                s += to_string(curr->val) + ",";
                q.push(curr->left);
                q.push(curr->right);
            } else {
                s += "#,";
            }
        }
        return s;
    }

    TreeNode* deserialize(string data) {
        if (data.empty()) return nullptr;
        stringstream ss(data);
        string item;
        getline(ss, item, ',');
        
        TreeNode* root = new TreeNode(stoi(item));
        queue<TreeNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            TreeNode* curr = q.front();
            q.pop();
            
            // Left child
            if (getline(ss, item, ',')) {
                if (item != "#") {
                    curr->left = new TreeNode(stoi(item));
                    q.push(curr->left);
                }
            }
            
            // Right child
            if (getline(ss, item, ',')) {
                if (item != "#") {
                    curr->right = new TreeNode(stoi(item));
                    q.push(curr->right);
                }
            }
        }
        return root;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | BFS visits all nodes and null leaves once. |
| **Space** | $O(n)$ | Queue memory + output string. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Tree** | `root = nullptr` | Dereferencing null | Encodes as `"#,"` (DFS) or `""` (BFS), deserializes to `nullptr`. |
| **Negative Values** | `Node.val = -42` | Parsing minus signs | `stoi("-42")` correctly reconstructs negative values. |
| **Skewed Tree** | Single chain of 10,000 nodes | Stack depth | In-order queue BFS avoids call stack depth issues. |

## Pattern Takeaways

1. **Sentinels Provide Unique Reconstruction:**  
   Recording null children eliminates ambiguity, making single-pass pre-order or level-order serialization 100% reversible.

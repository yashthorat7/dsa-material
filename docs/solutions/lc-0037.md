## What are we solving?

Write a program to solve a Sudoku puzzle by filling the empty cells.

A sudoku solution must satisfy all of the following rules:
1. Each of the digits `1-9` must occur exactly once in each row.
2. Each of the digits `1-9` must occur exactly once in each column.
3. Each of the digits `1-9` must occur exactly once in each of the 9 `3x3` sub-boxes of the grid.

The `'.'` character indicates empty cells.

**Example 1:**
```
Input:  board = [["5","3",".",".","7",".",".",".","."],["6",".",".","1","9","5",".",".","."],[".","9","8",".",".",".",".","6","."],["8",".",".",".","6",".",".",".","3"],["4",".",".","8",".","3",".",".","1"],["7",".",".",".","2",".",".",".","6"],[".","6",".",".",".",".","2","8","."],[".",".",".","4","1","9",".",".","5"],[".",".",".",".","8",".",".","7","9"]]
Output: [["5","3","4","6","7","8","9","1","2"],["6","7","2","1","9","5","3","4","8"],["1","9","8","3","4","2","5","6","7"],["8","5","9","7","6","1","4","2","3"],["4","2","6","8","5","3","7","9","1"],["7","1","3","9","2","4","8","5","6"],["9","6","1","5","3","7","2","8","4"],["2","8","7","4","1","9","6","3","5"],["3","4","5","2","8","6","1","7","9"]]
```

**Constraints:**
- $\text{board}.\text{length} == 9$
- $\text{board}[i].\text{length} == 9$
- $\text{board}[i][j]$ is a digit `1-9` or `'.'`. 
- It is **guaranteed** that the input board has only one unique solution.

## Approach 1 — Cell-by-Cell Constraint Propagation Backtracking ✅

**Key insight:**
1. Find the next empty cell `'.'`.
2. Try placing digits `'1'` through `'9'`.
3. Check validity in $O(1)$:
   - Row `r`: no duplicate in `board[r][i]`.
   - Column `c`: no duplicate in `board[i][c]`.
   - $3 \times 3$ Box: no duplicate in `board[3 * (r/3) + i/3][3 * (c/3) + i%3]`.
4. If valid, place digit and recurse. If recursion returns `true`, propagate success immediately.
5. If no digit leads to a solution, reset cell to `'.'` and backtrack (`return false`).

```
For empty cell (r, c):
Try '1' -> isValid? Yes -> recurse
  If child returns true -> return true!
  If child returns false -> reset to '.'
Try '2' ...
If 1-9 fail -> return false (trigger backtrack in parent)
```

```cpp
class Solution {
public:
    void solveSudoku(vector<vector<char>>& board) {
        solve(board);
    }
private:
    bool solve(vector<vector<char>>& board) {
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] == '.') {
                    for (char ch = '1'; ch <= '9'; ch++) {
                        if (isValid(board, r, c, ch)) {
                            board[r][c] = ch;
                            if (solve(board)) return true;
                            board[r][c] = '.'; // backtrack
                        }
                    }
                    return false; // no digit works for this empty cell
                }
            }
        }
        return true; // all cells filled
    }
    
    bool isValid(const vector<vector<char>>& board, int row, int col, char c) {
        for (int i = 0; i < 9; i++) {
            if (board[row][i] == c) return false;
            if (board[i][col] == c) return false;
            if (board[3 * (row / 3) + i / 3][3 * (col / 3) + i % 3] == c) return false;
        }
        return true;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(9^{81})$ worst-case theoretical, typically $< 10$ ms in practice | $O(81) = O(1)$ call stack depth |

> **This is the one.** Standard constraint satisfaction backtracking algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Almost full board with 1 empty cell | Deep recursion | Fills single cell and returns true immediately |
| Backtracking multiple levels | State corruption | In-place reset `board[r][c] = '.'` preserves clean board |

---

## Pattern Takeaway

The formula **`3 * (row / 3) + i / 3` and `3 * (col / 3) + i % 3`** indexes all 9 cells of the containing $3 \times 3$ sub-box in a single loop from `i = 0..8`.

## What are we solving?

Write a program to solve a **Sudoku puzzle** by filling the empty cells.

A sudoku solution must satisfy all of the following rules:
1. Each of the digits `1-9` must occur **exactly once** in each row.
2. Each of the digits `1-9` must occur **exactly once** in each column.
3. Each of the digits `1-9` must occur **exactly once** in each of the 9 $3 \times 3$ sub-boxes of the grid.

The `'.'` character indicates empty cells.

```
 5  3  . | .  7  . | .  .  .
 6  .  . | 1  9  5 | .  .  .
 .  9  8 | .  .  . | .  6  .
 --------+---------+--------
 8  .  . | .  6  . | .  .  3
 4  .  . | 8  .  3 | .  .  1
 7  .  . | .  2  . | .  .  6
 --------+---------+--------
 .  6  . | .  .  . | 2  8  .
 .  .  . | 4  1  9 | .  .  5
 .  .  . | .  8  . | .  7  9
```

### Input & Output Contract
- **Input:**
  - `board`: `vector<vector<char>>` of size $9 \times 9$, containing digits `'1'-'9'` and empty markers `'.'`.
  - Guaranteed to have **exactly one unique solution**.
- **Output:**
  - `void` (modifies `board` in-place).

### The Core Challenge
There are 81 cells, with up to ~64 empty positions. Brute forcing $9^{64}$ combinations is impossible. We must use **Backtracking with Constraint Propagation**:
- Test only valid candidate digits for each cell.
- As soon as a placement leads to a dead end, backtrack by resetting the cell to `'.'`.

- $\text{board}[i].\text{length} == 9$
- $\text{board}[i][j]$ is a digit `'1'-'9'` or `'.'`.
- Guaranteed that the input board has only one unique solution.

## Approach 1 — Cell-by-Cell Backtracking with Loop Validation

### Intuition
1. Iterate through cells to locate the first empty position `'.'`.
2. Try placing each candidate char `'1'` through `'9'`.
3. Check validity across the row, column, and $3 \times 3$ box using a loop of 9 steps.
4. If valid, place the character and recurse. If downstream recursion succeeds, propagate `true` immediately.
5. If no digit works, reset to `'.'` and return `false`.

### C++ Implementation
```cpp
class Solution {
public:
    void solveSudoku(vector<vector<char>>& board) {
        solve(board);
    }

private:
    bool solve(vector<vector<char>>& board) {
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] == '.') {
                    for (char ch = '1'; ch <= '9'; ch++) {
                        if (isValid(board, r, c, ch)) {
                            board[r][c] = ch;
                            if (solve(board)) return true;
                            board[r][c] = '.'; // Backtrack
                        }
                    }
                    return false; // No valid digit found for this cell
                }
            }
        }
        return true; // All cells filled successfully
    }

    bool isValid(const vector<vector<char>>& board, int row, int col, char c) {
        for (int i = 0; i < 9; i++) {
            if (board[row][i] == c) return false;
            if (board[i][col] == c) return false;
            if (board[3 * (row / 3) + i / 3][3 * (col / 3) + i % 3] == c) return false;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(9^M)$ | Where $M \le 81$ is the count of empty cells. In practice runs in $<15$ ms. |
| **Space** | $O(M)$ | Recursion call stack depth bounded by $81$. |

## Approach 2 — Bitmask / Boolean Array Fast Constraint Propagation ✅

### Key Insight
Instead of scanning 9 rows, 9 columns, and 9 box cells on every check, maintain three boolean arrays:
- `rowUsed[9][10]`
- `colUsed[9][10]`
- `boxUsed[9][10]` (where box index $= 3 \times (r / 3) + (c / 3)$).

Validity check becomes an instantaneous $O(1)$ bit test:
$$\text{isValid} = \neg \text{rowUsed}[r][d] \land \neg \text{colUsed}[c][d] \land \neg \text{boxUsed}[\text{boxIdx}][d]$$

```
Box Index Mapping:
[ 0 ][ 1 ][ 2 ]
[ 3 ][ 4 ][ 5 ]
[ 6 ][ 7 ][ 8 ]
boxIndex = 3 * (r / 3) + (c / 3)
```

### C++ Implementation
```cpp
class Solution {
private:
    bool rowUsed[9][10] = {false};
    bool colUsed[9][10] = {false};
    bool boxUsed[9][10] = {false};
    vector<pair<int, int>> emptyCells;

public:
    void solveSudoku(vector<vector<char>>& board) {
        // Step 1: Pre-populate existing numbers into fast lookup tables
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] != '.') {
                    int d = board[r][c] - '0';
                    int b = (r / 3) * 3 + (c / 3);
                    rowUsed[r][d] = colUsed[c][d] = boxUsed[b][d] = true;
                } else {
                    emptyCells.push_back({r, c});
                }
            }
        }
        
        backtrack(0, board);
    }

private:
    bool backtrack(int idx, vector<vector<char>>& board) {
        if (idx == emptyCells.size()) {
            return true; // All empty cells successfully populated
        }
        
        auto [r, c] = emptyCells[idx];
        int b = (r / 3) * 3 + (c / 3);
        
        for (int d = 1; d <= 9; d++) {
            if (!rowUsed[r][d] && !colUsed[c][d] && !boxUsed[b][d]) {
                // Place digit
                board[r][c] = d + '0';
                rowUsed[r][d] = colUsed[c][d] = boxUsed[b][d] = true;
                
                if (backtrack(idx + 1, board)) {
                    return true;
                }
                
                // Backtrack
                board[r][c] = '.';
                rowUsed[r][d] = colUsed[c][d] = boxUsed[b][d] = false;
            }
        }
        
        return false;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(9^M)$ | $O(1)$ constraint checks accelerate search tree pruning significantly (<3ms). |
| **Space** | $O(M)$ | Vector of empty cells + recursion stack depth $\le 81$. |

> **This is the one.** Instantaneous $O(1)$ bit checking with pre-indexed empty cells.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Board with Only 1 Empty Cell** | 80 pre-filled cells | Deep search | Fills single cell immediately on step 0, returns `true`. |
| **Deep Backtracking Chain** | Multiple plausible starts | State corruption | In-place reset `board[r][c] = '.'` preserves board integrity. |

## Pattern Takeaways

1. **Subgrid Coordinate Formula:**  
   The $3 \times 3$ box index for cell $(r, c)$ in a $9 \times 9$ board is always $\mathbf{(r / 3) \times 3 + (c / 3)}$.
2. **Pre-Filtering Empty Cells:**  
   Storing empty coordinates in a list `emptyCells` avoids rescanning the entire $9 \times 9$ matrix at every recursion frame.

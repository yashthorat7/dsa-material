## What are we solving?

Reverse the bits of a given 32-bit unsigned integer `n`.

```
 Input:  00000010100101000001111010011100 (43261596)
 Output: 00111001011110000010100101000000 (964176192)
```

### Input & Output Contract
- **Input:**
  - `n`: `uint32_t` 32-bit unsigned integer.
- **Output:**
  - `uint32_t`: Bit-reversed 32-bit unsigned integer.

---

**Example 1:**
```
Input:  n = 00000010100101000001111010011100
Output: 964176192 (00111001011110000010100101000000)
```

**Constraints:**
- The input must be a 32-bit integer.

## Approach 1 — Bit-by-Bit 32-Step Shift and Accumulate ✅

### Key Insight
Loop exactly 32 times:
1. Shift `result` left by 1: `result = (result << 1) | (n & 1)`.
2. Extract the least-significant bit of `n` using `n & 1`.
3. Shift `n` right by 1: `n >>= 1`.

```
Step 0: result = 0, n = ...100 -> extract 0 -> result = 0
Step 1: result = (0<<1)|0 = 0, n = ...10 -> extract 0 -> result = 0
Step 2: result = (0<<1)|1 = 1, n = ...1  -> extract 1 -> result = 1
...
After 32 iterations, bit 0 has been shifted 31 times into bit position 31!
```

### C++ Implementation
```cpp
class Solution {
public:
    uint32_t reverseBits(uint32_t n) {
        uint32_t result = 0;
        
        for (int i = 0; i < 32; i++) {
            result = (result << 1) | (n & 1);
            n >>= 1;
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(1)$ | Fixed loop of exactly 32 iterations. |
| **Space** | $O(1)$ | Pure CPU register operations. |

> **This is the one.** Clear, concise, standard bitwise technique.

## Approach 2 — Divide and Conquer (Parallel Mask Swapping)

### Intuition
Reverse bits in parallel using bitmask shifts in $\log_2(32) = 5$ steps:
1. Swap adjacent 16-bit halves: `(n >> 16) | (n << 16)`.
2. Swap 8-bit bytes: `((n & 0xFF00FF00) >> 8) | ((n & 0x00FF00FF) << 8)`.
3. Swap 4-bit nibbles: `((n & 0xF0F0F0F0) >> 4) | ((n & 0x0F0F0F0F) << 4)`.
4. Swap 2-bit pairs: `((n & 0xCCCCCCCC) >> 2) | ((n & 0x33333333) << 2)`.
5. Swap adjacent bits: `((n & 0xAAAAAAAA) >> 1) | ((n & 0x55555555) << 1)`.

### C++ Implementation
```cpp
class Solution {
public:
    uint32_t reverseBits(uint32_t n) {
        n = (n >> 16) | (n << 16);
        n = ((n & 0xFF00FF00) >> 8) | ((n & 0x00FF00FF) << 8);
        n = ((n & 0xF0F0F0F0) >> 4) | ((n & 0x0F0F0F0F) << 4);
        n = ((n & 0xCCCCCCCC) >> 2) | ((n & 0x33333333) << 2);
        n = ((n & 0xAAAAAAAA) >> 1) | ((n & 0x55555555) << 1);
        return n;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(1)$ | Exactly 5 parallel bitwise operations without any loops or branches. |
| **Space** | $O(1)$ | Hardware register only. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **All 1s** | `0xFFFFFFFF` | Mask boundaries | Reverses to `0xFFFFFFFF` identically. |
| **Single Bit at Position 0** | `n = 1` | Zero padding | Bit 1 shifted 31 positions left to become $2^{31} = 2147483648$. |
| **All Zeroes** | `n = 0` | Empty shifts | Returns `0`. |

## Pattern Takeaways

1. **Bit Reversal Invariant:**  
   Extracting bits via `(n & 1)` and pushing them via `(res << 1)` naturally reverses sequence order.
2. **Parallel SIMD-Style Bitmasking:**  
   Swapping chunks of size $16 \rightarrow 8 \rightarrow 4 \rightarrow 2 \rightarrow 1$ reduces 32 loop steps into 5 parallel hardware instructions.

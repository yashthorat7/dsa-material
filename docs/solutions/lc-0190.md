## What are we solving?

Reverse bits of a given 32 bits unsigned integer.

The question is: **how do we extract bits from right to left while shifting them left into the result across 32 iterations?**

**Example 1:**
```
Input:  n = 00000010100101000001111010011100
Output: 964176192 (00111001011110000010100101000000)
Explanation: The input binary string represents the unsigned integer 43261596, so return 964176192 which its binary representation is 00111001011110000010100101000000.
```

**Constraints:**
- The input must be a binary string of length 32

## Approach 1 — Bit-by-Bit Shift and Accumulate ✅

**Key insight:**
Loop 32 times:
1. Shift `result` left by 1 (`result <<= 1`).
2. Add the lowest bit of `n` to `result` (`result |= (n & 1)`).
3. Shift `n` right by 1 (`n >>= 1`).

```
For 32 steps:
Step i:
  result = (result << 1) | (n & 1)
  n >>= 1
Ensures bit 0 becomes bit 31, bit 1 becomes bit 30, ..., bit 31 becomes bit 0.
```

```cpp
class Solution {
public:
    uint32_t reverseBits(uint32_t n) {
        uint32_t result = 0;
        for (int i = 0; i < 32; i++) {
            result = (result << 1) | (n & 1);
            n >>= 1;
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(1)$ (exactly 32 iterations) | $O(1)$ |

> **This is the one.** Constant time and bitwise clarity.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All 1s (`0xFFFFFFFF`) | Reversing unchanged | Returns `0xFFFFFFFF` |
| Single bit at position 0 (`n = 1`) | Leading zeroes omitted | Bit shifted 31 times into highest bit position ($2^{31}$) |

---

## Pattern Takeaway

To reverse bits, construct the output by **pushing extracted least-significant bits into the accumulator via left shift**.

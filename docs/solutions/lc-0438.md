## What are we solving?

Given two strings `s` and `p`, return an array of all the **start indices** of `p`'s anagrams in `s`. You may return the answer in any order.

An **Anagram** is a word or phrase formed by rearranging the letters of a different word or phrase, typically using all the original letters exactly once.

**Example 1:**
```
Input:  s = "cbaebabacd", p = "abc"
Output: [0,6]
Explanation: The substring with start index = 0 is "cba", which is an anagram of "abc".
The substring with start index = 6 is "bac", which is an anagram of "abc".
```

**Example 2:**
```
Input:  s = "abab", p = "ab"
Output: [0,1,2]
Explanation: The substring with start index = 0 is "ab", which is an anagram of "ab".
The substring with start index = 1 is "ba", which is an anagram of "ab".
The substring with start index = 2 is "ab", which is an anagram of "ab".
```

**Constraints:**
- $1 \le s.\text{length}, p.\text{length} \le 3 \times 10^4$
- `s` and `p` consist of lowercase English letters.

## Approach 1 — Sliding Window with Vector Equality ✅

**Key insight:** Slide a window of length `p.length()` across `s`. Maintain frequency vectors of size 26. Whenever `sCount == pCount`, record the start index `i - p.length() + 1`.

```
s = "cbaebabacd", p = "abc" (len=3)
pCount = {a:1, b:1, c:1}

Init window [0..2] ("cba"): sCount = {a:1, b:1, c:1} == pCount -> record index 0
i=3 ('e'): remove 'c', add 'e' -> "bae", sCount != pCount
i=4 ('b'): remove 'b', add 'b' -> "aeb", sCount != pCount
...
i=8 ('c'): remove 'b', add 'c' -> "bac", sCount == pCount -> record index 6

Result: [0, 6] ✓
```

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int ns = s.size(), np = p.size();
        if (ns < np) return {};
        
        vector<int> pCount(26, 0), sCount(26, 0);
        for (char c : p) pCount[c - 'a']++;
        for (int i = 0; i < np; i++) sCount[s[i] - 'a']++;
        
        vector<int> result;
        if (sCount == pCount) result.push_back(0);
        
        for (int i = np; i < ns; i++) {
            sCount[s[i] - 'a']++;
            sCount[s[i - np] - 'a']--;
            if (sCount == pCount) {
                result.push_back(i - np + 1);
            }
        }
        return result;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(26 \cdot n) = O(n)$ | $O(1)$ (output vector excluded) |

> **This is the one.** Direct extension of fixed-window permutation pattern.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `s.length() < p.length()` | Out of bounds on initial window | Returns `{}` immediately |
| Overlapping anagrams `s = "abab", p = "ab"` | Skipping adjacent matches | Sliding window advances by 1 step at a time, capturing `[0, 1, 2]` |
| All identical characters `s = "aaaa", p = "aa"` | Frequency match logic | Correctly returns `[0, 1, 2]` |

---

## Pattern Takeaway

Tracking all occurrences of anagrams simply requires **recording the window start index `i - k + 1`** on each successful fixed-frequency equality check.

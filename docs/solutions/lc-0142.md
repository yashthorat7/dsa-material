## What are we solving?

Given the `head` of a linked list, return the **node where the cycle begins**. If there is no cycle, return `nullptr`.

There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the `next` pointer.

You must not modify the linked list and must use strictly **$O(1)$ extra memory**.

```
 List:  (3) -> (2) -> (0) -> (-4)
                ^              |
                +--------------+
                
 Phase 1: Slow and Fast pointers collide at node (-4).
 Phase 2: Pointer 1 starts at Head (3), Pointer 2 starts at Collision (-4).
          Both advance 1 step at a time:
          Step 1: Ptr1 at (2), Ptr2 at (2) -> COLLISION AT CYCLE ENTRANCE!
          
 Output: Node with val = 2
```

### Input & Output Contract
- **Input:**
  - `head`: `ListNode*` reference ($0 \le n \le 10^4$, $-10^5 \le \text{Node.val} \le 10^5$).
- **Output:**
  - `ListNode*`: Pointer to the cycle entry node, or `nullptr` if acyclic.
- **Constraint:** Must run in $O(n)$ time and $O(1)$ auxiliary space.

### The Mathematical Derivation
Let:
- $L_1$ = distance from `head` to the cycle entrance node.
- $L_2$ = distance from the cycle entrance to the meeting point inside the cycle.
- $C$ = circumference (length) of the cycle.

When `slow` and `fast` collide:
$$\text{Distance by slow} = L_1 + L_2$$
$$\text{Distance by fast} = L_1 + L_2 + k \cdot C \quad (\text{where } k \ge 1)$$
Because `fast` travels at $2\times$ the speed of `slow`:
$$2(L_1 + L_2) = L_1 + L_2 + k \cdot C \implies L_1 + L_2 = k \cdot C \implies \mathbf{L_1 = k \cdot C - L_2}$$

$$\mathbf{\text{Distance from Head to Entrance } (L_1) \equiv \text{Distance from Meeting Point to Entrance } (k \cdot C - L_2)}$$

## Approach 1 — Hash Set Address Tracking ($O(n)$ Space)

### Intuition
Traverse the linked list and record the memory address (`ListNode*`) of each visited node in an `unordered_set<ListNode*>`. The first node encountered that is already in the set is the cycle entry!

### C++ Implementation
```cpp
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        unordered_set<ListNode*> visited;
        ListNode* curr = head;
        
        while (curr != nullptr) {
            if (visited.count(curr)) {
                return curr; // First repeated pointer is the cycle start
            }
            visited.insert(curr);
            curr = curr->next;
        }
        
        return nullptr; // No cycle
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear traversal with $O(1)$ amortized hash set lookups. |
| **Space** | $O(n)$ | Allocates storage for $n$ pointers. |

> **Verdict:** Suboptimal. Floyd's Tortoise and Hare algorithm achieves $O(1)$ space.

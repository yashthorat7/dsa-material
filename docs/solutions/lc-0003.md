# 3. Longest Substring Without Repeating Characters

https://leetcode.com/problems/longest-substring-without-repeating-characters

> **Medium** $\rightarrow$ **Sliding Window**

## What are we solving?

Given a string `s`, find the length of the **longest substring** without repeating characters.

The challenge is: **how can we advance the left window boundary directly past the previously seen duplicate in $O(1)$?**

**Example 1:**
```
Input:  s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3.
```

**Example 2:**
```
Input:  s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.
```

**Example 3:**
```
Input:  s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3. Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.
```

**Constraints:**
- $0 \le s.\text{length} \le 5 \times 10^4$
- `s` consists of English letters, digits, symbols and spaces.

## Approach 1 — Sliding Window with Last Seen Index Map ✅

**Key insight:** Maintain the last seen index of each character in a map or direct lookup table `lastSeen[256]` initialized to `-1`.
When we encounter character `s[right]`:
- If `lastSeen[s[right]] >= left`, a duplicate exists within our current window! Jump `left = lastSeen[s[right]] + 1`.
- Update `lastSeen[s[right]] = right`.
- Update `maxLen = max(maxLen, right - left + 1)`.

```
s = "abcabcbb"
lastSeen = [-1]*256, left = 0, maxLen = 0

right=0 ('a'): lastSeen['a']=-1 -> maxLen = 1, lastSeen['a'] = 0
right=1 ('b'): lastSeen['b']=-1 -> maxLen = 2, lastSeen['b'] = 1
right=2 ('c'): lastSeen['c']=-1 -> maxLen = 3, lastSeen['c'] = 2
right=3 ('a'): lastSeen['a']=0 >= left(0) -> jump left = 1, maxLen = 3, lastSeen['a'] = 3
right=4 ('b'): lastSeen['b']=1 >= left(1) -> jump left = 2, maxLen = 3, lastSeen['b'] = 4
right=5 ('c'): lastSeen['c']=2 >= left(2) -> jump left = 3, maxLen = 3, lastSeen['c'] = 5
right=6 ('b'): lastSeen['b']=4 >= left(3) -> jump left = 5, maxLen = 3, lastSeen['b'] = 6
right=7 ('b'): lastSeen['b']=6 >= left(5) -> jump left = 7, maxLen = 3, lastSeen['b'] = 7

Result: 3 ("abc") ✓
```

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> lastSeen(256, -1);
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.size(); right++) {
            if (lastSeen[(unsigned char)s[right]] >= left) {
                left = lastSeen[(unsigned char)s[right]] + 1;
            }
            lastSeen[(unsigned char)s[right]] = right;
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ (fixed 256-sized array) |

> **This is the one.** Direct index jumps provide true single-pass $O(n)$ runtime.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty string `""` | Loop does not run | Returns 0 directly |
| All identical characters `"bbbbb"` | `left` jumping | `left` advances with `right`, returning maxLen 1 |
| Duplicate character seen *before* current `left` boundary `"abba"` | Jumping `left` backwards to index 0 on second 'a' | Condition `lastSeen[c] >= left` ensures `left` never moves backward |

---

## Pattern Takeaway

By storing the **most recent index of each character**, the left window pointer can skip directly past duplicates without step-by-step while loop retraction.

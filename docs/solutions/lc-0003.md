# 3. Longest Substring Without Repeating Characters

https://leetcode.com/problems/longest-substring-without-repeating-characters

> **Medium** $\rightarrow$ **Sliding Window**


> **Companies:** Amazon, Microsoft, Meta, Bloomberg, Apple, Google, Walmart Global Tech, Samsung, Deloitte

## What are we solving?

Given a string `s`, find the length of the **longest substring** that contains no duplicate characters.

```
 String: " a   b   c   a   b   c   b   b "
          [---------]
          "abc" -> length = 3
                  [---------]
                  "bca" -> length = 3
                          [---------]
                          "cab" -> length = 3
                          
 Longest Unique Substring Length = 3
```

### Input & Output Contract
- **Input:**
  - `s`: `string` containing alphanumeric characters, punctuation, symbols, and spaces ($0 \le s.\text{length} \le 5 \times 10^4$).
- **Output:**
  - `int` representing the maximum length of any contiguous substring with all distinct characters.

### The Core Challenge
A substring must be contiguous (e.g. in `"pwwkew"`, `"wke"` is valid with length 3, but `"pwke"` is a subsequence, not a substring). The challenge is to expand and contract our search window in linear time $O(n)$ without repeatedly re-scanning previous characters.

---

**Example 1:**
```
Input:  s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3.
```

**Example 2:**
```
Input:  s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.
```

**Example 3:**
```
Input:  s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3.
```

**Constraints:**
- $0 \le s.\text{length} \le 5 \times 10^4$
- `s` consists of English letters, digits, symbols and spaces.

## Approach 1 — Brute Force (Check All Substrings)

### Intuition
The most direct approach: examine every possible substring `s[i..j]`, verify if all characters in it are unique using a hash set, and keep track of the maximum length seen.

### Step-by-Step Algorithm
1. Outer loop `i` from $0$ to $n-1$ (substring start).
2. Inner loop `j` from $i$ to $n-1$ (substring end).
3. If `s[j]` has already been seen in the current substring, break early.
4. Otherwise, insert `s[j]` into the set and update `maxLen = max(maxLen, j - i + 1)`.

```
s = "abcabcbb"
i=0: "a" (len 1), "ab" (len 2), "abc" (len 3), "abca" (duplicate 'a' -> break)
i=1: "b" (len 1), "bc" (len 2), "bca" (len 3), "bcab" (duplicate 'b' -> break)
...
```

### C++ Implementation
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.length();
        int maxLen = 0;
        
        for (int i = 0; i < n; i++) {
            vector<bool> seen(256, false);
            for (int j = i; j < n; j++) {
                unsigned char c = s[j];
                if (seen[c]) {
                    break; // duplicate found
                }
                seen[c] = true;
                maxLen = max(maxLen, j - i + 1);
            }
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | In the worst case (e.g. all unique characters), checks all pairs $(i, j)$. |
| **Space** | $O(\min(n, \Sigma))$ | 256-sized boolean table per start position. |

> **Verdict:** Times out on $n = 5 \times 10^4$ ($50,000^2 = 2.5 \times 10^9$ operations). We need a sliding window.

## Approach 2 — Sliding Window with Hash Set (Retracting Left Boundary)

### Intuition
Instead of restarting from scratch when a duplicate is found, maintain a dynamic window `[left, right]`. As `right` expands:
- If `s[right]` is already in our set, shrink the window from the `left` by erasing `s[left]` and incrementing `left++` until `s[right]` is no longer in the set.
- Then insert `s[right]` and record the window size.

```
s = "a b c a b c b b"
     l     r           set={a,b,c}, maxLen=3
       l   r           'a' duplicate: erase s[0]('a'), left=1, insert 'a' -> set={b,c,a}, maxLen=3
```

### C++ Implementation
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> windowChars;
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            while (windowChars.count(s[right])) {
                windowChars.erase(s[left]);
                left++;
            }
            windowChars.insert(s[right]);
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(2n) = O(n)$ | Each character is visited at most twice: once by `right` and once by `left`. |
| **Space** | $O(\min(n, \Sigma))$ | Hash set stores at most $\Sigma = 128$ distinct ASCII characters. |

> **Much better!** But can we skip step-by-step `left++` retraction and jump `left` in $O(1)$?

## Approach 3 — Sliding Window with Direct Index Jump Map ✅

### Key Insight
Store the **most recent 0-indexed position** of every character in a direct array `lastSeen[256]` (initialized to `-1`).  
When `s[right]` is encountered:
- If `lastSeen[s[right]] >= left`, the character appeared inside our current window!
- Jump `left = lastSeen[s[right]] + 1` directly past the duplicate in **one step**!
- Update `lastSeen[s[right]] = right` and `maxLen = max(maxLen, right - left + 1)`.

```
s = "a b c a b c b b"
lastSeen = [-1]*256, left = 0, maxLen = 0

right=0 ('a'): lastSeen['a']=-1 -> maxLen = 1, lastSeen['a'] = 0
right=1 ('b'): lastSeen['b']=-1 -> maxLen = 2, lastSeen['b'] = 1
right=2 ('c'): lastSeen['c']=-1 -> maxLen = 3, lastSeen['c'] = 2
right=3 ('a'): lastSeen['a']=0 >= left(0) -> direct jump left = 1, maxLen = 3, lastSeen['a'] = 3
right=4 ('b'): lastSeen['b']=1 >= left(1) -> direct jump left = 2, maxLen = 3, lastSeen['b'] = 4
right=5 ('c'): lastSeen['c']=2 >= left(2) -> direct jump left = 3, maxLen = 3, lastSeen['c'] = 5
right=6 ('b'): lastSeen['b']=4 >= left(3) -> direct jump left = 5, maxLen = 3, lastSeen['b'] = 6
right=7 ('b'): lastSeen['b']=6 >= left(5) -> direct jump left = 7, maxLen = 3, lastSeen['b'] = 7

Result: 3 ("abc") ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> lastSeen(256, -1);
        int maxLen = 0;
        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            unsigned char c = s[right];
            
            // If duplicate is within current window, jump left past it
            if (lastSeen[c] >= left) {
                left = lastSeen[c] + 1;
            }
            
            lastSeen[c] = right;
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Strictly single pass. `right` advances from $0$ to $n-1$; `left` jumps directly in $O(1)$. |
| **Space** | $O(1)$ | Fixed 256-element array regardless of input string length. |

> **This is the one.** Single pass, zero memory re-allocation, cache-friendly array indexing.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty String** | `""` | Loop does not execute. | Returns initial `maxLen = 0`. |
| **All Identical Characters** | `"bbbbb"` | Window size stays 1. | `left` advances with each step (`left = lastSeen['b'] + 1`), returns 1. |
| **Duplicate Outside Window** | `"abba"` | At index 3 ('a'), `lastSeen['a'] = 0`, but `left = 2`! | Guard `lastSeen[c] >= left` ensures `left` never jumps backwards. |
| **Spaces and Symbols** | `"a b! a"` | Character table boundary overflow. | Cast to `unsigned char` ensures array indices stay strictly within $[0, 255]$. |

---

## Pattern Takeaways

1. **The Direct Jump Optimization:**  
   In sliding window problems with uniqueness constraints, storing indices (`lastSeen[char] = index`) rather than frequencies enables $O(1)$ pointer jumps instead of while-loop element deletion.
2. **The Invariant Rule:**  
   Always check `lastSeen[c] >= left` before jumping to prevent moving the left boundary backwards past stale indices from previous windows.

## What are we solving?

You are given a string `s`. You can convert `s` to a palindrome by adding characters in front of it. Return the **shortest palindrome** you can find by performing this transformation.

The core insight is: **find the longest palindromic prefix of `s`. Then reverse the remaining suffix and prepend it to `s`.**

**Example 1:**
```
Input:  s = "aacecaaa"
Output: "aaacecaaa"
```

**Example 2:**
```
Input:  s = "abcd"
Output: "dcbabcd"
```

**Constraints:**
- $0 \le s.\text{length} \le 5 \times 10^4$
- `s` consists of lowercase English letters only.

## Approach 1 — KMP Prefix Table (pi array) ✅

**Key insight:**
We need the longest palindromic prefix of `s`.
Construct a combined string: `temp = s + '#' + reverse(s)`.
Compute the KMP prefix table (`pi` / `lps` array) for `temp`.
The last value `pi.back()` gives the length of the longest prefix of `s` that is also a suffix of `reverse(s)` — which is precisely the **longest palindromic prefix** of `s`!
The remaining suffix after index `lps` is reversed and prepended to `s`.

```
s = "aacecaaa"
rev_s = "aaacecaa"
temp = "aacecaaa#aaacecaa"

KMP prefix table for temp:
temp:  a a c e c a a a # a a a c e c a a
pi:    0 1 0 0 0 1 2 2 0 1 2 2 3 4 5 6 7
pi.back() = 7 -> Longest palindromic prefix length = 7 ("aacecaa")
Remaining suffix = s[7..7] = "a"
Reversed remaining suffix = "a"
Prepend to s: "a" + "aacecaaa" = "aaacecaaa" ✓
```

```cpp
class Solution {
public:
    string shortestPalindrome(string s) {
        int n = s.size();
        if (n <= 1) return s;
        
        string rev = s;
        reverse(rev.begin(), rev.end());
        string temp = s + '#' + rev;
        
        int m = temp.size();
        vector<int> pi(m, 0);
        for (int i = 1; i < m; i++) {
            int j = pi[i - 1];
            while (j > 0 && temp[i] != temp[j]) {
                j = pi[j - 1];
            }
            if (temp[i] == temp[j]) j++;
            pi[i] = j;
        }
        
        int palPrefixLen = pi[m - 1];
        string suffixToAdd = s.substr(palPrefixLen);
        reverse(suffixToAdd.begin(), suffixToAdd.end());
        
        return suffixToAdd + s;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** Optimal linear KMP algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty string `""` or single char `"a"` | Empty vector / indexing | Returns `s` immediately |
| String is already a palindrome `"racecar"` | Adding unnecessary chars | `palPrefixLen = 7`, `suffixToAdd = ""`, returns `"racecar"` |
| No common prefix `"abcd"` | Full prepend | `palPrefixLen = 1`, prepends `"dcb"` -> `"dcbabcd"` |

---

## Pattern Takeaway

Finding the **longest palindromic prefix** is equivalent to finding the **longest proper prefix-suffix match** of `s + '#' + reverse(s)` using the **KMP LPS array** in $O(n)$.

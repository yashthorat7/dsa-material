## What are we solving?

You are given a string `s`. You can convert `s` to a palindrome by **adding characters in front of it**.

Return the **shortest palindrome** you can find by performing this transformation.

```
 s = " a a c e c a a a "
 
 Longest Palindromic Prefix: " a a c e c a a "  (Length 7)
 Remaining Unmatched Suffix: " a "              (Length 1)
 
 Suffix to Prepend: reverse(" a ") = " a "
 Shortest Palindrome: " a " + " a a c e c a a a " = " a a a c e c a a a "
 
 Output: "aaacecaaa"
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of lowercase English letters ($0 \le n \le 5 \times 10^4$).
- **Output:**
  - `string`: Shortest palindrome formed by prepending characters to `s`.

### The Core Challenge
To minimize the number of characters prepended to $s$, we must find the **longest palindromic prefix** of $s$:
1. Let the longest palindromic prefix have length $L$.
2. The remaining suffix of $s$ from index $L$ to $n - 1$ must be reversed and prepended to $s$.
3. How to compute $L$ in $O(n)$ time? Construct string:
   $$\text{combined} = s + \mathbf{'\#'} + \text{reverse}(s)$$
   and compute the **KMP Longest Prefix Suffix (LPS) array**!

---

**Example 1:**
```
Input:  s = "aacecaaa"
Output: "aaacecaaa"
```

**Example 2:**
```
Input:  s = "abcd"
Output: "dcbabcd"
```

**Constraints:**
- $0 \le s.\text{length} \le 5 \times 10^4$
- `s` consists of lowercase English letters only.

## Approach 1 — Brute Force Prefix Scan ($O(n^2)$)

### Intuition
Find the longest palindrome starting at index 0. Test candidate prefixes $s[0..i]$ backwards from $i = n - 1$ down to 0. The first prefix that is a valid palindrome leaves suffix $s[i+1..n-1]$, which is reversed and prepended to $s$.

### C++ Implementation
```cpp
class Solution {
public:
    string shortestPalindrome(string s) {
        int n = s.size();
        for (int i = n - 1; i >= 0; i--) {
            if (isPalindrome(s, 0, i)) {
                string suffix = s.substr(i + 1);
                reverse(suffix.begin(), suffix.end());
                return suffix + s;
            }
        }
        return s;
    }

private:
    bool isPalindrome(const string& s, int l, int r) {
        while (l < r) {
            if (s[l++] != s[r--]) return false;
        }
        return true;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | $n$ prefix checks $\times O(n)$ palindrome verification. |
| **Space** | $O(n)$ | Suffix string construction. |

> **Verdict:** Suboptimal. KMP LPS array finds the longest palindromic prefix in $O(n)$ linear time.

## Approach 2 — KMP LPS Table on `s + '#' + rev(s)` ✅

### Key Insight
1. Let `rev = reverse(s)`.
2. Form composite string `temp = s + '#' + rev`.
   - The delimiter `'#'` ensures the prefix match never extends beyond the length of $s$.
3. Compute the **KMP $\pi$ (LPS) array** for `temp`:
   - `pi[i]` represents the length of the longest proper prefix of `temp` that is also a suffix of `temp[0...i]`.
4. The final entry `pi.back()` is precisely the **length of the longest palindromic prefix of $s$**!
5. Extract suffix `suffix = s.substr(pi.back())`, reverse it, and prepend:
   $$\text{return } \text{reverse}(\text{suffix}) + s$$

```
s = "aacecaaa"
rev = "aaacecaa"
temp = "aacecaaa#aaacecaa"

KMP LPS array calculation:
temp:  a a c e c a a a # a a a c e c a a
pi:    0 1 0 0 0 1 2 2 0 1 2 2 3 4 5 6 7

pi.back() = 7 -> Longest Palindromic Prefix = "aacecaa" (length 7)
Unmatched suffix = s[7] = "a"
Reversed suffix = "a"
Output = "a" + "aacecaaa" = "aaacecaaa" ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    string shortestPalindrome(string s) {
        int n = s.length();
        if (n <= 1) return s;
        
        string rev = s;
        reverse(rev.begin(), rev.end());
        string temp = s + '#' + rev;
        
        int m = temp.length();
        vector<int> pi(m, 0);
        
        // Build KMP LPS array
        for (int i = 1; i < m; i++) {
            int j = pi[i - 1];
            while (j > 0 && temp[i] != temp[j]) {
                j = pi[j - 1];
            }
            if (temp[i] == temp[j]) {
                j++;
            }
            pi[i] = j;
        }
        
        int palPrefixLen = pi.back();
        string suffixToPrepend = s.substr(palPrefixLen);
        reverse(suffixToPrepend.begin(), suffixToPrepend.end());
        
        return suffixToPrepend + s;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Building KMP table takes linear time proportional to $2n + 1$. |
| **Space** | $O(n)$ | `temp` string and LPS integer array of size $2n + 1$. |

> **This is the one.** Mathematically optimal string prefix matching in strict $O(n)$ time.

## Approach 3 — Rabin-Karp Rolling Hash ($O(n)$ Time, $O(1)$ Space)

### Intuition
Maintain forward and reverse polynomial rolling hashes of prefix $s[0..i]$. When forward hash equals reverse hash, prefix $s[0..i]$ is a palindrome candidate!

### C++ Implementation
```cpp
class Solution {
public:
    string shortestPalindrome(string s) {
        int n = s.size();
        if (n <= 1) return s;
        
        long long base = 29, mod = 1e9 + 7;
        long long forwardHash = 0, reverseHash = 0, power = 1;
        int longestPrefix = 0;
        
        for (int i = 0; i < n; i++) {
            int val = s[i] - 'a' + 1;
            forwardHash = (forwardHash * base + val) % mod;
            reverseHash = (reverseHash + val * power) % mod;
            power = (power * base) % mod;
            
            if (forwardHash == reverseHash) {
                longestPrefix = i;
            }
        }
        
        string suffix = s.substr(longestPrefix + 1);
        reverse(suffix.begin(), suffix.end());
        return suffix + s;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single linear pass updating rolling hashes. |
| **Space** | $O(n)$ | Suffix string construction. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty String or Single Character** | `""` or `"a"` | Vector indexing | `if (n <= 1) return s;` returns immediately. |
| **Already a Palindrome** | `"racecar"` | Redundant prepends | `pi.back() = 7`, `suffix = ""`, returns `"racecar"`. |
| **Completely Asymmetric String** | `"abcd"` | Zero prefix match | `pi.back() = 1`, prepends `"dcb"` $\rightarrow$ `"dcbabcd"`. |

## Pattern Takeaways

1. **Longest Palindromic Prefix via KMP:**  
   $$\text{Longest Palindromic Prefix}(s) \equiv \text{LPS}(s + \text{'\#'} + \text{reverse}(s))$$
2. **KMP Delimiter Invariant:**  
   The non-alphanumeric sentinel delimiter `#'` is required to prevent the LPS match length from exceeding the original string length $n$.

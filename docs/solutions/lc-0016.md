## What are we solving?

Given an integer array `nums` of length $n$ and an integer `target`, find three integers in `nums` such that their sum is **closest to target**.

Return the **sum of the three integers**. You may assume that each input has exactly one unique closest sum.

```
 nums = [ -1, 2, 1, -4 ],  target = 1
 
 Sorted nums: [ -4, -1, 1, 2 ]
 
 Triplet: (-1) + (2) + (1) = 2
 Difference: |2 - 1| = 1 (Closest possible sum)
 
 Output: 2
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($3 \le n \le 500$, $-1000 \le \text{nums}[i] \le 1000$).
  - `target`: `int` ($-10^4 \le \text{target} \le 10^4$).
- **Output:**
  - `int`: Value of the triplet sum that minimizes $|\text{sum} - \text{target}|$.

---

**Example 1:**
```
Input:  nums = [-1,2,1,-4], target = 1
Output: 2
Explanation: The sum that is closest to the target is 2. (-1 + 2 + 1 = 2).
```

**Example 2:**
```
Input:  nums = [0,0,0], target = 1
Output: 0
Explanation: The sum that is closest to the target is 0. (0 + 0 + 0 = 0).
```

**Constraints:**
- $3 \le \text{nums.length} \le 500$
- $-1000 \le \text{nums}[i] \le 1000$
- $-10^4 \le \text{target} \le 10^4$

## Approach 1 — Brute Force (3 Nested Loops)

### Intuition
The most naive interview instinct: iterate through every possible triplet $(i, j, k)$ with $0 \le i < j < k < n$, compute their sum $S = 	ext{nums}[i] + 	ext{nums}[j] + 	ext{nums}[k]$, and update the closest sum seen so far whenever $|S - 	ext{target}| < |	ext{closestSum} - 	ext{target}|$.

### C++ Implementation
```cpp
class Solution {
public:
    int threeSumClosest(vector<int>& nums, int target) {
        int n = nums.size();
        int closestSum = nums[0] + nums[1] + nums[2];
        
        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                for (int k = j + 1; k < n; k++) {
                    int currentSum = nums[i] + nums[j] + nums[k];
                    if (abs(currentSum - target) < abs(closestSum - target)) {
                        closestSum = currentSum;
                    }
                }
            }
        }
        
        return closestSum;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^3)$ | $\frac{n(n-1)(n-2)}{6}$ triplet evaluations. TLEs on $n \ge 1000$. |
| **Space** | $O(1)$ | Constant extra space. |

> **Verdict:** Suboptimal. Sorting allows us to reduce the search from cubic to quadratic using two pointers.

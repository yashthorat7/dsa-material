## What are we solving?

A tree is an undirected graph in which any two vertices are connected by exactly one path (a connected acyclic graph).

Given a tree of $n$ nodes labelled from $0$ to $n - 1$, and an array of $n - 1$ undirected `edges` where `edges[i] = [ai, bi]`, you can choose any node of the tree as the root.

Return a list of all **Minimum Height Trees' (MHT) root labels**. You may return the answer in any order.

```
 Tree (n = 6):
 0 --- 3 --- 4 --- 5
       |
     1-+-2
     
 If Root = 3: Height = 2
 If Root = 4: Height = 2
 If Root = 0: Height = 3
 
 Centroids (MHT Roots): [ 3, 4 ]
```

### Input & Output Contract
- **Input:**
  - `n`: `int` number of vertices ($1 \le n \le 2 \times 10^4$).
  - `edges`: `vector<vector<int>>` of size $n - 1$.
- **Output:**
  - `vector<int>`: 1 or 2 node indices that minimize overall tree height.

### The Centroid Theorem
Any connected tree has **at most 2 centroids** (middle nodes along the longest diameter path of the tree):
- If the diameter has an odd number of vertices, there is **1 centroid**.
- If the diameter has an even number of vertices, there are **2 centroids**.
- Trimming the outer leaf boundary layer-by-layer (like peeling an onion) isolates the centroids in **$O(V)$ time**.

---

**Example 1:**
```
Input:  n = 4, edges = [[1,0],[1,2],[1,3]]
Output: [1]
Explanation: When root is node 1, tree height is 1.
```

**Example 2:**
```
Input:  n = 6, edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]
Output: [3,4]
```

**Constraints:**
- $1 \le n \le 2 \times 10^4$
- $\text{edges.length} == n - 1$
- $\text{edges}[i].\text{length} == 2$
- $0 \le a_i, b_i < n$
- $a_i \neq b_i$
- All pairs $(a_i, b_i)$ are distinct and form a valid connected tree.

## Approach 1 — Brute Force BFS from Every Node ($O(V^2)$)

### Intuition
Run BFS starting from each of the $n$ nodes to compute the maximum distance (height) to any other node. Return the nodes with the minimal height.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> findMinHeightTrees(int n, vector<vector<int>>& edges) {
        if (n == 1) return {0};
        vector<vector<int>> adj(n);
        for (const auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        
        vector<int> heights(n, 0);
        int minH = INT_MAX;
        
        for (int i = 0; i < n; i++) {
            // BFS from node i to find tree height
            queue<int> q;
            vector<bool> visited(n, false);
            q.push(i);
            visited[i] = true;
            int h = 0;
            
            while (!q.empty()) {
                int sz = q.size();
                for (int s = 0; s < sz; s++) {
                    int u = q.front(); q.pop();
                    for (int v : adj[u]) {
                        if (!visited[v]) {
                            visited[v] = true;
                            q.push(v);
                        }
                    }
                }
                if (!q.empty()) h++;
            }
            heights[i] = h;
            minH = min(minH, h);
        }
        
        vector<int> result;
        for (int i = 0; i < n; i++) {
            if (heights[i] == minH) result.push_back(i);
        }
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V \cdot (V + E)) = O(V^2)$ | $V$ BFS sweeps on tree ($E = V - 1$). TLE on $V = 2 \times 10^4$. |
| **Space** | $O(V)$ | Adjacency list and BFS queue. |

## Approach 3 — Tree Diameter Midpoints (Two BFS Passes)

### Intuition
1. Pick arbitrary node 0, run BFS to find farthest node $A$.
2. Run BFS from $A$ to find farthest node $B$ and reconstruct path $A \rightarrow B$ (the tree diameter).
3. The MHT roots are the 1 or 2 middle nodes of path $A \rightarrow B$.

### C++ Implementation
```cpp
class Solution {
public:
    vector<int> findMinHeightTrees(int n, vector<vector<int>>& edges) {
        if (n == 1) return {0};
        vector<vector<int>> adj(n);
        for (const auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        
        auto bfs = [&](int start, vector<int>& parent) -> int {
            vector<int> dist(n, -1);
            queue<int> q;
            q.push(start);
            dist[start] = 0;
            int farthest = start;
            
            while (!q.empty()) {
                int u = q.front(); q.pop();
                if (dist[u] > dist[farthest]) farthest = u;
                for (int v : adj[u]) {
                    if (dist[v] == -1) {
                        dist[v] = dist[u] + 1;
                        parent[v] = u;
                        q.push(v);
                    }
                }
            }
            return farthest;
        };
        
        vector<int> parent1(n, -1);
        int nodeA = bfs(0, parent1);
        
        vector<int> parent2(n, -1);
        int nodeB = bfs(nodeA, parent2);
        
        vector<int> path;
        for (int curr = nodeB; curr != -1; curr = parent2[curr]) {
            path.push_back(curr);
        }
        
        int len = path.size();
        if (len % 2 == 1) return {path[len / 2]};
        return {path[len / 2 - 1], path[len / 2]};
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(V)$ | Two BFS passes across tree. |
| **Space** | $O(V)$ | Path and parent arrays. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Node `n = 1`** | `n = 1, edges = []` | `degree[0] == 0` (never enters queue) | Early check `if (n == 1) return {0};`. |
| **Two Nodes `n = 2`** | `edges = [[0, 1]]` | Loop doesn't run | `remainingNodes = 2 <= 2`, returns `{0, 1}`. |
| **Star Graph** | Node 0 connected to all $1 \dots n-1$ | Single step trim | All outer nodes pruned in 1 layer, returns `{0}`. |

## What are we solving?

Given an input string `s`, reverse the order of the **words**. A word is defined as a sequence of non-space characters. The words in `s` will be separated by at least one space. Return a string of the words in reverse order concatenated by a single space.

Note that `s` may contain leading or trailing spaces or multiple spaces between two words. The returned string should only have a single space separating the words. Do not include any extra spaces.

The question is: **how do we reverse the whole string and then reverse each individual word in-place?**

**Example 1:**
```
Input:  s = "the sky is blue"
Output: "blue is sky the"
```

**Example 2:**
```
Input:  s = "  hello world  "
Output: "world hello"
Explanation: Your reversed string should not contain leading or trailing spaces.
```

**Example 3:**
```
Input:  s = "a good   example"
Output: "example good a"
Explanation: You need to reduce multiple spaces between two words to a single space in the reversed string.
```

**Constraints:**
- $1 \le s.\text{length} \le 10^4$
- `s` contains English letters (upper-case and lower-case), digits, and spaces `' '`.
- There is at least one word in `s`.

## Approach 1 — Reverse All + Reverse Words + Clean Spaces ✅

**Key insight:**
1. Reverse the entire string: `"the sky is blue"` -> `"eulb si yks eht"`.
2. Reverse each word back: `"blue is sky the"`.
3. Clean up extra leading, trailing, and multiple spaces using a two-pointer write index.

```
s = "  the  sky  "
1. Reverse all: "  yks  eht  "
2. Clean spaces & reverse individual words:
   Write word "sky", reverse -> "sky"
   Add space -> "sky "
   Write word "the", reverse -> "sky the"
3. Resize string to cleaned length.

Result: "sky the" ✓
```

```cpp
class Solution {
public:
    string reverseWords(string s) {
        // Reverse whole string
        reverse(s.begin(), s.end());
        int n = s.size();
        int writeIdx = 0;
        
        for (int start = 0; start < n; start++) {
            if (s[start] != ' ') {
                if (writeIdx != 0) s[writeIdx++] = ' ';
                int end = start;
                while (end < n && s[end] != ' ') {
                    s[writeIdx++] = s[end++];
                }
                // Reverse the word just written
                reverse(s.begin() + writeIdx - (end - start), s.begin() + writeIdx);
                start = end;
            }
        }
        s.resize(writeIdx);
        return s;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Truly in-place reversal with $O(1)$ extra space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Multiple consecutive spaces `"a   b"` | Extra spaces preserved | Write pointer logic outputs exactly 1 space between words |
| Leading and trailing spaces `"  hello  "` | Dangling space in output | `writeIdx != 0` check guarantees no leading/trailing space |
| Single word `"world"` | Space insertion errors | Outputs `"world"` |

---

## Pattern Takeaway

**Two-step reversal (Reverse Entire String + Reverse Each Segment)** reverses word order while preserving character order within words.

## What are we solving?

Given an input string `s`, reverse the order of the **words**.

A **word** is defined as a sequence of non-space characters. The words in `s` will be separated by at least one space.

Return a string of the words in reverse order concatenated by a **single space**.
- `s` may contain leading or trailing spaces or multiple spaces between two words.
- The returned string must not contain leading, trailing, or multiple consecutive spaces.

```
 Input:   "  the   sky   is   blue  "
 Output:  "blue is sky the"
```

### Input & Output Contract
- **Input:**
  - `s`: `string` where $1 \le n \le 10^4$, containing English letters, digits, and spaces.
  - At least one word is guaranteed to exist.
- **Output:**
  - `string` containing the normalized reversed word string.

### The Core Challenge
If we allocate intermediate word arrays or use string streams, space complexity is $O(n)$.  
To achieve **$O(1)$ auxiliary space**, we use the classic **Two-Step Reversal**:
1. Reverse the entire string: `"the sky is blue"` $\rightarrow$ `"eulb si yks eht"`.
2. Reverse each individual word back into original orientation: `"blue is sky the"`.
3. Compress multi-spaces in-place with a reader/writer two-pointer index.

---

**Example 1:**
```
Input:  s = "the sky is blue"
Output: "blue is sky the"
```

**Example 2:**
```
Input:  s = "  hello world  "
Output: "world hello"
Explanation: Your reversed string should not contain leading or trailing spaces.
```

**Example 3:**
```
Input:  s = "a good   example"
Output: "example good a"
Explanation: You need to reduce multiple spaces between two words to a single space.
```

**Constraints:**
- $1 \le s.\text{length} \le 10^4$
- `s` contains English letters (upper-case and lower-case), digits, and spaces `' '`.
- There is at least one word in `s`.

## Approach 1 — String Stream Token Extraction ($O(n)$ Space)

### Intuition
Use C++ `stringstream` to extract individual words automatically bypassing multiple whitespaces, store them in a vector, and concatenate in reverse order.

### C++ Implementation
```cpp
class Solution {
public:
    string reverseWords(string s) {
        stringstream ss(s);
        string word;
        vector<string> words;
        
        while (ss >> word) {
            words.push_back(word);
        }
        
        string result = "";
        for (int i = words.size() - 1; i >= 0; i--) {
            result += words[i];
            if (i > 0) result += " ";
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Reads all characters into words and builds result string. |
| **Space** | $O(n)$ | Stores tokens in a vector. |

## Approach 2 — In-Place Reversal & Space Compression ✅

### Key Insight
1. **Reverse the entire string** in-place: `reverse(s.begin(), s.end())`.
2. **Reader/Writer Two-Pointer Pass:**
   - Maintain `writeIdx = 0`.
   - Whenever we encounter the start of a non-space word at index `start`:
     - If `writeIdx != 0`, insert a single separating space `' '`.
     - Copy the word forward to `writeIdx`.
     - Reverse the newly copied word in-place: `reverse(s.begin() + wordStart, s.begin() + writeIdx)`.
3. **Resize `s`** to `writeIdx`.

```
s = "  the  sky  "

Step 1: Reverse all:
"  yks  eht  "

Step 2: Read & write words:
- Word 1 ("yks"): write at index 0 -> "yks", reverse -> "sky", writeIdx = 3
- Insert space at index 3 -> "sky "
- Word 2 ("eht"): write at index 4 -> "sky eht", reverse -> "sky the", writeIdx = 7

Step 3: Resize s to writeIdx (7) -> "sky the" ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    string reverseWords(string s) {
        int n = s.length();
        
        // Step 1: Reverse the entire string
        reverse(s.begin(), s.end());
        
        int writeIdx = 0;
        
        // Step 2: Read words, compress spaces, and reverse words individually
        for (int start = 0; start < n; start++) {
            if (s[start] != ' ') {
                // If not the first word, append a single space
                if (writeIdx != 0) {
                    s[writeIdx++] = ' ';
                }
                
                int wordStart = writeIdx;
                int end = start;
                
                // Copy current word forward
                while (end < n && s[end] != ' ') {
                    s[writeIdx++] = s[end++];
                }
                
                // Reverse the word back to its original spelling
                reverse(s.begin() + wordStart, s.begin() + writeIdx);
                
                start = end;
            }
        }
        
        // Step 3: Truncate string to clean written length
        s.resize(writeIdx);
        return s;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two passes over the string with in-place swaps. |
| **Space** | $O(1)$ | Pure in-place character shifting and reversing. |

> **This is the one.** Truly in-place word reversal with optimal linear time and constant memory.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Leading & Trailing Spaces** | `"   hello world   "` | Dangling boundary space | `writeIdx != 0` only adds spaces *between* words; trailing spaces discarded by `s.resize()`. |
| **Multiple Consecutive Spaces** | `"a    b"` | Multiple spaces preserved | Loop skips consecutive spaces automatically. |
| **Single Word** | `"world"` | Missing space handling | Returns `"world"`. |

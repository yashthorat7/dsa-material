## What are we solving?

Implement the `myAtoi(string s)` function, which converts a string into a **32-bit signed integer** (similar to C/C++'s `atoi` function).

The algorithm proceeds in 4 deterministic steps:
1. **Whitespace:** Ignore any leading whitespace (`" "`).
2. **Signedness:** Check if the next character is `'-'` or `'+'`. Default to positive if neither is present.
3. **Conversion:** Read contiguous digits (`0-9`) until a non-digit character or end-of-string is reached. If no digits were read, the integer is `0`.
4. **Rounding (Clamping):** If the integer exceeds 32-bit signed integer limits $[-2^{31}, 2^{31} - 1]$, clamp to `INT_MIN` ($-2147483648$) or `INT_MAX` ($2147483647$).

```
 Input:  s = "   -042 with words"
 1. Whitespace: "   " skipped
 2. Sign:       '-' detected -> sign = -1
 3. Conversion: "042" read -> 42
 4. Clamping:   -42 is within [-2^31, 2^31 - 1]
 
 Output: -42
```

### Input & Output Contract
- **Input:**
  - `s`: `string` of length $0 \le n \le 200$, containing English letters, digits, spaces, `'+'`, `'-'`, and `'.'`.
- **Output:**
  - `int`: Parsed signed 32-bit integer clamped to range $[-2^{31}, 2^{31} - 1]$.

### The Core Challenge
Handling overflow **before** multiplying by 10 or adding a digit without relying on 64-bit integer casting:
$$\text{Overflow occurs if: } \text{res} > \lfloor \text{INT\_MAX} / 10 \rfloor \quad \text{or} \quad (\text{res} == \lfloor \text{INT\_MAX} / 10 \rfloor \land \text{digit} > 7)$$

## Approach 1 — 4-Stage Deterministic Parser ✅

### Key Insight
1. **Advance index `i`** past leading spaces: `while (i < n && s[i] == ' ') i++;`.
2. **Read Sign:** If `s[i] == '-'`, set `sign = -1, i++`. If `s[i] == '+'`, set `sign = 1, i++`.
3. **Parse Digits with Pre-Multiplication Overflow Checks:**
   While `i < n && isdigit(s[i])`:
   - `digit = s[i] - '0'`
   - Check if `result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7)`:
     - Return `sign == 1 ? INT_MAX : INT_MIN`.
   - `result = result * 10 + digit, i++`.
4. Return `result * sign`.

```
s = " -042"
1. Skip space: i = 1
2. Sign: s[1] == '-' -> sign = -1, i = 2
3. Digits:
   i=2 ('0'): result = 0
   i=3 ('4'): result = 4
   i=4 ('2'): result = 42
4. Return sign * result = -1 * 42 = -42 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int myAtoi(string s) {
        int i = 0, n = s.length();
        
        // 1. Skip leading whitespaces
        while (i < n && s[i] == ' ') {
            i++;
        }
        if (i == n) return 0;
        
        // 2. Determine sign
        int sign = 1;
        if (s[i] == '+' || s[i] == '-') {
            sign = (s[i] == '-') ? -1 : 1;
            i++;
        }
        
        // 3. Convert digits with strict 32-bit overflow guarding
        int result = 0;
        while (i < n && isdigit(s[i])) {
            int digit = s[i] - '0';
            
            // INT_MAX is 2147483647 (ends in 7), INT_MIN is -2147483648 (ends in 8)
            if (result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7)) {
                return (sign == 1) ? INT_MAX : INT_MIN;
            }
            
            result = result * 10 + digit;
            i++;
        }
        
        return result * sign;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single pass over string of length $\le 200$. |
| **Space** | $O(1)$ | Pure stack primitive registers. |

> **This is the one.** Clean, robust overflow protection adhering strictly to 32-bit constraints.

## Approach 2 — Deterministic Finite Automaton (DFA State Machine)

### Intuition
Model character streaming formally with 4 states:
- `State 0 (Start)`: Discard leading whitespaces. Next: sign -> State 1, digit -> State 2, other -> State 3 (End).
- `State 1 (Signed)`: Next: digit -> State 2, other -> State 3.
- `State 2 (Digit)`: Accumulate digits with clamping. Next: digit -> State 2, other -> State 3.
- `State 3 (End)`: Terminate and return result.

### C++ Implementation
```cpp
class Solution {
public:
    int myAtoi(string s) {
        int state = 0; // 0: Start, 1: Signed, 2: Digits, 3: Dead
        long long num = 0;
        int sign = 1;
        
        for (char c : s) {
            if (state == 0) {
                if (c == ' ') continue;
                if (c == '+' || c == '-') {
                    sign = (c == '-') ? -1 : 1;
                    state = 1;
                } else if (isdigit(c)) {
                    num = c - '0';
                    state = 2;
                } else {
                    state = 3;
                }
            } else if (state == 1 || state == 2) {
                if (isdigit(c)) {
                    state = 2;
                    num = num * 10 + (c - '0');
                    if (sign * num >= INT_MAX) return INT_MAX;
                    if (sign * num <= INT_MIN) return INT_MIN;
                } else {
                    state = 3;
                }
            }
            if (state == 3) break;
        }
        
        return sign * num;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Strictly single pass, deterministic transition per character. |
| **Space** | $O(1)$ | Pure scalar state register. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Overflow Past `INT_MAX`** | `"2147483648"` | Undefined signed integer overflow | `result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7)` clamps to `INT_MAX`. |
| **Underflow Past `INT_MIN`** | `"-2147483649"` | Undefined signed integer overflow | Clamps to `INT_MIN`. |
| **Sign Embedded Inside Digits** | `"0-1"` | Treating `-` as negative sign | Stops parsing at `-`, returns `0`. |
| **Whitespace Only** | `"   "` | Out-of-bounds index access | `i == n` guard returns `0`. |

## Pattern Takeaways

1. **Pre-Multiplication Overflow Guard:**  
   To prevent signed 32-bit overflow before `res = res * 10 + d`, check:
   `if (res > INT_MAX / 10 || (res == INT_MAX / 10 && d > 7)) return (sign == 1) ? INT_MAX : INT_MIN;`

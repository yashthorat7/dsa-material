## What are we solving?

Implement the `myAtoi(string s)` function, which converts a string to a 32-bit signed integer.

The algorithm for `myAtoi(string s)` is as follows:
1. **Whitespace:** Ignore any leading whitespace (`" "`).
2. **Signedness:** Determine the sign by checking if the next character is `'-'` or `'+'`, assuming positivity if neither present.
3. **Conversion:** Read the integer by ignoring leading zeros until a non-digit character is encountered or end of string. If no digits were read, then the integer is `0`.
4. **Rounding:** If the integer is out of the 32-bit signed integer range $[-2^{31}, 2^{31} - 1]$, then clamp the integer to stay within range.

The question is: **how to handle overflow detection before multiplying by 10 without 64-bit storage?**

**Example 1:**
```
Input:  s = "42"
Output: 42
```

**Example 2:**
```
Input:  s = " -042"
Output: -42
```

**Example 3:**
```
Input:  s = "1337c0d3"
Output: 1337
```

**Example 4:**
```
Input:  s = "0-1"
Output: 0
```

**Example 5:**
```
Input:  s = "words and 987"
Output: 0
```

**Constraints:**
- $0 \le s.\text{length} \le 200$
- `s` consists of English letters (lower-case and upper-case), digits (`0-9`), `' '`, `'+'`, `'-'`, and `'.'`.

## Approach 1 — Sequential Deterministic Parsing ✅

**Key insight:**
1. Advance pointer `i` past leading spaces `s[i] == ' '`.
2. Check sign: if `s[i] == '-'`, `sign = -1, i++`; else if `s[i] == '+'`, `sign = 1, i++`.
3. Process digits `isdigit(s[i])`:
   - Overflow condition: `if (result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7))`:
     - return `sign == 1 ? INT_MAX : INT_MIN`.
   - Update: `result = result * 10 + digit`.
4. Return `result * sign`.

```
s = " -042"
1. Skip spaces: i = 1
2. Sign: s[1] == '-' -> sign = -1, i = 2
3. Digits:
   i=2 ('0'): result = 0
   i=3 ('4'): result = 4
   i=4 ('2'): result = 42
4. End of digits. Return -1 * 42 = -42 ✓
```

```cpp
class Solution {
public:
    int myAtoi(string s) {
        int i = 0, n = s.size();
        while (i < n && s[i] == ' ') i++;
        if (i == n) return 0;
        
        int sign = 1;
        if (s[i] == '+' || s[i] == '-') {
            sign = (s[i] == '-') ? -1 : 1;
            i++;
        }
        
        int result = 0;
        while (i < n && isdigit(s[i])) {
            int digit = s[i] - '0';
            if (result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7)) {
                return sign == 1 ? INT_MAX : INT_MIN;
            }
            result = result * 10 + digit;
            i++;
        }
        
        return result * sign;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Robust overflow prevention without 64-bit casting.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Clamping at `INT_MAX` or `INT_MIN` | Undefined behavior on integer overflow | Pre-multiplication boundary condition `result > INT_MAX / 10` clamps safely |
| Sign after digits `"0-1"` | Reading '-' as sign | Parses '0', stops at '-' |
| Only whitespace `"    "` | Out-of-bounds access | `i == n` check returns 0 |

---

## Pattern Takeaway

When parsing strings to 32-bit integers, check for overflow **before performing multiplication** via `result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7)`.

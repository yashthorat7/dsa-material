## What are we solving?

A **permutation** of an array of integers is an arrangement of its members into a sequence or linear order. The **next permutation** of an array of integers is the next lexicographically greater permutation of its integer. If no such arrangement is possible, the array must be rearranged as the lowest possible order (i.e., sorted in ascending order).

The challenge is: **how do we find the minimal suffix modification in $O(n)$ time and $O(1)$ extra memory?**

**Example 1:**
```
Input:  nums = [1,2,3]
Output: [1,3,2]
```

**Example 2:**
```
Input:  nums = [3,2,1]
Output: [1,2,3]
```

**Example 3:**
```
Input:  nums = [1,1,5]
Output: [1,5,1]
```

**Constraints:**
- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 100$

## Approach 1 — Standard 3-Step Pivot & Swap ✅

**Key insight:**
1. **Find pivot from right:** Scan backwards to find the first index `i` such that `nums[i] < nums[i+1]`. Suffix after `i` is in decreasing order.
2. **Find successor:** If `i >= 0`, scan backwards again to find the smallest number greater than `nums[i]` (first `nums[j] > nums[i]`), and swap `nums[i]` with `nums[j]`.
3. **Reverse suffix:** Reverse the strictly decreasing suffix from `i + 1` to the end to make it the smallest lexicographical sequence.

```
nums = [1, 2, 7, 4, 3, 1]

Step 1: Scan right-to-left for nums[i] < nums[i+1]
        1 < 3 (no), 3 < 4 (no), 4 < 7 (no), 2 < 7 (YES -> i = 1, value = 2)

Step 2: Scan right-to-left for nums[j] > nums[i] (nums[j] > 2)
        nums[4] = 3 > 2 -> swap nums[1] and nums[4]
        nums becomes [1, 3, 7, 4, 2, 1]

Step 3: Reverse suffix from index i+1 (2 to 5):
        [7, 4, 2, 1] reversed is [1, 2, 4, 7]
        nums becomes [1, 3, 1, 2, 4, 7] ✓
```

```cpp
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            swap(nums[i], nums[j]);
        }
        
        reverse(nums.begin() + i + 1, nums.end());
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** In-place, optimal, standard algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Strictly decreasing array `[3, 2, 1]` | i reaches -1 | `if (i >= 0)` is skipped, entire array reversed to `[1, 2, 3]` |
| Array with duplicates `[1, 5, 1]` | `nums[i] >= nums[i+1]` condition must handle equality | Strict comparison avoids infinite loops on identical elements |
| Single element `[1]` | Out of bounds on i | `i = -1` immediately, reversed safely |

---

## Pattern Takeaway

The **Lexicographical Pivot** algorithm is the gold standard for sequence generation. Decreasing suffixes represent the maximum permutation for that sub-array; reversing them resets them to the minimum configuration after swapping the pivot.

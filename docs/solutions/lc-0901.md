## What are we solving?

Design an algorithm that collects daily price quotes for some stock and returns the **span** of that stock's price for the current day.

The **span** of the stock's price in one day is the maximum number of consecutive days (starting from that day and going backward) for which the stock price was less than or equal to the price of that day.

Implement the `StockSpanner` class:
- `StockSpanner()` Initializes the object of the class.
- `int next(int price)` Returns the span of the stock's price given that today's price is `price`.

**Example 1:**
```
Input:  ["StockSpanner", "next", "next", "next", "next", "next", "next", "next"]
[[], [100], [80], [60], [70], [60], [75], [85]]
Output: [null, 1, 1, 1, 2, 1, 4, 6]
Explanation: StockSpanner stockSpanner = new StockSpanner();
stockSpanner.next(100); // return 1
stockSpanner.next(80);  // return 1
stockSpanner.next(60);  // return 1
stockSpanner.next(70);  // return 2
stockSpanner.next(60);  // return 1
stockSpanner.next(75);  // return 4
stockSpanner.next(85);  // return 6
```

**Constraints:**
- $1 \le \text{price} \le 10^5$
- At most $10^4$ calls will be made to `next`.

## Approach 1 — Monotonic Stack with Span Compression ✅

**Key insight:**
Store pairs `{price, span}` in a monotonic decreasing stack.
When receiving a new `price`:
- Initialize `span = 1`.
- While `!st.empty() && st.top().first <= price`:
  - Accumulate the span of the previous smaller price: `span += st.top().second`.
  - `st.pop()`.
- Push `{price, span}` onto stack.
- Return `span`.

```
next(100): stack = [{100, 1}], span = 1
next(80):  80 < 100 -> stack = [{100, 1}, {80, 1}], span = 1
next(60):  60 < 80  -> stack = [{100, 1}, {80, 1}, {60, 1}], span = 1
next(70):  70 >= 60 -> span += 1 (span=2), pop 60 -> stack = [{100, 1}, {80, 1}, {70, 2}], span = 2
next(60):  60 < 70  -> stack = [..., {60, 1}], span = 1
next(75):  75 >= 60 -> span += 1 (span=2); 75 >= 70 -> span += 2 (span=4) -> stack = [{100, 1}, {80, 1}, {75, 4}], span = 4
next(85):  85 >= 75 -> span += 4 (span=5); 85 >= 80 -> span += 1 (span=6) -> stack = [{100, 1}, {85, 6}], span = 6 ✓
```

```cpp
class StockSpanner {
private:
    stack<pair<int, int>> st; // {price, span}
public:
    StockSpanner() {}
    
    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        }
        st.push({price, span});
        return span;
    }
};
```

| Time | Space |
|:-----|:------|
| Amortized $O(1)$ per call | $O(n)$ |

> **This is the one.** Span compression delivers amortized $O(1)$ online queries.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Prices strictly increasing `[10, 20, 30, 40]` | Linear scans | Pops entire stack in amortized $O(1)$, spans: 1, 2, 3, 4 |
| Prices strictly decreasing `[40, 30, 20, 10]` | Excessive pops | No elements popped, each returns span 1 |

---

## Pattern Takeaway

**Monotonic Span Compression (`span += st.top().span`)** aggregates historical consecutive spans into a single stack frame in amortized $O(1)$ time.

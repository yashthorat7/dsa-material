## What are we solving?

Design an algorithm that collects daily price quotes for some stock and returns the **span** of that stock's price for the current day.

The **span** of the stock's price in one day is the maximum number of consecutive days (starting from today and going backward) for which the stock price was **less than or equal to** the price of today.

Implement the `StockSpanner` class:
- `StockSpanner()`: Initializes the object of the class.
- `int next(int price)`: Returns the span of the stock's price given that today's price is `price`.

```
 Stream of Quotes:
 next(100) -> 1  [ 100 ]
 next(80)  -> 1  [ 80 ]
 next(60)  -> 1  [ 60 ]
 next(70)  -> 2  [ 60, 70 ]
 next(60)  -> 1  [ 60 ]
 next(75)  -> 4  [ 60, 70, 60, 75 ]
 next(85)  -> 6  [ 80, 60, 70, 60, 75, 85 ]
 
 Output: [ null, 1, 1, 1, 2, 1, 4, 6 ]
```

### Input & Output Contract
- **Input:**
  - `price`: `int` ($1 \le \text{price} \le 10^5$, up to $10^4$ calls).
- **Output:**
  - `int`: Consecutive days $\le \text{today's price}$ ending today.

### The Monotonic Span Compression Invariant
When a new quote arrives:
- Any previous smaller prices `prevPrice <= currentPrice` will **never be needed again** to bound future days, because `currentPrice` is both larger and more recent!
- Therefore, we can **pop those stack entries and absorb their spans directly into today's span**:
$$\mathbf{\text{span}_{\text{today}} = 1 + \sum_{\text{popped items}} \text{popped.span}}$$
Each quote enters and leaves the stack at most once $\implies \mathbf{O(1) \text{ Amortized Time per Call!}}$

## Approach 1 — Brute Force Array History Scan ($O(n)$ per call)

### Intuition
Store all quotes in a vector `prices`. On `next(price)`, append `price`, then scan backwards from the end counting consecutive prices $\le \text{price}$.

### C++ Implementation
```cpp
class StockSpanner {
private:
    vector<int> prices;

public:
    StockSpanner() {}
    
    int next(int price) {
        prices.push_back(price);
        int span = 0;
        for (int i = prices.size() - 1; i >= 0 && prices[i] <= price; i--) {
            span++;
        }
        return span;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ per call, $O(n^2)$ total | Linear scan over price history. TLE on $10^4$ ascending queries. |
| **Space** | $O(n)$ | Stores all historical prices. |

> **Verdict:** Suboptimal. Monotonic stack span compression achieves amortized $O(1)$ per call.

## Approach 2 — Monotonic Stack with Span Compression ✅

### Key Insight
1. Maintain a stack `st` storing pairs `{price, span}` in strictly decreasing order of price.
2. When `next(price)` is called:
   - Initialize `span = 1`.
   - While `!st.empty() && st.top().first <= price`:
     - Accumulate span: `span += st.top().second`.
     - Pop `st.pop()`.
   - Push `{price, span}` onto `st`.
   - Return `span`.

```
Calls Trace:
- next(100): stack = [{100, 1}], span = 1
- next(80):  stack = [{100, 1}, {80, 1}], span = 1
- next(60):  stack = [{100, 1}, {80, 1}, {60, 1}], span = 1
- next(70):  70 >= 60 -> span = 1 + 1 = 2, pop 60
             stack = [{100, 1}, {80, 1}, {70, 2}], span = 2
- next(60):  stack = [..., {60, 1}], span = 1
- next(75):  75 >= 60 -> span = 1 + 1 = 2
             75 >= 70 -> span = 2 + 2 = 4, pop 70
             stack = [{100, 1}, {80, 1}, {75, 4}], span = 4
- next(85):  85 >= 75 -> span = 1 + 4 = 5
             85 >= 80 -> span = 5 + 1 = 6, pop 80
             stack = [{100, 1}, {85, 6}], span = 6 ✓
```

### C++ Implementation
```cpp
class StockSpanner {
private:
    // Monotonic stack storing pairs: {price, accumulated_span}
    stack<pair<int, int>> st;

public:
    StockSpanner() {}
    
    int next(int price) {
        int span = 1;
        
        // Discard all smaller/equal past prices and accumulate their spans
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        }
        
        // Push the consolidated span onto the stack
        st.push({price, span});
        
        return span;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(1)$ Amortized per `next()` call | Across $N$ calls, every price is pushed once and popped at most once ($2N$ operations total). |
| **Space** | $O(n)$ | Stack stores at most $n$ consolidated price-span pairs. |

> **This is the one.** Clean, robust, industry-standard span compression.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Strictly Ascending Quotes** | `10, 20, 30, 40` | Linear popping | Pops preceding items in $O(1)$ amortized time; returns 1, 2, 3, 4. |
| **Strictly Descending Quotes** | `40, 30, 20, 10` | Emptying stack | Stack retains all items, returning 1 for each quote. |
| **Equal Consecutive Prices** | `10, 10, 10` | Non-strict inequality | `<=` comparison aggregates equal quotes into accumulated span (1, 2, 3). |

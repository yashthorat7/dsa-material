## What are we solving?

You are given the head of a singly linked-list. The list can be represented as:
`L0 → L1 → … → Ln - 1 → Ln`

Reorder the list to be on the following form:
`L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …`

You may not modify the values in the list's nodes. Only nodes themselves may be changed.

The question is: **how do we combine finding the midpoint, reversing the second half, and alternatingly merging the two lists in $O(1)$ space?**

**Example 1:**
```
Input:  head = [1,2,3,4]
Output: [1,4,2,3]
```

**Example 2:**
```
Input:  head = [1,2,3,4,5]
Output: [1,5,2,4,3]
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 5 \times 10^4]$.
- $1 \le \text{Node.val} \le 1000$

## Approach 1 — Find Midpoint + Reverse Second Half + Interleave ✅

**Key insight:**
1. Find middle with slow/fast pointers (`slow->next && fast->next->next`).
2. Split list into two halves: `head1 = head`, `head2 = reverse(slow->next)`, `slow->next = nullptr`.
3. Interleave/merge the two lists:
   - Save `temp1 = p1->next`, `temp2 = p2->next`.
   - `p1->next = p2`, `p2->next = temp1`.
   - Advance `p1 = temp1`, `p2 = temp2`.

```
1 -> 2 -> 3 -> 4 -> 5
1. Middle: slow points to 3.
2. Split & reverse:
   first:  1 -> 2 -> 3 -> null
   second: 5 -> 4 -> null
3. Interleave:
   1 -> 5 -> 2 -> 4 -> 3 -> null ✓
```

```cpp
class Solution {
public:
    void reorderList(ListNode* head) {
        if (!head || !head->next || !head->next->next) return;
        
        // 1. Find midpoint
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next && fast->next->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        // 2. Reverse second half
        ListNode* second = reverseList(slow->next);
        slow->next = nullptr; // split lists
        
        // 3. Interleave
        ListNode* first = head;
        while (second != nullptr) {
            ListNode* tmp1 = first->next;
            ListNode* tmp2 = second->next;
            
            first->next = second;
            second->next = tmp1;
            
            first = tmp1;
            second = tmp2;
        }
    }
private:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr) {
            ListNode* nxt = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nxt;
        }
        return prev;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** In-place node rearrangement combining 3 linked list primitives.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| List of length <= 2 `[1, 2]` | Unnecessary operations | Early return `if (!head || !head->next || !head->next->next)` |
| Even vs Odd lengths | Dangling pointer / cycles | `slow->next = nullptr` properly terminates first half |

## Pattern Takeaway

Mastering **Find Midpoint + Reverse List + Interleave Merge** composes solutions to complex linked list structural mutations with zero extra memory.

## What are we solving?

You are given the head of a singly linked list:
$$L_0 \rightarrow L_1 \rightarrow \dots \rightarrow L_{n-1} \rightarrow L_n$$

Reorder the list to follow the alternating zig-zag pattern:
$$L_0 \rightarrow L_n \rightarrow L_1 \rightarrow L_{n-1} \rightarrow L_2 \rightarrow L_{n-2} \rightarrow \dots$$

You may **not modify the values** in the list's nodes; only node pointers themselves may be changed.

```
 Input:  (1) -> (2) -> (3) -> (4) -> (5)
 
 Step 1: Find Midpoint & Split:
         List 1: (1) -> (2) -> (3) -> nullptr
         List 2: (4) -> (5) -> nullptr
         
 Step 2: Reverse Second Half:
         List 2 Reversed: (5) -> (4) -> nullptr
         
 Step 3: Interleave Nodes Alternatingly:
         (1) -> (5) -> (2) -> (4) -> (3) -> nullptr
```

### Input & Output Contract
- **Input:**
  - `head`: `ListNode*` pointing to the first node of the list ($1 \le n \le 5 \times 10^4$, $1 \le \text{Node.val} \le 1000$).
- **Output:**
  - `void` (mutates the list in-place).

### The Core Challenge
Accessing the $k$-th node from the tail in a singly linked list is impossible without scanning from head or caching nodes. To perform this reordering in strictly **$O(1)$ auxiliary space**, we compose three fundamental linked list primitives:
1. Find Midpoint (Fast & Slow Pointers).
2. Reverse Sublist In-Place.
3. Splice / Interleave Two Lists.

---

**Example 1:**
```
Input:  head = [1,2,3,4]
Output: [1,4,2,3]
```

**Example 2:**
```
Input:  head = [1,2,3,4,5]
Output: [1,5,2,4,3]
```

**Constraints:**
- The number of nodes in the list is in the range $[1, 5 \times 10^4]$.
- $1 \le \text{Node.val} \le 1000$

## Approach 1 — Array / Vector of Node Pointers

### Intuition
Store all node pointers in a `vector<ListNode*> nodes`.  
Use two pointers `left = 0` and `right = n - 1` to rewire pointers from the outside inward:
`nodes[left]->next = nodes[right]`, `nodes[right]->next = nodes[left + 1]`, and so on.

### C++ Implementation
```cpp
class Solution {
public:
    void reorderList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) return;
        
        vector<ListNode*> nodes;
        ListNode* curr = head;
        while (curr != nullptr) {
            nodes.push_back(curr);
            curr = curr->next;
        }
        
        int left = 0, right = nodes.size() - 1;
        while (left < right) {
            nodes[left]->next = nodes[right];
            left++;
            if (left >= right) break;
            nodes[right]->next = nodes[left];
            right--;
        }
        
        nodes[left]->next = nullptr;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | One pass to populate array, one pass to rewire pointers. |
| **Space** | $O(n)$ | Vector stores $n$ node pointers. |

> **Verdict:** Intuitive and easy to write, but consumes $O(n)$ heap memory.

## Approach 2 — Midpoint Split + Reverse + Interleave ✅

### Key Insight
Achieve $O(1)$ space by chaining 3 linear subroutines:
1. **Find Midpoint:** Advance `slow` by 1 and `fast` by 2 steps until `fast->next == nullptr || fast->next->next == nullptr`.
2. **Reverse Second Half:** Detach second half `second = slow->next` and terminate first half `slow->next = nullptr`. Reverse `second` in-place using standard 3-pointer reversal ([LC 206](file:///e:/Projects/dsa-notes/docs/solutions/lc-0206.md)).
3. **Interleave Merge:** Simultaneously advance two pointers `first` (from head) and `second` (from reversed tail), splicing:
   - `tmp1 = first->next`, `tmp2 = second->next`
   - `first->next = second`, `second->next = tmp1`
   - `first = tmp1`, `second = tmp2`

```
Input: 1 -> 2 -> 3 -> 4 -> 5

Step 1: Midpoint:
- slow points to 3, fast points to 5.
- First half:  1 -> 2 -> 3 -> nullptr
- Second half: 4 -> 5 -> nullptr

Step 2: Reverse Second Half:
- Reversed second half: 5 -> 4 -> nullptr

Step 3: Interleave:
- 1 links to 5 -> 5 links to 2
- 2 links to 4 -> 4 links to 3
- 3 links to nullptr

Result: 1 -> 5 -> 2 -> 4 -> 3 -> nullptr ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    void reorderList(ListNode* head) {
        if (head == nullptr || head->next == nullptr || head->next->next == nullptr) {
            return;
        }
        
        // 1. Find midpoint of the linked list
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        // 2. Split and reverse second half
        ListNode* second = reverseList(slow->next);
        slow->next = nullptr; // Terminate first half
        
        // 3. Interleave first and second halves
        ListNode* first = head;
        while (second != nullptr) {
            ListNode* tmp1 = first->next;
            ListNode* tmp2 = second->next;
            
            first->next = second;
            second->next = tmp1;
            
            first = tmp1;
            second = tmp2;
        }
    }

private:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr != nullptr) {
            ListNode* nxt = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nxt;
        }
        return prev;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Find midpoint: $n/2$ steps. Reverse: $n/2$ steps. Interleave: $n/2$ steps. Total $= \frac{3}{2} n = O(n)$. |
| **Space** | $O(1)$ | Pure in-place pointer rewiring; zero heap or stack memory allocated. |

> **This is the one.** Mastery of linked list pointers, optimal $O(n)$ time, $O(1)$ space.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **List Length $\le 2$** | `[1]` or `[1, 2]` | Redundant rewiring / cycle formation | Early return `if (!head || !head->next || !head->next->next)` leaves list intact. |
| **Even Length Lists** | `[1, 2, 3, 4]` | Uneven halving | First half has 2 nodes (`1->2`), second half has 2 nodes (`4->3`), interleaves cleanly to `1->4->2->3`. |
| **Odd Length Lists** | `[1, 2, 3, 4, 5]` | Leftover middle node | First half receives extra node (`1->2->3`), terminates naturally when `second` reaches `nullptr`. |

## Pattern Takeaways

1. **The 3-Step Linked List Blueprint:**  
   Complex list reorderings ([LC 234: Palindrome Linked List](file:///e:/Projects/dsa-notes/docs/solutions/lc-0234.md), [LC 143: Reorder List](file:///e:/Projects/dsa-notes/docs/solutions/lc-0143.md)) almost always decompose into:

   - **Step 2:** In-Place Pointer Reversal (`prev / curr / nxt`).
   - **Step 3:** Pointer Stitching / Comparison.

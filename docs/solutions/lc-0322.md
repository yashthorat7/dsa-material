## What are we solving?

You are given an integer array `coins` representing coins of different denominations and an integer `amount` representing a total amount of money.

Return the **fewest number of coins** that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return `-1`.

You may assume that you have an **infinite number** of each kind of coin.

**Example 1:**
```
Input:  coins = [1,2,5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
```

**Example 2:**
```
Input:  coins = [2], amount = 3
Output: -1
```

**Example 3:**
```
Input:  coins = [1], amount = 0
Output: 0
```

**Constraints:**
- $1 \le \text{coins.length} \le 12$
- $1 \le \text{coins}[i] \le 2^{31} - 1$
- $0 \le \text{amount} \le 10^4$

## Approach 1 — 1D Unbounded Knapsack DP ✅

**Key insight:**
Let `dp[i]` be minimum coins to make amount `i`.
- Initialize `dp` array of size `amount + 1` with sentinel `amount + 1` (representing infinity).
- `dp[0] = 0`.
- For each `i` from `1` to `amount`:
  - For each `coin` in `coins`:
    - If `i >= coin`: `dp[i] = min(dp[i], 1 + dp[i - coin])`.
- Return `dp[amount] > amount ? -1 : dp[amount]`.

```
coins = [1, 2, 5], amount = 11
dp = [0, 12, 12, ..., 12]

i=1: min(12, 1+dp[0]) = 1
i=2: min(1+dp[1], 1+dp[0]) = 1 (using coin 2)
...
i=11: 1 + dp[6] (coin 5) = 1 + 2 = 3

Result: 3 ✓
```

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, amount + 1);
        dp[0] = 0;
        
        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (i >= coin) {
                    dp[i] = min(dp[i], 1 + dp[i - coin]);
                }
            }
        }
        
        return dp[amount] > amount ? -1 : dp[amount];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(\text{amount} \cdot \text{coins.size()})$ | $O(\text{amount})$ |

> **This is the one.** Standard Bottom-Up Unbounded Knapsack.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `amount = 0` | 0 coins needed | Returns 0 directly |
| Impossible amount `coins = [2], amount = 3` | Returning infinity | `dp[3] > 3` returns `-1` |

---

## Pattern Takeaway

In **Unbounded Knapsack**, iterating amounts forward (`i` from `1` to `amount`) allows the same coin to be reused an arbitrary number of times.

## What are we solving?

Given an integer array `nums`, return the length of the longest **strictly increasing subsequence**.

A **subsequence** is a sequence that can be derived from an array by deleting some or no elements without changing the order of the remaining elements.

```
 nums = [ 10, 9, 2, 5, 3, 7, 101, 18 ]
 
 Valid Increasing Subsequences:
 - [ 10, 101 ] (len 2)
 - [ 2, 5, 7, 101 ] (len 4)
 - [ 2, 3, 7, 18 ] (len 4)
 
 Maximum Length = 4
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 2500$, $-10^4 \le \text{nums}[i] \le 10^4$.
- **Output:**
  - `int` representing the length of the longest strictly increasing subsequence.

### The Core Challenge
The standard DP formulation checks all previous elements in $O(n^2)$ time:
$$\text{dp}[i] = 1 + \max_{j < i, \text{nums}[j] < \text{nums}[i]}(\text{dp}[j])$$

Can we achieve **$O(n \log n)$ time** using **Patience Sorting with Binary Search**?

---

**Example 1:**
```
Input:  nums = [10,9,2,5,3,7,101,18]
Output: 4
Explanation: The longest increasing subsequence is [2,3,7,101], therefore the length is 4.
```

**Example 2:**
```
Input:  nums = [0,1,0,3,2,3]
Output: 4
```

**Example 3:**
```
Input:  nums = [7,7,7,7,7,7,7]
Output: 1
```

**Constraints:**
- $1 \le \text{nums.length} \le 2500$
- $-10^4 \le \text{nums}[i] \le 10^4$

## Approach 1 — Classical Dynamic Programming ($O(n^2)$)

### Intuition
Let `dp[i]` be the length of the longest increasing subsequence ending at index $i$. Initialize all `dp[i] = 1`.  
For each $i$ from $1$ to $n-1$, look at all preceding indices $j < i$:
- If `nums[j] < nums[i]`, we can extend that subsequence: `dp[i] = max(dp[i], dp[j] + 1)`.

### C++ Implementation
```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, 1);
        int maxLen = 1;
        
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            maxLen = max(maxLen, dp[i]);
        }
        
        return maxLen;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Two nested loops over $n$ elements. |
| **Space** | $O(n)$ | 1D DP table of size $n$. |

## Approach 2 — Patience Sorting with Binary Search (`lower_bound`) ✅

### Key Insight
Maintain an array `tails` where `tails[k]` stores the **smallest ending element** of any strictly increasing subsequence of length $k + 1$:
- `tails` is mathematically guaranteed to be strictly sorted at all times!
- For each number `x` in `nums`:
  - Find the first element in `tails` that is $\ge x$ using binary search (`lower_bound`).
  - If no such element exists ($x > \text{all tails}$), append $x$ to `tails` ($\text{LIS length increases by 1}$).
  - If such element exists at index `idx`, replace `tails[idx] = x` (a smaller ending value makes it easier for future elements to build even longer subsequences).
- The answer is simply **`tails.size()`**.

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]
tails = []

x = 10:  tails = [10]
x = 9:   lower_bound(9) replaces 10 -> tails = [9]
x = 2:   lower_bound(2) replaces 9  -> tails = [2]
x = 5:   5 > 2 -> append 5          -> tails = [2, 5]
x = 3:   lower_bound(3) replaces 5  -> tails = [2, 3]
x = 7:   7 > 3 -> append 7          -> tails = [2, 3, 7]
x = 101: 101 > 7 -> append 101      -> tails = [2, 3, 7, 101]
x = 18:  lower_bound(18) replaces 101 -> tails = [2, 3, 7, 18]

LIS Length = tails.size() = 4 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;
        tails.reserve(nums.size());
        
        for (int x : nums) {
            // Find first element >= x in tails
            auto it = lower_bound(tails.begin(), tails.end(), x);
            
            if (it == tails.end()) {
                tails.push_back(x); // Extends the longest sequence found so far
            } else {
                *it = x; // Greedily minimize the tail value of this length
            }
        }
        
        return tails.size();
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Performs $n$ binary searches (`lower_bound`) on an array of size up to $n$. |
| **Space** | $O(n)$ | `tails` array stores at most $n$ elements. |

> **This is the one.** Optimal $O(n \log n)$ Patience Sorting algorithm.

## Approach 3 — Coordinate Compression + Segment Tree ($O(n \log n)$)

### Intuition
Sort unique values of `nums` to compress into ranks $1 \dots U$. Build a Segment Tree over ranks $[1 \dots U]$. For each $x$ in `nums`: query the max LIS ending at rank $< \text{rank}(x)$, increment by 1, and update the point in the segment tree.

### C++ Implementation
```cpp
class Solution {
    struct SegTree {
        int n;
        vector<int> tree;
        SegTree(int n) : n(n), tree(4 * n, 0) {}
        
        void update(int node, int l, int r, int idx, int val) {
            if (l == r) {
                tree[node] = max(tree[node], val);
                return;
            }
            int mid = l + (r - l) / 2;
            if (idx <= mid) update(2 * node, l, mid, idx, val);
            else update(2 * node + 1, mid + 1, r, idx, val);
            tree[node] = max(tree[2 * node], tree[2 * node + 1]);
        }
        
        int query(int node, int l, int r, int ql, int qr) {
            if (ql > r || qr < l) return 0;
            if (ql <= l && r <= qr) return tree[node];
            int mid = l + (r - l) / 2;
            return max(query(2 * node, l, mid, ql, qr), query(2 * node + 1, mid + 1, r, ql, qr));
        }
    };

public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> sorted = nums;
        sort(sorted.begin(), sorted.end());
        sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
        
        int u = sorted.size();
        SegTree st(u);
        int maxLIS = 0;
        
        for (int x : nums) {
            int rank = lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin() + 1;
            int bestPrev = (rank > 1) ? st.query(1, 1, u, 1, rank - 1) : 0;
            int currentLIS = bestPrev + 1;
            maxLIS = max(maxLIS, currentLIS);
            st.update(1, 1, u, rank, currentLIS);
        }
        
        return maxLIS;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | $n$ queries and updates in range tree of size $n$. |
| **Space** | $O(n)$ | Segment tree of size $4n$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Strictly Decreasing** | `[5, 4, 3, 2, 1]` | Repeated replacement | `lower_bound` repeatedly replaces index 0; `tails.size()` remains 1. |
| **All Duplicates** | `[7, 7, 7, 7]` | Non-strict vs strictly increasing | `lower_bound` matches `7` and overwrites itself; size stays 1. |
| **Single Element** | `[10]` | Vector size | Returns 1. |

## Pattern Takeaways

1. **Patience Sorting Tails Invariant:**  
   `tails[k]` maintains the best (lowest) possible tail for a subsequence of length $k + 1$.
2. **`lower_bound` vs `upper_bound`:**  
   - For **strictly increasing** LIS: use `lower_bound` (first element $\ge x$).
   - For **non-decreasing** LIS: use `upper_bound` (first element $> x$).

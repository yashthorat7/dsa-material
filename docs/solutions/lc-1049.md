## What are we solving?

You are given an array of integers `stones` where `stones[i]` is the weight of the $i$-th stone.

We can smash any two stones together. Suppose the stones have weights $x$ and $y$ with $x \le y$. The result of this smash is that both stones are destroyed if $x == y$, or a new stone with weight $y - x$ is produced if $x \neq y$.

Return the **smallest possible weight** of the remaining stone. If there are no stones left, return `0`.

```
 Stones: [ 2, 7, 4, 1, 8, 1 ],  Total Sum = 23
 
 Partition into two subsets with minimal difference:
 S1 = { 8, 4 }           -> Sum = 12
 S2 = { 7, 2, 1, 1 }     -> Sum = 11
 
 Difference: |S1 - S2| = |12 - 11| = 1
 Minimum Remaining Weight: 1
 Output: 1
```

### Input & Output Contract
- **Input:**
  - `stones`: `vector<int>` ($1 \le n \le 30$, $1 \le \text{stones}[i] \le 100$, $\sum \text{stones}[i] \le 3000$).
- **Output:**
  - `int`: Minimal final stone weight.

### The Algebraic Reduction to Partition Subset Sum
Notice that any arbitrary sequence of pairwise stone smashes corresponds to assigning each stone a `+` or `-` sign:
$$\text{Final Stone Weight} = \sum (\pm \text{stones}[i]) = S_1 - S_2$$
Where $S_1$ and $S_2$ partition the original stones ($S_1 + S_2 = \text{totalSum}$).
$$\mathbf{S_1 - S_2 = (\text{totalSum} - S_2) - S_2 = \text{totalSum} - 2S_2}$$
To minimize $S_1 - S_2 \ge 0$, we must **maximize $S_2 \le \lfloor \text{totalSum} / 2 \rfloor$**.  
$$\mathbf{\text{Last Stone Weight II} \equiv \text{0/1 Knapsack: Find max reachable subset sum } \le \lfloor \frac{\text{totalSum}}{2} \rfloor}$$

---

**Example 1:**
```
Input:  stones = [2,7,4,1,8,1]
Output: 1
Explanation: We can combine 2 and 4 to get 2, so the array converts to [2,7,1,8,1] then, we can combine 7 and 8 to get 1, so the array converts to [2,1,1,1] then, we can combine 2 and 1 to get 1, so the array converts to [1,1,1] then, we can combine 1 and 1 to get 0, so the array converts to [1], then that's the optimal value.
```

**Example 2:**
```
Input:  stones = [31,26,33,21,40]

```

**Constraints:**

- $1 \le \text{stones}[i] \le 100$

## Approach 1 — 0/1 Knapsack Space-Optimized 1D DP ✅

### Key Insight
1. Calculate `totalSum = sum(stones)`.
2. Target capacity: `target = totalSum / 2`.
3. Allocate boolean array `dp[target + 1]` with `dp[0] = true`.
4. For each `stone` in `stones`:
   - Iterate `j` backwards from `target` down to `stone`:
     $$\text{dp}[j] = \text{dp}[j] \lor \text{dp}[j - \text{stone}]$$
5. Scan $S_2$ from `target` down to $0$. The first $S_2$ where `dp[S2] == true` gives the minimal weight:
   $$\text{return } \text{totalSum} - 2 \cdot S_2$$

```
stones = [2, 7, 4, 1, 8, 1], totalSum = 23, target = 23/2 = 11

dp initialized: dp[0]=T, all others F

After processing all stones:
- dp[11] is TRUE (can form subset sum 11 using {8, 2, 1})
Minimal difference = 23 - 2 * 11 = 1 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int lastStoneWeightII(vector<int>& stones) {
        int totalSum = accumulate(stones.begin(), stones.end(), 0);
        int target = totalSum / 2;
        
        // dp[j] indicates whether a subset with sum j can be formed
        vector<bool> dp(target + 1, false);
        dp[0] = true; // Base case: sum 0 is always achievable with empty subset
        
        for (int stone : stones) {
            // Traverse backwards to enforce single-use 0/1 knapsack rule
            for (int j = target; j >= stone; j--) {
                dp[j] = dp[j] || dp[j - stone];
            }
        }
        
        // Find the maximum achievable subset sum S2 <= totalSum / 2
        for (int s2 = target; s2 >= 0; s2--) {
            if (dp[s2]) {
                return totalSum - 2 * s2;
            }
        }
        
        return 0;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \frac{\text{totalSum}}{2})$ | $30 \times 1500 = 45,000$ operations (<1ms). |
| **Space** | $O(\frac{\text{totalSum}}{2})$ | 1D vector of size at most $1501$. |

> **This is the one.** Clean, space-optimal mathematical reduction.

## Approach 2 — `bitset` Ultra-Fast Bitwise Reachability

### Intuition
Maintain a 1501-bit bitset `dp`. Transition is `dp |= (dp << stone)`. Scan down from `target` for the first set bit.

### C++ Implementation
```cpp
class Solution {
public:
    int lastStoneWeightII(vector<int>& stones) {
        int totalSum = accumulate(stones.begin(), stones.end(), 0);
        int target = totalSum / 2;
        
        bitset<1501> dp;
        dp[0] = 1;
        
        for (int stone : stones) {
            dp |= (dp << stone);
        }
        
        for (int s2 = target; s2 >= 0; s2--) {
            if (dp[s2]) {
                return totalSum - 2 * s2;
            }
        }
        return 0;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \cdot \frac{\text{totalSum}}{64})$ | Hardware 64-bit word parallel bit shifts. |
| **Space** | $O(1)$ | 188 bytes stack memory. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Single Stone** | `[5]` | Target calculation | `target = 2`, `s2 = 0` is true $\implies 5 - 2(0) = 5$. |
| **Identical Stones** | `[2, 2]` | Complete cancellation | `target = 2`, `s2 = 2` is true $\implies 4 - 2(2) = 0$. |

## What are we solving?

You are given an array of integers `stones` where `stones[i]` is the weight of the $i$-th stone.

We can smash two stones together. Suppose the stones have weights `x` and `y` with `x <= y`. The result is a new stone with weight `y - x`.

Return the **smallest possible weight** of the left stone. If there are no stones left, return `0`.

**Example 1:**
```
Input:  stones = [2,7,4,1,8,1]
Output: 1
Explanation: We can combine 2 and 4 to get 2, so the array converts to [2,7,1,8,1] then, we can combine 7 and 8 to get 1, so the array converts to [2,1,1,1] then, we can combine 2 and 1 to get 1, so the array converts to [1,1,1] then, we can combine 1 and 1 to get 0, so the array converts to [1], then that's the optimal value.
```

**Example 2:**
```
Input:  stones = [31,26,33,21,40]
Output: 5
```

**Constraints:**
- $1 \le \text{stones.length} \le 30$
- $1 \le \text{stones}[i] \le 100$

## Approach 1 — Reduction to Partition Subset Sum (0/1 Knapsack) ✅

**Key insight:**
Any sequence of stone collisions assigns a `+` or `-` sign to each stone!
We want to minimize $|S_1 - S_2|$ where $S_1 + S_2 = \text{totalSum}$.
Since $S_1 - S_2 = \text{totalSum} - 2 \cdot S_2$, this is equivalent to:
**Finding a subset with sum $S_2 \le \text{totalSum} / 2$ as close to $\text{totalSum} / 2$ as possible!**
Run standard 1D 0/1 Knapsack up to `target = totalSum / 2`.

```
stones = [2, 7, 4, 1, 8, 1], totalSum = 23, target = 23/2 = 11

Find max subset sum <= 11:
We can form sum S2 = 11 (e.g. 8 + 2 + 1).
Minimal difference = totalSum - 2 * S2 = 23 - 2 * 11 = 1 ✓
```

```cpp
class Solution {
public:
    int lastStoneWeightII(vector<int>& stones) {
        int totalSum = 0;
        for (int s : stones) totalSum += s;
        
        int target = totalSum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true;
        
        for (int stone : stones) {
            for (int j = target; j >= stone; j--) {
                dp[j] = dp[j] || dp[j - stone];
            }
        }
        
        for (int s2 = target; s2 >= 0; s2--) {
            if (dp[s2]) {
                return totalSum - 2 * s2;
            }
        }
        
        return 0;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \cdot \text{totalSum})$ | $O(\text{totalSum})$ |

> **This is the one.** Mathematical reduction of game simulation to 0/1 Knapsack.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Single stone `[5]` | Division roundoff | `target = 2`, `s2 = 0`, returns `5 - 0 = 5` |
| Two identical stones `[2, 2]` | Complete destruction | `target = 2`, `s2 = 2`, returns `4 - 4 = 0` |

---

## Pattern Takeaway

Reframing complex cancellation games as **Partition Subset Difference minimization ($|S_1 - S_2|$)** maps the problem directly to 0/1 Knapsack.

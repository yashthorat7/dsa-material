## What are we solving?

There are some spherical balloons taped onto a flat wall represented by the XY-plane. The balloons are represented as a 2D integer array `points` where `points[i] = [xstart, xend]` denotes a balloon whose horizontal diameter stretches between `xstart` and `xend`.

An arrow can be shot up exactly vertically (in the positive y-direction) from different points along the x-axis. A balloon with `xstart` and `xend` is burst by an arrow shot at `x` if `xstart <= x <= xend`. There is no limit to the number of arrows that can be shot. A single arrow can burst multiple overlapping balloons.

Given the array `points`, return the **minimum number of arrows** that must be shot to burst all balloons.

**Example 1:**
```
Input:  points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: The balloons can be burst by 2 arrows:
- Shoot an arrow at x = 6, bursting balloons [2,8] and [1,6].
- Shoot an arrow at x = 11, bursting balloons [10,16] and [7,12].
```

**Example 2:**
```
Input:  points = [[1,2],[3,4],[5,6],[7,8]]
Output: 4
```

**Constraints:**
- $1 \le \text{points.length} \le 10^5$
- $\text{points}[i].\text{length} == 2$
- $-2^{31} \le x_{start} < x_{end} \le 2^{31} - 1$

## Approach 1 — Greedy Sort by End Coordinate ✅

**Key insight:**
1. Sort balloons by their **end coordinates** in ascending order.
2. Shoot the first arrow at the earliest end point `lastArrow = points[0][1]`. This arrow is positioned as far right as possible while still hitting the first balloon, maximizing the chance of hitting subsequent overlapping balloons!
3. For each subsequent balloon `[start, end]`:
   - If `start > lastArrow`: the previous arrow cannot reach this balloon $\rightarrow$ shoot a new arrow at `lastArrow = end`, `arrows++`.
   - Else: the current arrow bursts this balloon too!

```
points = [[10,16],[2,8],[1,6],[7,12]]
Sorted by end: [[1,6], [2,8], [7,12], [10,16]]
lastArrow = 6, arrows = 1

1. [2,8]: start=2 <= 6 -> burst by arrow at 6!
2. [7,12]: start=7 > 6 -> new arrow at 12! arrows = 2, lastArrow = 12
3. [10,16]: start=10 <= 12 -> burst by arrow at 12!

Result: 2 arrows ✓
```

```cpp
class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        if (points.empty()) return 0;
        sort(points.begin(), points.end(), [](const auto& a, const auto& b) {
            return a[1] < b[1];
        });
        
        int arrows = 1;
        int lastArrow = points[0][1];
        
        for (int i = 1; i < points.size(); i++) {
            if (points[i][0] > lastArrow) {
                arrows++;
                lastArrow = points[i][1];
            }
        }
        
        return arrows;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n)$ | $O(1)$ |

> **This is the one.** Greedy interval intersection with $O(1)$ memory.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Integer overflow during comparison `[-2^31, 2^31-1]` | Subtraction comparator `a[1] - b[1]` causing integer overflow | Using `<` comparator lambda avoids subtraction overflow |
| Single balloon | 0 arrows | Returns 1 arrow |

---

## Pattern Takeaway

Greedily placing the arrow at the **rightmost boundary (`end`) of the earliest finishing interval** bursts the maximal number of intersecting intervals.

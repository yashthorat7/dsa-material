## What are we solving?

There are spherical balloons taped onto a flat wall represented by the XY-plane. The balloons are represented as a 2D integer array `points` where `points[i] = [xstart, xend]` denotes a balloon whose horizontal diameter stretches between `xstart` and `xend`.

An arrow can be shot vertically (in the positive y-direction) from any point along the x-axis. A balloon is burst by an arrow shot at $x$ if $x_{\text{start}} \le x \le x_{\text{end}}$.
- A single arrow can burst **multiple overlapping balloons**.
- Return the **minimum number of arrows** that must be shot to burst all balloons.

```
 Balloons: [ [10, 16], [2, 8], [1, 6], [7, 12] ]
 
 Timeline:
 [1======6]
   [2======8]
         [7========12]
              [10========16]
              
 Arrow 1 shot at x = 6  -> Bursts [1, 6] and [2, 8]
 Arrow 2 shot at x = 12 -> Bursts [7, 12] and [10, 16]
 
 Total Arrows = 2
```

### Input & Output Contract
- **Input:**
  - `points`: `vector<vector<int>>` ($1 \le n \le 10^5$, $-2^{31} \le x_{\text{start}} < x_{\text{end}} \le 2^{31} - 1$).
- **Output:**
  - `int`: Minimum arrows needed.

### The Greedy Selection Insight
$$\mathbf{\text{Minimum Arrows to Burst Balloons} \equiv \text{Maximum Number of Disjoint Intervals}}$$
To maximize the number of overlapping balloons hit by a single arrow:
- We should shoot the arrow as far to the right as possible while still piercing the earliest-ending balloon!
- That optimal shooting coordinate is precisely at **$x = \text{end}$ of the earliest-finishing balloon**.

---

**Example 1:**
```
Input:  points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: The balloons can be burst by 2 arrows:
- Shoot an arrow at x = 6, bursting balloons [2,8] and [1,6].
- Shoot an arrow at x = 11, bursting balloons [10,16] and [7,12].
```

**Example 2:**
```
Input:  points = [[1,2],[3,4],[5,6],[7,8]]
Output: 4
```

**Constraints:**
- $1 \le \text{points.length} \le 10^5$
- $\text{points}[i].\text{length} == 2$
- $-2^{31} \le x_{\text{start}} < x_{\text{end}} \le 2^{31} - 1$

## Approach 1 — Greedy Sort by End Coordinate ✅

### Key Insight
1. **Sort balloons by their end coordinate `points[i][1]` ascending.**
2. Initialize `arrows = 1`, and place the first arrow at `lastArrow = points[0][1]`.
3. For each subsequent balloon `[start, end]`:
   - If `start > lastArrow`: the current arrow cannot reach this balloon $\implies$ shoot a new arrow: `arrows++`, `lastArrow = end`.
   - If `start <= lastArrow`: the balloon is already burst by the arrow at `lastArrow`!

```
points = [[10,16],[2,8],[1,6],[7,12]]
Sorted by end: [[1,6], [2,8], [7,12], [10,16]]
lastArrow = 6, arrows = 1

1. [2, 8]: start (2) <= lastArrow (6) -> Burst by Arrow 1!
2. [7, 12]: start (7) > lastArrow (6) -> Arrow 1 misses! Shoot Arrow 2 at 12! (arrows = 2, lastArrow = 12)
3. [10, 16]: start (10) <= lastArrow (12) -> Burst by Arrow 2!

Total Arrows = 2 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        if (points.empty()) return 0;
        
        // Sort balloons by end coordinate (use < to avoid integer overflow subtraction)
        sort(points.begin(), points.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1];
        });
        
        int arrows = 1;
        int lastArrow = points[0][1];
        
        for (int i = 1; i < points.size(); i++) {
            // If current balloon starts after the previous arrow position, shoot new arrow
            if (points[i][0] > lastArrow) {
                arrows++;
                lastArrow = points[i][1];
            }
        }
        
        return arrows;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Sorting $n$ balloons takes $O(n \log n)$; linear scan takes $O(n)$. |
| **Space** | $O(1)$ auxiliary | In-place sorting. |

> **This is the one.** Standard, optimal Interval Scheduling / Greedy Arrow Shoot algorithm.

## Approach 2 — Greedy Sort by Start Coordinate (Interval Intersection Squeeze)

### Intuition
Sort by `start`. Maintain the active interval intersection `[activeStart, activeEnd]`. When the next balloon overlaps (`points[i][0] <= activeEnd`), squeeze `activeEnd = min(activeEnd, points[i][1])`. When disjoint, shoot an arrow and reset active interval.

### C++ Implementation
```cpp
class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        if (points.empty()) return 0;
        sort(points.begin(), points.end());
        
        int arrows = 1;
        int activeEnd = points[0][1];
        
        for (int i = 1; i < points.size(); i++) {
            if (points[i][0] <= activeEnd) {
                // Overlap: shrink target arrow coordinate
                activeEnd = min(activeEnd, points[i][1]);
            } else {
                // Disjoint: shoot arrow and reset
                arrows++;
                activeEnd = points[i][1];
            }
        }
        
        return arrows;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n \log n)$ | Sort + single linear pass. |
| **Space** | $O(1)$ auxiliary | Constant extra space. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **32-Bit Coordinate Extremes** | `[[-2147483648, 2147483647]]` | `a[1] - b[1]` comparator overflow | Using boolean comparator `a[1] < b[1]` prevents arithmetic overflow. |
| **Touching Balloons** | `[[1, 2], [2, 3]]` | Arrow point inclusivity | `start <= lastArrow` handles single-point intersection at $x = 2$ with 1 arrow. |
| **Single Balloon** | `[[1, 2]]` | Boundary condition | Returns 1 arrow. |

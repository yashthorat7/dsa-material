## What are we solving?

A **swap** is defined as taking two distinct positions in an array and swapping the values in them.

A **circular array** is defined as an array where we consider the first element and the last element to be adjacent.

Given a binary circular array `nums`, return the **minimum number of swaps** required to group all `1`'s present in the array together at any location.

```
 nums = [ 0, 1, 0, 1, 1, 0, 0 ] (Total 1s = 3)
 
 If target window is [ 1, 1, 1 ] at indices [ 3..5 ]:
 Current values in window: [ 1, 1, 0 ] (has two 1s, one 0)
 Swaps needed to fill with 1s = 1 (swap 0 at index 5 with 1 at index 1)
 
 Resulting array: [ 0, 0, 0, 1, 1, 1, 0 ] (all 1s grouped!)
 Minimum Swaps: 1
 Output: 1
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` ($1 \le n \le 10^5$, `nums[i]` $\in \{0, 1\}$).
- **Output:**
  - `int`: Minimum number of swaps to cluster all 1s contiguously.

### The Fixed Window Duality
Suppose there are `totalOnes` ones in `nums`:
1. Any valid final state has all `totalOnes` ones packed inside some contiguous circular window of length `totalOnes`.
2. For any window of length `totalOnes`, the number of swaps required to fill it entirely with 1s is **the count of zeroes inside that window**:
$$\mathbf{\text{Swaps Needed}} = \text{totalOnes} - (\text{1s in window})$$
3. Therefore:
$$\mathbf{\text{Minimum Swaps} = \text{totalOnes} - \max_{\text{all windows}} (\text{1s in window})}$$

---

**Example 1:**
```
Input:  nums = [0,1,0,1,1,0,0]
Output: 1
Explanation: [0,0,1,1,1,0,0] using 1 swap.
```

**Example 2:**
```
Input:  nums = [0,1,1,1,0,0,1,1,0]
Output: 2
```

**Example 3:**
```
Input:  nums = [1,1,0,0,1]
Output: 0
Explanation: All 1's are already grouped circularly across the boundary: [1,1,_,_,1].
```

**Constraints:**
- $1 \le \text{nums.length} \le 10^5$
- `nums[i]` is either `0` or `1`.

## Approach 1 — Doubled Array Concatenation ($O(n)$ Space)

### Intuition
Concatenate `nums` with itself (`nums` + `nums`) to flatten the circular array into length $2n$. Slide a fixed window of size `totalOnes` across $0 \dots 2n - 1$.

### C++ Implementation
```cpp
class Solution {
public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();
        int totalOnes = 0;
        for (int x : nums) totalOnes += x;
        if (totalOnes <= 1 || totalOnes == n) return 0;
        
        vector<int> doubled = nums;
        doubled.insert(doubled.end(), nums.begin(), nums.end());
        
        int currentOnes = 0;
        for (int i = 0; i < totalOnes; i++) currentOnes += doubled[i];
        
        int maxOnes = currentOnes;
        for (int i = totalOnes; i < doubled.size(); i++) {
            currentOnes += doubled[i] - doubled[i - totalOnes];
            maxOnes = max(maxOnes, currentOnes);
        }
        
        return totalOnes - maxOnes;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Linear scan over $2n$ elements. |
| **Space** | $O(n)$ | Allocates $2n$-element doubled vector. |

> **Verdict:** Suboptimal space. Modulo indexing achieves $O(1)$ extra space.

## Approach 2 — Fixed Circular Sliding Window ($O(1)$ Space) ✅

### Key Insight
1. Calculate `totalOnes = accumulate(nums)`.
2. If `totalOnes <= 1` or `totalOnes == n`: return `0`.
3. Compute 1s in initial window $[0 \dots \text{totalOnes} - 1]$: `currentOnes`.
4. Slide window from $i = \text{totalOnes}$ to $n + \text{totalOnes} - 1$:
   $$\text{currentOnes} += \text{nums}[i \% n] - \text{nums}[(i - \text{totalOnes}) \% n]$$
   $$\text{maxOnes} = \max(\text{maxOnes}, \text{currentOnes})$$
5. Return $\text{totalOnes} - \text{maxOnes}$.

```
nums = [0, 1, 0, 1, 1, 0, 0] (n=7, totalOnes=3)
Initial window [0..2]: [0, 1, 0] -> currentOnes = 1, maxOnes = 1

Slide i=3: in=nums[3](1), out=nums[0](0) -> currentOnes = 2, maxOnes = 2
Slide i=4: in=nums[4](1), out=nums[1](1) -> currentOnes = 2
Slide i=5: in=nums[5](0), out=nums[2](0) -> currentOnes = 2
Slide i=6: in=nums[6](0), out=nums[3](1) -> currentOnes = 1
Slide i=7 (%7=0): in=nums[0](0), out=nums[4](1) -> currentOnes = 0
Slide i=8 (%7=1): in=nums[1](1), out=nums[5](0) -> currentOnes = 1
Slide i=9 (%7=2): in=nums[2](0), out=nums[6](0) -> currentOnes = 1

Result: totalOnes - maxOnes = 3 - 2 = 1 swap ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();
        int totalOnes = accumulate(nums.begin(), nums.end(), 0);
        
        // Edge cases: No 1s, single 1, or all 1s require 0 swaps
        if (totalOnes <= 1 || totalOnes == n) {
            return 0;
        }
        
        // Count 1s in the first window of size totalOnes
        int currentOnes = 0;
        for (int i = 0; i < totalOnes; i++) {
            currentOnes += nums[i];
        }
        
        int maxOnesInWindow = currentOnes;
        
        // Slide window across the circular boundary (up to n + totalOnes)
        for (int i = totalOnes; i < n + totalOnes; i++) {
            currentOnes += nums[i % n] - nums[(i - totalOnes) % n];
            maxOnesInWindow = max(maxOnesInWindow, currentOnes);
        }
        
        return totalOnes - maxOnesInWindow;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Single loop of length $n + \text{totalOnes} \le 2n$ iterations. |
| **Space** | $O(1)$ | Pure scalar variable registers. |

> **This is the one.** Clean, space-optimal circular window counting.

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Circular Grouping Across Ends** | `[1, 1, 0, 0, 1]` | Failing to check wrap-around | Sliding up to $n + \text{totalOnes}$ checks indices $[4, 0, 1]$, finding 3 ones $\implies 0$ swaps. |
| **All Zeroes / All Ones** | `[0, 0, 0]` or `[1, 1, 1]` | Out of bounds window | `totalOnes <= 1 || totalOnes == n` returns 0 early. |

## What are we solving?

Given an array `nums` with `n` objects colored red, white, or blue, sort them **in-place** so that objects of the same color are adjacent, with the colors in the order red, white, and blue. We will use the integers `0`, `1`, and `2` to represent the color red, white, and blue, respectively.

You must solve this problem without using the library's sort function and in a **single pass** with $O(1)$ constant extra space (The Dutch National Flag problem).

**Example 1:**
```
Input:  nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
```

**Example 2:**
```
Input:  nums = [2,0,1]
Output: [0,1,2]
```

**Constraints:**
- $n == \text{nums.length}$
- $1 \le n \le 300$
- `nums[i]` is either `0`, `1`, or `2`.

## Approach 1 — Dutch National Flag 3-Way Partitioning ✅

**Key insight:** Maintain 3 pointers:
- `low`: boundary where 0s should be placed (everything before `low` is 0).
- `mid`: current element being evaluated.
- `high`: boundary where 2s should be placed (everything after `high` is 2).

- If `nums[mid] == 0`: `swap(nums[low], nums[mid])`, `low++`, `mid++`.
- If `nums[mid] == 1`: `mid++`.
- If `nums[mid] == 2`: `swap(nums[mid], nums[high])`, `high--` (do NOT increment `mid`, as swapped element must be inspected).

```
nums = [2, 0, 2, 1, 1, 0]
low = 0, mid = 0, high = 5

mid=0 (2): swap(nums[0], nums[5]) -> [0, 0, 2, 1, 1, 2], high=4
mid=0 (0): swap(nums[0], nums[0]) -> [0, 0, 2, 1, 1, 2], low=1, mid=1
mid=1 (0): swap(nums[1], nums[1]) -> [0, 0, 2, 1, 1, 2], low=2, mid=2
mid=2 (2): swap(nums[2], nums[4]) -> [0, 0, 1, 1, 2, 2], high=3
mid=2 (1): mid=3
mid=3 (1): mid=4 > high -> loop finishes!

Result: [0, 0, 1, 1, 2, 2] ✓
```

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0, mid = 0, high = nums.size() - 1;
        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                swap(nums[mid], nums[high]);
                high--;
            }
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Classic Dutch National Flag algorithm.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| All identical colors `[0, 0, 0]` or `[2, 2, 2]` | Pointer crossing | Terminates cleanly at `mid > high` |
| Already sorted `[0, 1, 2]` | Unnecessary swaps | Pointers traverse smoothly in single pass |
| Two elements `[2, 0]` | Mid pointer incrementing prematurely after swap with high | Swapping with high does not increment mid |

---

## Pattern Takeaway

**3-Way Partitioning (Dutch National Flag)** divides an array into three logical regions `[< pivot, == pivot, > pivot]` in a single pass. Essential for 3-way QuickSort (handling heavy duplicate keys).

## What are we solving?

Given an array `nums` with `n` objects colored red, white, or blue, sort them **in-place** so that objects of the same color are adjacent, with the colors in the order red, white, and blue.

We use integers `0`, `1`, and `2` to represent the color red, white, and blue, respectively.

You must solve this problem without using the library's sort function and in a **single pass** with **$O(1)$ constant extra space** (The Dutch National Flag problem).

```
 Input:  [ 2,  0,  2,  1,  1,  0 ]
 
 Region 0s (Red):   [ 0, 0 ]
 Region 1s (White): [ 1, 1 ]
 Region 2s (Blue):  [ 2, 2 ]
 
 Output: [ 0, 0, 1, 1, 2, 2 ]
```

### Input & Output Contract
- **Input:**
  - `nums`: `vector<int>` where $1 \le n \le 300$, $\text{nums}[i] \in \{0, 1, 2\}$.
- **Output:**
  - `void` (sorts `nums` in place).
- **Constraints:** Single pass, $O(1)$ extra memory.

---

**Example 1:**
```
Input:  nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
```

**Example 2:**
```
Input:  nums = [2,0,1]
Output: [0,1,2]
```

**Constraints:**
- $n == \text{nums.length}$
- $1 \le n \le 300$
- `nums[i]` is either `0`, `1`, or `2`.

## Approach 1 — Two-Pass Counting Sort

### Intuition
1. First pass: count the frequencies of `0`s, `1`s, and `2`s.
2. Second pass: overwrite `nums` with `c0` zeroes, followed by `c1` ones, and `c2` twos.

### C++ Implementation
```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int count0 = 0, count1 = 0, count2 = 0;
        for (int x : nums) {
            if (x == 0) count0++;
            else if (x == 1) count1++;
            else count2++;
        }
        
        int idx = 0;
        while (count0--) nums[idx++] = 0;
        while (count1--) nums[idx++] = 1;
        while (count2--) nums[idx++] = 2;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Two linear passes over $n$ elements. |
| **Space** | $O(1)$ | 3 integer frequency counters. |

> **Verdict:** Suboptimal because it requires two full passes over the array.

## Approach 2 — Dutch National Flag 3-Way Partitioning (Single Pass) ✅

### Key Insight
Partition the array into 4 logical regions using 3 pointers:
1. `[0 ... low - 1]`: strictly `0`s (Red).
2. `[low ... mid - 1]`: strictly `1`s (White).
3. `[mid ... high]`: unknown / uninspected elements.
4. `[high + 1 ... n - 1]`: strictly `2`s (Blue).

**Pointer Actions:**
- If `nums[mid] == 0`: `swap(nums[low], nums[mid])`, `low++`, `mid++`.
- If `nums[mid] == 1`: element is in its rightful place $\rightarrow$ `mid++`.
- If `nums[mid] == 2`: `swap(nums[mid], nums[high])`, `high--` (do **not** increment `mid`, because the element swapped from `high` has not yet been inspected!).

```
nums = [2, 0, 2, 1, 1, 0]
low = 0, mid = 0, high = 5

mid=0 (2): swap(nums[0], nums[5]) -> [0, 0, 2, 1, 1, 2], high = 4
mid=0 (0): swap(nums[0], nums[0]) -> [0, 0, 2, 1, 1, 2], low = 1, mid = 1
mid=1 (0): swap(nums[1], nums[1]) -> [0, 0, 2, 1, 1, 2], low = 2, mid = 2
mid=2 (2): swap(nums[2], nums[4]) -> [0, 0, 1, 1, 2, 2], high = 3
mid=2 (1): mid = 3
mid=3 (1): mid = 4 > high (3) -> Loop terminates!

Result: [0, 0, 1, 1, 2, 2] ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0;
        int mid = 0;
        int high = nums.size() - 1;
        
        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                // When nums[mid] == 2, swap with high and shrink high
                // Do NOT advance mid since the new nums[mid] must be re-evaluated
                swap(nums[mid], nums[high]);
                high--;
            }
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Strictly single pass. Each comparison either advances `mid` or decrements `high`. |
| **Space** | $O(1)$ | Constant extra space; pure in-place swaps. |

> **This is the one.** Classic Dutch National Flag algorithm designed by Edsger W. Dijkstra.

---

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Swap from `high` is a 0 or 2** | `[2, 0, 1]` | Incrementing `mid` prematurely | Keeping `mid` at current index after swapping with `high` allows re-inspecting the newly placed element. |
| **All Identical Elements** | `[0, 0, 0]` or `[2, 2, 2]` | Index crossing | Terminates cleanly when `mid > high`. |
| **Two Elements** | `[2, 1]` | Single swap | Correctly produces `[1, 2]`. |

## Pattern Takeaways

1. **The 3-Way Partition Invariant:**  
   The Dutch National Flag technique allows $O(n)$ single-pass 3-way partitioning, which is the foundational optimization in **3-Way QuickSort (Dual-Pivot)** for handling heavy duplicate distributions.

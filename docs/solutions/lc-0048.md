## What are we solving?

You are given an $n \times n$ 2D matrix representing an image. Rotate the image by **90 degrees clockwise**.

You have to rotate the image **in-place**, which means modifying the input 2D matrix directly without allocating another 2D matrix.

```
 Original (3x3):             Rotated 90° Clockwise:
 [ 1, 2, 3 ]                 [ 7, 4, 1 ]
 [ 4, 5, 6 ]       --->      [ 8, 5, 2 ]
 [ 7, 8, 9 ]                 [ 9, 6, 3 ]
```

### Input & Output Contract
- **Input:**
  - `matrix`: `vector<vector<int>>&` of square dimension $n \times n$ ($1 \le n \le 20$, $-1000 \le \text{matrix}[i][j] \le 1000$).
- **Output:**
  - `void` (mutates `matrix` in place).
- **Constraint:** Must use strictly $O(1)$ auxiliary memory.

### The Core Challenge
In a 90° clockwise rotation, the element at row $i$, col $j$ moves to row $j$, col $n - 1 - i$:
$$\text{matrix}[i][j] \longrightarrow \text{matrix}[j][n - 1 - i]$$
Linear algebra yields the ultimate shortcut:
$$\mathbf{\text{Rotate 90}^\circ \text{ Clockwise} \equiv \text{Transpose} + \text{Reverse Each Row}}$$

---

**Example 1:**
```
Input:  matrix = [[1,2,3],[4,5,6],[7,8,9]]
```

**Example 2:**

- $1 \le n \le 20$
- $-1000 \le \text{matrix}[i][j] \le 1000$

## Approach 1 — Auxiliary Matrix Copy ($O(n^2)$ Space)

### Intuition
In a 90-degree clockwise rotation, cell $(r, c)$ in the original matrix always maps to $(c, n - 1 - r)$ in the rotated matrix. Allocate a temporary matrix `rotated`, copy all values according to this formula, and overwrite `matrix`.

### C++ Implementation
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        vector<vector<int>> rotated(n, vector<int>(n));
        
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                rotated[c][n - 1 - r] = matrix[r][c];
            }
        }
        
        matrix = rotated; // Copy back
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n^2)$ | Two nested loops over $n \times n$ cells. |
| **Space** | $O(n^2)$ | Allocates a full $n \times n$ auxiliary copy matrix. |

> **Verdict:** Suboptimal. Violates the strict $O(1)$ in-place interview constraint.

## What are we solving?

Given `head`, the head of a linked list, determine if the linked list has a cycle in it. There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the `next` pointer.

Return `true` if there is a cycle in the linked list. Otherwise, return `false`.

The question is: **why are fast and slow pointers guaranteed to collide inside a cycle in $O(n)$ time without infinite loops?**

**Example 1:**
```
Input:  head = [3,2,0,-4], pos = 1
Output: true
Explanation: There is a cycle in the linked list, where the tail connects to the 1st node (0-indexed).
```

**Example 2:**
```
Input:  head = [1,2], pos = 0
Output: true
```

**Example 3:**
```
Input:  head = [1], pos = -1
Output: false
```

**Constraints:**
- The number of the nodes in the list is in the range $[0, 10^4]$.
- $-10^5 \le \text{Node.val} \le 10^5$
- `pos` is `-1` or a valid index in the linked-list.

## Approach 1 — Floyd's Cycle-Finding Algorithm (Tortoise and Hare) ✅

**Key insight:**
- Move `slow` by 1 step, `fast` by 2 steps.
- If there is no cycle, `fast` will reach `nullptr`.
- If there is a cycle, `fast` and `slow` will enter the loop. Each step reduces the distance between them by 1 within the loop ($2 - 1 = 1$). They are guaranteed to collide in at most $C$ steps, where $C$ is the cycle length.

```
List: 3 -> 2 -> 0 -> -4 -> (loops to 2)

Step 0: slow = 3, fast = 3
Step 1: slow = 2, fast = 0
Step 2: slow = 0, fast = 2
Step 3: slow = -4, fast = -4 (COLLISION!)

Result: true ✓
```

```cpp
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) return true;
        }
        
        return false;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Canonical $O(1)$ memory cycle detection.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty list or single node without cycle | Null pointer dereference | Loop condition `fast && fast->next` safely returns `false` |
| Single node with self cycle `1 -> 1` | Collision check order | Advances pointers before checking `slow == fast`, detects cycle |

---

## Pattern Takeaway

In closed loops, **relative speed differential of 1** guarantees pointer collision without skipping over the target.

# 686. Repeated String Match

## What are we solving?

Given two strings `a` and `b`, return the **minimum number of times** you should repeat string `a` so that string `b` is a substring of it. If it is impossible for `b` to be a substring of `a` after repeating it, return `-1`.

Notice: string `"abc"` repeated 0 times is `""`, repeated 1 time is `"abc"` and repeated 2 times is `"abcabc"`.

The question is: **what is the upper bound on the number of repetitions needed before we can guarantee `b` cannot appear?**

**Example 1:**
```
Input:  a = "abcd", b = "cdabcdab"
Output: 3
Explanation: After repeating a 3 times, we get "abcdabcdabcd". b is a substring of it.
```

**Example 2:**
```
Input:  a = "a", b = "aa"
Output: 2
```

**Constraints:**
- $1 \le a.\text{length}, b.\text{length} \le 10^4$
- `a` and `b` consist of lowercase English letters.

## Approach 1 — Repetition Bounding with String Search ✅

**Key insight:**
1. Repeat `a` until its length is at least `b.length()`. Let count of repetitions be `count`.
2. Check if `b` is a substring of `repeated_a`. If yes, return `count`.
3. Append `a` one more time (`count + 1`) to cover matches that start near the end of the first pattern.
4. If `b` is a substring of `repeated_a + a`, return `count + 1`.
5. Otherwise, `b` can NEVER be a substring, return `-1`.

```
a = "abcd", b = "cdabcdab" (len a = 4, len b = 8)

1. Repeat until len >= 8:
   "abcdabcd" (count = 2, len = 8)
   Is "cdabcdab" in "abcdabcd"? No.
2. Add one more repetition:
   "abcdabcdabcd" (count = 3, len = 12)
   Is "cdabcdab" in "abcdabcdabcd"? YES! (at index 2: "ab[cdabcdab]cd")

Result: 3 ✓
```

```cpp
class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        string repeated = "";
        int count = 0;
        
        while (repeated.size() < b.size()) {
            repeated += a;
            count++;
        }
        
        if (repeated.find(b) != string::npos) return count;
        
        repeated += a;
        count++;
        if (repeated.find(b) != string::npos) return count;
        
        return -1;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(N + M)$ with KMP / modern `find` | $O(N + M)$ |

> **This is the one.** Rigorously bounded search space.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| `b` already substring of `a` | Extra repetitions | Loop runs once, finds substring, returns 1 |
| Characters in `b` not present in `a` | Infinite loop | Terminates after at most `count + 1` iterations and returns -1 |

---

## Pattern Takeaway

For circular / repeated pattern matching, **expanding to length `b.length() + 2 * a.length()`** is mathematically sufficient to detect or rule out any occurrence.

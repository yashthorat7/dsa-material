## What are we solving?

Given two strings `a` and `b`, return the **minimum number of times** you should repeat string `a` so that string `b` is a substring of it.

If it is impossible for `b` to be a substring of `a` after repeating it, return `-1`.

```
 a = " a b c d " (len = 4)
 b = " c d a b c d a b " (len = 8)
 
 Repeat 1: "abcd" (length 4 < 8)
 Repeat 2: "abcdabcd" (length 8) -> Substring "cdabcdab" NOT in "abcdabcd"
 Repeat 3: "abcdabcdabcd" (length 12) -> Match found at index 2: "ab[cdabcdab]cd"
 
 Output: 3
```

### Input & Output Contract
- **Input:**
  - `a`: `string` ($1 \le |a| \le 10^4$).
  - `b`: `string` ($1 \le |b| \le 10^4$).
- **Output:**
  - `int`: Minimum repetition count, or `-1` if impossible.

### The Mathematical Repetition Bound
Why don't we repeat $a$ infinitely?
1. To contain $b$, the repeated string must have length **at least $|b|$**:
   $$k = \lceil |b| / |a| \rceil$$
2. However, $b$ could start near the very end of a repetition of $a$ and span across $k$ full copies of $a$, finishing inside a final copy.
3. Therefore, at most **$k + 1$ (or $k + 2$) repetitions** are mathematically sufficient to detect or conclusively rule out $b$!
4. If $b$ is not a substring of $a \times (k + 1)$, it can **never** be formed by further repetitions.

---

**Example 1:**
```
Input:  a = "abcd", b = "cdabcdab"
Output: 3
Explanation: After repeating a 3 times, we get "abcdabcdabcd". b is a substring of it.
```

**Example 2:**
```
Input:  a = "a", b = "aa"
Output: 2
```

**Constraints:**
- $1 \le a.\text{length}, b.\text{length} \le 10^4$
- `a` and `b` consist of lowercase English letters.

## Approach 1 — Repetition Bounding with `find` ✅

### Key Insight
1. Append $a$ into string `repeated` until `repeated.length() >= b.length()`, incrementing `count`.
2. Check `if (repeated.find(b) != string::npos)`: return `count`.
3. Append $a$ one additional time (`repeated += a`, `count++`) to cover offset overlaps.
4. Check `if (repeated.find(b) != string::npos)`: return `count`.
5. If still not found, return `-1`.

```
a = "abcd", b = "cdabcdab"

1. Repeat until len >= 8:
   repeated = "abcdabcd", count = 2
   find(b) -> not found
2. Append one more copy:
   repeated = "abcdabcdabcd", count = 3
   find(b) -> found at index 2!

Return 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        string repeated = "";
        int count = 0;
        
        // 1. Repeat until the length of repeated is at least the length of b
        while (repeated.length() < b.length()) {
            repeated += a;
            count++;
        }
        
        // 2. Check if b is already a substring
        if (repeated.find(b) != string::npos) {
            return count;
        }
        
        // 3. Append one more copy to check cross-boundary overlap
        repeated += a;
        count++;
        if (repeated.find(b) != string::npos) {
            return count;
        }
        
        // 4. Conclusively impossible
        return -1;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(|a| \cdot (|b| + |a|))$ | At most two substring search calls on string of length $\le |b| + 2|a|$. |
| **Space** | $O(|b| + |a|)$ | Holds repeated string in memory. |

> **This is the one.** Clean, robust, and handles all overlap configurations.

## Approach 2 — KMP String Search ($O(|a| + |b|)$)

### Intuition
Build KMP Longest Prefix Suffix (LPS) table on pattern $b$. Stream virtual repeated characters from $a$ via modulo indexing $(i \% |a|)$ to find $b$ without allocating huge strings.

### C++ Implementation
```cpp
class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        int na = a.size(), nb = b.size();
        vector<int> lps(nb, 0);
        
        // Build LPS table for b
        for (int i = 1, j = 0; i < nb; i++) {
            while (j > 0 && b[i] != b[j]) j = lps[j - 1];
            if (b[i] == b[j]) j++;
            lps[i] = j;
        }
        
        int i = 0, j = 0; // i is virtual index in repeated 'a'
        while (i < na + nb + na) {
            while (j > 0 && a[i % na] != b[j]) j = lps[j - 1];
            if (a[i % na] == b[j]) j++;
            if (j == nb) {
                return (i / na) + 1;
            }
            i++;
        }
        
        return -1;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(|a| + |b|)$ | Linear KMP streaming pass. |
| **Space** | $O(|b|)$ | LPS table for string $b$. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`b` is Substring of `a` Initially** | `a = "abc", b = "b"` | Over-repeating | Loop runs once, `repeated.find("b")` hits on step 1 $\implies$ returns 1. |
| **Impossible Characters** | `a = "abc", b = "abcd"` | Infinite loop | Loop terminates after at most $k + 1$ iterations and returns `-1`. |
| **Boundary Split Overlap** | `a = "abcd", b = "cdab"` | Offset mismatch | Handled by the extra $(k + 1)$-th repetition check. |

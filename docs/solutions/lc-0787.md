## What are we solving?

There are $n$ cities connected by some number of flights. You are given an array `flights` where `flights[i] = [from, to, price]` indicates a flight with cost `price`.

You are also given three integers `src`, `dst`, and `k`.

Return the **cheapest price** from `src` to `dst` with **at most $k$ stops**. If there is no such route, return `-1`.

```
 Flight Network:
     0 --- 100 ---> 1 --- 600 ---> 3
     |              |              ^
     |              | 100          |
     |              v              |
     +--- 100 ----> 2 ---- 200 ----+
     
 src = 0, dst = 3, k = 1 (at most 1 stop, i.e., at most 2 flights)
 
 Path 1 (0 stops): None
 Path 2 (1 stop):  0 -> 1 -> 3 (cost = 100 + 600 = 700) -> VALID!
 Path 3 (2 stops): 0 -> 1 -> 2 -> 3 (cost = 400) -> INVALID (> 1 stop)
 
 Output: 700
```

### Input & Output Contract
- **Input:**
  - `flights`: `vector<vector<int>>` ($1 \le n \le 100$, $0 \le |\text{flights}| \le \frac{n(n-1)}{2}$, $1 \le \text{price} \le 10^4$).
  - `src`, `dst`: `int` start and destination nodes ($0 \le \text{src}, \text{dst} < n$).
  - `k`: `int` maximum allowed stops ($0 \le k < n$).
- **Output:**
  - `int`: Cheapest cost to reach `dst` within $\le k$ stops, or `-1`.

### The Edge-Count Invariant
At most $k$ intermediate stops means any valid flight route contains at most **$k + 1$ edges**:
$$\text{Path: } \text{src} \xrightarrow{e_1} u_1 \xrightarrow{e_2} u_2 \dots \xrightarrow{e_k} u_k \xrightarrow{e_{k+1}} \text{dst}$$
This makes **Bellman-Ford relaxation with a snapshot array** the perfect choice: executing exactly $k + 1$ iterations ensures we never explore paths exceeding $k + 1$ edges.

- $\text{flights}[i].\text{length} == 3$

- $\text{src} \neq \text{dst}$

## Approach 1 — Bellman-Ford ($k+1$ Relaxations with Snapshot Array) ✅

### Key Insight
1. Initialize `prices` array of size $n$ filled with $\infty = 10^9$, with `prices[src] = 0`.
2. Run a loop for $k + 1$ iterations (representing path length from 1 to $k + 1$ flights):
   - **Snapshot Copy:** `tempPrices = prices`.
     - *Why?* Using `tempPrices` prevents "cascading updates" where multiple edges are chained together in a single iteration.
   - For each flight `[u, v, cost]`:
     - If `prices[u] < 1e9`:
       $$\text{tempPrices}[v] = \min(\text{tempPrices}[v], \text{prices}[u] + \text{cost})$$
   - `prices = tempPrices`.
3. Return `prices[dst] >= 1e9 ? -1 : prices[dst]`.

```
src = 0, dst = 3, k = 1 (2 iterations)
prices = [0, ∞, ∞, ∞]

Iteration 1 (1 edge / 0 stops):
- 0 -> 1 (100): tempPrices[1] = 100
prices = [0, 100, ∞, ∞]

Iteration 2 (2 edges / 1 stop):
- 1 -> 2 (100): tempPrices[2] = 200
- 1 -> 3 (600): tempPrices[3] = 700
prices = [0, 100, 200, 700]

Result: prices[3] = 700 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
        const int INF = 1e9;
        vector<int> prices(n, INF);
        prices[src] = 0;
        
        // Relax edges exactly k + 1 times (at most k stops = at most k + 1 flights)
        for (int i = 0; i <= k; i++) {
            vector<int> tempPrices = prices; // Snapshot to isolate edge lengths
            
            for (const auto& flight : flights) {
                int u = flight[0];
                int v = flight[1];
                int cost = flight[2];
                
                if (prices[u] < INF) {
                    tempPrices[v] = min(tempPrices[v], prices[u] + cost);
                }
            }
            
            prices = move(tempPrices);
        }
        
        return prices[dst] >= INF ? -1 : prices[dst];
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O((k + 1) \cdot E)$ | Where $E \le n(n-1)/2$. For $n=100$, takes $<500,000$ operations (<5ms). |
| **Space** | $O(V)$ | Two 1D price vectors of size $n$. |

> **This is the one.** Cleanest, most intuitive Bellman-Ford edge-limited shortest path.

## Approach 2 — Step-Bounded BFS Queue

### Intuition
Maintain a queue storing `{node, currentCost}`. Advance level-by-level up to $k + 1$ levels, maintaining an array `minCost` to prune redundant branches where cost is already greater than previously found paths.

### C++ Implementation
```cpp
class Solution {
public:
    int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
        vector<vector<pair<int, int>>> adj(n);
        for (const auto& f : flights) adj[f[0]].push_back({f[1], f[2]});
        
        vector<int> minCost(n, INT_MAX);
        queue<pair<int, int>> q; // {node, cost}
        q.push({src, 0});
        minCost[src] = 0;
        
        int stops = 0;
        while (!q.empty() && stops <= k) {
            int sz = q.size();
            for (int i = 0; i < sz; i++) {
                auto [u, cost] = q.front(); q.pop();
                for (auto& [v, price] : adj[u]) {
                    if (cost + price < minCost[v]) {
                        minCost[v] = cost + price;
                        q.push({v, minCost[v]});
                    }
                }
            }
            stops++;
        }
        
        return minCost[dst] == INT_MAX ? -1 : minCost[dst];
    }
};
```

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **`k = 0` (Direct Flights Only)** | `k = 0` | Running multiple steps | Loop runs exactly 1 iteration ($i = 0$), only checking 1-flight routes. |
| **Destination Unreachable Within $k$ Stops** | Path exists with $k + 2$ stops | Returning invalid long path | Stops at $k + 1$ iterations, returning `-1`. |

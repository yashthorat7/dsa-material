## What are we solving?

There are `n` cities connected by some number of flights. You are given an array `flights` where `flights[i] = [fromi, toi, pricei]` indicates that there is a flight from city `fromi` to city `toi` with cost `pricei`.

You are also given three integers `src`, `dst`, and `k`, return the **cheapest price** from `src` to `dst` with at most `k` stops. If there is no such route, return `-1`.

**Example 1:**
```
Input:  n = 4, flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]], src = 0, dst = 3, k = 1
Output: 700
Explanation: The optimal path with at most 1 stop from city 0 to 3 is 0 -> 1 -> 3 with cost 100 + 600 = 700.
```

**Example 2:**
```
Input:  n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 1
Output: 200
```

**Example 3:**
```
Input:  n = 3, flights = [[0,1,100],[1,2,100],[0,2,500]], src = 0, dst = 2, k = 0
Output: 500
```

**Constraints:**
- $1 \le n \le 100$
- $0 \le \text{flights.length} \le (n \cdot (n - 1) / 2)$
- $\text{flights}[i].\text{length} == 3$
- $0 \le \text{from}_i, \text{to}_i < n$
- $\text{from}_i \neq \text{to}_i$
- $1 \le \text{price}_i \le 10^4$
- There will not be any duplicated flights or self cycles.
- $0 \le \text{src}, \text{dst}, k < n$
- $\text{src} \neq \text{dst}$

## Approach 1 — Bellman-Ford / BFS Relaxing K+1 Times ✅

**Key insight:**
At most $k$ stops means a path with at most **$k + 1$ edges**.
Run Bellman-Ford relaxation for exactly $k + 1$ iterations:
1. `prices[n]` initialized to $\infty$, with `prices[src] = 0`.
2. In each iteration:
   - Copy `tempPrices = prices` (to ensure we only extend paths by 1 edge per step, avoiding multi-edge chain updates within the same iteration).
   - For each edge `[u, v, cost]`: if `prices[u] != ∞`, `tempPrices[v] = min(tempPrices[v], prices[u] + cost)`.
   - `prices = tempPrices`.
3. Return `prices[dst] == ∞ ? -1 : prices[dst]`.

```
src = 0, dst = 3, k = 1 (2 iterations)
prices = [0, ∞, ∞, ∞]

Iter 1 (1 edge):
- 0 -> 1 (100): tempPrices[1] = 100
prices = [0, 100, ∞, ∞]

Iter 2 (2 edges):
- 1 -> 2 (100): tempPrices[2] = 200
- 1 -> 3 (600): tempPrices[3] = 700
prices = [0, 100, 200, 700]

Result: prices[3] = 700 ✓
```

```cpp
class Solution {
public:
    int findCheapestPrice(int n, vector<vector<int>>& flights, int src, int dst, int k) {
        vector<int> prices(n, 1e9);
        prices[src] = 0;
        
        for (int i = 0; i <= k; i++) {
            vector<int> tempPrices = prices;
            for (const auto& f : flights) {
                int u = f[0], v = f[1], cost = f[2];
                if (prices[u] < 1e9) {
                    tempPrices[v] = min(tempPrices[v], prices[u] + cost);
                }
            }
            prices = tempPrices;
        }
        
        return prices[dst] >= 1e9 ? -1 : prices[dst];
    }
};
```

| Time | Space |
|:-----|:------|
| $O(K \cdot E)$ | $O(V)$ |

> **This is the one.** $K$-step Bellman-Ford is simple and immune to priority queue re-visitation cycles.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Destination unreachable within $k$ stops | Returning path with $> k$ stops | Terminates after $k+1$ rounds, returns -1 |
| `k = 0` (direct flight only) | Loop bounds | Runs exactly 1 iteration for direct connections |

---

## Pattern Takeaway

**Bellman-Ford with a snapshot array `tempPrices`** limits path traversal to strictly $\le K + 1$ edges without cycle interference.

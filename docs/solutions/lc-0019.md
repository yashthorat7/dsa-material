## What are we solving?

Given the `head` of a linked list, remove the $n$-th node from the end of the list and return its head.

The challenge is: **how to remove the node in a single pass using a fast and slow pointer offset by $n$ nodes with a dummy head?**

**Example 1:**
```
Input:  head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
```

**Example 2:**
```
Input:  head = [1], n = 1
Output: []
```

**Example 3:**
```
Input:  head = [1,2], n = 1
Output: [1]
```

**Constraints:**
- The number of nodes in the list is `sz`.
- $1 \le sz \le 30$
- $0 \le \text{Node.val} \le 100$
- $1 \le n \le sz$

## Approach 1 — Fast and Slow Pointers with Dummy Node ✅

**Key insight:**
1. Create a `dummy` node pointing to `head` (`dummy->next = head`).
2. Advance `fast` pointer $n + 1$ steps ahead of `slow` (starting both at `dummy`).
3. Advance both `fast` and `slow` one step at a time until `fast == nullptr`.
4. Now `slow` is positioned **immediately before** the node to delete!
5. Delete target: `slow->next = slow->next->next`.
6. Return `dummy->next`.

```
dummy -> 1 -> 2 -> 3 -> 4 -> 5 -> nullptr, n = 2
fast = dummy, slow = dummy

Advance fast n+1 = 3 steps: fast points to node 3.
Move both:
- fast=4, slow=1
- fast=5, slow=2
- fast=nullptr, slow=3

slow is at node 3 (node before target 4).
slow->next = slow->next->next (3 -> 5).
Result: dummy->next = 1 -> 2 -> 3 -> 5 ✓
```

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;
        
        for (int i = 0; i <= n; i++) {
            fast = fast->next;
        }
        
        while (fast != nullptr) {
            fast = fast->next;
            slow = slow->next;
        }
        
        ListNode* toDelete = slow->next;
        slow->next = slow->next->next;
        // delete toDelete; // in production
        
        return dummy.next;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(L)$ where $L$ is the length of list | $O(1)$ |

> **This is the one.** Single pass, elegant dummy node handling.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Remove the head node (`n == sz`, `[1, 2], n = 2`) | Dangling head | `dummy` node ensures `slow` remains before head, safely updating `dummy.next` |
| Single node list `[1], n = 1` | Returning non-empty list | `dummy.next` updated to `nullptr` |

---

## Pattern Takeaway

A **dummy pre-head node** eliminates special-case logic when modifying or deleting the head of a linked list.

# 17. Letter Combinations of a Phone Number

> **Medium** $\rightarrow$ **Backtracking**


> **Companies:** Amazon, Meta, Microsoft, Apple, Google, Uber, Bloomberg, Adobe, Flipkart, Wipro

## What are we solving?

Given a string containing digits from `2-9` inclusive, return all possible **letter combinations** that the number could represent. Return the answer in **any order**.

A mapping of digit to letters (just like on the telephone buttons) is given below:
- `2` $\rightarrow$ `"abc"`
- `3` $\rightarrow$ `"def"`
- `4` $\rightarrow$ `"ghi"`
- `5` $\rightarrow$ `"jkl"`
- `6` $\rightarrow$ `"mno"`
- `7` $\rightarrow$ `"pqrs"`
- `8` $\rightarrow$ `"tuv"`
- `9` $\rightarrow$ `"wxyz"`

```
 Digits: "23"
 Digit 2: ['a', 'b', 'c']
 Digit 3: ['d', 'e', 'f']
 
 Combinations:
 'a' -> "ad", "ae", "af"
 'b' -> "bd", "be", "bf"
 'c' -> "cd", "ce", "cf"
 
 Total: 3 * 3 = 9 combinations
```

### Input & Output Contract
- **Input:**
  - `digits`: `string` containing characters in range `'2'` to `'9'` ($0 \le \text{length} \le 4$).
- **Output:**
  - `vector<string>` containing all valid Cartesian product letter strings (or `[]` if `digits` is empty).

### The Core Challenge
Each digit corresponds to 3 or 4 candidate letters. For a string of $n$ digits, there are up to $4^n$ combinations. We must generate all paths from the root to leaves in the combinatorial search tree.

---

**Example 1:**
```
Input:  digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**Example 2:**
```
Input:  digits = ""
Output: []
```

**Example 3:**
```
Input:  digits = "2"
Output: ["a","b","c"]
```

**Constraints:**
- $0 \le \text{digits.length} \le 4$
- `digits[i]` is a digit in the range `['2', '9']`.

## Approach 1 — Recursive Backtracking (DFS State Space Tree) ✅

### Intuition
Traverse digit by digit from index $0$ to $n-1$:
- Map `digits[index]` to its candidate letters.
- For each letter, append it to `current`, recurse on `index + 1`, and backtrack by popping the character.
- Base case: when `index == digits.length()`, add `current` to `result`.

```
Digits: "23"

backtrack(index=0, ""):
 ├─ 'a': backtrack(index=1, "a")
 │   ├─ 'd': backtrack(index=2, "ad") ==> MATCH: "ad"
 │   ├─ 'e': backtrack(index=2, "ae") ==> MATCH: "ae"
 │   └─ 'f': backtrack(index=2, "af") ==> MATCH: "af"
 ├─ 'b': backtrack(index=1, "b") -> "bd", "be", "bf"
 └─ 'c': backtrack(index=1, "c") -> "cd", "ce", "cf"

Total: 9 combinations ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        
        const vector<string> phoneMap = {
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        };
        
        vector<string> result;
        string current = "";
        backtrack(0, digits, phoneMap, current, result);
        return result;
    }

private:
    void backtrack(int index, const string& digits, const vector<string>& phoneMap,
                   string& current, vector<string>& result) {
        if (index == digits.length()) {
            result.push_back(current);
            return;
        }
        
        const string& letters = phoneMap[digits[index] - '0'];
        for (char c : letters) {
            current.push_back(c);
            backtrack(index + 1, digits, phoneMap, current, result);
            current.pop_back(); // Backtrack
        }
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(4^n)$ | In the worst case (e.g. digits '7' and '9'), branches 4 ways per digit: $4^n \times n$. |
| **Space** | $O(n)$ | Call stack depth is at most $n = \text{digits.length} \le 4$. |

> **This is the one.** Standard Cartesian product backtracking template.

## Approach 2 — Iterative BFS (Level-Order Generation)

### Intuition
Start with an array containing an empty prefix `[""]`. For each digit, expand all existing prefixes by appending each possible letter.

### C++ Implementation
```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        
        const vector<string> phoneMap = {
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        };
        
        vector<string> result = {""};
        
        for (char d : digits) {
            const string& letters = phoneMap[d - '0'];
            vector<string> temp;
            for (const string& prefix : result) {
                for (char c : letters) {
                    temp.push_back(prefix + c);
                }
            }
            result = move(temp);
        }
        
        return result;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(4^n)$ | Generates all combinations level by level. |
| **Space** | $O(4^n)$ | Stores intermediate result strings. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Input String** | `digits = ""` | Returning `[""]` instead of `[]` | `if (digits.empty()) return {};` returns `[]`. |
| **4-Letter Digits** | `"79"` ('pqrs', 'wxyz') | $4 \times 4 = 16$ combinations | String map sizes handle 4-letter digits accurately. |
| **Single Digit** | `"2"` | Recursion bounds | Returns `["a", "b", "c"]`. |

## Pattern Takeaways

1. **Cartesian Product Backtracking:**  
   When each choice comes from an independent pool determined by input index, recurse on `index + 1` across mapped character arrays.

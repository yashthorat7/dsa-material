# 17. Letter Combinations of a Phone Number

https://leetcode.com/problems/letter-combinations-of-a-phone-number

> **Medium** $\rightarrow$ **Backtracking**


> **Companies:** Amazon, Microsoft, Meta, Uber, Apple, Google, Swiggy, Infosys

## What are we solving?

Given a string containing digits from `2-9` inclusive, return all possible letter combinations that the number could represent. Return the answer in **any order**.

A mapping of digits to letters (just like on the telephone buttons) is given below:
- `2`: "abc", `3`: "def", `4`: "ghi", `5`: "jkl"
- `6`: "mno", `7`: "pqrs", `8`: "tuv", `9`: "wxyz"

Note that `1` does not map to any letters.

**Example 1:**
```
Input:  digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**Example 2:**
```
Input:  digits = ""
Output: []
```

**Example 3:**
```
Input:  digits = "2"
Output: ["a","b","c"]
```

**Constraints:**
- $0 \le \text{digits.length} \le 4$
- `digits[i]` is a digit in the range `['2', '9']`.

## Approach 1 — Backtracking Depth-First Search ✅

**Key insight:**
1. Map each digit `'2'`–`'9'` to its string of mapped characters.
2. Backtrack with parameter `index`:
   - If `index == digits.length()`: add `currentCombination` to `result`.
   - For each character `c` in mapping for `digits[index]`:
     - Append `c`, recurse `backtrack(index + 1)`, pop `c`.

```
digits = "23"
Mapping: 2 -> "abc", 3 -> "def"

Index 0 ('2'):
  'a' -> Index 1 ('3'): 'd' -> "ad", 'e' -> "ae", 'f' -> "af"
  'b' -> Index 1 ('3'): 'd' -> "bd", 'e' -> "be", 'f' -> "bf"
  'c' -> Index 1 ('3'): 'd' -> "cd", 'e' -> "ce", 'f' -> "cf"

Total: 3 * 3 = 9 combinations ✓
```

```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        
        vector<string> mapping = {
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        };
        
        vector<string> result;
        string current = "";
        backtrack(0, digits, mapping, current, result);
        return result;
    }
private:
    void backtrack(int index, const string& digits, const vector<string>& mapping, string& current, vector<string>& result) {
        if (index == digits.size()) {
            result.push_back(current);
            return;
        }
        
        const string& letters = mapping[digits[index] - '0'];
        for (char c : letters) {
            current.push_back(c);
            backtrack(index + 1, digits, mapping, current, result);
            current.pop_back();
        }
    }
};
```

| Time | Space |
|:-----|:------|
| $O(4^n \cdot n)$ | $O(n)$ recursion stack |

> **This is the one.** Clear recursion on telephone pad mappings.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty digits string `""` | Returning `[""]` instead of `[]` | Early check `if (digits.empty()) return {};` returns empty vector |
| Digits with 4 letters (`7` and `9`) | Fixed 3-letter assumption | Mapping dynamically accommodates "pqrs" and "wxyz" |

## Pattern Takeaway

Multi-choice positional branch recursion directly maps $N$-ary decision trees into clean backtracking loops.

## What are we solving?

You are given two **non-empty** linked lists representing two non-negative integers. The digits are stored in **reverse order**, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.

The question is: **how do we simulate column-by-column digit addition with carry propagation across varying list lengths?**

**Example 1:**
```
Input:  l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807.
```

**Example 2:**
```
Input:  l1 = [0], l2 = [0]
Output: [0]
```

**Example 3:**
```
Input:  l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
```

**Constraints:**
- The number of nodes in each linked list is in the range $[1, 100]$.
- $0 \le \text{Node.val} \le 9$
- It is guaranteed that the list represents a number that does not have leading zeros.

## Approach 1 — Linear Traversal with Carry Accumulation ✅

**Key insight:**
Since digits are stored in **reverse order**, the heads correspond to the least significant digits (ones column).
1. Initialize `dummy` head, `curr = &dummy`, and `carry = 0`.
2. Loop while `l1 != nullptr || l2 != nullptr || carry != 0`:
   - `sum = carry + (l1 ? l1->val : 0) + (l2 ? l2->val : 0)`
   - `carry = sum / 10`
   - `curr->next = new ListNode(sum % 10)`
   - Advance `curr`, `l1`, `l2`.
3. Return `dummy.next`.

```
l1 = [2, 4, 3] (342)
l2 = [5, 6, 4] (465)
carry = 0

1. 2 + 5 + 0 = 7 -> node(7), carry = 0
2. 4 + 6 + 0 = 10 -> node(0), carry = 1
3. 3 + 4 + 1 = 8 -> node(8), carry = 0
Result: 7 -> 0 -> 8 (807) ✓
```

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* curr = &dummy;
        int carry = 0;
        
        while (l1 != nullptr || l2 != nullptr || carry != 0) {
            int sum = carry;
            if (l1 != nullptr) {
                sum += l1->val;
                l1 = l1->next;
            }
            if (l2 != nullptr) {
                sum += l2->val;
                l2 = l2->next;
            }
            
            carry = sum / 10;
            curr->next = new ListNode(sum % 10);
            curr = curr->next;
        }
        
        return dummy.next;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(\max(m, n))$ | $O(\max(m, n))$ for the result list |

> **This is the one.** Clean, robust simulation with single loop.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Lists of unequal length `[9, 9] + [1]` | Early loop exit | Ternary operator `l1 ? l1->val : 0` substitutes 0 for exhausted list |
| Final carry remaining at end `[5] + [5]` | Dropping the last carry node | `carry != 0` in loop condition appends the final `1` node -> `[0, 1]` |

---

## Pattern Takeaway

When simulating column addition, keep the **carry condition inside the main while loop (`l1 || l2 || carry`)** to automatically generate the final overflow node.

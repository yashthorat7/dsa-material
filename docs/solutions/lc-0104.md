## What are we solving?

Given the `root` of a binary tree, return its **maximum depth**.

A binary tree's **maximum depth** is defined as the number of nodes along the longest path from the root node down to the farthest leaf node.

```
            (3)           Level 1: Depth = 1
           /   \
         (9)   (20)       Level 2: Depth = 2
               /  \
             (15)  (7)    Level 3: Depth = 3 (Maximum Depth = 3)
```

### Input & Output Contract
- **Input:**
  - `root`: `TreeNode*` pointing to the root of a binary tree ($0 \le \text{nodes} \le 10^4$, $-100 \le \text{Node.val} \le 100$).
- **Output:**
  - `int` representing the maximum depth of the tree (0 if the tree is empty).

### The Core Challenge
We can determine the tree's height either top-down by measuring levels during breadth-first exploration, or bottom-up by recursively aggregating subtree heights:
$$\text{Depth}(\text{root}) = 1 + \max(\text{Depth}(\text{root}\rightarrow\text{left}), \text{Depth}(\text{root}\rightarrow\text{right}))$$

---

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: 3
```

**Example 2:**
```
Input:  root = [1,null,2]
Output: 2
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Recursive DFS (Divide & Conquer) ✅

### Intuition
The maximum depth of any node is $1$ (for itself) plus the maximum depth between its left and right children.
Base case: If `root == nullptr`, its depth is $0$.

```
maxDepth(3)
 ├─ maxDepth(9) = 1 + max(0, 0) = 1
 └─ maxDepth(20)
     ├─ maxDepth(15) = 1
     └─ maxDepth(7) = 1
     = 1 + max(1, 1) = 2
 = 1 + max(1, 2) = 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        return 1 + max(maxDepth(root->left), maxDepth(root->right));
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Visits every node in the binary tree exactly once. |
| **Space** | $O(h)$ | Recursion stack height equals the tree height $h$ ($O(\log n)$ for balanced, $O(n)$ for degenerate skewed list). |

> **This is the one.** Canonical, 3-line bottom-up divide and conquer.

## Approach 2 — Iterative BFS (Level-Order Traversal)

### Intuition
Use a `queue<TreeNode*>` to traverse the tree level by level. In each round of the `while` loop, process all nodes belonging to the current level and increment our `depth` counter by 1.

```
Queue: [3]                    -> depth = 1
Queue: [9, 20]                -> depth = 2
Queue: [15, 7]                -> depth = 3
Queue: [] (empty)             -> returns depth = 3 ✓
```

### C++ Implementation
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        
        while (!q.empty()) {
            int levelSize = q.size();
            depth++;
            
            // Drain current level and enqueue children for next level
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = q.front();
                q.pop();
                
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
        }
        
        return depth;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Enqueues and dequeues every node once. |
| **Space** | $O(w)$ | Maximum queue size equals the maximum tree width $w \le n/2$. |

> **Verdict:** Very clear representation of tree levels without recursion stack usage.

## Approach 3 — Iterative DFS (Stack with Explicit Depths)

### Intuition
Emulate pre-order DFS using an explicit stack storing pairs `(node, current_depth)`. Maintain a running `max_depth` across all visited nodes.

### C++ Implementation
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        
        stack<pair<TreeNode*, int>> st;
        st.push({root, 1});
        int maxDepthVal = 0;
        
        while (!st.empty()) {
            auto [node, currentDepth] = st.top();
            st.pop();
            
            maxDepthVal = max(maxDepthVal, currentDepth);
            
            if (node->right) st.push({node->right, currentDepth + 1});
            if (node->left)  st.push({node->left, currentDepth + 1});
        }
        
        return maxDepthVal;
    }
};
```

### Complexity Analysis
| Metric | Complexity | Explanation |
|:-------|:-----------|:------------|
| **Time** | $O(n)$ | Pushes and pops each node once. |
| **Space** | $O(h)$ | Stack stores at most $h$ active tree nodes along the branch. |

## Edge Cases to Watch

| Case | Input Example | Trap | How it's handled |
|:-----|:--------------|:-----|:-----------------|
| **Empty Tree** | `root = nullptr` | Null pointer dereference | Guard `if (!root) return 0;` returns 0 immediately. |
| **Single Node** | `root = [1]` | Height off-by-one error | Evaluates to `1 + max(0, 0) = 1`. |
| **Completely Skewed Tree** | `1 -> 2 -> 3 -> 4` | Call stack overflow | Max recursion depth equals $n$, correctly returns 4. |

## What are we solving?

Given the `root` of a binary tree, return its **maximum depth**.

A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

**Example 1:**
```
Input:  root = [3,9,20,null,null,15,7]
Output: 3
```

**Example 2:**
```
Input:  root = [1,null,2]
Output: 2
```

**Constraints:**
- The number of nodes in the tree is in the range $[0, 10^4]$.
- $-100 \le \text{Node.val} \le 100$

## Approach 1 — Post-Order Divide and Conquer ✅

**Key insight:**
The height of any tree is $1 + \max(\text{height}(\text{left}), \text{height}(\text{right}))$.
Base case: `if (!root) return 0;`.

```
3 (1 + max(1, 2) = 3)
     / \
    9   20 (1 + max(1, 1) = 2)
       /  \
      15   7 (1 + 0 = 1)

Result: 3 ✓
```

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return 1 + max(maxDepth(root->left), maxDepth(root->right));
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(h)$ |

> **This is the one.** Canonical recursive depth definition.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty tree `root = nullptr` | Base case | Returns 0 |
| Skewed tree (linked list structure) | Recursion depth equals $n$ | Correctly computes $n$ |

## Pattern Takeaway

**Divide and Conquer on Trees** computes node properties from left and right subtree return values.
